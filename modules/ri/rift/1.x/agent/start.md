# RIFT (rift) — agent index

Front-end **toolkit** — services, field formatters, Twig helpers. Version **1.4.6**. Submodules
`rift_starter_kit`, `rift_ui`. Developer/theming infrastructure; no fixed security surface (helpers
render in the trusted theme layer).

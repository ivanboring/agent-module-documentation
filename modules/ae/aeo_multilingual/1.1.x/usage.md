AEO Multilingual optimizes multilingual sites for SEO/AEO.

---

AEO Multilingual **optimizes multilingual sites for SEO / Answer Engine Optimization (AEO)** — improving how
translated content is presented to search engines and AI answer engines (hreflang, language signals, structured
hints) across languages. It depends on core Language, Content Translation and Node, provides its own
permissions, in the SEO / AEO package.

Use it to improve multilingual discoverability. It is an SEO/multilingual feature; it works with translated
content (which follows core translation access) and it has no access-control role beyond its permission.
Configure the AEO settings.

As Event Listener lets modules register event listeners with the #[AsEventListener] attribute.

---

As Event Listener (ael) enables event listener registration by using the Symfony `#[AsEventListener]` PHP attribute — so developers can register event subscribers/listeners declaratively via an attribute on a class/method instead of a tagged service in services.yml, modernizing event handling in Drupal modules.

It's a developer/framework enhancement with no content or access role of its own. Requires Drupal 11.3+.

Calculator provides a block to display a calculator on your site.

---

Calculator provides a **block that displays an interactive calculator** — a simple on-page calculator widget
placed via the block system. It depends on core Block, in the Calculator package.

Use it to add a calculator widget to a page. It is a content-display feature; it is self-contained (client-side)
and has no content or access role. Place and configure the calculator block.

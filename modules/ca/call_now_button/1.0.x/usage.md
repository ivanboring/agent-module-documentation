Call Now Button places a button at the bottom of the screen visible only on mobile.

---

Call Now Button places a **click-to-call button fixed at the bottom of the screen**, shown **only on
mobile** devices — so mobile visitors can tap to phone the business directly. It provides its own permissions,
in the Other package.

Use it to add a mobile call-to-action. It is a user-engagement/display feature; the phone number is
admin-configured and rendered as a public `tel:` link (don't use a number that shouldn't be public), and it
has no access-control role beyond its permission. Configure the phone number and button.

Calimals provides the Calimals animal-themed icon set for UI Icons.

---

Calimals is the animal-friendly Calimals icon pack for UI Icons — providing a set of animal-themed icons as a UI Icons pack, so themes/modules using UI Icons can pick from the Calimals icon set for a playful/friendly visual style.

It's an icon-pack asset for UI Icons with no content or access role of its own. Depends on `ui_icons`; supports Drupal 10.3+, 11, and 12.

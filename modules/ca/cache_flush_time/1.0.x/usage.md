Cache Flush Time prints when the Drupal cache was last rebuilt.

---

Cache Flush Time **shows the last cache-rebuild time** — printing when Drupal's cache was last cleared/rebuilt,
for developers/ops to verify cache state. It depends on core System.

Use it to check cache freshness. It is a developer/ops convenience; it displays a timestamp and has no content or
access role. Note: expose the timestamp only where appropriate (operational detail). View the cache flush time.

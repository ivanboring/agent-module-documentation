# Camunda BPMN for ECA — agent index

A **BPMN modeller for ECA** — model ECA workflows as BPMN in the standalone Camunda desktop app, import/export
to/from Drupal. Depends on `eca`. Version **2.0.0**. Core `^10.3||^11`.

Automation/developer — imported models are **executable automation** running with site privileges (restrict
import/authoring to trusted users). No access role.

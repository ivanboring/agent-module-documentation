Camunda BPMN for ECA provides a BPMN modeller for ECA, a standalone desktop application with import and export to/from the Drupal site.

---

Camunda BPMN for ECA integrates the Camunda BPMN modeller with the ECA (Event-Condition-Action)
module — letting you model ECA workflows as BPMN diagrams in the standalone Camunda desktop application and
import/export them to/from the Drupal site, for a visual way to author ECA automations. It depends on the ECA
module, in the ECA package.

Use it to model ECA workflows visually with Camunda BPMN. It is an automation/developer feature for authoring
ECA models; the imported models define automations that run with the site's privileges (as ECA does), so
only trusted users should import/author models (a model is executable automation). It has no access-control
role. Configure the BPMN import/export.

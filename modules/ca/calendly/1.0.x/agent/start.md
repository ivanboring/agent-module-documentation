# Calendly — agent index

Embeds **Calendly scheduling pages** on the site (inline/popup booking widget; configure the Calendly URL).
Version **1.0.3**. Core `^9||^10||^11`.

Third-party integration — scheduling runs on **Calendly**; loads Calendly's **third-party JS** (trust the
vendor; runs in your origin) and processes visitor scheduling data (privacy/consent). No access role.

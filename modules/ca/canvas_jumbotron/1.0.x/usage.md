Canvas Jumbotron provides a Jumbotron Code Component for Canvas.

---

Canvas Jumbotron provides a **Jumbotron code component for Canvas** — a large hero/banner "jumbotron"
building block usable in the Canvas (Experience Builder) page-building UI. It is in the Custom package.

Use it to add hero banners in Canvas layouts. It is a content-display/site-building component; its content is
admin/editor-authored and it has no content or access role. Add the jumbotron component to a Canvas page.

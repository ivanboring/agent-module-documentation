Cache Tools contains caching related tools, offering utilities for working with Drupal's cache.

---

Cache Tools provides a set of caching-related tools and utilities — helpers for working with Drupal's
cache system (invalidation, tags, inspection or programmatic cache operations), aimed at developers building
cache-aware features. It is in the Cache package.

Use it as a developer utility for cache operations. It is a performance/developer feature manipulating the
cache; cache operations affect performance/freshness, not access, and it has no access-control role. Use the
provided tools where cache handling is needed.

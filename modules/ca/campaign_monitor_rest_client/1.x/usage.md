Campaign Monitor REST Client provides basic settings and a service for the Campaign Monitor email-marketing REST API.

---

Integrating Campaign Monitor (email marketing) needs an API client. Campaign Monitor REST Client provides the settings and service for its REST API, for other code to build subscriber/list integrations on. It needs a Campaign Monitor API key (a credential to keep out of plain config). Any integration built on it will forward subscriber PII to Campaign Monitor, so the usual marketing-data considerations (consent, disclosure) apply to consumers of this client. It is infrastructure — the client, not a finished feature.

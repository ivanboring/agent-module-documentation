Cache Debugger surfaces cache behavior/metadata for debugging.

---

Cache Debugger is a cache debugging tool for Drupal — surfacing information about caching behavior (cache tags, contexts, hits/misses) to help developers understand and debug why pages/elements are or aren't cached, improving cacheability.

It's a development/debugging tool gated by `administer cache debugger configuration` — for dev use. Supports Drupal 10 and 11.

# Calendar Links Tokens — agent index

Generates **"add to calendar" links** (Google/iCal/Outlook, etc.) using **tokens** (event date/title/details
→ calendar links). Version **1.0.0**. Core `^10.2||^11||^12`.

Content-display/calendar — links derived from event data; no access role. Use the tokens where calendar
links should appear.

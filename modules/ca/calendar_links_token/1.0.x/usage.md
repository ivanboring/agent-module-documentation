Calendar Links Tokens generates add-to-calendar links for Google, iCal and other calendars using tokens.

---

Calendar Links Tokens generates "add to calendar" links — for Google Calendar, iCal/Outlook and other
calendar services — built from tokens, so an event's date/title/details can be turned into calendar links
via token replacement in content/templates. This lets sites offer one-click "add this event to your
calendar" links.

Use it on event content to provide add-to-calendar links. It is a content-display/calendar feature
generating links from token values; the links are derived from event data and it has no access-control
role. Use the tokens where calendar links should appear.

Canvas Bootstrap provides Bootstrap 5 components for the Canvas editor.

---

Canvas is a visual page editor; Canvas Bootstrap supplies Bootstrap 5 components for building pages in it. It is a theming/editor-integration module with no security surface. It assumes Bootstrap 5, so the emitted markup is Bootstrap's — on a non-Bootstrap theme the components need the framework to render as intended. For sites using Canvas with Bootstrap it provides ready components.

Canvas Entity Reference adds entity-reference support for Canvas editor components, letting components reference Drupal entities.

---

The Canvas visual editor builds pages from components; referencing Drupal entities (a node, a media item) from a component connects visual building to structured content. Canvas Entity Reference adds that support. It is an editor-integration feature; the referenced entities keep their own access (a reference does not bypass access — a referenced entity the user cannot view will not render). Confirm references resolve and respect access in the Canvas context.

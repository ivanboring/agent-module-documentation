Canvas Focal Point Widget provides a visual focal point picker for Canvas.

---

Canvas Focal Point Widget provides a **visual focal-point picker for images in Canvas** — letting editors
click to set the focal point of an image (so responsive crops keep the important part) within the Canvas
(Experience Builder) UI. It depends on the Canvas module.

Use it to set image focal points in Canvas. It is a media/content-editing feature; the focal point is
admin/editor metadata and it has no content or access role. Use the focal-point picker on images.

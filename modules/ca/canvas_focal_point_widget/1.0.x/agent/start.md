# Canvas Focal Point Widget — agent index

A **visual focal-point picker widget for images in the Canvas (Experience Builder) page builder**. Depends on
`canvas`. Version **1.0.0-alpha1**. Core `^11`.

Media/content-editing — focal point is admin/editor metadata; no content/access role.

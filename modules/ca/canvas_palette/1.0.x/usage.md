Canvas Palette adds a set of fancy components for the Canvas page builder.

---

Canvas Palette provides fancy components for the Canvas page builder — a palette of pre-built, styled components (with image, views and webform integration) that editors can use when building pages in Canvas, enriching the available building blocks.

It's a page-builder/component library with no content or access role of its own (component access follows the referenced content). Depends on `canvas`, core `image`, `views`, and `webform`; supports Drupal 10.3+ and 11.

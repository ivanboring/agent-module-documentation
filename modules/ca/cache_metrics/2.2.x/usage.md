Cache Metrics logs and measures cache performance over time, tracking hit/miss rates.

---

Cache Metrics logs and measures cache performance over time — recording cache hit/miss metrics so
developers can see how effective the site's caching is and spot regressions. It is in the Performance
package.

Use it to monitor cache effectiveness. It is a performance/developer feature that records cache metrics;
it collects performance data (adds some measurement overhead) and has no content or access role. Enable it
during performance analysis and review the recorded metrics.

CacheViz visualizes cache metadata to help debugging.

---

CacheViz **visualizes render-cache metadata** — showing the cache tags, contexts and max-age attached to
rendered elements, so developers can debug why something is/isn't cached or invalidated. It provides its own
permissions, in the Development package.

Use it in development to debug caching. It is a developer/debugging tool. Operational note: it exposes
**internal cache metadata** (a developer view), so gate its permission to developers and prefer it on dev/
staging (don't leave debug visualization on production). It has no content or access role beyond its permission.
Enable it to inspect cache metadata.

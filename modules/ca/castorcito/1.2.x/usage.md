Castorcito allows you to assemble components, providing a component-based content assembly system.

---

Castorcito provides a component-based content-assembly system — letting site builders define and
assemble reusable components (`castorcito_component` config entities) to build content, with submodules for
base/advanced component packs, date components, sync and webform integration. It is configured at the
`castorcito_component` collection and provides its own permissions.

Use it to build content from reusable components (a page-building approach). It is a content-editing/site-
building feature; components are authored content rendered through Drupal's layers, and it has no
access-control role. Configure the components and assemble content.

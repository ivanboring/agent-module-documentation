Canvas Pattern Blocks exposes Drupal Canvas patterns as placeable blocks.

---

Canvas Pattern Blocks **exposes Drupal Canvas patterns as blocks** — so patterns built in Canvas (Experience
Builder) can be placed as reusable blocks elsewhere (Layout Builder, block layout). It depends on the Canvas
module, provides its own permissions, in the Canvas package.

Use it to reuse Canvas patterns as blocks. It is a site-building/theming feature; pattern content is
admin/editor-authored and it has no access-control role beyond its permission. Place the pattern blocks.

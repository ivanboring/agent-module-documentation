Categorized Token Filter improves the token-browser UI with categorized filtering.

---

Categorized Token Filter enhances performance by providing a filter for browsing tokens — adding a categorized, filterable UI to the token browser so editors/developers can find the token they need quickly among the many available tokens, improving the token-selection experience.

It's a developer/UX enhancement over the Token module with no content or access role of its own. Depends on core `token`; supports Drupal 10 and 11.

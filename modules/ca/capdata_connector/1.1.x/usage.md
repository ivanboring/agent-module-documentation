CapData connector produces an RDF export of site data for open-data consumption.

---

CapData connector exports Drupal site data into an RDF-format file — providing an endpoint that generates an RDF representation of the site's data (for open-data/CapData or linked-data consumption), commonly used by French agricultural/open-data platforms.

The RDF export endpoint (`/rof/capdata-rdf-export`) is intentionally anonymous (for public open-data consumption) — ensure only intended, non-sensitive data is exported. Supports Drupal 10.2+ and 11.

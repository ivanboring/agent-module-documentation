Canvas Page Metatag exposes the full Metatag SEO tag set to the Canvas (Experience Builder) page builder.

---

Canvas Page Metatag **exposes the full Metatag SEO tag set to Canvas** — so editors building pages in Canvas
(Experience Builder) can set meta tags (title, description, Open Graph, Facebook, Twitter Cards) per page. It
depends on the Canvas and Metatag modules (plus the Open Graph/Facebook/Twitter Cards submodules), in the SEO
package.

Use it to manage SEO meta tags in Canvas. It is an SEO feature; meta values reflect on-page content and it has no
content or access role. Configure meta tags on Canvas pages.

# Field Display Kit (fdk) — agent index

Helps **fine-tune the display of fields** (extra control over field output — wrappers/markup/conditional
display, beyond default display settings). Version **2.3.0**. Core `^9.3||^10||^11`.

Content-display — affects field output, not content/access (fields respect their access). No access role.

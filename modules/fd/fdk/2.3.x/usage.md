Field Display Kit (fdk) helps to fine tune the displaying of fields, giving extra control over field output.

---

Field Display Kit (fdk) helps fine-tune how fields are displayed — providing extra control/options over
field output (wrappers, markup, conditional display) beyond the default field display settings, so themers/
site builders can shape field rendering more precisely.

Use it for finer control over field display. It is a content-display feature affecting field output; the
field content and its access are unchanged (fields still respect their access), and it has no access-control
role. Configure the display options on the fields.

Arguments provides a sub-entity list with arguments.

---

Arguments **provides a sub-entity list with arguments** — a building block in the RulesFinder toolset for
defining/managing argumented sub-entities (structured argument data), used by other RulesFinder modules. It
provides its own permissions, in the RulesFinder package.

Use it as part of the RulesFinder stack. It is a developer/site-building building block; the argument data is
admin/editor content and it has no access-control role beyond its permission. Configure the arguments within the
RulesFinder toolset.

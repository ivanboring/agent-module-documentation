Advanced Render Auditor traces and profiles Drupal's render tree for debugging.

---

Advanced Render Auditor (ara) is a site-wide render-tree profiler for local development — tracing the render tree of pages to show what is rendered, cache metadata, and performance characteristics, helping developers debug rendering and caching issues.

It's a development/debugging tool gated by `use ara profiler` — for local/dev use, not production. Depends on core `system`; supports Drupal 10 and 11.

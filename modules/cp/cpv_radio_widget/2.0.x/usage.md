Commerce Product Variation Radio Widget provides a radio widget for the product-variation field on purchasable entities.

---

Commerce Product Variation Radio Widget provides a radio-button widget for the product-variation
selector in Drupal Commerce — so customers pick a variation (size, color, etc.) via radio buttons instead
of the default select dropdown, which can be clearer for a small number of variations. It depends on
Commerce and Commerce Product.

Use it on stores where a radio selector improves the add-to-cart UX over a dropdown. It is an
e-commerce/form-widget feature affecting variation selection; it has no access or pricing role. Configure
it as the widget on the product-variation field.

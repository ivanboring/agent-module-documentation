Display Layout allows custom layouts when configuring entity display.

---

Display Layout lets you **use custom Layout API layouts when configuring an entity's display** — arranging
fields into layout regions in the Manage Display view-mode config, without Layout Builder. It depends on core
Layout Discovery and Field UI, in the Display package.

Use it to lay out fields in view modes. It is a site-building/display feature; it affects field arrangement and
has no content or access role. Choose a layout in Manage Display.

Dismiss adds a 'Dismiss' close button to Drupal's status messages, warnings and errors so users can hide them.

---

Dismiss adds a "Dismiss" close button to Drupal's messages — the status, warning and error
notices rendered in the messages area. Users can click to hide a message they have read, giving a
tidier interface than messages that persist until the next page load. It is a small UI enhancement in
the "User interface" package, applied to the standard Drupal messages output.

Use it to improve the admin/editor experience where multiple messages stack up. It is purely a
front-end/UI convenience — it does not change what messages are generated or any access behaviour;
it just lets a rendered message be closed. No configuration beyond enabling is typically needed.

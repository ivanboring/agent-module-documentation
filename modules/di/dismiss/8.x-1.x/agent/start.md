# Dismiss — agent index

Adds a **"Dismiss" close button** to Drupal status/warning/error **messages** so users can hide them.
Version **8.x-1.0-alpha2**. Core `^8.8||^9||^10||^11`.

Purely a front-end/UI convenience — no change to generated messages or access. No config beyond
enabling.

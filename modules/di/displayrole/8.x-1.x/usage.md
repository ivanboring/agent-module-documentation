Display Role lets administrators configure which roles are displayed on user profiles or listings.

---

Showing a user's roles — 'Editor', 'Moderator' — on their profile can be useful for community sites, but exposing all roles indiscriminately can leak organisational structure or administrative status. Display Role lets administrators choose which roles are displayed. The security-adjacent consideration is exactly that disclosure control: displaying that a user holds an 'administrator' role tells attackers who to target, so choose displayed roles deliberately and avoid surfacing privileged roles publicly. It is admin-configured which roles show.

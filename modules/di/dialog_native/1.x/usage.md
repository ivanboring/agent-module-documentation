Native HTML <dialog> element support, replacing dialog.js.

---

Dialog Native provides native dialog HTML element support replacing dialog.js — so Drupal's modal/dialog system uses the browser-native `<dialog>` element instead of the jQuery UI dialog.js implementation, for lighter, more standards-based modals. It's a frontend/JS enhancement. Supports Drupal 10 and 11.

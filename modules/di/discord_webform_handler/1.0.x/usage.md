A Webform handler that posts submissions to a Discord webhook.

---

Discord Webform Handler sends webform submissions to Discord via a webhook — a Webform handler where the site admin configures a Discord `webhook_url`, and each matching submission is posted to that Discord channel, for notifications.

The Discord webhook URL is an admin-configured setting per webform (a `#type => url` field), so it's not attacker-controlled; keep the webhook URL out of version control. Depends on `webform`; supports Drupal 10 and 11.

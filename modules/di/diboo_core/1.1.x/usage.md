Base functionality for a Diboo installation.

---

Diboo core provides base functionality for a Diboo installation — the shared foundation (views, entity helpers, labels, tokens) that the Diboo distribution/product modules build on. It's a base/framework module for the Diboo ecosystem. Depends on core `views`, `entity`, `entity_link_formatter`, `token`, and `change_labels`; supports Drupal 11.2+.

Dify provides Dify integration for Drupal.

---

Dify **integrates the Dify LLM-application platform** with Drupal — connecting to a Dify instance so Drupal
can use Dify-hosted AI apps/agents/workflows (chat, completion, knowledge bases). It is in the Dify package.

Use it to power AI features via Dify. It is an AI/integration feature. Security/data handling: it **sends
prompts/content to your Dify instance** (external egress to whatever the Dify app does — confirm the endpoint is
trusted and over HTTPS) and authenticates with a **Dify API key** — store it as a **secret** (env/Key). It has
no access-control role. Configure the Dify endpoint and credentials.

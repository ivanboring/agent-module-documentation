Display Builder is an advanced display builder for Drupal, letting site builders compose entity displays, page layouts and views output visually, with UI, entity-view, page-layout and views submodules.

---

Building how content displays — entity view modes, page layouts, Views output — with a visual builder rather than the standard forms. Display Builder provides an advanced builder for that, with `display_builder_ui`, `display_builder_entity_view`, `display_builder_page_layout` and `display_builder_views` submodules. It is a site-building/theming tool. It composes displays of access-controlled content, so the displayed data keeps its own field/entity access (building a display does not grant access to the data in it). It is a builder capability, so restrict who can use it to trusted site builders, and confirm that displays it produces respect field access. No unusual runtime security surface beyond that.

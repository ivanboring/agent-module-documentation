Adds a Disable button to field configuration on entity display pages.

---

Disable Field Button adds a Disable button to field configuration forms on entity display pages — giving site builders a quick way to disable a field (hide/turn it off) directly from the Manage fields/display UI rather than editing configuration manually. Depends on core `field_ui`; supports Drupal 11.

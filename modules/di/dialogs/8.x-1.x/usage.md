Dialogs opens links in dialogs by adding magic query strings.

---

Dialogs lets you **open links in a dialog** (modal or off-canvas) by adding **magic query strings** to
the link — so a normal link can be made to open its target in a Drupal dialog without custom JS, useful for
quick modals. It is a UI/content-display feature.

Use it to open links as dialogs. It is a display/UI feature; the linked route still enforces its own access
(the dialog just changes presentation), so it doesn't bypass access, and it has no access-control role. Add
the magic query string to the links you want opened in a dialog.

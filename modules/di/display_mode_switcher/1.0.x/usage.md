Display Mode Switcher provides rule-based entity display-mode switching via pluggable condition plugins.

---

Display Mode Switcher **provides rule-based display-mode switching** — choosing which view mode an entity
renders with based on pluggable condition plugins (e.g. path, role, context), with correct cache-metadata
propagation. It provides its own permissions (core 11.3+).

Use it to vary how content displays by condition. It is a content-display/site-building feature; it switches view
modes and propagates cache metadata correctly, and has no access-control role beyond its permission. Configure the
switching rules.

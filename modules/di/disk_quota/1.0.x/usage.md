Defines per-user disk quota limits on file uploads.

---

Disk Quota defines users' disk quota limits on file uploads — enforcing a maximum total upload size per user (or role), so users cannot exceed their allotted storage, preventing disk exhaustion from uploads. Depends on core `user` and `file`; supports Drupal 10, 11, and 12.

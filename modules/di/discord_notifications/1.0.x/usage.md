Discord Notifications posts Drupal event/content-change notifications to Discord via webhooks.

---

Discord Notifications sends messages to a Discord channel for various Drupal events and content changes (e.g. new/updated nodes, user activity), using Discord webhooks — useful for keeping a team channel informed of site activity in real time.

The Discord webhook URL is a secret and should be stored securely (env-backed), never committed. Depends on core `node` and `user`; supports Drupal 9, 10, and 11.

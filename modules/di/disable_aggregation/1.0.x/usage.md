Disable Aggregation turns off asset aggregation for logged-in users (useful for debugging).

---

Disable Aggregation disables JavaScript and CSS aggregation specifically for authenticated users, so logged-in developers/editors see individual asset files (easier debugging) while anonymous visitors still benefit from aggregated, cached assets for performance.

It's a developer/operations convenience with no content or access role. Supports Drupal 8 through 12.

# Display Name — agent index

Provides **user display-name field types** (show a friendly display name vs the raw username). Depends on core
`field`, `user`, `token`. Provides permissions. Version **1.0.0-alpha2**. Core `^8.8||^9||^10||^11`.

User/fields — changes the **displayed** name, not the login/account identity; display names are user content
(normal escaping). No access role beyond permission.

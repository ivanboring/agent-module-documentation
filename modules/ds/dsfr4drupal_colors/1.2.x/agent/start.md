# DSFR for Drupal - Colors — agent index

Provides a **DSFR colors picker widget** (pick from the French State Design System palette — DSFR-compliant
gov sites). Config at `dsfr4drupal_colors.settings`. Version **1.2.3**. Core `^10.3||^11||^12`.

Content-editing/widget — color value is authored data constrained to the palette; no access role.

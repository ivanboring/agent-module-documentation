DSFR for Drupal - Colors provides a DSFR colors widget.

---

DSFR for Drupal - Colors provides a DSFR colors widget — letting editors pick colors from the DSFR
(French State Design System) palette on DSFR-compliant (French government) sites, so color choices stay
within the official design-system palette. It is configured at `dsfr4drupal_colors.settings`, in the DSFR for
Drupal package.

Use it on DSFR-based sites to constrain color choices to the DSFR palette. It is a content-editing/widget
feature; the color value is authored data (constrained to the palette) and it has no access-control role.
Configure the colors widget.

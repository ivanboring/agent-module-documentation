Twig components implementing the DSFR (French State Design System).

---

DSFR Twig Components provides Twig components for DSFR — reusable Single-Directory/Twig components that implement the DSFR (Système de Design de l'État, the French government design system) UI elements, used by DSFR Core and the other DSFR modules to render compliant markup. Depends on core `media`, `media_library`, and `text`; supports Drupal 9, 10, and 11.

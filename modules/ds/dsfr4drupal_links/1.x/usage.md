DSFR for Drupal Links applies French State Design System (DSFR) recommendations to external links, styling and marking them per DSFR.

---

French government sites follow the DSFR, which has conventions for external links (an icon, an accessible indication that a link leaves the site). DSFR for Drupal Links applies those to external links. It is a theming/accessibility feature with no security surface — it styles and marks links. (Marking external links can pair with rel/target handling; confirm any target=_blank added also uses noopener, per general link-safety, though DSFR styling is the focus here.) For a DSFR government site it makes external links compliant.

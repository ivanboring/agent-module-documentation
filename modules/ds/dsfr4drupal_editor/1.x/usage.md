DSFR for Drupal Editor applies the French State Design System (DSFR) recommendations to HTML generated by the editor.

---

French government sites must follow the DSFR (Système de Design de l'État). DSFR for Drupal Editor applies DSFR conventions to editor-generated HTML, so rich-text content matches the design system. It is a theming/editor-integration module with no security surface. Adopt on a French government (DSFR) site.

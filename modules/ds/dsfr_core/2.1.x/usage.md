Base services for the DSFR (French State Design System) module suite.

---

DSFR Core provides services for other DSFR modules — the shared base for implementing the DSFR (Système de Design de l'État, the French government design system) in Drupal, on which the DSFR menu/component modules build. Depends on `dsfr_twig_components`, `form_options_attributes`, and `style_selector`; supports Drupal 10 and 11.

Crowd Bruteforce Protection adds crowd-based brute-force login protection via the Ban module.

---

Crowd Bruteforce Protection (cbp) is a hybrid security suite protecting against brute-force login attacks — combining per-account and crowd/IP-based detection to identify and block brute-force attempts (banning offending IPs via the core Ban module), hardening the login flow beyond core's flood control.

It builds on core `ban`; tune thresholds to avoid false positives (shared IPs). It's a defensive security module. Supports Drupal 9, 10, and 11.

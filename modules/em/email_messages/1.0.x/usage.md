Create and manage messages to be sent as notifications.

---

Email Messages provides a way to create and manage messages to be sent out as notifications — a store of reusable message templates/content that other flows can send as emails, centralising notification copy. Depends on core `text`; supports Drupal 9, 10, and 11.

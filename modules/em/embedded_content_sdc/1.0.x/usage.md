Embedded Content: Single Directory Components lets editors embed Single Directory Components (SDC) inside text fields.

---

Embedded Content: SDC **lets editors embed Single Directory Components in text fields** — exposing SDC
components as embeddable content so they can be inserted into rich-text/body fields via the Embedded Content
framework. It depends on the Embedded Content and CL Editorial modules.

Use it to embed components in content. It is a content-editing/display feature; embedding follows the Embedded
Content framework's editor gating and the components render their defined markup, and it has no access-control
role. Note: as with any embed, the components/props available should be curated so editors only insert trusted
components. Configure the embeddable components.

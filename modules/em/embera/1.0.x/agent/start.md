# Embera — agent index

Provides a **service wrapping the Embera PHP oEmbed library** (turn URLs — YouTube/Vimeo/etc. — into embed
markup for other modules). Version **1.0.7**. Core `^9||^10||^11`.

Developer/library integration — embeds come from **third-party providers**; no content/access role.

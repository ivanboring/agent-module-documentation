# Emoji Reactions — agent index

**Emoji reaction system** with user analytics, a REST API, sortable layouts, a reaction log and Views integration.
Depends on core `user`, `field`, `rest`. Provides permissions. Version **1.0.3**. Core `^10||^11`.

User-engagement — reactions are **user-submitted** + tie users to content (analytics = personal data); exposes a
**REST API** (ensure endpoints enforce access, gate log/analytics, anti-abuse against reaction spam).

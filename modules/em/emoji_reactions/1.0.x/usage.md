Emoji Reactions provides an emoji reaction system with analytics, a REST API, Views integration and a reaction log.

---

Emoji Reactions **provides an emoji reaction system** — letting users react to content with emoji, with user
analytics, a REST API, sortable layouts, a reaction log and Views integration (reactions are fieldable log
entries). It depends on core User, Field, Serialization and REST, and provides its own permissions.

Use it to add emoji reactions. It is a user-engagement feature. Security/data handling: reactions are
**user-submitted** and tie **users to content** (the analytics/log record who reacted — personal data), and it
exposes a **REST API** — so gate the reaction/log permissions appropriately, ensure the REST endpoints enforce
access, apply anti-abuse to prevent reaction spam, and expose analytics/logs only to appropriate roles. Configure
the reactions and permissions.

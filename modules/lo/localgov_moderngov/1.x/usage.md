LocalGov Modern.Gov presents a single page aggregating Modern.Gov tagged content, for LocalGov Drupal council sites integrating with Modern.Gov democratic-services data.

---

Modern.Gov is a committee/democratic-services system used by UK councils. LocalGov Modern.Gov presents a page of Modern.Gov-tagged content for LocalGov Drupal sites. It is a distribution-specific integration. It fetches/presents external Modern.Gov data, so the considerations are trusting and validating that external data before display, and any credentials for the Modern.Gov integration kept secure. Adopt on a LocalGov council site using Modern.Gov.

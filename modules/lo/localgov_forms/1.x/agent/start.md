# LocalGov Forms (localgov_forms) — agent index

Form config/styling/components for **LocalGov Drupal** government sites. Version **1.1.1**.
Submodules: `localgov_forms_date`, `localgov_forms_decision_tree`, `localgov_forms_feedback_form`,
`localgov_forms_lts`, an example integration.

Distribution-oriented. Feedback/service forms collect submissions (potential PII) — apply spam
protection, retention, and submission-access control.

Cincopa embeds Cincopa-hosted video/image galleries in Drupal.

---

Cincopa Multimedia Platform integrates Cincopa — a media hosting/delivery platform — into Drupal, letting editors embed Cincopa-hosted videos, galleries, and media assets on the site via the Cincopa plugin, offloading media hosting/streaming to Cincopa.

Cincopa API credentials should be stored securely (env-backed); media is hosted on Cincopa. Supports Drupal 9.3+, 10, and 11.

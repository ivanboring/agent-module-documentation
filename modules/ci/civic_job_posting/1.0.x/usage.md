Civic Job Posting provides a way to add job listings and integrates Google Job Posting structured data (schema.org JobPosting) for search visibility.

---

Civic Job Posting provides job-listing content and integrates Google Job Posting — emitting
schema.org `JobPosting` structured data so jobs are eligible for Google's job-search rich results. It
builds job content from Paragraphs and Field Group, and exposes data via serialization/REST and core
Search. Use it on career/recruitment sections that want jobs discoverable in Google for Jobs.

It depends on Paragraphs, Field Group, Serialization, REST and Search, and loads a `civic_job_posting`
library. It is a content/SEO feature: the value is the structured-data markup for search engines. As
with any structured data, keep the emitted fields accurate to the actual posting. It has no
access-control role.

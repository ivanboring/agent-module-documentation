City Weather Field stores a city and displays its current weather via a weather API.

---

City Weather Field provides a field type that, given a city, returns and displays the current weather for that location by querying a weather API. It's useful for location/travel/event content that wants live weather context alongside a place.

Because it calls an external weather service, configure the API endpoint/key securely (env-backed) and be mindful of request volume/caching. Depends on core `field`; supports Drupal 9.3+, 10.1+, and 11.

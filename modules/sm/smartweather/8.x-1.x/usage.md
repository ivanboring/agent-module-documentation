Smart Weather gets a weather forecast from OpenWeather and displays it.

---

A weather widget — a forecast for a location — sourced from OpenWeather. Smart Weather fetches and displays it. It needs an OpenWeather API key (a credential to keep out of plain config). It is a content/display feature; the API key is the only sensitive item, and forecasts are public data. Confirm the key is stored securely and that request volume stays within the OpenWeather plan's limits.

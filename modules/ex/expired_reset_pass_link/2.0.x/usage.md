Adds a configurable timeout for password-reset links.

---

Expired Reset Pass Link adds the expired password-reset link timeout setting on the user settings page — so an admin can configure how long a one-time login / password-reset link stays valid (core hard-codes 24 hours), tightening the window in which a reset link can be used. It's a security-hardening/UX setting. Supports Drupal 10, 11, and 12.

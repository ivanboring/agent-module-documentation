Expense Tracker helps you see all your expenses/income.

---

Expense Tracker **helps you record and review expenses and income** — a finance-tracking tool (entries,
categories, views/reports, bulk operations, and a REST API) for personal/business budgeting in Drupal. It
depends on core Views, Comment, Path, REST, Serialization, Basic Auth and Views Bulk Operations, provides its own
permissions, in the Expense and income tracker package.

Use it to track finances in Drupal. It is a content/finance feature. Security/data handling: financial entries
are **personal/sensitive data** — restrict who can view/manage them via its permissions and core access, and note
it exposes a **REST API (with Basic Auth)** so ensure the REST resources are permission-gated and served over
HTTPS (financial data over an authenticated, encrypted API only). It has no broad access-control role beyond its
permission. Configure the tracker and its REST/access.

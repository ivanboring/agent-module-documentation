# Existing Filename Sanitizer — agent index

Provides **Drush commands to sanitize existing (already-uploaded) filenames**. Depends on core `file`, `system`.
Version **1.0.2**. Core `^10||^11`.

File-management/developer (Drush) — a **data-integrity operation** (renames files, updates references): back up +
verify references. Cleaner filenames reduce special-character risk. No access role.

Extra Pagination adds a set of pager items between the last visible page and the last page, for better pagination on large result sets.

---

Core's pager can be awkward on very large result sets (jumping to the last page, seeing intermediate pages). Extra Pagination adds pager items to improve navigation across many pages. It is a display/UX feature with no security surface — it paginates what a view/query already returns. Confirm it fits your listing's page count.

# Exif Manipulate — agent index

**Cleans EXIF metadata from uploaded images** — strips embedded **GPS location**, camera/device info,
timestamps. Version **1.0.1**. Core `^10||^11`.

Positive **privacy control** (mitigates EXIF/GPS exposure on public uploads); processes images on upload;
no access role. One of several EXIF strippers (cf. `exif_removal`).

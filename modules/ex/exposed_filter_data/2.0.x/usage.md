Exposed Filter Data provides a simple way to print exposed filter data.

---

Exposed Filter Data provides a **simple way to print the current exposed-filter values** of a View — so a
template/View can display what the user filtered by (e.g. "Showing results for: Category = News"), giving
context to filtered listings. It depends on core Views.

Use it to surface active exposed-filter selections. It is a content-display/Views feature; it reflects the
filter values the user submitted (present them through normal escaping, as with any request-derived value) and
it has no access-control role. Use it in the View/template.

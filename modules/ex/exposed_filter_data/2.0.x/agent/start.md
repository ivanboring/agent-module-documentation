# Exposed Filter Data — agent index

Provides a simple way to **print the current exposed-filter values of a View** (show "filtering by …" context).
Depends on core `views`. Version **2.0.0**. Core `^10||^11`.

Content-display/Views — reflects submitted filter values (present through normal escaping); no access role.

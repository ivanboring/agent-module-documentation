Extra Field Configuration provides a configuration manager to attach extra fields to entity types.

---

Extra Field Configuration provides a configuration UI/manager for the Extra Field module — letting site
builders attach extra fields (pseudo-fields provided by Extra Field plugins) to entity displays via
configuration, rather than code. It ships an examples submodule and depends on core Field and the Extra Field
module.

Use it to configure extra/pseudo-fields on entities without code. It is a content-display configuration
feature; extra fields render computed/plugin output in the display, and it has no access-control role.
Configure which extra fields attach to which entity displays.

Project Browser Extra Recipes surfaces a set of extra_* recipes in Project Browser.

---

Project Browser Extra Recipes exposes a curated set of `extra_*` recipes to Drupal's Project Browser, so site builders can discover and apply those recipes (pre-packaged configuration/feature bundles) directly from the Project Browser UI.

It's a Project Browser source/integration with no content or access role of its own. Depends on core `project_browser`; supports Drupal 10 and 11.

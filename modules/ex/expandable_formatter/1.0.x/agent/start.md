# Expandable Formatter — agent index

Field **formatter** rendering text fields with **expand/collapse (read-more)** — configurable
collapsed height, ellipsis, trigger labels, effect. Renders via `processed_text` (respects text
format) / autoescaped Twig for plain values (safe output). Depends on core `field`. Version **1.0.x**
(dev). Core `^8.7.7||^9||^10||^11||^12`.

Presentation/formatter only (no access role).

# EXIF Removal — agent index

**Strips EXIF metadata from uploaded images** — removes embedded **GPS location**, camera/device info,
capture time. Version **1.0.0**. Core `^10.3||^11`.

Positive **privacy control** — the direct mitigation for EXIF/GPS exposure on public image uploads.
Processes images on upload; no access role. (Counterpart to `media_image_metadata`'s GPS caveat.)

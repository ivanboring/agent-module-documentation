# Extension Reference Field — agent index

Field type for **referencing Drupal extensions (modules/themes)** by machine name (documentation/catalogs/
config). Version **1.2.3-beta1**. Core `^9.5||^10||^11`.

Fields/content — referenced value is an extension identifier; no access role.

Extension Reference Field defines a field type for referencing Drupal extensions (modules/themes).

---

Extension Reference Field defines a field type for referencing Drupal extensions — modules and themes —
so content/config can point at a specific extension by machine name. This is useful for documentation,
catalogs or config that needs to record which extension something relates to. It is in the Field types
package.

Use it where an entity needs to reference an extension. It is a fields/content feature providing the field
type; the referenced value is an extension identifier and it has no access-control role. Configure the
field on the relevant entity.

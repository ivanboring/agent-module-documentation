Extends module help pages with maintainer info from multiple sources.

---

Extend Help Maintainers extends module help pages with maintainers info from multiple sources — a plugin-based architecture that fetches maintainer/ownership data (from info.yml, drupal.org, and custom fetchers) and shows it on each module's help page, so admins/developers can see who maintains a module. Supports Drupal 10 and 11.

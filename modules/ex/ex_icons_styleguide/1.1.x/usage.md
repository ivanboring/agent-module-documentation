Bridges the ex_icons module with Styleguide to preview all icons.

---

EX Icons Styleguide bridges the ex_icons module with the Styleguide module and provides a preview of all available icons — so on the Styleguide page a developer/themer can see every icon that ex_icons exposes, easing icon selection during theming. Depends on `ex_icons` and `styleguide`; supports Drupal 8 through 11.

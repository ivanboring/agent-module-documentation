Real-time currency exchange rates with blocks, an AJAX converter, and a JSON REST API.

---

Exchange Rate provides real-time currency exchange rates with configurable blocks, an AJAX converter, a JSON REST API, and intelligent caching — so a site can display live rates, let visitors convert amounts, and expose rates to a frontend via REST, backed by cached calls to ExchangeRate-API.

It requires an ExchangeRate-API key (admin-configured; store it securely, env-backed) and caches results to limit API calls. Depends on core `block`, `rest`, and `serialization`; supports Drupal 10 and 11.

Expirable Content lets any content entity type be configured for expiration.

---

Expirable Content **configures content entity types for expiration** — setting content to expire (be
unpublished/handled) after a date/period, so time-limited content is retired automatically. It provides its own
permissions.

Use it to auto-expire content. It is a content-scheduling/governance feature; it changes publication/state on a
schedule (typically via cron) and has no access-control role beyond its permission. Configure expiration per
entity type.

Toast UI Image Editor integrates the Toast UI Image Editor for editing media images in the browser — crop, rotate, filters, drawing.

---

Editing an image — crop, rotate, annotate — without leaving Drupal is convenient for media workflows. Toast UI Image Editor integrates that editor for media images. It is a browser-based editor; edited images are saved back through the normal media/file flow, so access control is that of the media entity. No unusual server-side surface. Confirm which roles can edit media images, since editing replaces the stored image.

# Simple XML sitemap exclude pattern (simple_sitemap_exclude) — agent index

Adds **path-pattern exclusions** to Simple XML Sitemap. Requires `simple_sitemap`. Settings at
`/admin/config/…/simple_sitemap_exclude`. Version **1.0.0**.
Core requirement `^10.2 || ^11.0`.

**The gap:** Simple XML Sitemap decides inclusion per **bundle** and per **entity**, which cannot
express "not any of the URLs this thing generates" — faceted search permutations, paginated archive
variants, thank-you pages, a staging section, paths generated by a module rather than an entity.

**Why it matters — a search-engine argument, not tidiness.** A sitemap tells a crawler which URLs
are worth its attention, and **crawl budget is finite**. Submitting fifty thousand faceted
permutations dilutes the signal for the two thousand pages that matter, and near-duplicate URLs in
a sitemap are an **active negative**.

**The point of care is the mirror image: an exclusion pattern is broader than it looks.** A pattern
that quietly removes a whole content section is a page that stops being found — discovered months
later in a traffic report. Write patterns narrowly, and **check the generated sitemap** after
changing one.

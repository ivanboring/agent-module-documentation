# SimpleAds (simpleads) — agent index

Advertisement module — **ads, ad groups, campaigns** as entities; serves them in blocks; tracks
**impressions and clicks**. Version **2.0.12**. Core `^9 || ^10 || ^11`.
Full entity permission set per type (add/edit/delete/view published/unpublished) + `count simpleads
clicks/impressions`.

House-ad / campaign management with performance tracking. Set the entity permissions per role.

USWDS Layout Builder Configuration provides configuration for using the U.S. Web Design System (USWDS) within Layout Builder, with a media-library submodule.

---

U.S. government sites use the U.S. Web Design System (USWDS). USWDS Layout Builder Configuration supplies the configuration to build USWDS-compliant layouts in Layout Builder, with a media-library submodule. It is distribution/theming configuration with no security surface; it aligns layout building with USWDS patterns. Adopt on a USWDS-based government site.

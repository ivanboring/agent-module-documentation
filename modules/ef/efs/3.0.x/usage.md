Extra Field Settings provides a plugin type for extra fields that look like real fields but do not store data.

---

Extra Field Settings (efs) provides a **plugin type for extra fields** — pseudo-fields that appear and
behave like real fields on entity displays (configurable, themeable) but **store no data** — letting developers
declare computed/display-only fields as plugins with settings, in the Fields package.

Use it as a developer framework for configurable display-only fields. It is a developer/API module — a
plugin's rendered output is developer-controlled (escape/authorize in that code), and efs itself has no content
or access role. Depend on it and implement extra-field plugins.

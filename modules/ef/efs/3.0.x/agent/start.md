# Extra Field Settings (efs) — agent index

A **plugin type for extra fields that look like real fields but store no data** (configurable/themeable
display-only pseudo-fields declared as plugins). Version **3.0.x** (dev). Core `^10||^11`.

Developer/API — a plugin's rendered output is developer-controlled (escape/authorize there); no content/access
role.

A button to create content that references the content being viewed.

---

Create Referencing Content button makes it easy to give site users a button to create content that references the content that they were looking at — so from a node an editor can click to create a new entity with a reference field pre-filled to point back at the current content, streamlining building linked content. Depends on `epp`, `extra_field_plus`, and `extra_field_configuration`; supports Drupal 8 through 11.

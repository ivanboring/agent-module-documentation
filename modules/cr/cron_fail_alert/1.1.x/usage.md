Cron Fail Alert watches over cron execution and provides helpful action items.

---

Cron Fail Alert **watches cron execution** and alerts when cron fails or stalls — surfacing helpful
action items so a broken/stuck cron (which silently degrades a site: unsent mail, unindexed search, unrun
cleanup) is noticed and fixed. It provides its own permissions.

Use it to monitor cron health. This is an operational/administration feature (reliability-positive — a stalled
cron often hides real problems). If it sends alert **emails**, configure the recipients appropriately (alerts
can contain operational detail). It has no access-control role beyond its permission. Configure the cron
monitoring and alerts.

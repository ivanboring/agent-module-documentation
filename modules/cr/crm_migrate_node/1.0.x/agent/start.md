# Node Migration to CRM — agent index

**Migrates Drupal nodes into Drupal CRM** (contacts/records) via Migrate Plus. Depends on `crm`, `migrate_plus`.
Provides permissions. Version **1.0.0-alpha1**. Core `^11`.

CRM/migration — nodes may carry **PII** that becomes CRM records (handle per policy; run/review carefully). No
access role beyond permission.

Node Migration to CRM migrates Drupal nodes into Drupal CRM (contacts/records).

---

Node Migration to CRM **migrates Drupal nodes into Drupal CRM** — using Migrate Plus to move node data into
CRM entities (e.g. turning node content into CRM contacts/records). It depends on the Drupal CRM module and
Migrate Plus, provides its own permissions.

Use it to seed/sync CRM records from nodes. It is a CRM/migration developer feature. Data-handling note: nodes may
contain **personal data** that becomes CRM contact records — ensure the mapping is intended and handle PII per your
privacy policy; migrations are powerful, so run and review them carefully. It has no access-control role beyond its
permission. Configure the node-to-CRM migration.

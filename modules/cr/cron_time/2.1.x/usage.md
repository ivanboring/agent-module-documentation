Cron Time lets admins set a manual/custom cron run interval.

---

Cron Time **lets admins set a manual cron time** — configuring the interval at which Drupal's automated cron
runs (or disabling automatic cron), giving control over cron frequency. It works across core 8–11.

Use it to tune cron frequency. It is an administration/performance setting; it changes when cron runs and has no
content or access role. Note: setting cron too infrequently can delay scheduled tasks (indexing, cleanup);
disabling automated cron means you must trigger cron externally. Configure the cron interval.

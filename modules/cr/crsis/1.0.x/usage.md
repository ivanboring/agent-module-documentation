CRSIS scores content readability (Flesch-Kincaid) and suggests improvements.

---

CRSIS (Content Readability Scoring & Improvement Suggestions) analyzes node content readability using the Flesch-Kincaid formula and offers suggestions to improve it — helping editors write clearer, more accessible copy. It surfaces scores in a dashboard.

Permissions cover the dashboard (`access crsis dashboard`) and administration (`administer crsis`). Depends on core `node`; supports Drupal 10, 11, and 12.

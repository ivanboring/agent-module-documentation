Critical CSS UI provides a UI to manage Critical CSS entities stored in the database.

---

Critical CSS UI **provides a UI to manage Critical CSS entities** — letting admins create/edit the
above-the-fold "critical CSS" (stored as entities in the database) that gets inlined to speed up first paint. It
provides its own permissions, in the Page Speed Optimization package.

Use it to manage critical CSS for performance. It is a performance/theming tool. Security note: critical CSS is
**CSS that gets inlined into pages**, so restrict who can edit it (its permission) to trusted users — injected
CSS can be used for defacement/UI-redress, and the field should be treated as trusted markup. It has no broad
access-control role beyond its permission. Configure the critical CSS.

# Critical CSS UI — agent index

Provides a **UI to manage Critical CSS entities** (inlined above-the-fold CSS) stored in the DB. Provides
permissions. Version **1.0.0-alpha3**. Core `^10||^11`.

Performance/theming — the CSS is **inlined into pages** (restrict the edit permission to trusted users; treat as
trusted markup — defacement/UI-redress risk). No broad access role beyond permission.

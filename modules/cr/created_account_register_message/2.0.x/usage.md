Tells a registering user when they already have an account.

---

Created Account Register Message: if a user tries to register and they already have an account, the module lets them know — showing a message on the registration form so an existing user is guided to log in / reset their password rather than being confused by a failed registration.

Note: revealing that an email/username already exists is a usability-vs-privacy trade-off (it can enable account enumeration); enable only if that trade-off is acceptable for the site. Supports Drupal 10.1+ and 11.

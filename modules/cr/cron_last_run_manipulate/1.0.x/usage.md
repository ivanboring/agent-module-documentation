Update the last cron run time, for debugging and development.

---

Cron Last Run Manipulate is designed to update the last cron run time, making it particularly useful for debugging and development purposes — so a developer can reset/adjust when cron 'last ran' to force or test cron-triggered behaviour without waiting. It's a development helper (not for production). Depends on core `automated_cron`; supports Drupal 10 and 11.

Convert scholarly metadata between formats via the crosswalk CLI tool.

---

Crosswalk integrates with the crosswalk CLI tool to convert scholarly metadata between formats — so a site handling citations/bibliographic data can transform metadata (e.g. between BibTeX, RIS, CSL-JSON) using the external crosswalk tool, useful for academic/repository sites. Depends on core `serialization`; supports Drupal 10 and 11.

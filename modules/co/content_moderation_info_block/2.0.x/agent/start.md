# Content Moderation Info Block — agent index

Block that **displays content-moderation info** (state, transitions) for the current content. Depends on
core `content_moderation`. Version **2.0.0-beta2**. Core `^9||^10||^11`.

Content-display/editorial — shows moderation data, respects viewer access (moderation permissions govern);
no access role.

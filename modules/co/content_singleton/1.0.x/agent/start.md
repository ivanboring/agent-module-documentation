# Content Singleton — agent index

Provides a **fieldable content entity where each bundle has a single instance (singleton)** (model site-wide
one-off content — "Homepage settings" — as an entity). Requires PHP 8.3. Provides permissions. Version
**1.0.0-alpha1**. Core `^11`.

Content-modelling — singletons are content entities (access follows normal entity access + its permissions); no
special access role.

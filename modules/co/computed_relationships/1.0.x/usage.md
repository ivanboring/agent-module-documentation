Reference entities dynamically via computed relationship fields.

---

Computed relationships provides the power to reference entities dynamically — computed reference fields whose targets are derived at runtime (by code/config) rather than stored, so a site can express relationships between entities that follow a rule (e.g. related-by-taxonomy, by-author) without manually maintaining reference values. It's a fields/developer feature. Depends on core `field`; supports Drupal 9, 10, and 11.

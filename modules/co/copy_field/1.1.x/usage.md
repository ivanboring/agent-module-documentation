Adds a button to copy a field's machine name.

---

Copy field machine name provides the ability to copy the machine name of a field — adding a small copy button/affordance in the field UI so site builders can quickly grab a field's machine name (for templates, code, or config) without retyping it. It's a small admin/DX convenience. Supports Drupal 9, 10, and 11.

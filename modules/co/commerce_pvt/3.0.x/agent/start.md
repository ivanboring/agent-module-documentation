# Commerce Product Variations Table (commerce_pvt) — agent index

Displays a Commerce product's **variations as a configurable table with add-to-cart** (attributes/price per
row — good for many-variation products). Depends on core `system`, `views`, `commerce_product`,
`commerce_order`, `commerce_cart`. Version **3.0.1-beta1**. Core `^10.3||^11||^12`.

E-commerce/content-display — pricing/add-to-cart go through Commerce (server-authoritative); no access role.

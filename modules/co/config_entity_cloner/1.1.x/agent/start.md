# Config Entity Cloner — agent index

Adds the ability to **clone configuration entities** (views, content types, image styles, field configs,
etc.) as a starting point. Provides **Drush commands** + permissions. Version **1.1.0**. Core
`^9||^10||^11`.

Developer/site-building tool (creates config) — restrict the permission to trusted builders; review
clones. Config-layer, no runtime access role.

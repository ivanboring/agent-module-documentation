A frontend API to switch between Light/Auto/Dark color schemes.

---

Color Scheme Switcher (cosesi) provides a frontend API to switch between Light / Auto / Dark color schemes — so a theme can offer visitors a light/dark/auto mode toggle, respecting the OS preference in Auto mode and persisting the choice. It's a theming/frontend feature. Depends on core `config`; supports Drupal 11.

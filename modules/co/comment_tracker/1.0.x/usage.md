Comment tracker records view counts for comments on top of the core comment system.

---

Comment tracker extends Drupal core's comment system to track how many times comments are viewed, giving editors/analysts insight into which comments get attention. It records view data alongside existing comment entities.

It's an analytics enhancement over core comments with no access role of its own. Be mindful that per-view tracking has caching and privacy implications. Supports Drupal 10 and 11.

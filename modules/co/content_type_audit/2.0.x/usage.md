Content Type Audit provides a simple report of the number of nodes for each content type on the site.

---

Content Type Audit provides a simple report of node counts per content type — a quick audit of how much
content exists for each type, useful for site audits, cleanup planning and understanding content
distribution. It is configured/viewed at `content_type_audit.content_report`.

Use it to see per-content-type node counts. It is an administration/reporting feature that reads aggregate
counts; it is informational and has no access-control role. Keep the report admin-gated (it reveals content
volumes). View the audit report.

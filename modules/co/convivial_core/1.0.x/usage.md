Convivial Core provides shared functionality for Convivial.

---

Convivial Core provides **shared functionality for the Convivial** distribution/toolkit — common services,
config and helpers used by other Convivial modules. It provides its own permissions, in the Convivial package.

Use it as the base for Convivial-based sites. It is a base/framework module for that ecosystem; on its own it
provides shared plumbing and has no content or access role beyond its permission. Enable it with the Convivial
stack.

Content Moderation Link provides a permissions-aware link that can be used to move content through moderation states.

---

Transitioning moderated content usually happens on the edit form; sometimes a direct link to perform a transition is wanted (in a listing, a dashboard). Content Moderation Link provides such a link, and — importantly — it is permissions-aware: the link only works if the user has permission to perform the transition. So it does not bypass moderation access; it surfaces a transition the user is already allowed to make. Confirm the link respects your workflow's transition permissions (it is designed to), and use it to streamline moderation rather than to grant unintended transitions.

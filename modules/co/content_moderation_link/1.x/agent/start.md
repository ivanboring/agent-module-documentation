# Content Moderation Link (content_moderation_link) — agent index

**Permissions-aware link** to move content through moderation states. Version **1.1.0**.

Does **not** bypass moderation access — the link only works if the user has the transition permission
(it surfaces an already-allowed transition). Streamlines moderation from listings/dashboards.

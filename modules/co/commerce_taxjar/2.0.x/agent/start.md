# Commerce TaxJar — agent index

A Drupal Commerce **connector for TaxJar sales-tax calculation** (US sales tax via TaxJar's API). Depends on
`commerce`, `commerce_order`, `commerce_store`, `commerce_tax`, `commerce_payment`. Version **2.0.5**. Core
`^8.8||^9||^10||^11`.

E-commerce/tax — **sends order data to TaxJar** (egress); **API token** as a secret (HTTPS). No access role.

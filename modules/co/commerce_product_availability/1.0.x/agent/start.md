# Commerce Product Availability — agent index

Provides **product-variation availability logic** for Drupal Commerce (when variations are purchasable — by
stock/dates/rules). `..._webform_request` submodule. Config at `commerce_product_availability.settings`;
provides permissions. Version **1.0.23**. Core `^10||^11`.

E-commerce — governs purchasability, not content access.

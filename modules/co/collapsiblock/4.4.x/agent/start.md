# Collapsiblock (collapsiblock) — agent index

Makes individual **blocks collapsible**, with per-block default state, remembered via **`js_cookie`**.
Version **4.4.0**. Core `^10 || ^11`. No permission surface — affects all viewers.

Per-block default (always open / collapsed / collapsed-on-load / remember). Attaches to block
markup — confirm compatibility with your theme's block structure.

# Content Entity Builder (content_entity_builder) — agent index

UI to **build custom content entity types** (generates entity/fields/code, no PHP). Version **2.1.0**.

Powerful admin/dev capability — restrict to trusted developers; **review the generated entity's
access handler** and treat generated entities like any custom entity for access control. Build-time
tool, not a runtime feature.

Content Entity Builder provides a UI to build custom content entity types, generating the entity, fields and code without writing PHP.

---

Creating a custom content entity type in Drupal normally means writing entity classes and annotations. Content Entity Builder provides a UI to build custom entity types — define the entity, its fields and base fields — and generates the code. It is a developer/site-builder tool. Because it generates code and defines entities (which can carry access implications), it is a powerful admin capability: restrict it to trusted developers, review the generated entity's access handler, and treat generated entities like any custom entity for access control. It is a build-time tool, not a runtime feature.

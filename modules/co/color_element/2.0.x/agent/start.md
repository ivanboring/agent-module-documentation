# Color Element — agent index

Adds a **color-picker field for storing a color value on entities** (per-entity styling/theming). Version
**2.0.1**. Core `^10||^11`.

Fields/content-editing — stores a color value; no content/access role. If emitting the color into inline CSS,
output it safely (validate it is a color).

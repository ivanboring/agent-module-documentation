Color Element adds a color picker field for use against entities.

---

Color Element adds a **color-picker field** — a field type/widget that lets editors choose and store a
color value (e.g. a hex color) on entities, for use in theming or per-entity styling. It is in the Custom
package.

Use it to let editors set a color per entity. It is a fields/content-editing feature; it stores a color value
and has no content or access role. Add the color field to a bundle. Note that if the stored color is emitted
into inline CSS in a template, output it safely (validate it is a color) as with any field value.

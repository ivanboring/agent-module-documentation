# Views Contextual Filter Validator: Number Range — agent index

A **Views contextual-filter argument validator for number ranges** (accept only arguments within a configured
min/max). Depends on core `views`. Version **2.0.2**. Core `^9.5||^10||^11`.

Site-search/Views — validates the argument format (not access control). No access role.

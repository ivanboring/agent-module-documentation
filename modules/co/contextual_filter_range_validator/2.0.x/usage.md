Views Contextual Filter Validator: Number Range provides a contextual filter validator for number ranges.

---

Views Contextual Filter Validator: Number Range provides a validator for Views contextual filters that
accepts only arguments within a configured number range — so a View's argument is validated to be a number
between a min and max, rejecting out-of-range values. It depends on core Views.

Use it to constrain View contextual-filter arguments to a numeric range. It is a site-search/Views feature
that validates the argument; validation constrains input, not access (it is not access control), and it has
no access-control role. Configure the range on the contextual filter.

# Commerce Rave (Flutterwave) — agent index

A Drupal Commerce **payment gateway for Flutterwave Rave**. Depends on `commerce_payment`. Version **2.0.0**.
Core `^9||^10||^11`.

E-commerce/payment — **verifies the transaction server-side** (`verifyTransaction`) on return and completes on
the authoritative result (not the client redirect). API keys as secrets, HTTPS. No access role.

Cookie-Script integrates the Cookie-Script.com consent service, adding its cookie-consent banner and script blocking.

---

Cookie-Script.com is a commercial cookie-consent product; this module integrates it into Drupal — the consent banner and the script-blocking it provides. It needs a Cookie-Script account/ID. The recurring point for any consent integration: a banner only achieves compliance if the scripts that set cookies actually respect consent, so configure the service to block analytics/marketing/embeds until the visitor agrees, and disclose the third-party consent service itself. It loads Cookie-Script's script, so that origin is added to every page.

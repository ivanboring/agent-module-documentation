# Cookie-Script (cookie_script) — agent index

Integrates the commercial **Cookie-Script.com** consent service (banner + script blocking). Version
**1.0.1**. Needs a Cookie-Script account/ID.

**Compliance caveat:** a banner only complies if cookie-setting scripts **respect consent** —
configure blocking of analytics/marketing/embeds until consent. Loads a third-party script (added
origin).

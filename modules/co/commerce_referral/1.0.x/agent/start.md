# Commerce Referral — agent index

A **referral system integrating with Commerce promotions** (reward referrals via discounts). Depends on
`commerce`, `commerce_promotion`. Provides permissions. Version **1.0.3**. Core `^10||^11`.

E-commerce/marketing — referral codes are user-visible (validate attribution server-side; guard self-referral/
abuse — rewards = money). No access role beyond permission.

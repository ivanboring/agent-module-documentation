# Commerce BOXNOW — agent index

**Integrates the BOX NOW parcel-locker API as a Commerce shipping method**. Depends on `commerce_shipping`.
Version **1.0.2**. Core `^9||^10||^11`.

E-commerce/shipping — calls the **BOX NOW API** (egress) with **credentials** (secrets — env/Key, HTTPS); sends
order/recipient **PII** (disclose). No access role.

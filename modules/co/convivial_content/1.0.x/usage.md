Convivial Content ships default content for the Convivial distribution/profile.

---

Convivial Content **ships default content for the Convivial profile** — providing starter/demo content used
by the Convivial Drupal distribution so a new site has example pages/structure out of the box. It depends on the
Convivial Core module.

Use it as part of a Convivial-based site. It is a distribution/site-building feature; it imports default content
and has no access-control role. Note: default/demo content is meant as a starting point — review and replace it for
production. Install it with the Convivial profile.

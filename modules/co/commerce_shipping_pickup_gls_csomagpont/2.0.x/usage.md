Commerce Shipping Pickup GLS CsomagPont provides pickup service for GLS CsomagPont (Hungary).

---

Commerce Shipping Pickup GLS CsomagPont adds **GLS CsomagPont pick-up-point shipping** (Hungary) to Drupal
Commerce — letting customers choose a GLS CsomagPont parcel-point as the delivery location at checkout. It
depends on the Commerce Shipping Pickup API module, in the Commerce (contrib) package.

Use it to offer GLS CsomagPont pickup in Hungary. It is an e-commerce/shipping feature; it integrates with the
GLS pickup-point data (handle any **API credentials** as secrets, HTTPS), and it has no access-control role.
Configure the GLS pickup settings.

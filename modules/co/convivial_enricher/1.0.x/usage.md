Convivial Enricher enriches user profiles with data from external sources.

---

Convivial Enricher **enriches user profiles from external sources** — augmenting user profile data with
information pulled from external services (part of the Convivial ecosystem). It depends on the Convivial Core
module and provides its own permissions.

Use it to enrich profiles. It is an integration/user-data feature. Security/data handling: it **fetches profile-
enrichment data from external services** (egress) and augments **user profiles with third-party personal data
(PII)** — vet the data sources, disclose the enrichment in your privacy policy, obtain any required consent, and
store provider credentials as secrets. It has no access-control role beyond its permission. Configure the
enrichment sources.

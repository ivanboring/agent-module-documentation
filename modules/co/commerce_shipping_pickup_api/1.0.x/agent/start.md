# Commerce Shipping Pickup API — agent index

Provides a **shipping-method API for pickup points and parcel machines** (locker/pickup delivery; customer
chooses a pickup location). demo/store submodules. Depends on `commerce`. Version **1.0.3**. Core
`^8.7.7||^9||^10||^11`.

E-commerce/shipping API — if using a carrier API, store credentials as secrets + HTTPS; pickup location
becomes order address data. No access role.

# Contact Storage Options Email Recipient — agent index

Maps a **contact-form options field to email recipients** (route submissions by the selected option). Depends on
`contact_storage`. Version **2.1.0**. Core `^9||^10||^11`.

Forms — mapping is **admin-configured** (options→address; users pick an option, not a free-text address — no
mail-relay). No access role.

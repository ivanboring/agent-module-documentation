Component Fields compiles a field value from component parts.

---

Component Fields lets you **compile a field value from component parts** — building a composite field whose
value is assembled from several component sub-values, for structured/computed field content. It provides its own
permissions, in the Custom package.

Use it to build composite field values from parts. It is a fields/content feature; values follow normal field
sanitization on display and it has no access-control role beyond its permission. Configure the component field.

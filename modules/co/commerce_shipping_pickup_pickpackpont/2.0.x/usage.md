Commerce Shipping Pickup PickPackPont provides PickPackPont pickup service.

---

Commerce Shipping Pickup PickPackPont provides **PickPackPont pickup-point shipping for Drupal Commerce** —
letting customers choose a PickPackPont (Hungarian pickup-network) collection point at checkout, via the Commerce
Shipping Pickup API. It depends on that module, in the Commerce (contrib) package.

Use it to offer PickPackPont pickup delivery. It is an e-commerce/shipping feature. Security/data handling: it
calls the **PickPackPont API** for pickup points and may need **API credentials** (store as secrets over HTTPS);
customer/parcel data is shared with the carrier. It has no access-control role. Configure the pickup shipping.

# Config2PHP — agent index

**Exports configuration elements as PHP code** (for install/update hooks). Depends on core `config`. Provides
permissions. Version **3.0.4**. Core `>=8.7.7`.

Developer tool — exported PHP may include **secret config values**: review/redact before pasting/committing;
export UI gated to developers. No content/access role beyond permission.

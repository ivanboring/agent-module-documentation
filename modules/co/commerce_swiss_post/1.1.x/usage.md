Commerce Swiss Post provides a Swiss Post shipping method.

---

Commerce Swiss Post provides a **Swiss Post shipping method for Drupal Commerce** — offering Swiss Post
delivery options and rates at checkout for stores shipping within/from Switzerland. It is in the Commerce
(contrib) package.

Use it to offer Swiss Post shipping. It is an e-commerce/shipping feature. Security/data handling: if it calls
the **Swiss Post API** for rates/labels, store any **API credentials** as secrets over HTTPS and note customer
address data is sent to the carrier. It has no access-control role. Configure the Swiss Post shipping method.

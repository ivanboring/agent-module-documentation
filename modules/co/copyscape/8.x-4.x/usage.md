Check content for plagiarism using the Copyscape API.

---

Copyscape checks the content theft of web pages using the Copyscape API — so editors can verify that a page's content is original (not duplicated elsewhere on the web) by submitting it to Copyscape's plagiarism-detection service.

The Copyscape API username/key are admin-configured and should be stored securely; requests go to Copyscape's fixed API endpoint over the Guzzle HTTP client (default TLS verification). Supports Drupal 10 and 11.

# Coupon After Order — agent index

**Generates a Commerce promotion coupon after a purchase** (reward/thank-you). Depends on `commerce`,
`commerce_order`, `commerce_price`, `commerce_promotion`, `state_machine`. Provides permissions. Version
**1.0.0**. Core `^9||^10||^11`.

E-commerce/marketing — coupons have **monetary value**: set promotion limits (usage/expiry/single-use) to prevent
abuse. No access role beyond permission.

# Contextual Image Widget Crop — agent index

Shows **contextual image cropping for Media images** — brings Image Widget Crop into the media library
workflow (crop types/aspect ratios during media editing). Depends on `media_library`,
`image_widget_crop`. Version **1.0.6**. Core `^10.2||^11||^12`.

Media/editorial feature (no access role). Configure crop types via Crop API.

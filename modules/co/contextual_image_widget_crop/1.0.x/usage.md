Contextual Image Widget Crop adds contextual image cropping to Media images, integrating Image Widget Crop into the media library workflow.

---

Contextual Image Widget Crop brings image cropping into the Media editing workflow, showing the
crop UI contextually for Media images. It builds on the Image Widget Crop module and core Media
Library, so editors can define crops (per crop type / aspect ratio) directly when working with media
rather than in a separate step. It depends on `media_library` and `image_widget_crop`.

Use it where editorial teams need to control image framing (crop types for different display contexts)
within the media library experience. It is a media/editorial feature governing how images are cropped
for display; it has no access-control role. Configure crop types in the Image Widget Crop / Crop API
setup and this module surfaces them contextually for media.

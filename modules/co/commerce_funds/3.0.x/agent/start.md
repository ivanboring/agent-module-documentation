# Commerce Funds (commerce_funds) — agent index

**Funds-management for Commerce** — user wallets, deposits, withdrawals, **transfers between users**,
escrow. Version **3.0.2**.

**Money-handling — treat with proportionate caution.** Balance/transfer/withdrawal are financial
operations: verify authorization against your rules, **require admin approval for withdrawals**,
restrict funds permissions tightly, enable and reconcile the transaction log, and test deposit/
withdraw/transfer/escrow against adversarial cases before running real value.

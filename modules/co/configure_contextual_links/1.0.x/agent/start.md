# Configure Contextual Links — agent index

Lets admins **enable/disable/modify contextual (pencil) links**. Depends on core `contextual`. Config at
`configure_contextual_links.settings`; provides permissions. Version **1.0.4**. Core `^9.4||^10||^11`.

Admin/UI feature — affects which contextual links show, not underlying access (links already respect
permissions).

# Component Builder — agent index

Lets site builders **create and manage reusable content components** (compose into pages; built with inline
entity forms). Depends on `entity`, `inline_entity_form`. `toolbar` submodule. Provides permissions. Version
**3.1.0**. Core `^10||^11`.

Content-editing/site-building — component content is authored (rendered normally); access via permissions/
entity access; no special access role.

Comments Ban allows you to ban users from commenting.

---

Comments Ban **lets administrators ban specific users from commenting** — preventing named users from
posting comments (spam/abuse control) without banning them from the whole site. It depends on core Comment, in
the Spam control package.

Use it to stop abusive commenters. It is a moderation/spam-control feature governed by admin permission; the ban
blocks comment posting for the listed users, and it has no broader access-control role. Configure the banned
users.

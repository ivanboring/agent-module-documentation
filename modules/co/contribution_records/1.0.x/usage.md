Contribution Records models contribution records using Paragraphs and drupal.org integration.

---

Contribution Records provides a system for recording contributions — built with Paragraphs and integrating with the drupalorg module — to capture and display structured records of individual/organizational contributions (as used in drupal.org-style contribution tracking). It models each record as structured content.

Administration is gated by `administer contribution records`. Depends on `paragraphs`, core `node`, and `drupalorg`; supports Drupal 9, 10, and 11.

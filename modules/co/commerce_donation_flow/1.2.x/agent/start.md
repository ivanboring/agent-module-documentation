# Commerce Donation Flow — agent index

Donation-specific **checkout flow and configuration** for Drupal Commerce — amount selection + a
streamlined flow for one-off donations instead of product sales. Version **1.2.0**. Core `^10.3||^11`.

Depends on `commerce_order`, `commerce_price`, `commerce_payment`, `commerce_checkout`. Pair with a
signature-verifying payment gateway (money-movement security lives in the gateway). Provides its own
admin permissions.

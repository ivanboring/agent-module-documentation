# Commerce Customers Also Bought — agent index

Displays **"customers also bought"** products (frequently purchased together, from order history) as a
block — cross-sell/basket-size. Depends on core `block`. Version **2.0.1**. Core `^9.5||^10||^11`.

E-commerce/content-display — recommendations from aggregate order history; no access role. Place the block
on product displays.

# Commerce Gallery — agent index

An **advanced masonry image-gallery block for Drupal Commerce products** (masonry product image layout).
Depends on core `file`, `image`, `commerce`, `commerce_product`. Version **2.0.0**. Core `^10||^11`.

E-commerce/content-display — product images follow normal media/file access; no access role.

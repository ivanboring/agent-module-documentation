# Contact Block AJAX — agent index

Provides **blocks that load Contact forms via AJAX** (lazy loading for performance). Depends on core `block`,
`contact`. Provides permissions. Version **1.1.0**. Core `^10||^11`.

Content-display/performance — the form follows core Contact access/spam handling; no access role beyond
permission.

# Controlled Access Terms (controlled_access_terms) — agent index

Authority-controlled vocabulary types (**topic, geographic, person, family, corporate**) + an
**authority-link** field. Version **2.6.0**. Core `^10.2 || ^11`. Depends on `geolocation`, `token`.
Submodule `controlled_access_terms_defaults` (starter config).

For **library/archive/digital-collection** metadata (Islandora-adjacent) — recognised authority
modelling (LCNAF/VIAF/geonames links), not general content tagging. Provides the entities and field;
cataloguing practice is yours.

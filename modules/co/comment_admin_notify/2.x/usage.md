Comment Admin Notify emails the site administrator when a new comment is posted.

---

On a moderated or low-traffic site, an admin wants to know when a comment arrives — to approve it or respond. Comment Admin Notify emails the administrator on new comments. It is a notification convenience with no unusual security surface. The comment content is in the email, so direct notifications to an appropriate inbox, and be mindful of volume on busy sites.

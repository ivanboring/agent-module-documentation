# Content Reviewed Date — agent index

**Tracks when content was last reviewed** and surfaces stale content needing attention. Depends on core `node`,
`datetime`. Provides permissions. Version **1.1.0**. Core `^11`.

Content-editing/governance — stores a review date + reports staleness (editor-facing); no access role beyond
permission.

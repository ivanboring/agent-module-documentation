# Context Active Inspector — agent index

A **toolbar inspector showing which Context-module contexts are active on the current page** (debug conditions/
reactions). Depends on core `toolbar`, `context`. Provides permissions. Version **1.0.2**. Core `^9||^10||^11`.

Developer/debugging — inspector gated by its permission; no access role beyond that.

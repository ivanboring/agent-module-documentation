Context Active Inspector provides an inspector of active contexts.

---

Context Active Inspector adds a **toolbar inspector of active Context-module contexts** — showing which
contexts (and their conditions/reactions) are firing on the current page, to help debug Context configuration.
It depends on core Toolbar and the Context module, provides its own permissions, in the Administration package.

Use it to debug why contexts do/don't fire. It is a developer/debugging tool; its inspector is gated by its
permission (admin/developer), and it has no access-control role beyond that. View the active-context inspector.

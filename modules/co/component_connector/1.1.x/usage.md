Component Connector provides components Drupal integration.

---

Component Connector **integrates front-end components with Drupal** — wiring a component library into
Drupal's rendering/theming so design-system components can be used from Drupal (fields/templates). It is in the
Other package.

Use it for component-based theming. It is a theming/developer feature; components are developer-authored and
rendered through Drupal's theme layer, and it has no content or access role. Configure the component
integration.

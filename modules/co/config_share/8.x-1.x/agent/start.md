# Configuration Share — agent index

Enables **sharing configuration between multiple extensions/distributions** (collaborative config ownership vs
single-extension). Depends on core `config`. Version **8.x-1.0-rc5**. Core `^10.1||^11`.

Configuration-management — affects how config is provided/shared, not runtime access. No access role.

CountUp Formatter is a field formatter that animates numeric field values counting up when they scroll into view.

---

Animated statistics — a number counting up as it enters the viewport — are a popular impact-section effect. CountUp Formatter applies that as a field formatter on numeric fields, so the value animates on scroll. It is a display formatter with no security surface (distinct from the CKEditor CountUp plugin: this one formats a field value). Confirm the effect suits accessibility (reduced motion) and that the field holds the number to animate.

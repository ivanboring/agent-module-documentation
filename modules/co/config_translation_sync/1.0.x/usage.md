Config Translation Sync automatically synchronizes configuration translations during deployment.

---

Config Translation Sync **keeps configuration translations in sync** — automatically synchronizing the
translated config (interface/config translations) during config import/deployment, so translated config
doesn't drift or get lost when config is deployed. It depends on core Config Translation, provides its own
permissions, in the Config package.

Use it to keep config translations consistent across deployments. It is a multilingual/config-management
feature; it manages translation config (not content) and has no access-control role beyond its permission.
Configure the sync behaviour.

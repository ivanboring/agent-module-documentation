Combined image style is a drop-in replacement for the standard image style system, with combined output of multiple image styles.

---

Combined image style provides a drop-in replacement for Drupal's image-style system that combines the
output of **multiple image styles** — so a single "combined" style can apply a sequence/combination of style
effects, giving more flexible derivative generation than a single style chain. It ships a
`combined_image_style_formatters` submodule, in the Image package.

Use it for advanced combined image derivatives. It is a media/display feature affecting image derivative
generation; the images are processed content and it has no access-control role. Configure the combined image
styles.

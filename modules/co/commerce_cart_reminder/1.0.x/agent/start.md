# Commerce Cart Reminder — agent index

**Sends reminder emails for abandoned Drupal Commerce carts** (token-personalized nudge). Depends on core
`commerce_cart`, `token`. Provides permissions. Version **1.0.0**. Core `^10||^11`.

E-commerce/marketing — emails **customers** using cart/account data (PII — respect marketing-consent/
unsubscribe; avoid spamming). No access role beyond permission.

Content Type Config Export exports content type, block type, paragraph type and vocabulary config.

---

Content Type Config Export **exports the configuration of content types, block types, paragraph types and
vocabularies** — bundling a bundle's config (fields, form/view displays) for transfer/reuse between sites. It
provides its own permissions, in the Custom package.

Use it to export bundle configuration. It is a configuration-management/administration feature. Security note:
**exported configuration can contain sensitive values** depending on your setup, so gate its permission to
trusted administrators and review what's exported before sharing. It has no access-control role beyond its
permission. Configure and run the export.

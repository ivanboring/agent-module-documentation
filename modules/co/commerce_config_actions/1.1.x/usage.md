Commerce Config Actions provides experimental config actions for Commerce recipes.

---

Commerce Config Actions is an experimental module providing custom configuration actions for use in Drupal Commerce recipes, letting recipe authors apply Commerce-specific config transformations. Developing it standalone allows releases at a pace unconstrained by Commerce core.

It's a developer/recipe tool with no content or access role of its own. Depends on Commerce `commerce_price`; requires Drupal 11.

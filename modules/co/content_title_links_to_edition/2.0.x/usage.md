Out-of-the-box option to link a content view title to the entity edit form.

---

Content Title Links to Edition provides a quick out-of-the-box solution to link a content view title to the entity edit form — so in listings/views the content title becomes a shortcut to edit that content (for users with edit access), speeding up editorial navigation. Depends on core `node` and `views`; supports Drupal 8.8 through 11.

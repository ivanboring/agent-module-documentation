# Contact Mail — manual setup guide

**Contact Mail** (`contact_mail`) is a small utility for shaping the emails that
Drupal's contact forms send. It provides a settings form where you can set
**common recipients** for contact forms and adjust how those contact-form emails
are formatted, so you don't have to repeat the same recipient configuration on
every form.

It's aimed at sites that want consistent handling of outbound contact-form mail. It
operates purely on the emails generated by contact submissions — it doesn't change
who can see or submit a form, and it has no content-access role. It sits in the Mail
package and has no other module dependencies.

One thing worth keeping in mind, as with any mail customization: contact-form
emails contain the submitter's message and often their email address, so review the
formatting you configure and make sure that information is handled appropriately in
the outgoing mail.

This module does have a settings form, described in
[Configuration](configuration/index.md).

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

The module provides its own settings form (route `synmail.config`). The most
reliable way to reach it is from the modules list at **Extend**
(`/admin/modules`): find **Contact Mail** and follow its **Configure** link. See
[Configuration](configuration/index.md).

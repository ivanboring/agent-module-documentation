Count on Scroll provides a field formatter for integer fields that counts up (animates) when the value scrolls into view.

---

Count on Scroll provides a field formatter for integer fields that animates the number counting up
from zero to its value when it scrolls into the viewport — the familiar "animated statistics" effect
(e.g. "1,240 customers" ticking up). It is in the User interface package.

Use it on stat/number fields where an animated count draws attention. It is a content-display/formatter
feature affecting how the integer renders; the stored value is unchanged and it has no access-control
role. Select the formatter on the integer field's display.

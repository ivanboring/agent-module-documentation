Confetti provides a confetti animation effect.

---

Confetti **adds a celebratory confetti animation effect** — showing an on-screen confetti burst on
configured events (e.g. a successful form submission or a milestone), for a delightful UX touch. It provides its
own permissions, in the confetti package.

Use it to add a confetti celebration. It is a front-end/UX feature affecting presentation; it has no content or
access role beyond its permission. Configure when the confetti fires.

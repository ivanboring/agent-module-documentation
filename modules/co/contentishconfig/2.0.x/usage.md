Mark configuration to be ignored during config sync.

---

Contentish Config lets you mark config to be ignored for config-sync — designating certain configuration as 'content-ish' (site-specific, treated more like content) so it is excluded from configuration import/export and doesn't get overwritten or flagged as an override during deployment. It's a config-management helper. Supports Drupal 8.8 through 11.

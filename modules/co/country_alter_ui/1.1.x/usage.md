Country Alter UI provides an interface to alter the country list.

---

Country Alter UI **provides an interface to alter the country list** — enabling/disabling or relabeling the
countries offered in country/address fields, so forms show only the relevant countries. It works across core
10.3–12.

Use it to customize available countries. It is a site-building/localization feature affecting country options;
it has no content or access role. Configure the country list.

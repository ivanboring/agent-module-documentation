# Commerce BAT — agent index

Provides **configurable date-range/availability (booking) products for Drupal Commerce** (via BAT). Depends on
`commerce`, `commerce_cart`, `commerce_order`, `bat`, `bat_unit`, `bat_event`. Provides permissions. Version
**2.0.0**. Core `^10||^11`.

E-commerce/booking — availability/pricing from BAT (keep availability authoritative at purchase to avoid
double-booking); layers on Commerce access. No access role beyond permission.

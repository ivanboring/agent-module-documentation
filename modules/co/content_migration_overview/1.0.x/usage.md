Content Migration Overview provides an overview of content migrations.

---

Content Migration Overview **provides an overview/dashboard of content migrations** — summarizing migration
progress, counts and status (e.g. from a Drupal-to-Drupal upgrade), so operators can track a migration. It
depends on core Migrate Drupal, in the Migration package.

Use it to monitor a migration. It is a developer/migration reporting tool run by privileged users; it reads
migration state and it has no access-control role. View the migration overview.

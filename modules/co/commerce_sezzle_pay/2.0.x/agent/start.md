Commerce Sezzle Pay (v2.0.x): offsite BNPL gateway src/Plugin/Commerce/PaymentGateway/SezzlePayCheckout.php. onReturn() re-fetches the Sezzle order via getOrderDetails() with a fresh merchant token and completes only if captured/approved (sound, re-fetch from gateway). onNotify() is effectively a no-op (logs only, no fulfillment). Minor: decoupled mode reads the Sezzle order uuid from the attacker-suppliable `session` query param and does not verify Sezzle amount == order total, but the re-fetched order must be captured under the merchant account and the return route needs checkout access. Depends on commerce_payment.

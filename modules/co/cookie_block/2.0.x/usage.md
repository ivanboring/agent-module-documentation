Cookie Block adds a condition based on a cookie.

---

Cookie Block adds a **block-visibility condition based on a cookie** — so a block can be shown/hidden
depending on whether a named cookie is present (or has a value), e.g. show a block only to returning visitors
or those who accepted something. It works across core 8–11.

Use it to drive block visibility from cookies. It is a site-building/conditions feature. Note cookies are
**client-controlled** — a visitor can set/clear a cookie — so this is a **visibility/UX** condition, not a
security gate; never use it as the sole control protecting sensitive content. It has no access-control role.
Configure the cookie condition on a block.

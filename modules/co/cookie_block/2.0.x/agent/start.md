# Cookie Block — agent index

Adds a **block-visibility condition based on the presence/value of a cookie**. Version **2.0.3**. Core
`^8||^9||^10||^11`.

Site-building/conditions — cookies are **client-controlled**, so this is a **visibility/UX** condition, **not**
a security gate (never the sole control on sensitive content). No access role.

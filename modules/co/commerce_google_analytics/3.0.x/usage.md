Commerce Google Analytics integrates Google Analytics with Drupal Commerce, sending e-commerce events (purchases, etc.) to GA via ga_push.

---

Commerce Google Analytics integrates Google Analytics e-commerce tracking with Drupal Commerce —
sending commerce events (product views, add-to-cart, checkout, purchases) to Google Analytics so store
performance can be measured in GA's e-commerce reports. It uses the `ga_push` module to dispatch events
and depends on Commerce Order.

Use it for GA-based store analytics and conversion tracking. As with any analytics integration, it
sends order/product/user event data to Google — obtain appropriate consent, integrate with your
cookie-consent mechanism, and disclose the tracking per your jurisdiction. It is an integration/analytics
feature with no access-control role; configure which events are pushed to GA.

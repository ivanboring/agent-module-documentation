# Commerce Google Analytics — agent index

Integrates **Google Analytics e-commerce tracking** with **Drupal Commerce** (purchase/cart/checkout
events via `ga_push`). Depends on `commerce_order`, `ga_push`. Version **3.0.1**. Core `^10||^11`.

**Privacy/consent:** sends order/product/user data to Google — require consent, integrate cookie-consent,
disclose. No access role.

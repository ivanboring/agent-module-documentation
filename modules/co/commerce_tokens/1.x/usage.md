Commerce Tokens provides commerce-related tokens — order, product, cart values — for use in text, emails and other token contexts.

---

Order-confirmation emails, receipts and messages need order/product values as tokens. Commerce Tokens provides those commerce tokens. It is a token-provider with no security surface of its own; tokens render commerce data into text. Confirm tokens used in customer-facing contexts expose only intended values (an order token in an email should not surface internal-only fields).

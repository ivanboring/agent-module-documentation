Commerce Pricelist Schedule adds scheduled import functionality for Commerce Pricelist.

---

Commerce Pricelist Schedule **adds scheduled import for Commerce Pricelist** — automating the import of price
lists (from a source file/feed) on a schedule so prices update without manual runs. It depends on the Commerce
Pricelist module.

Use it to auto-import price lists. It is an e-commerce/pricing feature; it runs imports (typically via cron) and
has no access-control role. Data-handling note: if the price-list source is remote, treat the source credentials/
URL as configuration to secure. Configure the scheduled pricelist import.

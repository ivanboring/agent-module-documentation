# Content Metrics — agent index

**Shows charts of content activity** (e.g. items created per month over the past 12 months). Depends on
`chartjs_api`. Version **1.0.0-beta2**. Core `^10||^11`.

Statistics/reporting — aggregates content metadata into admin charts (expose to appropriate roles); no access
role.

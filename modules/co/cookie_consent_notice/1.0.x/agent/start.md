# Cookie Consent Notice — agent index

Shows a **cookie-consent notice** and hides/gates designated elements until the visitor consents (GDPR/ePrivacy
presentation; stores the choice, usually a cookie). Version **1.0.2**. Core `^8||^9||^10||^11`.

Privacy/consent UX — a **presentation tool**: real compliance depends on **actually gating cookie-setting
scripts** behind it (a banner alone isn't compliance; trackers must not fire before consent). No access
role.

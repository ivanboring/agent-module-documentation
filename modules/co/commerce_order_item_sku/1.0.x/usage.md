Commerce Order Item SKU stores each purchased entity's SKU on the order item.

---

Commerce Order Item SKU **stores the purchased entity's SKU on the order item** — persisting the SKU at
purchase time so order history keeps the SKU even if the product/variation later changes or is deleted. It depends
on Commerce and Commerce Order (3.x+).

Use it to retain SKUs on orders. It is an e-commerce/data-integrity feature; it records SKU data on order items and
has no access-control role. Enable it to store purchased SKUs.

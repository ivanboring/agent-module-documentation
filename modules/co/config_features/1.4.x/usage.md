Config Features allows sharing/bundling configuration from one site to another.

---

Config Features **allows sharing configuration from one site to another** — bundling sets of config into
reusable "features" that can be exported from one site and imported into another, for config packaging/reuse
(similar in spirit to the Features module). It provides its own permissions, in the Config package.

Use it to package and share config across sites. It is a configuration-management/developer feature; it moves
**configuration** (not content) and has no access-control role beyond its permission. Note: exported config can
include sensitive settings — review a feature's contents before sharing so you don't leak keys/credentials
embedded in config. Configure and export features.

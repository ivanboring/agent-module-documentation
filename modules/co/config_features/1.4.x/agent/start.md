# Config Features — agent index

**Allows sharing/bundling configuration from one site to another** (reusable config features). Provides
permissions. Version **1.4.0**. Core `^9.4||^10||^11`.

Config-management/developer — moves configuration (not content); review a feature before sharing (config can embed
secrets). No access role beyond permission.

# Commerce InPost — agent index

Provides an **InPost shipping provider (parcel lockers) for Drupal Commerce**. Depends on `commerce`,
`commerce_checkout`, `commerce_shipping`, `commerce_order`. Version **8.x-1.0-beta2**. Core `^8||^9||^10||^11`.

E-commerce/shipping — calls the **InPost API** (credentials as secrets, HTTPS; address/parcel data sent to
InPost). No access role.

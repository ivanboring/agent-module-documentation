Conword integrates the Conword service with Drupal for content/translation workflows.

---

Conword provides integration between Drupal and the Conword service — a content/translation collaboration platform — so content can be exchanged with Conword for translation or collaborative editing. Administration is gated by a dedicated permission.

Because it exchanges content with an external service, store API credentials securely (env-backed) and review what content is sent. Gated by `administer conword`; supports Drupal 10.3+ and 11.

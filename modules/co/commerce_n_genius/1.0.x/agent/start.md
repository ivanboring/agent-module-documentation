Commerce N-Genius (v1.0.x): offsite Commerce payment gateway for Network International N-Genius. Single gateway plugin src/Plugin/Commerce/PaymentGateway/NgeniusPayment.php (id n_genius_payment); redirect form NgeniusPaymentRedirect. onReturn() reads $_GET['ref'], gets a client-credentials token, and GETs the N-Genius order to read the 3DS status. SECURITY NOTE: onReturn trusts the attacker-controllable ref and does not bind the fetched transaction amount to the Commerce order, and creates no payment entity on success (logs only) -- treat as weak binding. Depends on commerce_payment.

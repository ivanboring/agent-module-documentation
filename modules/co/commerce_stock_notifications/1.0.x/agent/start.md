# Commerce Stock Notifications — agent index

Lets users **request a notification when an out-of-stock product is back in stock** (via Commerce
Stock). Depends on `commerce`, `commerce_cart`, `commerce_product`, `commerce_stock`,
`commerce_stock_field`, `token`. Requires PHP 7.0+. Provides permissions. Version **1.0.x** (dev). Core
`^8.8||^9||^10||^11`.

Collects email for notifications — handle with consent/privacy. Sends driven by stock changes.

Commerce Payment Extra provides expanded payment API for Drupal Commerce.

---

Commerce Payment Extra provides an expanded payment API for Drupal Commerce — additional payment-related
API/functionality (extra hooks, order-payment helpers) that other payment modules/integrations can build on.
It ships a `commerce_payment_extra_order` submodule and depends on Drupal Commerce, in the Commerce package.

Use it as a base/extension for advanced payment handling. It is an e-commerce/developer feature extending the
payment API; payments still go through Commerce's normal handling and access, and it has no access-control
role. Use its API in payment integrations.

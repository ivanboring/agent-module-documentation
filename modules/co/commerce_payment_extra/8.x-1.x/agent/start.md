# Commerce Payment Extra — agent index

Provides an **expanded payment API for Drupal Commerce** (extra hooks/order-payment helpers for other payment
integrations to build on). `commerce_payment_extra_order` submodule. Depends on `commerce`. Version
**8.x-1.0-rc5**. Core `^10||^11`.

E-commerce/developer — extends the payment API; payments go through Commerce's normal handling/access. No
access role.

# Commerce Store Filter — agent index

Adds **store filtering** for multi-store Drupal Commerce (filter products/orders by store). Depends on
`commerce`, `commerce_store`; provides permissions. Version **2.0.3**. Core `^10||^11`.

E-commerce/admin feature — scopes listings by store; doesn't change store access (Commerce permissions
govern).

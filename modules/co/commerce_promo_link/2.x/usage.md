Commerce Promo Link applies a Commerce promotion/coupon code automatically via a URL, so a shared link pre-applies a discount.

---

Marketing campaigns share links that should pre-apply a discount. Commerce Promo Link applies a promotion code from a URL, so clicking the link adds the coupon to the cart. It is a Commerce marketing convenience. The consideration is that the coupon code is in the URL (shareable, loggable) — which is intended for a promo link, but confirm the promotion's own usage limits/eligibility still apply (a URL should not bypass a coupon's per-user or expiry rules). The promotion logic remains Commerce's; this just applies the code.

Color Scheme Field provides a field type for storing a color scheme.

---

Color Scheme Field **provides a field type for color schemes** — a custom field to store a color scheme
(a set of related colors) on entities, for theming/branding per entity. It works on core 10–11.

Use it to attach a color scheme to content. It is a content-editing/field feature; the stored value is color data
and it has no content or access role. Note: colors applied to output should be emitted as sanitized style values.
Configure the color scheme field.

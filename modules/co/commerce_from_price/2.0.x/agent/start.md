# Commerce From Price — agent index

A product-variation field **formatter displaying the lowest ("from") variation price** ("from £X" starting
price for multi-variation products). Depends on `commerce`. Version **2.0.1**. Core `^10||^11`.

E-commerce/display — computes the minimum variation price (reflects product data, respects its access); no
access role.

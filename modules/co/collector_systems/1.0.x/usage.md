Collector Systems connects Drupal to the Collector Systems collections-management API.

---

Collector Systems integrates Drupal with the Collector Systems API — a collections-management platform used by museums, galleries and private collectors — so collection/artwork data can be pulled into or synced with Drupal content. It bridges the external collections database to the site.

API credentials should be stored securely (env-backed). Because it fetches from an external service, review which data is imported and cache appropriately. Supports Drupal 9, 10, and 11.

# Commerce Tax Washington — agent index

Calculates **Washington State (US) sales tax** by looking up the destination rate. Depends on `commerce_tax`.
Version **3.0.0-alpha1**. Core `^10||^11`.

E-commerce/tax — if rates come from an external API, handle credentials as secrets (HTTPS); tax applied
server-side via Commerce Tax. No access role.

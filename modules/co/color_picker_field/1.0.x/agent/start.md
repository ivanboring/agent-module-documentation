# Color Picker Field — agent index

Provides a **field/widget for selecting text color** (for the body field). Depends on core `field`. Version
**1.0.1**. Core `^10.3||^11`.

Content-editing/field — stored value is a color (output it as a sanitized style value); no content/access role.

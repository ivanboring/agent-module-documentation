Color Picker Field provides a field/widget for selecting a text color for the body field.

---

Color Picker Field **provides a color-picker field** — letting editors choose a text color (for use with the
body/text field) via a color-picker widget, storing the chosen color. It depends on core Field.

Use it to let editors pick text colors. It is a content-editing/field feature; the stored value is a color and it
has no content or access role. Note: applying user-chosen colors to markup is a styling concern (ensure the color
is output as a sanitized style value). Configure the color picker field.

Commerce Custom Checkout Message adds a configurable message panel in the Commerce checkout flow.

---

Checkout often needs a message — delivery notes, a promotion, terms. Commerce Custom Checkout Message adds a configurable message panel to checkout. It is a Commerce UX feature; the message is admin-configured content, so no unusual security surface. Confirm the message renders at the intended checkout step.

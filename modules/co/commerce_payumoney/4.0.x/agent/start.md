Commerce PayUMoney (v4.0.x): offsite PayU gateway. Controller src/Controller/PayUMoneyController.php exposes notify/success/failure routes, all `_access: TRUE` (anonymous). CRITICAL SECURITY: verifyPaymentHash() is a placeholder that returns TRUE unconditionally, and processPaymentResponse() marks the commerce_payment 'completed' for any POST with status=success (order id parsed from productinfo regex, amount only logged, not bound). An anonymous forged POST fulfills an order. Do not use as-is; implement PayU reverse-hash (sha512) verification and bind amount to the order total. Depends on commerce + commerce_payment.

# Container Query Images — agent index

Extends **Responsive Image** to size images by **container width via CSS container queries** (not
viewport) — correct sizing when a component appears in different-width regions. Depends on core `image`,
`responsive_image`, `breakpoint`. Version **1.0.2**. Core `^10.2||^11`.

Media/performance (variant selection; no content/access). Requires modern-browser container-query
support.

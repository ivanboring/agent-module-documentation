# Commerce Shipping Best Rate — agent index

Filters the **shipping rates shown to the customer** (e.g. only the cheapest per service — narrow a long rate
list). Depends on `commerce_shipping`. Version **1.1.2**. Core `^10.2||^11`.

E-commerce/shipping — rates computed by Commerce Shipping (this only filters display); no access role.

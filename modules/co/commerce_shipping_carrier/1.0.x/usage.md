Commerce Shipping Carrier adds shipping carrier config entities for Drupal Commerce Shipping.

---

Commerce Shipping Carrier adds shipping-carrier config entities to Drupal Commerce Shipping — letting
you define carriers (UPS, DHL, local couriers, etc.) as configuration so shipping methods/rates can be
associated with a named carrier. It depends on Commerce Shipping, provides its own permissions, in the
Commerce (contrib) package.

Use it to model shipping carriers in Commerce. It is an e-commerce/shipping configuration feature; it defines
carrier config entities used by shipping methods, and it has no access-control role beyond its permission
(gating who manages carriers). Configure the carriers.

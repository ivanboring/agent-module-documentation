# Commerce Shipping Carrier — agent index

Adds **shipping-carrier config entities** to Drupal Commerce Shipping (define carriers UPS/DHL/etc.,
associate methods/rates). Depends on `commerce_shipping`; provides permissions. Version **1.0.0-alpha3**.
Core `^9.3||^10||^11`.

E-commerce/shipping config — defines carrier entities used by shipping methods; no access role beyond
permission.

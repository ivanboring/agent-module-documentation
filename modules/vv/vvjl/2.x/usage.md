VVJL provides an accessible lightbox display format for Views, showing view results in an accessibility-minded lightbox.

---

A lightbox for a Views gallery, built with accessibility in mind. VVJL is an accessible lightbox display format for Views. It is a front-end display style with no security surface. Its selling point is accessibility, so confirm the lightbox's keyboard navigation and ARIA behaviour meet your requirements — an accessible lightbox is the reason to prefer it over a plain one.

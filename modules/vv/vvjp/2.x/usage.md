---

A parallax scrolling effect — background and foreground moving at different speeds as the user scrolls — applied to a Views listing. VVJP is a scroll-driven parallax display format for Views. It is a front-end display style with no security surface. Confirm the effect performs acceptably (parallax can be heavy on long lists) and respects reduced-motion preferences.

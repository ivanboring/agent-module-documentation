Alerts Format **provides styling/formatting support for alerts** — presentation for alert/notice components
(colors, icons, layout), part of the Recipes Support ecosystem. It works across core 10–11.

Use it to style alert messages. It is a theming/content-display feature affecting presentation; it has no content
or access role. Use the alert formatting.

Alt Text Import CSV allows updating image alt texts from a CSV.

---

Alt Text Import CSV lets you **bulk-update image/media alt texts from a CSV** — mapping media items to new
alternative-text values in an uploaded spreadsheet, for accessibility remediation at scale. It depends on core
Media and Path, Entity Usage and Multivalue Form Element, provides its own permissions.

Use it to fix alt text in bulk. It is a content/accessibility tool run by editors/admins (gated by its
permission). Data-handling note: it processes an **uploaded CSV** (untrusted input — the values become field
content, so they follow normal field sanitization on output), and it edits media across the site, so run it as
a trusted operator. It has no access-control role beyond its permission. Upload the CSV and run the import.

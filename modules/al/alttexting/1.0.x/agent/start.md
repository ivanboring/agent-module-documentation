# AltTexting — agent index

**Adds AI-generated alt text to media images** (accessibility assist). Depends on core `media`. Provides
permissions. Version **1.0.0-beta4**. Core `^10.1||^11||^12`.

AI/accessibility — **sends images to the AI provider** (egress — confirm for sensitive images; key as a secret);
**review** generated alt text. No access role beyond permission.

# Alert Telegram — agent index

**Sends alert/notification messages to Telegram** via a bot. Depends on core `block`. Provides permissions.
Version **1.5.2**. Core `^10||^11`.

Integration/notifications — **bot token** as a secret (HTTPS; leaked token = post as bot); keep alert content
non-sensitive. No access role beyond permission.

Allowed Values Functions makes it easy to define dynamic allowed values for fields via a method.

---

Allowed Values Functions allows setting methods easily as allowed-values functions for fields — so a list/options field's allowed values can be generated dynamically by a configured callable (method) instead of a static list, useful when options depend on other data or context.

It's a developer/site-builder tool with no content or access role of its own; the configured callable runs server-side, so restrict who can configure it. Requires Drupal 11.

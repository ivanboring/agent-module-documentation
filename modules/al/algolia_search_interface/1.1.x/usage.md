Algolia Search Interface provides an instant search JavaScript interface.

---

Algolia Search Interface provides an **Algolia InstantSearch** JavaScript search UI — a fast, as-you-type
search interface backed by the Algolia hosted search service. It is in the Search package.

Use it to add Algolia instant search. It is a site-search/integration feature. Security/data handling: it uses
**Algolia API keys** — use the **search-only** key on the client (never the admin/write key in front-end JS),
and content is indexed in **Algolia** (external data — ensure only content meant to be searchable/public is
indexed, since Algolia's index isn't governed by Drupal access). It has no access-control role. Configure the
Algolia app ID and search key.

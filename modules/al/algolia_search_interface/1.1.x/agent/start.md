# Algolia Search Interface — agent index

Provides an **Algolia InstantSearch JavaScript search interface** (as-you-type, backed by Algolia). Version
**1.1.0**. Core `^8.8||^9||^10||^11`.

Site-search/integration — use the **search-only** Algolia key on the client (never the admin/write key in JS);
content indexed in **Algolia** (external — index only searchable/public content; not Drupal-access-governed). No
access role.

Alias Manager displays a list of aliases on every entity.

---

Alias Manager **displays the list of URL aliases for an entity** — surfacing all path aliases pointing at
a given entity (on the entity itself), so editors/admins can see and manage which URLs resolve to it. It
provides its own permissions, in the Other package.

Use it to review an entity's aliases. It is a site-structure/administration feature; aliases are public URLs
already, and it has no access-control role beyond its permission (gating who sees the alias list). Enable it to
show aliases on entities.

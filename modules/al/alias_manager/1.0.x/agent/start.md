# Alias Manager — agent index

Displays the **list of URL aliases for every entity** (see/manage which URLs resolve to it). Provides
permissions. Version **1.0.0**. Core `^10||^11`.

Site-structure/admin — aliases are public URLs; no access role beyond permission (gates who sees the list).

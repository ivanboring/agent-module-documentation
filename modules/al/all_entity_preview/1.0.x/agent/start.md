# Preview (all_entity_preview) — agent index

Preview **any selected entity type** in **any view mode** before saving. Version **1.0.0-alpha7**.
Core `^10.1 || ^11 || ^12`. No dependencies.

**Machine name is `preview`** (project is `all_entity_preview`) — note when enabling/reading config.

Extends core's node-only preview to chosen entity types (terms, media, custom entities). No extra
permission surface — shows what the editor could already edit. Confirm the target view modes exist
for the entity types you enable it on.

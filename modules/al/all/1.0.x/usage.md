All provides a single admin page to edit settings across many content types simultaneously.

---

All is a site-builder convenience module that gathers content-type settings onto one page so an administrator can change options across multiple content types at once, instead of visiting each content type's settings form individually. It streamlines bulk configuration on sites with many content types.

It's gated by a single `administer all` permission and edits content-type configuration, so grant it only to trusted site builders. A configuration/admin-UX utility with no front-end role. Supports Drupal 8 through 11.

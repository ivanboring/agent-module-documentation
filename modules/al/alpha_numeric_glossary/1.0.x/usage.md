Alpha Numeric Glossary provides an alpha numeric glossary in the global area.

---

Alpha Numeric Glossary adds an **A–Z / 0–9 glossary** to a View's global area — a set of letter/number
links that filter a listing to entries starting with that character, for building glossary/directory-style
browsing. It depends on core Views.

Use it to add A–Z glossary navigation to a View. It is a content-display/Views feature; results respect the
View's access and it has no access-control role. Add the glossary to a View's global area.

Alpha Pagination provides an alphabetic paginator in the global area of any view, letting users jump to items by first letter.

---

Alpha Pagination provides an alphabetic (A–Z) paginator that can be placed in the global area of any
View — so a listing can be filtered/jumped to by first letter (e.g. a glossary, staff directory, or
title index). It ships an `alpha_pagination_sample_view` submodule and depends on core Views.

Use it to add A–Z navigation to a View. It is a content-display/Views feature affecting navigation; the
listed items respect the View's access and it has no access-control role. Add the alpha paginator to the
View's global area and configure the source field.

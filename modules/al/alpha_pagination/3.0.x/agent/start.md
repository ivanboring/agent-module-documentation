# Alpha Pagination — agent index

Provides an **alphabetic (A–Z) paginator in a View's global area** (jump to items by first letter —
glossary/directory/index). `alpha_pagination_sample_view` submodule. Depends on core `views`. Version
**3.0.1**. Core `^9||^10||^11`.

Content-display/Views navigation — listed items respect the View's access; no access role.

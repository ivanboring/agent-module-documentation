Awareness provides traits and interfaces for developers.

---

Awareness provides **traits and interfaces** — a developer API/library offering reusable PHP traits and
interfaces (e.g. for file-aware or context-aware components) that other modules build on. It depends on core
File.

Use it as a developer dependency, not a standalone feature. It is a base/API module; on its own it provides code
scaffolding and has no content or access role. Depend on it from your module.

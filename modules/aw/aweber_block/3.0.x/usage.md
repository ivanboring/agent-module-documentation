Aweber Block integrates Drupal with AWeber, providing a block for AWeber email sign-up.

---

Aweber Block integrates Drupal with AWeber — the email-marketing service — providing a block (typically
an AWeber sign-up/opt-in form) so visitors can subscribe to AWeber mailing lists from the Drupal site. It is
in the Aweber package.

Use it to add AWeber subscription forms to the site. It is an integration/marketing feature; if it embeds
AWeber's form/script, that loads third-party code (a privacy/consent consideration for tracking), and any
AWeber API credential should be stored as a secret. It has no access-control role. Configure the AWeber
block.

Track Usage tracks usages of a certain entity type by a source entity, recording where entities are used — a lightweight entity-usage tracker.

---

Knowing where an entity is used — which pages reference this media, this term — helps before editing or deleting it. Track Usage records usages of an entity type by source entities. It is content-modelling/administration infrastructure similar to Entity Usage. No unusual security surface; the usage data is metadata about content relationships. As with any usage tracker, an empty usage record means 'not tracked', not necessarily 'not used' — the tracking is only as complete as what the module observes, so do not treat absence of recorded usage as proof an entity is safe to delete.

Duet Date Picker offers a date picker field widget that uses the duetds/date-picker web component.

---

Duet Date Picker provides a date-picker field widget built on the Duet Date Picker
(`duetds/date-picker`) — an accessible, framework-agnostic date-picker web component known for strong
accessibility and internationalization. It replaces the default date input with Duet's picker on date
fields.

Use it where an accessible, well-designed date picker improves date entry. It is a form/date widget
affecting input; the stored value is a standard date, and it has no access-control role. Configure it as
the widget on date fields.

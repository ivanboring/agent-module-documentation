Feature Flags Extensions provides extensions for the featureflags module.

---

Feature Flags Extensions **extends the Feature Flags module** — adding extra functionality (additional flag
behaviours/integrations) on top of core Feature Flags for toggling features on/off. It depends on the
featureflags module, provides its own permissions.

Use it to enhance feature-flag handling. It is a developer/site-building feature; who can toggle flags is
governed by its permissions (gate to trusted operators, since flags change site behaviour) and it has no broad
access-control role beyond its permissions. Configure the extended flag behaviour.

Fetches Instagram media via the Facebook/Meta Graph API for Feeds.

---

Feeds Instagram fetches Instagram media via the Facebook (Meta) Graph API — a Feeds fetcher/parser that imports a connected Instagram account's media into Drupal as content, for displaying an Instagram feed on the site.

It requires Instagram/Facebook Graph API credentials (admin-configured; store securely, env-backed). Depends on `pcb` and `feeds`; supports Drupal 9.3+, 10, and 11.

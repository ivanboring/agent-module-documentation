Analyzes the sentiment of feedback submissions using the OpenAI API.

---

Feedback AI analyzes the sentiment of feedback submissions using the OpenAI API — scoring submitted feedback as positive/negative/neutral via an LLM so teams can triage and understand user sentiment at scale, with results exportable via Views Data Export.

The OpenAI API key is admin-configured and should be stored securely (env-backed), never committed; each submission triggers an API call (watch cost and PII sent to OpenAI). Depends on `views_data_export`; supports Drupal 9, 10, and 11.

Feeds Enhanced provides enhancements for the Feeds import module, including additional tokens.

---

Feeds imports external data into Drupal; Feeds Enhanced adds capabilities on top, including a tokens submodule. It is Feeds infrastructure. As with any import tool, the security consideration is that importing creates content and the source data should be validated/trusted — Feeds Enhanced extends that pipeline, so review what the enhanced import does and where its data comes from. Restrict who configures and runs feeds.

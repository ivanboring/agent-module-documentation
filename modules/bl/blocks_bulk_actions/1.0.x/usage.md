Blocks Bulk Actions lets admins bulk-manage blocks on the block layout page.

---

Blocks Bulk Actions enhances the block layout page with bulk actions functionality — like delete, enable/disable, and other operations applied to multiple blocks at once, so administrators can manage many blocks efficiently instead of one at a time.

It's a block-administration/site-building tool; bulk operations follow the user's block administration access. Supports Drupal 9, 10, and 11.

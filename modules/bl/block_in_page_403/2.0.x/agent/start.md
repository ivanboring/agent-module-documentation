# Block In Page 403 — agent index

Place a **block on the 403 (access denied) page** (custom content — login prompt/help/contact — vs the bare
default). Depends on core `block`. Version **2.0.1**. Core `^8||^9||^10||^11`.

Admin/UX — enriches the denial page; the placed block keeps its own access, the 403 still denies the
resource. No access role.

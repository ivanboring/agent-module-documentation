Block Component Library provides a Block Component Library to use custom blocks as reusable components.

---

Block Component Library lets custom (content) blocks be treated as reusable components — organizing and
reusing custom blocks as building-block components across the site (e.g. in Layout Builder or block layout),
for a component-driven build approach. It is in the Other package.

Use it to build with reusable block components. It is a content-editing/site-building feature affecting how
blocks are organized/reused; blocks keep their own access and it has no access-control role. Configure the
component library.

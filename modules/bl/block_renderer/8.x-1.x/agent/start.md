# Block Renderer — agent index

Renders **Drupal blocks programmatically/independently** of normal placement, so their output can be
reused (embedded, returned, composed). Version **8.x-1.0-alpha6**. Core `^8||^9||^10||^11`.

Rendering utility — blocks still honour their own access + cache metadata when rendered; no access role
of its own.

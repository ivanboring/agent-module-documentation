Block Extras adds assorted extra features/options to Drupal blocks.

---

Block Extras provides extra functionality for blocks — assorted enhancements (additional configuration options, behaviors, or display features) for Drupal blocks, giving site builders more control over how blocks are configured and rendered.

It's a block/site-building enhancement with no content or access role of its own. Supports Drupal 10.1+ and 11.

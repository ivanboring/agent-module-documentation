Block Breakpoint conditionally loads blocks based on breakpoints, so blocks appear only at certain screen sizes.

---

Block Breakpoint conditionally loads blocks based on responsive breakpoints — so a block is only
rendered/shown at certain screen sizes (e.g. a block only on desktop, or only on mobile). It depends on
core Breakpoint. This helps tailor which blocks appear per device without duplicating content.

Use it to show/hide blocks by screen size. It is a content-display/responsive feature affecting block
visibility by breakpoint; the block's own access still applies (it doesn't grant access), and it changes
presentation only. Configure the breakpoint condition on the block.

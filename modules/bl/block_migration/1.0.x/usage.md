Block Migration exports/imports block content (with translations) using single_content_sync.

---

Block Migration exports and imports Drupal block content — any block bundle and field type, with auto-detection and translation support — building on the single_content_sync framework. It lets you move custom blocks between environments as portable content rather than re-creating them by hand.

It's a content-migration/site-builder tool. Because it imports content, run imports from trusted sources only. Depends on core `block_content` and `single_content_sync`; supports Drupal 10 and 11.

Block Button Modal lets blocks be opened in a modal via a button.

---

Block Button Modal **lets a block be viewed as a modal via a button** — placing a button that opens a chosen
block's content in a pop-up modal, for on-demand content (help, forms, promos). It depends on core Block.

Use it to show a block in a modal. It is a content-display/UX feature; the block content follows normal block
access and it has no access-control role. Configure the modal button on a block.

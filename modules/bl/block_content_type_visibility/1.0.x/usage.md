Block Content Type Visibility adds content type-based visibility conditions to blocks.

---

Block Content Type Visibility adds a **block-visibility condition based on the current node's content
type** — so a block can be shown/hidden depending on the type of node being viewed (e.g. show a sidebar only on
Articles). It depends on core Block and Node, core 11.

Use it to scope block placement by content type. It is a site-building/block feature affecting block
visibility; it does not restrict access to the block's content (visibility ≠ access — a hidden block's
underlying content isn't protected by hiding it), and it has no access-control role. Configure the content-type
visibility condition.

# Block Content Type Visibility — agent index

Adds a **block-visibility condition based on the current node's content type** (show/hide a block per node
type). Depends on core `block`, `node`. Version **1.0.1**. Core `^11`.

Site-building/block — **visibility, not access** (hiding a block doesn't protect its content); no access
role.

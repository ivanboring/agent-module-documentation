Block Description Modifier configures Layout Builder inline block descriptions.

---

Block Description Modifier lets you **configure how Layout Builder inline-block descriptions/labels are
shown** — controlling the admin label/description of inline blocks so they're easier to identify when building
layouts. It depends on core Block Content, Layout Builder and Inline Entity Form, provides its own permissions,
in the Contrib package.

Use it to make Layout Builder inline blocks easier to manage. It is a site-building/admin feature affecting the
Layout Builder UI; it has no content or access role beyond its permission. Configure the block description
behaviour.

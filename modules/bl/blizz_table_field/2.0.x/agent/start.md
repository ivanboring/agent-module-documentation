# Blizz Table Field — agent index

Table **field type edited with a spreadsheet-like Handsontable widget** — rows/columns stored on the
entity, rendered as a table (cells can hold formatted/media content). Depends on core `field`, `file`,
`filter`, `image`. Config at `blizz_table_field.settings_form`. Version **2.0.8**. Core `^9||^10||^11`.

Fields/content feature — cell content goes through filter formats/render layer; no access role.

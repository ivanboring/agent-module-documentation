Blizz Table Field provides a table field type edited with a spreadsheet-like (Handsontable) widget, storing tabular data on entities.

---

Blizz Table Field provides a field type for storing tabular data, edited through a spreadsheet-like
Handsontable widget — editors enter rows and columns in a familiar grid and the data is stored on the
entity and rendered as a table. It supports rich table content (it depends on core Field, File, Filter
and Image, so cells can include formatted/media content) and is configured at
`blizz_table_field.settings_form`.

Use it where content needs editable tables (specifications, comparisons, schedules) with a comfortable
spreadsheet editing experience rather than hand-built markup. It is a fields/content feature; table
data is authored and rendered through Drupal's layers (filter formats apply to cell content), with no
access-control role. Configure the field's settings and display for the table output.

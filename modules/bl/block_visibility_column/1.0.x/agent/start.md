# Block Visibility Column — agent index

Adds a **Visibility column to the Block Layout page** — see each block's visibility conditions (pages/
roles/types) in the list. Depends on core `block`. Version **1.0.3**. Core `^9||^10||^11`.

Admin/UI convenience — surfaces existing config; changes nothing. No config beyond enabling.

Block Visibility Column adds a Visibility column to the Block Layout page, showing each block's visibility conditions at a glance.

---

Block Visibility Column adds a "Visibility" column to the Block Layout administration page, so
administrators can see each placed block's visibility conditions (pages, roles, content types, etc.)
directly in the block list instead of opening each block's configuration. It depends on core Block.

Use it to audit and manage block placement more efficiently on sites with many blocks and complex
visibility rules. It is an administration/UI convenience that surfaces existing configuration; it does
not change block visibility or access, only displays it. No configuration needed beyond enabling.

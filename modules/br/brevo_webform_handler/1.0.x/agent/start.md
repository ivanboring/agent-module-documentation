# Brevo Webform Handler (brevo_webform_handler) — agent index

Webform handler sending submissions to **Brevo** (ex-Sendinblue) as contacts. Version **1.0.1**.

**Privacy/creds:** needs a Brevo API key (keep out of plain config); forwards submission PII to an
external marketing service — disclose, capture consent.

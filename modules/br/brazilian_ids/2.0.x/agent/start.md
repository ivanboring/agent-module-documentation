# Brazilian IDs — agent index

Adds **CPF / CNPJ / CPF+CNPJ** widgets to text fields (Field UI) + matching **Form API element types**
— input handling/validation for Brazilian tax identifiers. Version **2.0.1**. Core `^10||^11`.

Fields/forms feature (no access role). **These are personal/tax data — handle/store with privacy
care.** Configure the widget on the text field.

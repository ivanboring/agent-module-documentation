Brazilian IDs adds CPF, CNPJ and CPF/CNPJ widget options to text fields and provides matching Form API element types.

---

Brazilian IDs adds support for Brazilian identification numbers — CPF (individual taxpayer), CNPJ
(company) and a combined CPF/CNPJ — as widget options on text fields (via the Field UI) and as new Form
API element types. This gives proper input handling/validation and formatting for these
Brazil-specific identifiers on both entity fields and custom forms. It is in the Field package.

Use it on Brazilian sites collecting CPF/CNPJ on user profiles, registrations, orders or custom forms.
It is a fields/forms feature providing input widgets and elements; validation/formatting applies to the
identifier, and it has no access-control role. Note these identifiers are personal/tax data — handle
and store them with appropriate privacy care. Configure the widget on the relevant text field.

Brazilian Address Field provides a Brazilian address field with postal-code (CEP) lookup, auto-filling address parts from the postal code.

---

Brazilian addresses have a specific structure and a postal-code (CEP) system that can auto-fill the address. Brazilian Address Field provides that field with CEP lookup. The lookup queries an external CEP service (e.g. ViaCEP), so the consideration is an outbound request per lookup — confirm it uses TLS with verification and handles the service being unavailable, and be aware address data is personal data. For Brazilian sites it eases address entry.

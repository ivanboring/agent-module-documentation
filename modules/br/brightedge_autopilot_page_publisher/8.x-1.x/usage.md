BrightEdge Autopilot Page Publisher applies BrightEdge SEO recommendations to page metadata.

---

BrightEdge Autopilot Page Publisher is a plugin that updates a page's Title, Meta Description, and H1 tag based on recommendations from BrightEdge Autopilot — so SEO recommendations from BrightEdge can be automatically applied to content metadata, improving search performance.

BrightEdge API credentials should be stored securely (env-backed). It integrates Metatag. Depends on `metatag`, `node`, and `token`; supports Drupal 8 through 11.

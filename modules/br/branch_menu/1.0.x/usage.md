Branch Menu displays a menu as an interactive branching tree diagram.

---

Branch Menu renders a Drupal menu as a visual branching tree graph — presenting a menu's hierarchy as an interactive tree/diagram rather than a nested list, useful for sitemaps, navigation overviews, or visualizing large menu structures.

It's a display/visualization feature with no content or access role of its own. Requires Drupal 11.

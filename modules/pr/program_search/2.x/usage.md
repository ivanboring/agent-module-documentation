Program Search (machine name openy_programs_search) provides a block to search programs, part of the Open Y (YMCA) distribution.

---

YMCA sites list programs (classes, activities) that visitors search. Program Search provides a search block for programs, part of the Open Y distribution. It is a distribution-specific search feature. It searches program content, so the standard search consideration applies (it surfaces what the search index exposes, subject to access). Adopt on an Open Y site with program content.

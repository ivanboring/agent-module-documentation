Media File Formatters (mff) provides display formatters for file media entities, giving more control over how file media render.

---

Core's file media rendering is limited; sites often want a download link with the file size, an icon by type, or a specific layout for document media. Media File Formatters adds display formatters for file media entities to cover those cases. It is a display-layer module with no security surface — it changes how existing, access-controlled file media render, not what is accessible.

Integrates the DXP assistant scripts and provides its endpoints.

---

DXP Assistant integrates the DXP assistant scripts and provides it the required endpoints and information — wiring a Digital Experience Platform assistant (an on-site AI/help assistant) into Drupal by loading its scripts and exposing the endpoints/data it needs.

Any DXP/assistant API credentials should be stored securely (env-backed). Supports Drupal 10.4+ and 11.

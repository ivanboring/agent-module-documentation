Navigation Blocks provides navigational blocks — a generic back button and similar — for placement in layouts.

---

Small navigation helpers — a back button, a next/previous — are common needs that core does not provide as blocks. Navigation Blocks supplies them for placement. It is a UI/navigation convenience with no security surface. A 'back' block typically uses browser history or a referrer; confirm the behaviour is what you want (referrer-based back can be manipulated, but for navigation UX that is not a security concern).

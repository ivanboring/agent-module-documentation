EPT Quote adds a Quote paragraph type for styled pull-quotes and blockquotes, part of the Extra Paragraph Types family.

---

A styled quote — a pull-quote, a testimonial blockquote — is a common editorial element. EPT Quote adds it as a paragraph type in the Extra Paragraph Types (EPT) family. It is a display paragraph with no security surface.

# e-Plikt — agent index

Provides **RSS export for entities affected by mandatory (legal) delivery** (with downloadable media). Depends on
core `media`, `media_entity_download`. Version **1.0.4**. Core `^11`.

Web-services — the feed **exposes entity content + media** to readers (restrict the audience if not public; include
only intended items); no access role.

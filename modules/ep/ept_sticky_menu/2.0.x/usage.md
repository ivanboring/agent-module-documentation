EPT Sticky Menu is an Extra Paragraph Types (EPT) Sticky Menu module.

---

EPT Sticky Menu provides an **Extra Paragraph Types (EPT) paragraph for a sticky in-page menu** — a
paragraph type that renders a menu which sticks to the viewport as the user scrolls (e.g. section navigation on
a long landing page). It depends on EPT Core and Paragraphs, in the Extra Paragraph Types package.

Use it to add a sticky navigation paragraph. It is a content-editing/display feature; the menu is authored
content and it has no access-control role. Add the sticky-menu paragraph.

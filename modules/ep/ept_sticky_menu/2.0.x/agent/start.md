# EPT Sticky Menu — agent index

An **Extra Paragraph Types (EPT) paragraph that renders a sticky in-page menu** (section nav that sticks on
scroll). Depends on `ept_core`, `paragraphs`. Version **2.0.2**. Core `^10.1||^11||^12`.

Content-editing/display — menu is authored content; no access role.

A client module to connect to Epsilon Harmony APIs.

---

Epsilon Harmony is a client module to connect to Epsilon Harmony APIs — integrating with Epsilon's Harmony marketing/customer-data platform so a site can send/retrieve data (profiles, campaigns) via its API.

The Epsilon Harmony API credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on core `views`; supports Drupal 8 through 11.

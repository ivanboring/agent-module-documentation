EPT Micromodal adds a button-with-popup paragraph type using Micromodal, part of the Extra Paragraph Types family.

---

A button that opens a modal — for a video, a form, extra detail — is a common landing-page element. EPT Micromodal adds it as a paragraph type using the Micromodal library, part of the Extra Paragraph Types (EPT) family. It is a display paragraph with no security surface. The modal content is authored content, so it renders with normal content handling.

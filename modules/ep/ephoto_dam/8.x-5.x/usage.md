Ephoto DAM lets you find your media on the Ephoto digital asset management solution.

---

Ephoto DAM integrates the **Ephoto digital-asset-management** solution with Drupal — browsing and using
Ephoto-hosted assets in content (with CKEditor 5 integration and an `ephoto_dam_field` submodule). It depends
on core CKEditor 5 and System, in the Ephoto Dam package.

Use it to use Ephoto DAM assets. It is a media/DAM integration feature. Security handling: it authenticates to
the **Ephoto DAM API with credentials** — store as **secrets** (env/Key), use HTTPS — and assets are
hosted/served by **Ephoto** (third-party). It has no access-control role. Configure the Ephoto credentials.

# Ephoto DAM — agent index

Integrates the **Ephoto digital-asset-management** solution with Drupal (browse/use assets; CKEditor 5 +
`ephoto_dam_field`). Depends on core `ckeditor5`. Version **8.x-5.3**. Core `^10||^11`.

Media/DAM — authenticates with **Ephoto API credentials** (secrets, HTTPS); assets served by **Ephoto**
(third-party). No access role.

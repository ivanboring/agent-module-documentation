# Markdown Sitemap (mdsitemap) — agent index

Generates a **markdown sitemap for LLM crawlers** (llms.txt-style AI-discoverability). Version
**1.0.3**.

**Policy note:** it deliberately makes content more available to AI crawlers (and any scraper) —
expose only **public content you intend AI systems to ingest**; confirm the sitemap's scope.

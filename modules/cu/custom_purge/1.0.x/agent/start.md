# Custom Purge — agent index

Provides **lightweight, queueable, customizable cache purging**. Depends on core `page_cache`. Provides
permissions. Version **1.0.0-rc6**. Core `^9||^10||^11`.

Performance/cache — triggers cache invalidation (store any CDN endpoint credentials as secrets); no content/access
role beyond permission.

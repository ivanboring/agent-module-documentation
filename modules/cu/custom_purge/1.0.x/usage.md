Custom Purge provides lightweight, queueable, customizable cache purging.

---

Custom Purge **provides lightweight, queueable cache purging** — a customizable mechanism to purge/invalidate
caches (with queue support) so external caches/CDNs or Drupal caches can be cleared on demand or by rules. It
depends on core Page Cache, provides its own permissions.

Use it to purge caches flexibly. It is a performance/cache feature; it triggers cache invalidation and has no
content or access role beyond its permission. If it purges an external cache/CDN, any endpoint credentials should
be stored as secrets. Configure the purge rules.

# Custom Book Block (custom_book_block) — agent index

A **configurable book-navigation block** — more flexible than core's. Version **2.0.0**.
Core `^10.3 || ^11`. Depends on core `book`.

Options to scope what part of the book tree shows (current chapter, start depth, max depth). Compare
`book_tree_menu` (same wave): this leans on **configurability**, that on rendering the **full tree**.
More settings to get right per placement.

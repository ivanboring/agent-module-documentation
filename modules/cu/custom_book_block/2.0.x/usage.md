Custom Book Block provides a more flexible book-navigation block than core's, with options to configure what part of the book tree is shown and how.

---

Core's Book navigation block is fixed in behaviour, and documentation sites often want more control: show only the current chapter, start the tree at a certain depth, limit how deep it renders. This module makes book navigation a configurable block, so the navigation matches the shape of the documentation rather than core's one-size rendering.

It depends on core **Book** and, like `book_tree_menu` (also in this wave), exists because core's book block is not enough — the difference is emphasis: this one leans on configurability (what to show, from where), the other on rendering the full tree. On a site with several books or deep hierarchies, being able to scope the block per placement is the useful part.

For handbook and documentation sites on Book, it is the more adjustable navigation option. Confirm the block's configuration produces the tree scope you want in each placement, since the flexibility is also more settings to get right.

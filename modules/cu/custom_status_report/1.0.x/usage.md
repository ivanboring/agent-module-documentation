Custom Status Report lets admins customize what appears on /admin/reports/status.

---

Custom Status Report lets administrators customize Drupal's core Status Report page (/admin/reports/status) — for example hiding, reordering, or adjusting which checks/messages appear — so the report shows what matters to a given site or team.

It's an administration utility that alters an admin-only report; it has no front-end role. Supports Drupal 9, 10, and 11.

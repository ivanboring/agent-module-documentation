# Custom Add Content (custom_add_content) — agent index

Converts `/node/add` into a **configurable menu** — order, group, hide, describe.
Version **2.1.1**. Core `^10 || ^11`. No dependencies.

Real editorial effect: content lands in the right type more often when the right type is obvious.

**State the distinction clearly: ordering a menu is presentation, not permission.** Removing a type
from the menu does not stop anyone creating it — `/node/add/type` still works for whoever holds the
permission. A genuine restriction is a permission change; this is usability layered on top.

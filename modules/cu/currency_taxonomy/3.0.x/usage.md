Currency Taxonomy creates a currency taxonomy vocabulary populated with ISO currency codes and associated countries.

---

Currency Taxonomy creates a taxonomy of currencies — a vocabulary populated with currency ISO codes and
their associated countries — so content can reference currencies as taxonomy terms (for multi-currency
listings, financial content, or currency selection). It depends on core Taxonomy and provides Drush
commands (to populate/manage the vocabulary).

Use it where currencies should be available as taxonomy terms. It is a site-structure/taxonomy feature
providing reference data; the currency terms are reference content and it has no access-control role. Run
the population command and reference the terms as needed.

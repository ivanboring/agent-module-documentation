Current Year provides an input filter (and token) that outputs the current year, so a copyright line or similar stays current without editing.

---

A footer copyright '© 2026' goes stale every January, and updating it by hand across content is the kind of tiny recurring chore that gets forgotten. Current Year makes the year dynamic: an input filter (and token) that renders the current year at display time, so '© [current-year]' always shows the right year. It is a trivial, safe display helper — the output is a computed number, no user input involved.

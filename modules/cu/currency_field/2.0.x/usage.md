Currency Field provides a field type storing an ISO 4217 currency.

---

Currency Field provides a field type for storing a currency chosen from the ISO 4217 standard list (USD, EUR, GBP, …), so content can carry a structured currency value — useful for pricing, finance, and internationalization data alongside amounts.

It's a field provider with no access role of its own; render output is escaped normally. Supports Drupal 8 through 11.

Curated entity block lets editors hand-pick and order entities (from a View-defined pool) rendered in a chosen view mode.

---

Curated entity block provides blocks in which an editor hand-picks and orders specific existing entities — a View defines the selectable pool and the allowed view modes, and the block renders the chosen entities in one view mode. It's ideal for editorially-curated 'featured' or 'related' lists where automatic Views sorting isn't enough.

It's a content-display/block tool with no access role of its own; rendered entities still respect their own access. Depends on core `views`; supports Drupal 10.3+ and 11.

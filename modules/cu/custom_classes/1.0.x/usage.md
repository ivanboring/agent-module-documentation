Custom Classes lets site builders add arbitrary CSS classes to form elements.

---

Custom Classes lets site builders attach custom CSS classes to form elements, so forms can be styled or targeted by JavaScript without custom theme code. Configuration is gated by a settings permission.

It's a form-theming utility; the classes are admin-configured, so restrict the configuration permission to trusted roles. Depends on core `path_alias`; supports Drupal 10 and 11.

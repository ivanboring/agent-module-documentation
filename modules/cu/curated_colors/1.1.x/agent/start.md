# Curated Colors — agent index

Provides **reusable color palettes + a color-picker field** (constrain color choices to a curated/brand set;
works with entities + Drupal Canvas components). `curated_colors_example` submodule. Config at
`entity.curated_color_palette.collection`; provides permissions. Version **1.1.0**. Core `^10.3||^11||^12`.

Content-editing/fields — color value is authored data constrained to the palette; no access role.

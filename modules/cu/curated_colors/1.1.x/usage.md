Curated Colors provides reusable color palettes and a color picker field that works with standard Drupal entities and Drupal Canvas components.

---

Curated Colors provides reusable color palettes and a color-picker field — letting site builders define
curated palettes (a controlled set of brand colors) and offer them via a color-picker field on standard
entities and Drupal Canvas components, so editors pick from approved colors rather than free-form values. It
ships a `curated_colors_example` submodule, is configured at the `curated_color_palette` collection, provides
its own permissions, in the Field types package.

Use it to constrain color choices to a curated palette. It is a content-editing/fields feature; the color
value is authored data (constrained to the palette) and it has no access-control role. Configure the palettes
and add the color field.

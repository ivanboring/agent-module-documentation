Custom Checkboxes provides custom styling for checkbox elements, replacing the default browser checkboxes with styled ones.

---

Custom Checkboxes provides custom styling for checkbox form elements — replacing the default browser
checkbox appearance with a styled version for a more consistent, branded look across browsers. It is a
theming/form-styling feature.

Use it to style checkboxes consistently. It is a front-end/theming feature affecting checkbox appearance;
it does not change form behaviour, data or access. Enable it and (if applicable) configure the styling.

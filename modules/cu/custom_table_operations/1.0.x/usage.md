Render and update custom (non-entity) database tables.

---

Custom Table Operations helps to render custom db tables and update the table content — providing a UI to list and edit rows of arbitrary custom database tables (ones not managed as Drupal entities), useful for legacy or integration tables that still need admin editing.

Because it operates directly on database tables, restrict it to trusted administrators and be careful with the tables it's pointed at. It's a developer/admin utility. Supports Drupal 10 and 11.

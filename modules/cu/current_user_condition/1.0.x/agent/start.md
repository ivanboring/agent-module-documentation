# Current User Profile Condition — agent index

Condition plugin evaluating against the **current authenticated user's profile** — show blocks/logic by
the logged-in user's profile properties. Depends on core `user`. Version **1.0.5**. Core `^9||^10||^11`.

Display/visibility (condition system) — governs where things appear by user, not content access (content
access still applies).

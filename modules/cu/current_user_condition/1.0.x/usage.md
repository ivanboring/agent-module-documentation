Current User Profile Condition provides a condition plugin based on the current authenticated user's profile, for conditional display/logic.

---

Current User Profile Condition provides a Drupal condition plugin that evaluates against the current
authenticated user's profile — so a block (or any condition-aware feature) can be shown/applied based on
properties of the logged-in user's profile. It depends on core User. This enables per-user conditional
display driven by profile data.

Use it to show blocks/content conditionally based on the current user's profile attributes. It is a
display/visibility feature built on the condition system; it governs where things appear based on the user,
not access to content (the content's own access still applies). Configure it where Drupal conditions are
used (block visibility, etc.).

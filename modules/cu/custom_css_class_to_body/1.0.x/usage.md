Custom CSS Class to Body adds personalized CSS classes to the <body> tag of specific node pages and content types.

---

Custom CSS Class to Body adds custom CSS classes to the page `<body>` element for specific node pages
and content types — so themers/site builders can target styling by node or content type via body classes
set through configuration, without custom preprocessing. It is in the Custom package.

Use it to drive body-class-based styling per node/content type. It is a theming feature adding CSS hooks to
the body; it affects markup (body classes), not content or access. Configure the classes for the relevant
nodes/content types.

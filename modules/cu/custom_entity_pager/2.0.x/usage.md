Custom Entity Pager provides a custom entity pager.

---

Custom Entity Pager adds **previous/next ("pager") navigation between entities** — so on an entity page
you can offer links to the previous and next entity in a configurable sequence (for example the order defined
by a View), useful for browsing articles, products or gallery items one after another. It is a content-display
feature.

Use it to add prev/next navigation to entity pages. It is a display/navigation feature; the sequence follows
its configured source (e.g. a View, which enforces its own access) and it has no access-control role.
Configure the pager source and placement.

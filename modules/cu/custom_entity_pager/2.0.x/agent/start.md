# Custom Entity Pager — agent index

Adds **previous/next navigation between entities** from a configurable source (e.g. a View) — browse
articles/products/gallery items in sequence. Version **2.0.0**. Core `^9||^10||^11`.

Content-display/navigation — sequence follows its configured source (a View enforces its own access); no
access role.

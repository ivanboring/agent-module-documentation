Ajax link uses AJAX to load link content into the DOM without a full page load, and can work as infinite scroll.

---

Ajax link uses AJAX to load the content of a link into the current page's DOM instead of a full page
navigation — useful for loading more content in place, and it can function as infinite scroll (loading
the next page's content as the user reaches the end). It is in the User interface package.

Use it to build in-place content loading or infinite-scroll listings without custom JavaScript. It is a
front-end/UI feature affecting how link content loads; the loaded content still respects its own access
(it fetches the linked page/route). Configure which links use AJAX loading.

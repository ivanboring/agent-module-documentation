Ajax Wrapper provides a way to use AJAX functionality and callbacks to refresh wrapper elements on the page.

---

Ajax Wrapper provides a helper for AJAX — a way to define wrapper elements and refresh them via AJAX
callbacks, so parts of a page can update without a full reload. It gives developers a reusable pattern for
AJAX-refreshing content wrappers.

Use it as a developer utility for AJAX-updating page regions. It is a developer/front-end feature providing
AJAX plumbing; the refreshed content respects its own access (it re-renders content the user can see), and
it has no access-control role. Use the wrapper/callback API where AJAX refresh is needed.

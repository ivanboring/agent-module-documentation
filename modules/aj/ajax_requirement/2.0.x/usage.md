Ajax requirement provides a Form API utility to make field required-state respond dynamically (AJAX/states) based on other inputs.

---

Ajax requirement is a Form API utility that helps make a field's required state respond dynamically —
so whether a field is required can change based on other form inputs, updated via AJAX/Form API states.
This supports conditional-requirement forms without custom JavaScript for the required logic.

Use it where a field should be required only under certain conditions (e.g. "if X is selected, Y becomes
required"). It is a forms/developer utility affecting validation/required behaviour; it operates on form
handling and has no content or access role. Apply it within the relevant form definitions.

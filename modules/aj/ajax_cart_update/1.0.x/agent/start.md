# AJAX Cart Update — agent index

Adds **AJAX to the Commerce cart form** — update quantities + recalculate totals dynamically (no full reload).
Depends on core `views`. Version **1.0.1**. Core `^10.3||^11`.

E-commerce/UX — affects the cart form; operations still go through Commerce's normal handling/access. No
access role.

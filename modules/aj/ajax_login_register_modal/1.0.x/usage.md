Ajax Login and Register Modal shows core login/register/reset forms in a modal dialog.

---

Ajax Login and Register Modal extends the user login, registration and password-reset experience by rendering them in an AJAX modal dialog — so visitors can log in or register without a full page navigation, improving the auth UX. It wraps core's user forms (which handle authentication).

It's a UX wrapper around core's authentication forms (no custom auth logic that bypasses core), so login/registration security follows core. Supports Drupal 8.8 through 11.

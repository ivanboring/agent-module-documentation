Ajax Callbacks Field Formatter turns Link fields into AJAX-triggering elements.

---

Ajax Callbacks Field Formatter provides a field formatter that alters the Link field type to render links as AJAX callbacks — so a Link field value can trigger an AJAX callback (in-place update) instead of a normal page navigation, useful for interactive link behaviors without custom code.

It's a display formatter with no content or access role of its own; the AJAX callback runs with the current user's privileges. Supports Drupal 9, 10, and 11.

Ajax Dependency provides a helper service for easy ajax dependencies.

---

Ajax Dependency provides a helper service that makes it easy to build AJAX dependencies between form
elements — so one element can update/refresh another via AJAX without repetitive boilerplate. It ships an
`ajax_dependency_example` submodule.

Use it as a developer utility for AJAX-dependent form elements. It is a developer/Form-API feature providing
AJAX plumbing; refreshed content respects its own access and it has no access-control role. Use the service
in your forms.

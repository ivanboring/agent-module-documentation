# AJAX Placeholder — agent index

A **render element that replaces itself via an AJAX callback** (render a placeholder first, swap in expensive/
personalized content — perceived perf + cacheability). Version **1.0.2**. Core `^10||^11`.

Developer/render — callback runs with the current user's privileges, output escaped normally; no content/
access role.

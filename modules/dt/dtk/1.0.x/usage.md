Drush DTK provides opt-in token-saving output compression for common Drush commands, built for AI agents.

---

Drush DTK provides opt-in output compression for common Drush commands — reducing the verbosity/token
count of command output, built for AI agents that consume Drush output (enable via `--ai-compress`,
`DTK_COMPRESS=1`, or config). It provides Drush commands, in the Drush DTK package.

Use it when an AI agent (or a token-constrained consumer) runs Drush and you want more compact output. It is
a developer/CLI tooling feature affecting Drush output formatting; it has no content or access role. Enable
compression via the flag/env/config.

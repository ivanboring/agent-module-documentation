PapaParse provides the PapaParse JavaScript CSV-parsing library as a Drupal library for other modules to use.

---

PapaParse is a fast in-browser CSV parser; modules that process CSV client-side need it available. This module packages PapaParse as a Drupal library for others to depend on. It is a library-provider with no functionality or security surface of its own — it makes the library available; what uses it defines the behaviour.

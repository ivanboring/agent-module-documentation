Paragraphs Tabs Widget displays each paragraph in a multi-value paragraphs field as a tab, giving a tabbed editing interface.

---

Editing a long list of paragraphs in one stacked form is unwieldy. Paragraphs Tabs Widget presents each paragraph as a tab, so editors switch between them rather than scrolling one long form. It is an editorial-UX widget with no security surface; it changes the editing interface, not what is stored or who can edit.

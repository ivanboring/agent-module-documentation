Event creates Event Entities for managing Events.

---

Event provides a dedicated Event entity type — for managing events (with dates via Datetime Range) as
first-class content entities, rather than repurposing nodes. It depends on core Datetime Range, provides its
own permissions.

Use it to manage events as their own entity type. It is a content/entity feature; events are content
governed by the entity's access and its permissions (gate who can create/edit events). It has no other
access-control role. Configure the Event entity and fields.

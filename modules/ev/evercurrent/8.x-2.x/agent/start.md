# Evercurrent — agent index

**Sends data about required updates to the Evercurrent server**. Depends on core `update`. Provides permissions.
Version **8.x-2.x** (dev). Core `^10.1||^11`.

Monitoring integration — update/version info is **fingerprinting data** sent externally (egress); securely-stored
token, trusted endpoint, HTTPS. No access role beyond permission.

Animated Counter provides animated number counters.

---

Animated Counter provides **animated number counters** — a block that animates a number counting up to a
target (e.g. "10,000+ customers") when scrolled into view, using Block Animate. It depends on core Block and
Block Animate.

Use it to display animated stat counters. It is a content-display/UX feature; the numbers are admin-configured
and it has no content or access role. Place and configure the counter block.

Anime.js integrates the Anime.js lightweight JavaScript animation library as a Drupal library for other code to use.

---

Anime.js is a small, capable JS animation library. This module packages it as a Drupal library for themes/modules to depend on. It is a library-provider with no functionality of its own. Confirm the library is served locally if third-party origins are a concern; the animation behaviour is defined by the code that uses it, which should respect prefers-reduced-motion.

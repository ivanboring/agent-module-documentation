Animate Fields AOS provides options to animate fields when they scroll into view, using the AOS JavaScript library.

---

Animate Fields AOS adds scroll-triggered animations to field output — using the AOS (Animate On
Scroll) library, fields animate (fade, slide, etc.) as the user scrolls them into view. It provides
per-field animation options and its own permissions.

Use it to add subtle entrance animations to content fields for a more dynamic page. It is a
content-display/theming feature affecting how fields render/animate; the stored value is unchanged and it
has no access-control role. Configure the animation options on the field's display.

# Animate Fields AOS — agent index

Scroll-triggered **field animations** via the **AOS (Animate On Scroll)** library (fade/slide fields into
view). Provides permissions. Version **2.0.0**. Core `^9||^10||^11`.

Content-display/theming — affects rendering/animation, not stored values/access. Configure on the field's
display.

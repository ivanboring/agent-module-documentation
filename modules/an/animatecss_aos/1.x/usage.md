AnimateCSS AOS adds Animate On Scroll (AOS) options to the AnimateCSS UI, letting animations trigger as elements scroll into view.

---

AnimateCSS provides animations; AOS (Animate On Scroll) triggers them when an element enters the viewport. AnimateCSS AOS adds AOS options to the AnimateCSS UI. It is a front-end animation enhancement with no security surface. Confirm scroll animations suit accessibility (respect prefers-reduced-motion) and do not harm performance on long pages.

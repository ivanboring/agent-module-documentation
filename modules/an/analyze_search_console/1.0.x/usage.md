Analyze Search Console displays Google Search Console performance data.

---

Analyze: Search Console **displays Google Search Console performance data** — surfacing search
impressions/clicks/queries for content within the Analyze module's reporting. It depends on the Analyze and Key
modules, provides its own permissions, in the Analyze package.

Use it to see Search Console data in Drupal. It is an SEO/analytics integration. Security/data handling: it
authenticates to the **Google Search Console API** with **credentials stored via the Key module** (secret, HTTPS)
and fetches your site's search-performance data (Google account data). Its report is gated by its permission. It
has no access-control role beyond that. Configure the Search Console credentials (via Key).

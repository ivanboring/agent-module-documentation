Annoying Popup displays a configurable, cookie-aware popup overlay.

---

Annoying Popup displays a configurable **popup overlay** to visitors — with cookie awareness so a visitor
who has dismissed it isn't shown it again (until the cookie expires). Popups are configuration entities
(managed at `/admin/config/system/annoying_popup`), useful for announcements, consent prompts, promotions or
newsletter calls-to-action. It provides its own permissions (`administer annoying popups`), in the User
interface package.

Use it for dismissible site popups. It is a user-engagement/UI feature; the popup content is authored by
admins (rendered markup — keep it trusted), and it has no access-control role beyond its permission. Note it
sets a browser cookie to remember dismissal (a minor privacy/consent consideration). Configure the popup(s).

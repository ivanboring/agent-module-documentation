Analyze PostHog surfaces PostHog analytics data in the Analyze dashboard.

---

Analyze PostHog displays PostHog analytics data — pageviews, visitors, sessions — for content within Drupal, integrating with the Analyze module so editors can see PostHog metrics alongside content without leaving Drupal.

PostHog API credentials are stored via the Key module (env-backed). Access is gated by `access posthog analytics`. Depends on `analyze` (>=1.1.0) and `key`; supports Drupal 10.3+ and 11.

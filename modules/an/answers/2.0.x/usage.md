Answers provides a Stack-Overflow-style Q&A system with questions, answers and voting.

---

Answers is a Question & Answer project for Drupal — providing a Q&A system where users post questions and answers (with voting/best-answer selection), building a community knowledge base similar to Stack Overflow. It ships an answers_core submodule with the core functionality.

It's a community/engagement feature; posting and voting follow its permission model — grant appropriately. Supports Drupal 9, 10, and 11.

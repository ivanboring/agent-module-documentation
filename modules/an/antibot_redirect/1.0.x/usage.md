AntiBot Redirect gates external redirects/pages behind reCAPTCHA to block bots.

---

AntiBot Redirect protects specific pages from bots by requiring reCAPTCHA — inserting a reCAPTCHA challenge before external redirects (or on protected pages), so automated bots are stopped from following redirects or accessing gated pages, reducing bot abuse.

It builds on the reCAPTCHA module (keys stored securely). Configuration is admin-gated. Depends on `recaptcha`; supports Drupal 10 and 11.

Views Dynamic Fields and Filters lets site builders enable or disable a view's fields and filters dynamically based on configuration or context.

---

A single view sometimes needs to show different fields or apply different filters depending on context — a role, a setting, a display. Views Dynamic Fields and Filters lets fields and filters be toggled dynamically rather than building multiple near-identical views. It is a site-building convenience. The security note is the standard Views one: toggling a field's display does not change access — a field hidden dynamically is not access-protected, and a filter toggled off may broaden results, so confirm that dynamic changes do not inadvertently expose data (removing a filter that was restricting results, or showing a field with sensitive data).

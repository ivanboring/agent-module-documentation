Views Expandable Table is a Views style plugin rendering results as a table where each row can expand to reveal additional detail.

---

A table that shows key columns and lets a user expand a row for more detail is a clean way to present dense data without overwhelming the initial view. Views Expandable Table provides that as a Views style plugin — rows expand to reveal extra fields. It is a display style with no security surface; it renders what the view already exposes, so the expanded detail is subject to the same field access as any Views output.

Views Color Scales automatically enhances numeric Views fields with optional color scales, shading cells by value like a heatmap.

---

A table of numbers reads better with colour — high values in one shade, low in another, a heatmap. Views Color Scales adds optional colour scales to numeric Views fields, shading by value. It is a display enhancement with no security surface; it colours what the view already shows. Confirm the colour scale is accessible (colour alone should not be the only signal for colour-blind users) and that the scale's min/max suit the data range.

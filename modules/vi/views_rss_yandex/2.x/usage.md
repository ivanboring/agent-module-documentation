Views RSS: Yandex provides Yandex XML namespace and item elements for Views RSS feeds, for Yandex-specific feed formats (Turbo/news).

---

Yandex consumes feeds in specific formats (Yandex Turbo pages, Yandex News) with its own XML namespace and elements. Views RSS: Yandex adds those to Views RSS feeds, so a site can produce Yandex-compatible feeds. It is an SEO/feed feature with no security surface. Confirm the feed includes only public content intended for Yandex, and that the Yandex-specific elements are configured to their current spec.

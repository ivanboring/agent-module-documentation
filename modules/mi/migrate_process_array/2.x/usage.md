Migrate Process Array provides array-centric process plugins for Migrate — manipulating arrays during a migration.

---

Migrations often need to reshape arrays — merge, filter, flatten, key-by. Migrate Process Array provides process plugins for those array operations. It is developer/CLI migration infrastructure with no request-time security surface; the migration is authored by a developer and run under Drush.

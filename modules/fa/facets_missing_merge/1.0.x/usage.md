Facets Missing Merge provides a facet processor that allows the missing facet item to be merged into another item.

---

Facets Missing Merge provides a Facets processor that merges the "missing" facet item (results with no
value for the faceted field) into another facet item — so instead of a separate "missing/none" option, those
results are folded into a chosen existing facet value. It depends on the Facets module, in the Search package.

Use it to tidy faceted-search output by merging the missing item. It is a site-search/facets feature affecting
facet presentation/aggregation; it shapes how facets display and has no access-control role. Configure the
merge on the facet.

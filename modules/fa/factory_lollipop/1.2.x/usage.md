Factory Lollipop generates short-lived test data using the factory pattern.

---

Factory Lollipop is a developer/testing tool that uses the factory pattern to generate short-lived test data structures (entities, fields, fixtures) — making it easy to set up consistent test data in automated tests or local development without hand-crafting each fixture.

It's a developer/testing utility with no content or access role in production. Depends on core `user`; supports Drupal 10.5+ and 11.

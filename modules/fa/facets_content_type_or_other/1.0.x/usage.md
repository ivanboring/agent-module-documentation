Facets Content type or Other provides a facet to display Content types with an 'Other' value.

---

Facets Content type or Other provides a facet processor/type for the Facets module that displays content
types as facet options with an **"Other"** catch-all — so a faceted listing can offer specific content types
plus an "Other" bucket for the rest, tidying content-type faceting. It depends on the Facets module, in the
Search package.

Use it for content-type faceting with an Other bucket. It is a site-search/facets feature shaping facet
display; the listed content respects its own access and it has no access-control role. Configure the facet.

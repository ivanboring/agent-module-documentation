# Facets Content type or Other — agent index

A Facets facet displaying **content types with an "Other" catch-all** value (specific types + an Other bucket
for the rest). Depends on `facets`. Version **1.0.2-alpha1**. Core `^10||^11`.

Site-search/facets — shapes facet display; listed content respects its own access; no access role.

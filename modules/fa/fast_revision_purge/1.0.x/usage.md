Fast Revision Purge plans and purges node/paragraph revisions in bulk.

---

Fast Revision Purge **bulk-purges old revisions** — an ultra-fast planner and purger for node and paragraph
revisions, with dry-run planning and batch execution, to control revision-table growth. It depends on core Node.

Use it to prune revision history. It is an administration/maintenance tool with an important caution: deleting
revisions is **destructive and irreversible** — it removes historical versions (and their content), so use the
**dry-run** first, back up before purging, keep the tool to trusted admins, and be aware you may lose audit/rollback
history. It has no access-control role. Configure and run the purge.

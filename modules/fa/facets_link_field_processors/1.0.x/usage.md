Facets Link Field Processors provides Facets processors specific to the core Link field.

---

Facets Link Field Processors provides **Facets processors for the core Link field** — e.g. relabelling a
link-field facet's raw URI with the referenced entity's translated label, so facets built on link fields read
better. It depends on the Facets module, in the Search package.

Use it to improve link-field facets. It is a search/display feature (reviewed CLEAN): it relabels facet values
that already come from search results the user is permitted to see, adding no access bypass, and results still
respect the underlying index/View access. It has no access-control role. Add the processor to a facet.

Facets Max Facets enforces a global maximum number of facets.

---

Facets Max Facets **enforces a global maximum number of active facets** — limiting how many facet filters a
user can apply at once in Search API faceted search, to keep queries/URLs manageable and avoid performance/UX
degradation from too many simultaneous facets. It depends on the Facets module, in the Search package.

Use it to cap simultaneous facets. It is a site-search feature affecting facet behaviour; results follow the
search index's access and it has no access-control role. Configure the maximum facet count.

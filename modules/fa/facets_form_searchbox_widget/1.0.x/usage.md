Facets Form Searchbox Widget extends facets with a searchbox widget.

---

Facets Form Searchbox Widget **adds a searchbox widget to the Facets module** — letting users type to
filter a long list of facet values (find-as-you-type within a facet) in a facets form, improving usability of
faceted search. It extends the core Facets module.

Use it to make long facet lists searchable. It is a site-search feature affecting the facet widget; results
follow the search index's access and it has no access-control role. Configure the searchbox widget on a facet.

# Facets Form Searchbox Widget — agent index

Extends the **Facets module with a searchbox widget** to filter (find-as-you-type) long facet-value lists.
Version **1.0.x** (dev). Core `^9.2||^10.0||^11`.

Site-search — affects the facet widget; results follow the index's access; no access role.

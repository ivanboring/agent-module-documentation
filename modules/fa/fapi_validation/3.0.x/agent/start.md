# FAPI Validation — agent index

A **declarative validation layer for Form API** (reusable email/numeric/length/regex validators vs custom
`#element_validate`). Example submodule. Provides permissions. Version **3.0.0**. Core `^10.3||^11`.

Developer/Form API — improves input validation ergonomics; remember **validation ≠ sanitization** (escape
output regardless). No access role beyond permission.

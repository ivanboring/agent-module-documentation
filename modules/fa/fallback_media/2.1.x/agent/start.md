# Fallback Media — agent index

Falls back to **another media/entity when a media field is empty** (show a configured default instead of a gap
— consistent layouts). Depends on core `media`. Version **2.1.0**. Core `^8||^9||^10||^11`.

Media/display — fallback is admin-configured; no content/access role.

Fallback Media falls back to another entity if the field is empty.

---

Fallback Media **displays a fallback media item when a media field is empty** — so a listing/teaser
without its own image (or other media) shows a configured default instead of a gap, keeping layouts consistent.
It depends on core Media, in the Media package.

Use it to provide default media for empty fields. It is a media/display feature; the fallback is
admin-configured and it has no content or access role. Configure the fallback media on the field.

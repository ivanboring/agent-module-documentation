# Fasttoggle — agent index

One-click **toggle links** for node published/promoted/sticky and comment/user status (flip without the
edit form). Depends on core `node`, `comment`. Config at `fasttoggle.settings`; provides permissions.
Version **4.1.0**. Core `^10.1||^11`.

Editing convenience — **each toggle is permission-gated** (grants no new capability, just faster).
Confirm permissions match your moderation model.

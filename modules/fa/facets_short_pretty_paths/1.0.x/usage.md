Facets Short Pretty Paths shortens the pretty-path URLs generated by the Facets Pretty Paths module.

---

Facets Short Pretty Paths shortens the URLs produced by Facets Pretty Paths — the module that gives
facets clean, human-readable URLs instead of query parameters. On sites with many active facets those
pretty paths can grow long; this module compresses them into shorter, tidier URLs while keeping them
readable and bookmarkable. It depends on Facets Pretty Paths.

Use it where faceted-search URLs have become unwieldy and you want shorter canonical paths for sharing
and SEO. It is a routing/URL presentation feature layered on Facets Pretty Paths; it changes URL form,
not access or results. Configure it alongside the pretty-paths setup.

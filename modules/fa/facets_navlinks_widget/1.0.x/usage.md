Facets Navigation Links Widget renders search facets as plain navigation links.

---

Facets Navigation Links Widget provides a widget for the Facets module that displays facet values as simple navigation links (rather than checkboxes or dropdowns) — a clean, SEO-friendly way to present faceted navigation in menus or sidebars.

It's a Facets display widget with no content or access role of its own. Depends on `facets`; supports Drupal 10.1+ and 11.

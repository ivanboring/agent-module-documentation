Facebook Block embeds Facebook content (a page feed, like box) as a block via the Facebook social plugins.

---

Showing a Facebook page feed or like box on a site is a common social element. Facebook Block embeds Facebook's social plugins as a block. It loads Facebook's third-party script, which is the privacy consideration: Facebook social plugins track visitors (even without interaction), so the embed should be gated behind cookie/tracking consent where required, and it adds Facebook as a third-party origin on every page it appears. For a site wanting Facebook content, it embeds it; handle the consent/privacy dimension.

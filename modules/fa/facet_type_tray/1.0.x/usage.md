Provides Type Tray content-type groupings as a Search API facet.

---

Facet Type Tray provides type trays as a facet — exposing the Type Tray module's content-type groupings/categories as a Search API facet, so search/listing pages can offer a facet that filters by the type-tray grouping a content type belongs to. Depends on `search_api`, `facets`, and `type_tray`; supports Drupal 10 and 11.

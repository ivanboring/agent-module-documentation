API Orchestrator provides API orchestration with queueing and retry.

---

API Orchestrator provides an **API-orchestration framework** — coordinating calls to external APIs with
request **queueing, retry logic**, REST/GraphQL support and service management, so integrations are reliable and
resilient. It provides its own permissions, in the API Orchestrator package (core 11).

Use it as a developer foundation for resilient API integrations. It is a developer/integration framework.
Security/data handling: it calls **external APIs** (you own the endpoints and **credentials** — store as secrets,
HTTPS), and orchestrated flows may carry sensitive data — build them with care and gate management by its
permission. It has no access-control role of its own beyond that permission. Configure the orchestration
services.

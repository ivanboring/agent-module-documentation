Project Browser API Browser adds external-API-backed sources to Project Browser.

---

Project Browser API Browser lets you create Project Browsers that connect with external APIs — so the Project Browser UI can list/install items sourced from arbitrary external API endpoints (not just drupal.org), useful for private module registries or curated catalogs.

External API endpoints/credentials are admin-configured (store securely, env-backed). Administration is gated by `administer api_browser_service`. Depends on core `project_browser`; supports Drupal 11.2+.

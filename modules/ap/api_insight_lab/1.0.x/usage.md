API Insight Lab provides in-Drupal API testing with load tests and request chaining.

---

API Insight Lab is a comprehensive API testing suite — supporting load testing, request chaining, and other advanced testing features inside Drupal, so developers can test and profile REST APIs (internal or external) without leaving the site.

Because it can make arbitrary requests (including load tests), restrict access to trusted developers and mind that it can hit external/internal endpoints. Depends on core `rest`; supports Drupal 10 and 11.

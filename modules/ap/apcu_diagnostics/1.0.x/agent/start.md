# APCu Diagnostics — agent index

Integrates **APCu diagnostic tools** (`krakjoe/apcu`) into Drupal — inspect APCu cache usage/hit-miss/
entries. Provides permissions. Version **1.0.0**. Core `^9||^10||^11`.

Admin/developer diagnostic (reads APCu state; no content/access effect). Grant the permission to
trusted admins only (cache internals reveal operational detail).

# Apigee Extras — agent index

Provides **extended functionality for the Apigee Edge (API management/developer portal)** integration. Depends on
`apigee_edge`. Version **1.0.0-beta1**. Core `^10.3||^11.1`.

Integration — works with the **Apigee Edge API** (credentials in Apigee Edge; secrets, HTTPS); manages developer-
app/API-key data (secrets). No access role of its own beyond Apigee Edge's.

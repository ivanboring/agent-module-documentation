Apigee Extras provides extended functionality for Apigee Edge.

---

Apigee Extras **provides extended functionality for Apigee Edge** — adding features on top of the Apigee
Edge module (Google's API management platform) for developer portals (apps, API products, analytics). It depends
on the Apigee Edge module, in the Apigee package.

Use it to enhance an Apigee developer portal. It is an integration feature. Security/data handling: it works with
the **Apigee Edge API** (the base Apigee Edge module holds the **credentials** — store as secrets, HTTPS) and
manages developer-app/API-key data (which includes **API secrets** for portal developers) — handle that data
carefully. It has no access-control role of its own beyond Apigee Edge's. Configure it alongside Apigee Edge.

API Data Connector lets fields autocomplete/populate from external API data.

---

API Data Connector allows APIs to be connected to Drupal fields with autocomplete features — so a field can offer autocomplete suggestions or values pulled from an external API (via Select2), letting editors pick from live remote data when filling fields.

External API endpoints/credentials should be stored securely (env-backed). Depends on the `select2` module; requires Drupal 11.

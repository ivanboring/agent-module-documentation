API Tester provides a Postman-style in-Drupal REST API testing UI.

---

API Tester is a complete REST API testing tool similar to Postman — letting developers build, send, and inspect REST requests (with environments/switching) directly in Drupal, useful for testing the site's own APIs or external services during development.

Because it can send arbitrary requests, restrict access to trusted developers. Permissions cover use (`use api tester`) and administration (`administer api tester`). Depends on core `user` and `system`; supports Drupal 10 and 11.

Append File Info appends file info (extension, size) to links to local managed files.

---

Append File Info **appends file information** — the file extension and size — to links that point at local
managed files, so a download link reads e.g. "Annual report (PDF, 1.2 MB)" automatically, improving clarity
and accessibility of file links. It works on links to managed files.

Use it to annotate file links with type/size. It is a content-display/accessibility feature affecting how file
links render; the info comes from the managed file's own metadata and it has no content or access role. Enable
it to append file info to links.

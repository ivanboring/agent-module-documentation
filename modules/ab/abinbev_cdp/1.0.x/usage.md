AbInBev CDP connects Drupal to the AB InBev CDP with multi-configuration support.

---

AbInBev CDP provides integration with the AB InBev Customer Data Platform (CDP) — pushing/syncing customer data and events to the CDP, with support for multiple configurations (e.g. per brand/market). It's a bespoke marketing-data integration for AB InBev sites.

CDP API credentials should be stored securely (env-backed); customer data is sent to the CDP (privacy). Supports Drupal 9, 10, and 11.

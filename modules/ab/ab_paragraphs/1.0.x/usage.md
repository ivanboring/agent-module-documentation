A/B Paragraphs provides an A/B test paragraph type with frontend session-based variant selection.

---

A/B Paragraphs provides an **A/B-test paragraph type** — editors add variant content, and the front end
picks a variant per visitor (**session-based**), so you can A/B test blocks of content without a full
experimentation platform. It is in the Custom package.

Use it for lightweight content A/B testing. It is a content-editing/user-engagement feature; the variants are
authored content and the selection is session-based (a minor privacy/cookie consideration), and it has no
access-control role. Configure the A/B paragraph variants.

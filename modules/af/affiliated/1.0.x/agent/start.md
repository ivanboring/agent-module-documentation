# Affiliated — agent index

Provides **common affiliate-marketing functionality** (referrals/commissions; `affiliate_commerce`,
`affiliate_registrations`, `affiliate_webform` submodules). Depends on core `views`, `user`. Provides
permissions. Version **1.0.0-alpha3**. Core `^10.1||^11`.

Marketing/user-engagement — affiliate/commission data is personal/financial (gate admin perms; don't trust
referral codes for security). No access role beyond permissions.

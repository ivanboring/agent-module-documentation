Afterburner provides task/queue processing.

---

Afterburner is a **task/queue processing framework** — providing tasks, commands and event subscribers to
run deferred/background work, so heavy operations can be queued and processed after the request. It works across
core 10–11.

Use it as a developer foundation for background tasks. It is a developer/automation module; tasks run with the
privileges of whatever queues/triggers them, and it has no access-control role. Define and run Afterburner
tasks.

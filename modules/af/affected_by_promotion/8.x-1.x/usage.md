Affected By Promotion gives you the entities that are affected by a promotion.

---

Affected By Promotion identifies which Commerce entities are affected by a given promotion — so store
managers can see which products/orders a promotion applies to. It depends on Commerce Promotion, in the
Commerce (contrib) package.

Use it to audit a promotion's reach. It is an e-commerce/reporting feature reading promotion applicability;
it is informational and has no access-control role. View which entities a promotion affects.

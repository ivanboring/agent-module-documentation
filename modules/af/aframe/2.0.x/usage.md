A-Frame Integration brings the A-Frame WebVR/WebXR framework into Drupal as fields and formatters.

---

A-Frame Integration wires the A-Frame WebVR/WebXR framework into Drupal, providing field widgets and formatters so editors can attach and render immersive 3D/VR scenes (models, entities, cameras) on content. It lets a site publish interactive 3D/VR experiences without hand-writing the front-end scene bootstrap.

It is a display/media-embedding feature. Scene markup and asset URLs are author-controlled, so the usual field-input trust applies; render output should be escaped/sanitised as normal. A developer/editorial feature with no access role of its own.

Automatic Site Icon Picker provides an automatic site-icon (favicon) picker/formatter for link fields.

---

Automatic Site Icon Picker **provides an automatic site-icon (favicon) picker** — for a link field, it
fetches/derives the target site's favicon so links can display the destination site's icon automatically. It
depends on core Field, in the Link package.

Use it to show favicons on links. It is a content-display feature. Note: fetching a remote site's favicon
involves a request to the **external site** (public asset) — it displays third-party icons; ensure caching and
that it degrades gracefully. It has no content or access role. Configure the icon picker on a link field.

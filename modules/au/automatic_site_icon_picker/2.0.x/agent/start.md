# Automatic Site Icon Picker — agent index

Provides an **automatic site-icon (favicon) picker/formatter for link fields** (display the destination site's
icon). Depends on core `field`. Version **2.0.1**. Core `^10||^11`.

Content-display — fetches third-party favicons (public assets; cache/degrade); no content/access role.

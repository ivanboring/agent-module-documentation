# autotagger — agent index

**Core framework for automatically tagging content** with taxonomy terms via configurable actions —
enable a submodule (e.g. search-in-text) or custom plugin for the actual logic. Depends on core
`taxonomy`. Version **1.0.4**. Core `^9||^10||^11`.

Automation/content — writes taxonomy references onto content; review results for accuracy. No access
role.

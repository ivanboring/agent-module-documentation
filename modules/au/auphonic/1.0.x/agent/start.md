# Auphonic — agent index

A **core module for calling the Auphonic audio-post-production API** via the AI module. Depends on `ai`. Version
**1.0.0-beta3**. Core `^10||^11`.

AI/media — **sends audio to the Auphonic API** (egress; audio can be sensitive); **API key** as a secret (env/Key,
HTTPS). No access role.

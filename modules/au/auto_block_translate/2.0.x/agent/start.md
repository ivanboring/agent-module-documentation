# Auto Block Translation — agent index

**Automatically translates custom blocks** via a configured translator. Config at
`auto_node_translate.settings`. Version **2.0.0**. Core `^10.2||^11`.

Multilingual — sends block content to the (often external) translator (data-handling; auto-trigger removes
the human gate — review translations). No access role.

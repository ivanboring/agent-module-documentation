Auto Block Translation translates custom blocks automatically using a configured translation service.

---

Auto Block Translation automatically translates custom (content) blocks — sending block content to a
configured translation service so block translations are created without manual effort. It is configured at
`auto_node_translate.settings`, in the Multilingual package.

Use it to auto-translate custom blocks. Operational/security notes: block content is sent to the configured
(often external machine-translation) service — a data-handling consideration, and auto-translation removes
the human "should this be sent?" gate, so be deliberate about it; auto-created translations may need review.
It has no access-control role. Configure the translator and which blocks translate.

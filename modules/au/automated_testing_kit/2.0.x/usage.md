Automated Testing Kit provides reusable tests and helper functions for end-to-end automated testing with Cypress and Playwright.

---

Automated Testing Kit provides a toolkit of reusable end-to-end tests and helper functions for
testing Drupal sites with Cypress and Playwright — common flows (login, content creation, etc.) and
utilities that test suites can build on, so teams don't reimplement the same E2E scaffolding. It ships
an `automated_testing_kit_demo` submodule and provides Drush commands.

Use it to bootstrap E2E test coverage with Cypress/Playwright against a Drupal site. It is a
developer/testing tool used in development and CI; the helpers and demo are for test environments. As a
testing kit it may create/log in test users and content during runs — keep it and its demo out of
production. It provides Drush commands to support the testing workflow.

Auto Config Form generates a custom module's configuration form automatically from its config schema.

---

Auto Config Form **generates a custom module's configuration (settings) form automatically** — building an
admin config form from a module's config schema, so developers don't hand-write settings forms. It works on core
11.

Use it as a developer aid to scaffold config forms. It is a developer/site-building tool; the forms it generates
are admin-gated config forms and it has no content or access role. Use it to generate config forms.

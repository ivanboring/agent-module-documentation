Auto entity form mode automatically registers form modes so they can be used in custom code.

---

Auto entity form mode automatically registers entity form modes — so form modes defined in the site are
available to custom code/modules without manual registration, easing programmatic use of alternate entity
edit forms. It is a developer utility.

Use it when custom code needs to reference form modes reliably. It is a developer/entity-API feature; it
registers form modes and has no content or access role. Enable it to auto-register form modes.

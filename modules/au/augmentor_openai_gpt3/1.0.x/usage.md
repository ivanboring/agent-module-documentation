Augmentor OpenAI GPT provides integration of Augmentor with OpenAI GPT.

---

Augmentor OpenAI GPT integrates **OpenAI GPT** as an **Augmentor** provider — so Augmentor's AI-augmentation
actions (summarize, rewrite, classify, etc.) can be powered by OpenAI's models. It depends on the Augmentor
module, in the Augmentor package.

Use it to power Augmentor with OpenAI. It is an AI/integration feature. Security/data handling: it **sends
content to OpenAI** to process (external data egress — confirm acceptable for the content), and it authenticates
with an **OpenAI API key** — store it as a **secret** (env/Key), over HTTPS. It has no access-control role.
Configure the OpenAI credentials and model.

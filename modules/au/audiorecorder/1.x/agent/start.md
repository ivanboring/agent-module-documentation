# Audio Recorder (audiorecorder) — agent index

File-field **widget that records audio in the browser**. Version **1.0.1**. Submodule
`audiorecorder_webform_integration`. Needs HTTPS + user permission (browser media API). Recorded
file is access-controlled like any upload — use private storage if sensitive.

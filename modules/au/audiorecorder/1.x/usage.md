Audio Recorder provides a file-field widget that records audio in the browser, with a Webform integration submodule.

---

Collecting audio — a voice note, a pronunciation, an interview clip — usually means recording elsewhere and uploading. Audio Recorder adds a widget that records audio directly in the browser and saves it to a file field, with a Webform integration submodule. It uses the browser's media APIs, which require HTTPS and user permission. No unusual server-side security surface; the recorded file is stored and access-controlled like any file upload, so confirm the field's file settings (allowed extensions, private storage if sensitive).

Auto Link provides a custom field formatter that auto-links text.

---

Auto Link provides a **field formatter that automatically turns URLs (and configured text) into links** —
detecting URLs in a text field's output and rendering them as clickable links without manual markup. It depends
on core Filter.

Use it to auto-link plain-text URLs. It is a content-display feature affecting field rendering; output goes
through filtering and it has no content or access role. Apply the auto-link formatter to a field.

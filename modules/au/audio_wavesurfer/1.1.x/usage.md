Audio Wavesurfer provides audio visualization.

---

Audio Wavesurfer provides **audio waveform visualization and playback** using wavesurfer.js — rendering an
audio file as an interactive waveform player, with an `audio_wavesurfer_clips` submodule for clip regions. It
depends on core Media, in the Audio package.

Use it to display audio as waveforms. It is a media/content-display feature; audio files follow core media/file
access and it has no access-control role. Configure the waveform player on audio fields.

# Auto Retina — agent index

Automatically generates **high-magnification (retina/2x) derivatives for image styles** (crisp images on
high-DPI displays without manual doubled styles). Config at `auto_retina.admin_settings`. Version **2.0.3**.
Core `^9||^10||^11`.

Media/display — affects image derivative generation; no content/access role.

Auto Retina provides automatic magnification derivatives for image styles.

---

Auto Retina automatically creates high-magnification ("retina" / 2x) derivatives for image styles — so
images look crisp on high-DPI/retina displays without manually defining doubled image styles. It is
configured at `auto_retina.admin_settings`, in the Media package.

Use it to serve retina image derivatives automatically. It is a media/display feature affecting image
derivative generation; it has no content or access role. Configure which image styles get retina
derivatives.

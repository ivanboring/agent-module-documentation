# Auto heading ids — agent index

Text-format **filter that auto-adds `id` attributes to headings** (from heading text) — headings become
anchor targets (jump-to-section, TOC, deep links). Version **2.0.0-beta3**. Core `^8||^9||^10||^11`.

Content-display/filter — affects output, not stored values/access. Add to the text format(s).

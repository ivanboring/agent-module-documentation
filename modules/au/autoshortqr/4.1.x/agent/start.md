# AutoShortQR — agent index

**Auto-generates a self-referencing QR code** (encodes the current page URL) via `drupal/barcode`. Depends on
`barcodes`. Version **4.1.1**. Core `^10||^11`.

Content-display/user-engagement — encodes a public page URL; no content/access role.

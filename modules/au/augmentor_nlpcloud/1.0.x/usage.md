Augmentor: NLP Cloud integrates NLP Cloud as an Augmentor provider (NLP tasks: summarize, classify, generate).

---

Augmentor: NLP Cloud **integrates NLP Cloud as an Augmentor provider** — running text through NLP Cloud's
models (summarization, classification, generation, etc.) within Augmentor AI-augmentation workflows. It depends
on the Augmentor module, in the Augmentor package.

Use it to process text with NLP Cloud. It is an AI/integration feature. Security/data handling: it **sends content
to the NLP Cloud API** (external egress — confirm acceptable) and authenticates with an **NLP Cloud API key**
(store as a secret — env/Key — over HTTPS). It has no access-control role. Configure the NLP Cloud credentials.

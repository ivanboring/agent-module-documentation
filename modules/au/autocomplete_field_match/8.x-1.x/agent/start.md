# Autocomplete Field Match — agent index

Enables **autocomplete matching on entity fields other than the title** (reference/suggest by SKU/email/etc.).
Depends on core `field`, `field_ui`. Version **8.x-1.0-alpha6**. Core `^8||^9||^10||^11`.

Content-editing/field — suggestions follow normal entity access; no access role.

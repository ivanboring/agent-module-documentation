Azure OpenAI Augmentor adds Azure OpenAI as an Augmentor provider.

---

Azure OpenAI Augmentor provides integration between the Augmentor module and the Azure OpenAI API — so Augmentor-based AI transformations (summaries, classification, generation) can be powered by Azure OpenAI models, for organizations using Microsoft's hosted OpenAI service.

Azure OpenAI credentials/endpoint should be stored securely (env-backed); requests send content to Azure (cost + egress). Depends on `augmentor`; supports Drupal 9.3+, 10, and 11.

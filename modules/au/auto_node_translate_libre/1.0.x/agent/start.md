# Auto Node Translate Libre — agent index

**LibreTranslate provider** for the **Auto Node Translate** module — machine-translate nodes via a
(self-hostable, open-source) LibreTranslate server. Depends on `auto_node_translate`; config at
`auto_node_translate_libre.settings`. Version **1.0.0**. Core `^10.2||^11`.

Store any API key as a secret; node content is sent to the LibreTranslate endpoint. Multilingual
integration (no access role).

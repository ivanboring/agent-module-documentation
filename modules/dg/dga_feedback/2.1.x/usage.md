DGA Feedback collects accessible page feedback (Yes/No + reasons + demographics) with a dashboard.

---

DGA Feedback provides an accessible feedback widget offering Yes/No options, reason selection, optional free text, and demographic data, with UI-based English/Arabic translations, inline validation, auto-refresh, and a comprehensive admin dashboard. It follows DGA (Digital Government Authority) Design System guidelines and is aimed at government/public-sector sites gathering page feedback.

Permissions cover the dashboard (`view dga feedback dashboard`), submission management (`manage dga feedback submissions`), and settings (`administer dga feedback settings`). Because it can collect demographic data, handle submissions per privacy policy. Supports Drupal 10, 11, and 12.

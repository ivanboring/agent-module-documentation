DL provides a comprehensive document management system.

---

DL provides a **comprehensive document-management/library system** — uploading, categorizing (taxonomy) and
browsing documents (files) with views/listings, for a document library/repository. It depends on core Node,
File, User, Views and Taxonomy, provides its own permissions, in the Content package.

Use it to build a document library. It is a content/DMS feature. Security/data handling: documents are **files**
— consider whether they should be in the **private file scheme** with access control (public files are served by
the web server regardless of any listing's access), keep upload permissions to trusted roles, and gate the
library's access via its permissions and file field settings. It has no special access-control role beyond core
node/file access + its permissions. Configure the document library.

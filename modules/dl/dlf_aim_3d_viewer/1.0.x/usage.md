DLF AIM 3D Viewer provides Drupal integration for the DLF 3D viewer.

---

DLF AIM 3D Viewer **integrates the DLF AIM 3D model viewer** — embedding an interactive 3D model viewer to
display 3D assets (e.g. cultural-heritage/artefact models) on the site, via a field. It depends on core Field,
provides its own permissions.

Use it to display 3D models. It is a media/content-display feature; models are admin/editor-provided assets
(loaded by the viewer library) and it has no access-control role beyond its permission. Configure the 3D viewer
field.

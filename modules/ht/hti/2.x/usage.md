Hierarchical Taxonomy Importer (machine name hierarchical_taxonomy_importer) imports taxonomy terms in a hierarchical structure from a file (CSV/Excel), building parent-child relationships.

---

Building a large hierarchical vocabulary by hand is tedious; importing it from a spreadsheet is faster. Hierarchical Taxonomy Importer imports terms with their parent-child structure from a file. It is an admin/site-building tool. Because importing creates taxonomy terms (which can drive access, menus, and content organisation), run it as a controlled operation: confirm the source file is trusted, review the resulting hierarchy, and back up before importing into an existing vocabulary where a bad import could disrupt term references.

# Hierarchical Taxonomy Importer (hti) — agent index

**Machine name `hierarchical_taxonomy_importer`.** Imports taxonomy terms in a **hierarchical
structure** from a file (CSV/Excel). Version **2.0.0**.

Creates terms (can drive access/menus) — run as a controlled op: trust the source file, review the
result, back up before importing into an existing vocabulary.

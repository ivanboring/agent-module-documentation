Retina Images provides an image effect that outputs higher-resolution images for high-DPI (retina) displays.

---

High-DPI screens show standard-resolution images as soft; serving a 2x image makes them crisp. Retina Images adds an image effect that outputs a high-resolution variant for retina displays. It is a display/media enhancement with no security surface. The trade-off to weigh is bandwidth — 2x images are larger — so apply it where crispness matters and consider responsive image styles for the broader case.

Responsive Gallery creates responsive, modern gallery displays for image content.

---

Image galleries that adapt to screen size — reflowing, responsive grids of images with a viewer — are a common content need. Responsive Gallery provides that display for image content. It is a front-end presentation module with no security surface. Confirm it works with your image styles and theme, and consider lazy-loading for galleries with many images.

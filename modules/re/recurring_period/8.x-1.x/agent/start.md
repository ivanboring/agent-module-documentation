# Recurring Period (recurring_period) — agent index

Configurable **plugin system for recurring time periods** (daily/weekly/monthly/custom), reusable by
other modules. Version **8.x-1.3**. Core `^8.8 || ^9 || ^10 || ^11`.

A building block (e.g. for subscriptions, memberships, recurring donations) — provides the period
plugins and boundary computation; the consuming feature is elsewhere.

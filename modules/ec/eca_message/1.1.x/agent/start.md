# ECA Message — agent index

Lets **ECA models create Message entities** (Message module) as actions (messages in automated workflows —
activity streams/notifications). Depends on `eca`, `message`. Version **1.1.0**. Core `^9||^10||^11`.

Automation/integration — created Messages follow the Message module's access; no access role.

ECA Message makes it possible to create message entities with ECA.

---

ECA Message adds **ECA actions to create Message entities** — so an ECA (Events-Conditions-Actions) model
can generate a Message (from the Message module) as part of an automated workflow, for activity streams/
notifications. It depends on the ECA and Message modules, in the Custom package.

Use it to create Messages from ECA automations. It is an automation/integration feature; the Messages it
creates follow the Message module's access, and it has no access-control role. Configure the ECA model to
create messages.

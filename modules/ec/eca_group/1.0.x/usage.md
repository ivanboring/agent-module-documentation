ECA Group integrates ECA with the Group module and its plugins, adding Group-related events, conditions and actions to ECA.

---

ECA Group integrates ECA (Events-Conditions-Actions — the no-code automation framework) with the Group
module — adding Group-related events (membership changes, group content operations), conditions (group
membership/role checks) and actions (add/remove members, etc.) to ECA models. So automation can react to
and act on Group activity without custom code. It depends on ECA (^2||^3) and Group (^3||^4).

Use it to automate Group-related workflows (onboarding, notifications, role management) via ECA. It is an
automation feature bridging ECA and Group; the actions it enables run configured ECA logic, so — as with
any automation touching access/membership — review ECA models that change group membership or roles so
they can't grant unintended access. Configure the ECA models using the Group events/conditions/actions.

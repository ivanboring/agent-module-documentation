# ECA Group — agent index

Integrates **ECA (Events-Conditions-Actions)** with the **Group** module — group events/conditions/actions
for no-code automation (membership, roles, group content). Depends on `eca` (^2||^3), `group` (^3||^4).
Version **1.0.1**. Core `^10.4||^11`.

Automation — review ECA models that change group membership/roles (so they can't grant unintended
access).

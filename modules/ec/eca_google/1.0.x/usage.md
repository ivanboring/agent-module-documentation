Google API integration services for ECA.

---

ECA: Google provides Google API integration services for ECA (Event-Condition-Action) — adding ECA actions that call Google APIs, so no-code ECA models can interact with Google services as part of automated workflows. Google API credentials are handled via `google_api_client` (store them securely). Depends on `eca` and `google_api_client`; supports Drupal 10 and 11.

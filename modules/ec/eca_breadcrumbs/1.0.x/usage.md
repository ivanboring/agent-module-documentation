ECA Breadcrumbs provides ECA actions for breadcrumb customization with token support.

---

ECA Breadcrumbs **provides ECA actions for customizing breadcrumbs** — letting site builders set/modify the
breadcrumb trail from ECA (Event-Condition-Action) models, with token support. It depends on core System, the ECA
module and Token.

Use it to build breadcrumbs via ECA no-code models. It is a site-building/automation add-on for ECA; it affects
breadcrumb display and has no content or access role. Use its actions in ECA models.

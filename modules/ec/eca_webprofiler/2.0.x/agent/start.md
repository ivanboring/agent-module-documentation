# ECA Webprofiler — agent index

Integrates **ECA (Event-Condition-Action) with Webprofiler** (debug which ECA models fired). Depends on `eca`,
`webprofiler`. Version **2.0.2**. Core `^10.4||^11`.

Developer/debugging — **dev only** (Webprofiler is dev-only, adds overhead/exposes internals); not for
production. No content/access role.

ECA Webprofiler integrates ECA with the Webprofiler module.

---

ECA Webprofiler **integrates ECA (Event-Condition-Action) with Webprofiler** — surfacing ECA event/
condition/action execution in the Webprofiler toolbar/panel, so developers can debug which ECA models fired on
a request. It depends on the ECA and Webprofiler modules, in the ECA package.

Use it to debug ECA automation during development. It is a developer/debugging tool for **dev environments**
(Webprofiler is dev-only and adds overhead/exposes internals) — do not enable it on production. It has no
content or access role. View ECA execution in Webprofiler.

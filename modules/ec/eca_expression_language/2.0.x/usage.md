ECA Expression Language adds Symfony expression language to ECA.

---

ECA Expression Language **adds Symfony Expression Language support to ECA** — so ECA (Event-Condition-Action)
models can use expressions to compute conditions and values dynamically, for more powerful no-code automation.
It depends on the ECA module, in the ECA package.

Use it to write expressions in ECA models. It is a developer/automation feature. Security note: expressions are
**evaluated** — since ECA models are configured by privileged users, keep ECA-model editing to **trusted admins**
(an expression is powerful logic, and ECA models can be exported as config), and don't build expressions from
untrusted input. It has no access-control role. Use expressions in your ECA models.

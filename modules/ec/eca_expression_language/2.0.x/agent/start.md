# ECA Expression Language — agent index

Adds **Symfony Expression Language support to ECA** (dynamic conditions/values). Depends on `eca`. Version
**2.0.0**. Core `^10||^11`.

Developer/automation — expressions are **evaluated**: keep ECA-model editing to trusted admins, don't build
expressions from untrusted input. No access role.

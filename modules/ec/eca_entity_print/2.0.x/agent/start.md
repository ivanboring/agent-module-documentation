# ECA Entity Print — agent index

**ECA actions to print an entity or View to a PDF/document and save it as a file entity** (automate document
generation in ECA workflows — e.g. invoice on order completion). Depends on `eca`. Version **2.0.1**. Core
`^10.4||^11`.

Automation/content — generated document reflects the rendered entity/View; no access role of its own.

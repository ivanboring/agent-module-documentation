ECA Entity Print provides ECA rules to print a file document from a chosen entity or view and save it as a file entity.

---

ECA Entity Print provides ECA (Event-Condition-Action) actions for Entity Print — letting no-code ECA
models print a chosen entity or View to a PDF/document and save it as a file entity, so document generation
can be automated within ECA workflows (e.g. generate an invoice PDF on order completion). It depends on the
ECA module, in the ECA package.

Use it to generate documents from entities/Views within ECA automations. It is an automation/content feature;
the generated document reflects the rendered entity/View (content the render context can access), and it has
no access-control role of its own. Configure the ECA model and print action.

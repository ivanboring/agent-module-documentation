# ECA Parameters (eca_parameters) — agent index

Adds **parameter support to ECA** (Event-Condition-Action automation). Version **2.0.2**.
Submodule `eca_parameters_ui`. Depends on ECA.

Makes ECA models reusable/configurable. **ECA automations run with real privileges** (change
content/config) — building models is a trusted capability; this doesn't change that.

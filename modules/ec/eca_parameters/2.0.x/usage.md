ECA Parameters extends the ECA (Event-Condition-Action) automation module with parameter support, letting ECA models take and pass parameters.

---

ECA is Drupal's no-code automation engine — model events, conditions and actions without code. ECA Parameters adds parameter handling to it, so models can accept, pass and reuse parameters, making reusable, configurable automations. It is an extension for sites already using ECA; a UI submodule provides the interface. As with ECA generally, the automations run with real privileges and can change content and configuration, so who can build ECA models is a trusted capability — the parameter feature does not change that, it makes models more flexible.

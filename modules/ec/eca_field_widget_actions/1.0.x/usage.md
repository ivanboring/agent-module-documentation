ECA Field Widget Actions integrates ECA with the Field Widget Actions module.

---

ECA Field Widget Actions **integrates ECA with the Field Widget Actions module** — letting Event-Condition-
Action models drive the buttons/actions added to field widgets, connecting no-code automation to in-form widget
actions. It depends on the ECA module and Field Widget Actions.

Use it to wire ECA logic to field-widget buttons. It is a site-building/automation add-on; it affects form/widget
behavior and has no content or access role. Use its integration in ECA models.

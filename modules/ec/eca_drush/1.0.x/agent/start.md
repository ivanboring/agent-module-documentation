# ECA Drush Integration — agent index

**Integrates ECA (Event-Condition-Action) with Drush** (run/trigger ECA models from the CLI). Depends on `eca`.
Version **1.0.0-alpha2**. Core `^11.1`.

Developer/automation — **ECA models are powerful** (entity CRUD, email, actions); the trust boundary is **who can
author ECA models** (code-equivalent — keep to trusted admins). Extends where they run (Drush/CLI needs shell
access); doesn't broaden authoring permissions.

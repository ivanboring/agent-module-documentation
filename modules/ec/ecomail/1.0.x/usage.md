Ecomail provides API integration with the Ecomail email-marketing platform.

---

Ecomail **provides API integration with the Ecomail marketing platform** — connecting Drupal to Ecomail
(email marketing) to sync subscribers/contacts and trigger campaigns via its API. It stores credentials via the
**Key** module and provides its own permissions.

Use it to integrate Ecomail. It is an integration/marketing feature. Security/data handling: it **sends contact/
subscriber data (PII) to the Ecomail API** (egress — disclose per privacy policy) and authenticates with an
**Ecomail API key stored via the Key module** (secret handling, a positive). Serve over HTTPS. It has no access-
control role beyond its permission. Configure the Ecomail API key (via Key).

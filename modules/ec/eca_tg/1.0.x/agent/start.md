# ECA Telegram — agent index

An **ECA action to send messages to Telegram** (no-code ECA notifications to a chat/channel via a bot).
Depends on `eca`. Version **1.0.2**. Core `^10||^11`.

Automation/ECA. **Security:** store the Telegram **bot token** as a **secret**; HTTPS; avoid sending
sensitive data to an external chat. No access role.

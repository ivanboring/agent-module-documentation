ECA Condition provides integration of Condition plugins with ECA.

---

ECA Condition adds **Condition-plugin integration to ECA** — letting an ECA (Events-Conditions-Actions)
model use Drupal's Condition plugins (e.g. request path, user role, node type) as conditions, extending which
conditions ECA workflows can branch on. It depends on the ECA module, in the ECA package.

Use it to use core/contrib condition plugins in ECA. It is an automation feature; conditions gate ECA actions
and follow the underlying plugins, and it has no access-control role. Configure conditions in your ECA
model.

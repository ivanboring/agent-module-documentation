# ECA Condition — agent index

Adds **Condition-plugin integration to ECA** (use Drupal condition plugins — path/role/type — as conditions in
ECA models). Depends on `eca`. Version **2.0.0-beta2**. Core `^10.3||^11`.

Automation — conditions gate ECA actions, following the underlying plugins; no access role.

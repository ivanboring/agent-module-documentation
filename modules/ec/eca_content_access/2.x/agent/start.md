# ECA Content Access (eca_content_access) — agent index

Integrates **ECA automation with the Content Access** module — access grants driven by ECA models.
Version **2.0.1**. Depends on ECA + Content Access.

**Access-as-automation — high care.** The access rules are as correct as the ECA models built with
it; restrict who builds them, **test grants adversarially** (does the wrong user get in?), rebuild
node access appropriately.

# ECK Site Settings (eck_site_settings) — agent index

Editor UI + developer API for **site-wide settings as entities**. Version **1.3.6**. Submodule
`eck_site_settings_domain` (per-domain).

Settings appear site-wide (headers/footers) — a lever affecting every page. Restrict who can edit;
any setting outputting markup is subject to text-format/escaping considerations.

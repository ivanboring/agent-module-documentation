# ECA Views data export — agent index

Integrates **ECA with the Views Data Export module** (no-code ECA models trigger View data exports —
CSV/XML). Depends on `eca`. Version **2.0.1**. Core `^10.4||^11`.

Automation/export — exported data reflects what the View exposes (respects the View's access; ensure it
doesn't over-expose fields). No access role of its own.

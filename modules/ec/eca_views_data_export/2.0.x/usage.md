ECA Views data export integrates ECA with the views_data_export module.

---

ECA Views data export integrates ECA (Event-Condition-Action) with the Views Data Export module — so
no-code ECA models can trigger data exports of a View (CSV/XML/etc.), automating export generation within ECA
workflows. It depends on the ECA module, in the ECA package.

Use it to export View data as part of ECA automations. It is an automation/export feature; the exported data
reflects what the View exposes (respecting the View's access), and it has no access-control role of its own.
As with any export, ensure the exported View doesn't include fields the recipient shouldn't see. Configure
the ECA model and export.

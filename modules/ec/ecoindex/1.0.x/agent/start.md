# EcoIndex — agent index

Implements the **EcoIndex service** to measure/report a page's environmental impact (grade pages on
complexity/weight → carbon/eco footprint — track sustainability). Config at `ecoindex.settings`; provides
permissions. Version **1.0.1-beta4**. Core `^9.4||^10||^11`.

Admin/reporting — informational eco-impact data; no access role beyond permission.

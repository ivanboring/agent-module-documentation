EcoIndex provides an implementation of the EcoIndex service.

---

EcoIndex integrates the EcoIndex service — measuring and reporting a page's environmental/eco impact
(EcoIndex grades pages on complexity/weight to estimate their carbon/environmental footprint), so site owners
can track and improve the site's sustainability. It is configured at `ecoindex.settings`, provides its own
permissions, in the EcoIndex package.

Use it to measure page eco-impact. It is an administration/reporting feature that queries/computes EcoIndex
data; it is informational and has no access-control role beyond its permission. If it calls the external
EcoIndex API, any credentials/config should be handled appropriately. Configure the EcoIndex measurement.

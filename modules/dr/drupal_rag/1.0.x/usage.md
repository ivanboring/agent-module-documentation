Turns Drupal content/media into a RAG system using pgvector and Ollama.

---

Drupal RAG converts Drupal content types and media types into a Retrieval-Augmented Generation (RAG) system using pgvector and Ollama — embedding site content into a pgvector store and using a local Ollama LLM so an AI can answer questions grounded in the site's own content.

It requires a PostgreSQL + pgvector database and an Ollama endpoint (configure their connection securely). Depends on core `system`, `node`, and `media`; supports Drupal 11.

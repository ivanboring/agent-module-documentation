Druhels (Drupal Helpers) provides reusable helper functions/utilities for module and theme developers.

---

Druhels (Drupal Helpers) is a developer utility library providing assorted general-purpose helper functions and utilities used by other modules (such as Drupal Improvements) — common routines that save reimplementing the same boilerplate across projects.

It's a base developer library with no content or access role of its own. Supports Drupal 8 through 15.

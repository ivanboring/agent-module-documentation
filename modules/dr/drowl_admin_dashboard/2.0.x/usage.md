DROWL Admin Dashboard provides an administrative dashboard as a helpful overview and entry point for site maintainers.

---

DROWL Admin Dashboard provides an administrative dashboard — a helpful overview/landing page for site
maintainers, surfacing key information and entry points (content, configuration, status) in one place. It
provides its own permissions, in the Administration package.

Use it to give admins a dashboard overview. It is an administration/UI feature; the dashboard aggregates
admin information (governed by the viewer's admin access), and it has no access-control role beyond its
permission. Gate who can see the dashboard. Configure the dashboard.

Drupal Metrics provides database metrics in the Reports section.

---

Drupal Metrics **provides database metrics in the Reports section** — surfacing statistics about the site's
database (table sizes, row counts, etc.) on an admin reports page for monitoring/insight. It provides its own
permissions, in the Statistics package.

Use it to inspect DB metrics. It is an administration/monitoring tool; the metrics are **admin-facing operational
data**, so gate the report to trusted admins via its permission. It has no content or access role beyond that.
View the database metrics report.

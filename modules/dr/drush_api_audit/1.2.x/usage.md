Drush API Audit provides drush commands to audit APIs.

---

Drush API Audit provides **Drush commands to audit API usage/definitions** — scanning the codebase from the
command line to report on API usage (deprecated calls, plugin/service definitions, etc.) to aid maintenance and
upgrades. It is in the drush package (core 11).

Use it as a developer/CLI maintenance aid. It is a developer tool run from Drush (inherently limited to those
with shell/Drush access — trusted operators); it reads code and reports, and has no content or access role. Run
the audit commands.

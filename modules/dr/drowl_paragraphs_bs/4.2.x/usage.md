Paragraphs UX/UI enhancements (settings fields and helpers) for Bootstrap.

---

DROWL Paragraphs for Bootstrap provides Paragraphs enhancements — settings fields and other UX / UI / helper features — for building Bootstrap-based layouts with Paragraphs and Layout Paragraphs, part of the DROWL toolset. It builds on Paragraphs, Layout Paragraphs, UI Styles, Field Group and related modules; supports Drupal 10.3+ and 11.

Tokens for embedding Drupal Forge launch widgets.

---

Drupal Forge Token provides tokens for embedding Drupal Forge launch widgets — so content/config can include a token that renders a 'Launch on Drupal Forge' widget/button, making it easy to add try-it launch links to pages. It integrates with the Token system. Supports Drupal 8 through 11.

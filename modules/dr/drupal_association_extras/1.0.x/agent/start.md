# Drupal Association Extras (drupal_association_extras) — agent index

Container for features supporting Drupal Association initiatives and programs.
Version **1.0.0-alpha1**. Core `^11.2`. Depends on core **`navigation`**.

**Currently near-empty**: an `.install` file and a `LaunchLinkTest` functional test. **No `src/`,
no routing, no permissions, no config.** Whatever it does today arrives through the navigation UI.

Report this accurately rather than inferring capability from the name: it is a placeholder that
will accumulate features. Install only if you are participating in the program it supports, and
expect substantial change between alpha releases.

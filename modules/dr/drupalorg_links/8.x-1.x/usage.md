Field formatters that output links to Drupal.org.

---

Drupal.org Links provides various field formatters to output links to Drupal.org — so a field holding a project name/id renders as a proper link to the relevant drupal.org project (or related resource), useful for directories and community/documentation sites. Supports Drupal 8 through 11.

---

Drift - Communication Tool integrates the Drift.com platform — a live-chat/conversational-marketing tool
— adding Drift's chat widget to the site so visitors can chat with sales/support. It is configured at
`drift.config` and provides its own permissions.

Use it to add Drift live chat. It embeds Drift's third-party JavaScript widget, so consider: the widget
loads external JS and can track visitors/set cookies (privacy/consent — pair with cookie-consent and
disclose), and any chat data is handled by Drift. It is an integration/chat feature with no access-control
role. Configure the Drift account and where the widget loads.

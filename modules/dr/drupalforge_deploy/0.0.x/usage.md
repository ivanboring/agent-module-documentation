Prepare Drupal Forge launch URLs from backup and repository metadata.

---

Drupal Forge Deployment prepares Drupal Forge launch URLs from backup and repository metadata — generating the URLs that launch a site on Drupal Forge (the hosting/demo platform) based on a backup (via Backup and Migrate to S3) and repo info, easing one-click deployment/demo. Depends on `backup_migrate_aws_s3`; supports Drupal 8 through 11.

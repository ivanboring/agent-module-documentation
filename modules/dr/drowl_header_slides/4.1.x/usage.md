DROWL Header Slides provides a flexible header slideshow based on a custom block type.

---

DROWL Header Slides provides a **flexible header slideshow** — built on a custom block type and Slick
carousel, with media, links and per-slide configuration (from the DROWL agency), for building hero/header
sliders. It depends on a broad stack (Slick, Views, Media, DROWL Media, Fences, Menu Item Extras, Views
Linkarea, etc.), provides its own permissions, in the DROWL.de package.

Use it for a configurable header/hero slideshow. It is a content-display/site-building feature; slide content
is authored (rendered normally) and follows normal block/media access, and it has no access-control role beyond
its permission. Configure the header slides.

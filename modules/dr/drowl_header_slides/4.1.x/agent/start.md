# DROWL Header Slides — agent index

A flexible **header slideshow built on a custom block type (Slick-based)** with media/links/per-slide config.
Depends on `slick`, `views`, `media`, `drowl_media`, `fences`, `menu_item_extras`, `views_linkarea`. Provides
permissions. Version **4.1.14**. Core `^9||^10||^11`.

Content-display/site-building — slide content authored (normal block/media access); no access role beyond
permission.

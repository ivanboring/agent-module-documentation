A Webform handler that sends submissions to Drip.

---

Drip webform handler is a Webform handler for Drip — sending webform submissions to the Drip email-marketing/CRM platform, so form submitters become Drip subscribers/records. The Drip API credentials are admin-configured and should be stored securely (env-backed). Depends on `webform`; supports Drupal 9, 10, and 11.

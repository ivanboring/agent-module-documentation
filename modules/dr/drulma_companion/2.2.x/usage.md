Drulma Companion extends the Drulma theme (Bulma-based) with additional module functionalities.

---

Drulma Companion extends the Drulma theme — a Bulma-CSS-framework-based Drupal theme — with additional
module-provided functionality (features that belong in a module rather than the theme, such as menu-item
fields via a `drulma_menu_item_fields` submodule). It depends on Block Class and is in the Bulma package.

Use it alongside the Drulma theme to get its companion features. It is a theming/site-building companion
module; it enhances the Drulma theme's capabilities and has no content or access role. Enable it with
Drulma.

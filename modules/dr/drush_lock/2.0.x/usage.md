Drush Lock provides Drush commands for handling locks.

---

Drush Lock provides **Drush commands for handling locks** — acquiring and releasing named locks so that
concurrent Drush operations (deploys, imports, long tasks) don't overlap and step on each other. It provides
Drush commands, in the Drush package.

Use it to serialize concurrent Drush/deploy operations. It is a developer/DevOps feature; it manages
operational locks and has no content or access role. Use the lock commands around critical operations.

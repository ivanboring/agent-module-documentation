Drupal Path in JS makes the active Drupal path and route available to JavaScript.

---

Drupal Path in JS adds the current Drupal path and route information to the client-side `drupalSettings`, so front-end JavaScript can reliably read the active path/route (for conditional behavior, analytics, or routing) without parsing the URL itself.

It's a developer utility with no content or access role of its own. Supports Drupal 8 through 12.

DROWL Media provides default Media entity configurations and enhancements.

---

DROWL Media provides default Media entity configuration and enhancements — ready-made media types,
settings and improvements (from the DROWL agency) so a site gets a sensible media setup out of the box, with
`drowl_media_types` and `drowl_media_video` submodules. It depends on core Media.

Use it to bootstrap a media configuration. It is a media/default-content feature configuring media types/
handling; media access follows core's media/file access and it has no access-control role. Enable the
submodules for the media features you need.

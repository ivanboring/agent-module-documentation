Dropdown Pager provides an accessible dropdown pager option for Views, replacing numbered links with a select dropdown.

---

Dropdown Pager provides an accessible dropdown pager for Views — replacing the standard numbered pager
links with an accessible `<select>` dropdown for choosing the page, which is more compact and keyboard/
screen-reader friendly for listings with many pages. It depends on core Views.

Use it on Views with many pages where a compact accessible pager helps. It is a content-display/Views
feature affecting pager presentation; results and their access are unchanged (the View's access applies), and
it has no access-control role. Select the dropdown pager on the View.

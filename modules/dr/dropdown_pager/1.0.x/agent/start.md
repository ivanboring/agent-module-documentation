# Dropdown Pager — agent index

Provides an **accessible dropdown (`<select>`) pager for Views** (compact, keyboard/screen-reader friendly vs
numbered links). Depends on core `views`. Version **1.0.2**. Core `^10.3||^11`.

Content-display/Views — affects pager presentation, not results/access (View access applies). No access
role.

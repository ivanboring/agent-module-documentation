Environment-based protection against running Drush commands.

---

Drush Firewall allows environment protection against Drush commands — letting a site block/allow specific Drush commands per environment (e.g. forbid destructive commands on production), a defensive guardrail so risky commands can't be run where they shouldn't. It's a defensive/ops tool. Supports Drupal 10.2+ and 11.

Provides DROWL's default Bootstrap layouts.

---

DROWL Layouts for Bootstrap provides DROWL's default Bootstrap layouts — a set of Bootstrap-grid layout plugins (via Layout Discovery / Layout Options) used by the DROWL toolset (e.g. with Layout Paragraphs and DROWL Paragraphs for Bootstrap) to build responsive multi-column page sections. Depends on core `layout_discovery`, `twig_real_content`, and `layout_options`; supports Drupal 10 and 11.

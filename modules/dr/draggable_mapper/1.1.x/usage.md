Draggable Mapper provides a draggable map entity.

---

Draggable Mapper provides a **draggable image-map entity** — letting editors place and drag markers/hotspots
onto an image (an interactive image map), using Paragraphs, Inline Entity Form and jQuery UI. It depends on core
Field, Image, Text plus Paragraphs, Inline Entity Form and jQuery UI draggable/droppable/resizable, provides its
own permissions, in the Custom package.

Use it to build interactive image maps. It is a content-editing/media feature; the map/markers are admin/editor
content and it has no access-control role beyond its permission. Configure the draggable map.

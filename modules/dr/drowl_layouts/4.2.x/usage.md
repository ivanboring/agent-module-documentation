DROWL Layouts provides DROWL's default ZURB Foundation layouts.

---

DROWL Layouts provides a set of **ZURB Foundation-based layouts** for Layout Builder and Layout Discovery —
responsive, column-based section layouts (with Twig Real Content for previews) that editors can use when
building pages. It depends on core Layout Discovery and Layout Builder plus Twig Real Content, provides its own
permissions, in the Layout package.

Use it to add responsive section layouts. It is a site-building/theming feature; layouts are used within the
Layout Builder edit flow (gated by layout/edit access), and it has no access-control role of its own. Use the
DROWL layouts when configuring sections.

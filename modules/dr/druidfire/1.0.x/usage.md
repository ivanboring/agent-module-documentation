Druidfire provides drush commands and an API to alter field definitions.

---

Druidfire provides Drush commands and an API for altering entity **field definitions** — programmatically
changing field schemas/definitions (adding, modifying) from the CLI/code, useful for deployment/migration
scripting of field structure. It provides Drush commands, in the Development package.

Use it as a developer/DevOps tool for field-definition changes. **This is a powerful capability** — altering
field definitions changes the data schema (potentially destructive: reshaping/dropping field storage), so it
must be used by **trusted developers** on the CLI, tested, and backed up before running against real data. It
has no runtime access-control role (it's a developer/CLI tool). Use its commands/API deliberately.

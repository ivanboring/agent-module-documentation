# Druidfire — agent index

Provides **Drush commands + an API to alter entity field definitions** (change field schemas from CLI/code —
deployment/migration scripting). Drush commands. Version **1.0.0**. Core `^10||^11`.

Developer/DevOps — **powerful/potentially destructive** (alters data schema; reshapes/drops field storage).
Use by **trusted developers** on the CLI, test + back up first. No runtime access role.

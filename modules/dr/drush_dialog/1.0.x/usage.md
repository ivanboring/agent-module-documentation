Provides an interactive Drush dialog for site administrators.

---

Drush dialog provides a Drush dialog for the site administrator — an interactive CLI dialog/menu for running common administrative Drush operations, giving admins a guided command-line interface instead of remembering individual commands. It's a developer/admin CLI tool. Supports Drupal 9.2+, 10, and 11.

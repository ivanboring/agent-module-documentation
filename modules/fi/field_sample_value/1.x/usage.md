Field Sample Value lets sample/placeholder values be configured per field, used when generating default content or previews.

---

Generating demo content, previews or default-content needs plausible field values. Field Sample Value lets a sample value be configured per field, used when such values are generated. It is a site-building/development convenience with no security surface; the sample values are admin-configured and used for generation, not shown to end users in production unless the generated content is published.

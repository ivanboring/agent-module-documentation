BEF Entity Select Buttons adds bundle-selection button widgets to Better Exposed Filters.

---

BEF Entity Select Buttons extends the Better Exposed Filters module so that, in Views overviews, users can select entity bundles via button widgets rather than plain select lists — a nicer exposed-filter UX for filtering listings by bundle/type.

It's a Views/exposed-filter UX enhancement with no content or access role of its own. Depends on `better_exposed_filters`; supports Drupal 9.4, 10, and 11.

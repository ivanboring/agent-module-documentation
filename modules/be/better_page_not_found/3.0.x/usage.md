Better Page Not Found provides improved styling for 404, 403 and error pages.

---

Better Page Not Found provides **improved styling for the 404 (not found), 403 (access denied) and error
pages** — nicer, more branded error pages than core's plain output, improving the experience when users hit a
missing or forbidden page. It works across core 8–11.

Use it to give error pages a better look. It is an administration/display feature affecting error-page
presentation; it does not change access decisions (a 403 is still a 403) and has no access-control role.
Configure the error-page styling.

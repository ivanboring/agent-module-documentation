Better Entity Reference Table (bert) provides a more user-friendly table-based widget for entity reference list fields.

---

Better Entity Reference Table (bert) provides a friendlier widget for entity reference fields —
rendering the referenced items as a manageable table rather than the default autocomplete/select,
making it easier to view, order and manage multiple references. It targets fields that reference many
entities where the standard widget becomes unwieldy. It depends only on core System.

Use it on multi-value entity reference fields (related content, curated lists) where editors need a
clearer table UI to manage the referenced items. It is a content-editing/form-widget feature affecting
how references are entered and ordered; it respects the field's target and entity access and adds no
access of its own. Configure it as the widget on the reference field.

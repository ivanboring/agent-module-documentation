Better Taxonomy enhances Drupal's core Taxonomy functionality.

---

Better Taxonomy adds **usability and management improvements to core Taxonomy** — refinements to how
vocabularies/terms are managed and used, making working with taxonomy more convenient than core alone. It
depends on core Taxonomy, in the Taxonomy package.

Use it to improve the taxonomy experience. It is a site-structure/content feature; term/vocabulary access
follows core taxonomy access and it has no access-control role. Enable it and use the enhancements.

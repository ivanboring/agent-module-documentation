BE-Alert integrates the Belgian BE-Alert emergency notification system.

---

BE-Alert provides features around BE-Alert — the Belgian government emergency-alert system — so a (Belgian government/public) site can integrate BE-Alert notifications, letting residents be informed of emergency alerts relevant to their location.

BE-Alert API credentials should be stored securely (env-backed). It's an integration for Belgian public sites. Supports Drupal 10 and 11.

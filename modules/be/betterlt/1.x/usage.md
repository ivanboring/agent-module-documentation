Better Local Tasks replaces the default rendering of Drupal's local task tabs — the Edit / View / Delete style tabs — with a more refined, modern UI.

---

Local tasks are the small tab strip at the top of many pages, and core's rendering of them is functional but plain, and awkward when there are many of them or on narrow screens. This module restyles that region, giving the tabs a cleaner look and better behaviour without changing what the tabs are or do — it is a presentation layer over the existing local-task system.

The machine name is `better_local_tasks` while the project is `betterlt`, which is the thing to know when enabling it. It has no configuration or permissions of its own; enabling it changes how the tabs render site-wide (or in the admin theme, depending on where local tasks appear). Because it is purely visual, the main check is that its styling agrees with your theme — a restyle that assumes one theme's markup can look odd in another.

For a site where the admin or editorial UI matters, it is a low-cost polish. It changes appearance, not behaviour.

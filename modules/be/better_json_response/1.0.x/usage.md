Better Json Response extends JsonResponse with JSON:API compatibility and cache metadata.

---

Better Json Response improves the native Symfony/Drupal JsonResponse by adding JSON:API support and cache metadata — so custom JSON responses can be JSON:API-compliant and cacheable, useful for decoupled/API endpoints that want proper caching and JSON:API structure without full JSON:API resources.

It's a developer/API utility with no content or access role of its own. Depends on core `jsonapi`; supports Drupal 10, 11, and 12.

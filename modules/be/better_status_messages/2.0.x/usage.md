Better Status Messages provides styled status messages with a close (dismiss) button.

---

Better Status Messages restyles Drupal's status/warning/error messages and adds a close button — giving
a more polished, dismissible message presentation than the default. Users can dismiss messages after reading
them for a tidier interface.

Use it to improve message presentation and let users close messages. It is a front-end/UI feature affecting
how messages display; it does not change what messages are generated or any access behaviour. Enable it for
styled, dismissible messages.

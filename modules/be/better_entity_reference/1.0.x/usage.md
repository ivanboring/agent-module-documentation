Better Entity Reference is an entity-reference widget rendering selections as removable tags via a popover.

---

Better Entity Reference provides an improved entity-reference field widget: instead of a stack of autocomplete rows, selected entities appear as tags, and an add/remove popover makes managing references quick and visual. It improves the editorial experience for multi-value reference fields.

It's a widget/UX enhancement with no content or access role of its own; render output is escaped normally. Supports Drupal 10.6+, 11.3+, and 12.

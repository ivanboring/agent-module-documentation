Better User Accounts provides improvements to user accounts.

---

Better User Accounts **provides various improvements to the user-account UI and management** — enhancements
to the account edit/view experience and admin user management. It depends on core User, provides its own
permissions, in the User interface package.

Use it to improve account management UX. It is an administration/user feature; it works within core user access
(edit/administer users) and it has no access-control role beyond its permission. Configure the account
improvements.

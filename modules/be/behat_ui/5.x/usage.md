Behat UI lets you create and run Behat/Mink functional tests from a web interface inside Drupal.

---

Behat/Mink drives browser-based functional tests. Behat UI provides a web interface to author and run them from within Drupal. It is a development/testing tool, and running tests is a powerful capability — tests can create content, log in as users, and exercise the whole site, so the ability to run them must be tightly restricted to trusted developers. Running test suites in production is inadvisable (tests can mutate data and consume resources); this belongs in development/CI environments. Confirm the interface is admin/developer-gated and, ideally, not enabled in production at all.

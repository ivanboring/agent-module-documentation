# Behat UI (behat_ui) — agent index

Create/run **Behat/Mink functional tests from a web interface**. Version **5.0.1**.

**Security:** running tests is powerful (creates content, logs in as users, exercises the whole
site) — **restrict tightly to trusted developers**, and **do not enable in production** (tests mutate
data/consume resources). Dev/CI only.

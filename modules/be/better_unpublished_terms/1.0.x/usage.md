Better Unpublished Terms improves access control around unpublished terms.

---

Better Unpublished Terms **improves access control around unpublished taxonomy terms** — tightening how
unpublished terms are handled (in listings, references and forms) so they aren't shown to users who shouldn't see
them, addressing gaps in core's handling of unpublished terms. It depends on core Taxonomy and Inline Entity Form,
in the Custom package.

Use it to better hide unpublished terms. It is an access-control/taxonomy feature aiming to be **security-positive**
(closing exposure of unpublished terms). Verify it covers the paths you care about (term pages, term reference
displays, autocomplete, Views) for your use, and remember term access ultimately relies on core taxonomy access
plus this module's improvements. It has no broad access-control role beyond that. Enable it on sites using
unpublished terms.

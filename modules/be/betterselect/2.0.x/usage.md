Better Select replaces multi-select HTML elements with styled checkbox lists.

---

Better Select lets you use stylized checkboxes instead of the default multiple-select HTML element — improving the UX of multi-value select fields by presenting options as a styled checkbox list (easier to scan/select than a native multi-select box).

It's a form-widget/theming enhancement with no content or access role of its own. Supports Drupal 10 and 11.

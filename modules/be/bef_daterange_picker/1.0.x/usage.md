BEF Date Range Picker provides an enhanced date range picker.

---

BEF Date Range Picker provides an **enhanced date-range picker for Better Exposed Filters** — a friendlier
calendar/range widget for date exposed filters in Views, improving date filtering UX. It depends on core Views
and the Better Exposed Filters module.

Use it for nicer date-range filtering in views. It is a content-display/Views feature affecting the exposed
filter widget; results follow the view's access and it has no access-control role. Configure the picker on a
date exposed filter.

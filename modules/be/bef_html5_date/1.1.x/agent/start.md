# BEF HTML5 Date plugin — agent index

**Better Exposed Filters** plugin enabling **HTML5 date inputs** in Views exposed date filters (native date
picker). Depends on `better_exposed_filters`. Version **1.1.0**. Core `^9.3||^10||^11`.

Site-search/Views-UI — shapes the filter widget, not results/access (View access applies).

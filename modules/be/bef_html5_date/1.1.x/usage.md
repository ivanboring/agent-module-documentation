BEF HTML5 Date plugin adds a Better Exposed Filters plugin allowing HTML5 date fields in Views exposed filters.

---

BEF HTML5 Date plugin extends Better Exposed Filters (BEF) with an HTML5 date input option — so a
Views exposed date filter can use the browser's native HTML5 date picker instead of a text input,
improving date-filter UX. It depends on the Better Exposed Filters module.

Use it on Views with exposed date filters where a native date picker is preferred. It is a site-search/
Views-UI feature affecting the filter widget; it shapes the exposed filter input, not results or access
(the View's access applies). Select the HTML5 date option in the BEF settings for the date filter.

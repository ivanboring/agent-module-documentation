BlueSky Integration integrates the BlueSky (AT Protocol) API with Drupal.

---

BlueSky Integration (bsky) **integrates the BlueSky API** — providing plugins for other modules to post to and
read from BlueSky (the AT Protocol social network). It stores credentials via the **Key** module, in the
Integrations package.

Use it to connect Drupal to BlueSky. It is a social/integration feature. Security/data handling: it **calls the
BlueSky API** (egress) and authenticates with **credentials/app passwords stored via the Key module** (secret
handling, a positive) over HTTPS. It has no access-control role. Configure the BlueSky credentials (via Key).

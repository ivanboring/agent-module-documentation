BS Slider provides a base for various slider, carousel, gallery and similar implementations.

---

BS Slider provides a base framework for sliders — a foundation for building carousels, galleries and
similar slider implementations, with submodules integrating specific slider libraries (Bootstrap, Swiper,
Tiny Slider) and sources (paragraphs, entity-reference-revisions, Views). It provides its own permissions, in
the Media package.

Use it as the base for slider/carousel features, choosing a library submodule. It is a content-display/media
feature; the slider content comes from the configured source (respecting its access) and it has no
access-control role. Enable the library/source submodules you need and configure the slider.

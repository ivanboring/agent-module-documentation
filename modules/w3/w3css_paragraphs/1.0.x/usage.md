W3CSS Paragraphs supplies twenty-three ready-made Paragraph bundles built on the W3.CSS framework — columns, hero units, cards, tabs, accordions, carousels, modals and more — as a complete page-building component set.

---

Where the EPT family documented earlier in this campaign ships one small module per component, this ships the whole set in one project with a submodule per bundle, so a site enables the components it wants from a single install. The range is broad: layout (`one_column`, `two_columns`, `three_columns`), display (`card`, `hero`, `hero_full_width`, `image_overlay`, `responsive_image`, `parallax`), interaction (`tabs`, `accordion`, `modal`, `slideshow`, `3d_carousel`, `3d_flip_box`) and integration (`block`, `custom_block`, `views`, `webform`, `menu`, `quicklinks`, `contact_form`). Styling comes from **W3.CSS**, a small standalone CSS framework with no JavaScript dependency and no jQuery — which is the reason this suite exists alongside the Bootstrap-based alternatives. Note the module description: the companion W3CSS theme is being renamed to **Solo** for version 3, so a site adopting this should check which theme generation it is aligning with. Composer requirements are unpinned (`"*"` for paragraphs, `entity_reference_revisions` and `field_group`), which is worth noticing when resolving versions.

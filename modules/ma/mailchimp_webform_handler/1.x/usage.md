Mailchimp Webform Handler is a Webform handler that adds submissions to a Mailchimp audience as contacts.

---

A Webform signup should add the person to a mailing list. Mailchimp Webform Handler sends submissions to a Mailchimp audience. It needs a Mailchimp API key (keep out of plain config) and forwards submission PII to Mailchimp, so disclose the marketing use and capture consent before submissions become contacts. Configure the field-to-merge-field mapping.

# Easy Low Quality Placeholder — agent index

**Automatically generates low-quality image placeholders (LQIP)** for lazy loading (blur-up while the full image
loads). Depends on core `image`. Version **2.0.4**. Core `^10||^11`.

Performance/media — affects image rendering; no content/access role.

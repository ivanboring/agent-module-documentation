Easy LQP provides a settings form to automatically generate low-quality image placeholders.

---

Easy LQP (Low Quality Placeholder) **automatically generates low-quality image placeholders** — tiny
blurred stand-ins shown while the full image loads (LQIP), configured via a settings form, to improve perceived
performance. It depends on core Image, in the Other package.

Use it to add blur-up image placeholders. It is a performance/media feature affecting image rendering; it has no
content or access role. Configure the placeholder generation.

# Easy Google Analytics Counter — agent index

Fetches/displays **page-view counts from Google Analytics** (content popularity / most-viewed). Config at
`easy_google_analytics_counter.admin_form`. Version **3.0.1**. Core `^9||^10||^11`.

Integration/analytics — connects to GA with API credentials (store as secrets, scope the credential). No
access role.

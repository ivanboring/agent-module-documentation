Easepick adds an easepick date interface to Drupal.

---

Easepick adds the **easepick JavaScript date-picker** to Drupal — a lightweight, modern date/date-range
picker UI for date form inputs, as an alternative to the default browser/date widget. It is in the Custom
package.

Use it for a nicer date-picker UI. It is a content-editing/UI feature affecting date input rendering; it has no
content or access role. Configure easepick on date fields/elements.

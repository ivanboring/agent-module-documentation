Easy Migration provides the base code for content migration.

---

Easy Migration provides **base code and helpers for content migration** — scaffolding to make building
Migrate-based content imports simpler, with an `easy_migration_example` submodule showing usage. It is in the
Migration package.

Use it as a foundation for content migrations. It is a developer/migration tool run by privileged users; it
processes source data with migration privileges (validate sources; run as a trusted operator) and it has no
access-control role. Build and run your migration on top of it.

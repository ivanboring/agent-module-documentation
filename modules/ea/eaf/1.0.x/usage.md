EAF provides an entity attributes field and features.

---

EAF (Entity Attributes Field) provides an **entity-attributes field type** — a flexible field for storing
a set of attribute (key/value-style) data on an entity, plus related handling/formatting features. It is in the
Field types package.

Use it to model attribute data on entities. It is a fields/content feature; values follow normal field
sanitization on display and it has no content or access role. Add the EAF field to an entity.

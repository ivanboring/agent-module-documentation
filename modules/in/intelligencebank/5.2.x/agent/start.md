# IntelligenceBank DAM (intelligencebank) — agent index

**Machine name `ib_dam`.** Bridge to the **IntelligenceBank** DAM platform — browse/use DAM assets
in Drupal. Version **5.2.3**. Core `^10.3 || ^11`. Submodules `ib_dam_media`, `ib_dam_wysiwyg`.
Permission `administer intelligencebank configuration`.

Requires an IntelligenceBank account. Connects an enterprise DAM so approved assets are used in
Drupal without re-uploading. Keep the connection credentials out of plain config.

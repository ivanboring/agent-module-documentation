# ib_dam_wysiwyg — agent index

Submodule of **intelligencebank**. Integrates ib_dam directly into ckeditor. Useful for websites not using the media suite of modules that need WYSIWYG support. Core `^10.3 || ^11`.
Depends on: `drupal:field`, `drupal:filter`, `ib_dam:ib_dam`.

Governed by the parent's configuration and permissions. See [[intelligencebank]].

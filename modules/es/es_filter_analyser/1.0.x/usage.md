ES Filter-Analyser lets you declare ElasticSearch filters/analysis for Search API + Elasticsearch Connector.

---

ElasticSearch Filter-Analyser Management lets you declare and integrate custom ElasticSearch filters and analysers into the Search API / Elasticsearch Connector stack — so site builders can tune tokenization, stemming, synonyms and other analysis without hand-editing index mappings.

Administration is gated by `administer es_filter_analyser`. Depends on `elasticsearch_connector` and `search_api`; supports Drupal 10, 11, and 12.

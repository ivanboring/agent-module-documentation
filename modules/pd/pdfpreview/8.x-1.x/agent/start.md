# PDF Preview (pdfpreview) — agent index

Generates a **first-page snapshot image** of PDF files attached to nodes. Version **8.x-1.2**.
Core `^10 || ^11`.

Needs a PDF-rendering toolkit (ImageMagick/Ghostscript) available on the server to rasterise the
page. Turns a generic file icon into a document-cover thumbnail.

Webform Counter provides a submissions-counter feature for webforms, displaying how many submissions a form has received.

---

Showing a submission count — 'join 1,200 others who signed up' — is social proof, and Webform Counter provides that counter for webforms. It is a display feature. The consideration is what the count reveals: a public submission count discloses participation volume, which is usually intended, but for sensitive forms (a whistleblower form, a private survey) the count itself can be information — so confirm displaying the count is appropriate for the form. No unusual server-side surface.

Webform Revision UI adds a revision interface for webform configuration, letting form definition changes be reviewed and reverted.

---

Webform definitions are configuration, and a change to a live form (a removed field, an altered handler) can disrupt submissions with no easy undo. Webform Revision UI adds a revision interface for webform config, so changes can be reviewed and reverted. It is an administrative governance tool. Because webform config can include handlers that send data externally and access settings, the revision history records changes to how a form behaves — keep it admin-gated, and treat reverting a webform with the care of any config change to a live form.

# eTracker Analytics — agent index

Integrates **eTracker** (privacy-focused German) web-analytics JS tracking; `cookies_etracker` submodule for
COOKiES consent integration. Config at `etracker.admin_settings_form`; provides permissions. Version
**8.x-3.2**. Core `^9||^10||^11`.

**Privacy/consent:** loads tracking JS + cookies — use the consent submodule, obtain consent, disclose
(GDPR). No access role.

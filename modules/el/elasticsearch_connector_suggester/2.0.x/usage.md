Use the Elasticsearch suggester for Search API autocomplete.

---

Elasticsearch Connector Suggester adds the ability to use the Elasticsearch suggester for autocomplete — so Search API Autocomplete can serve suggestions from Elasticsearch's native suggester (completion/term suggestions), giving fast typeahead backed by Elasticsearch. Depends on `elasticsearch_connector` and `search_api_autocomplete`; supports Drupal 9, 10, and 11.

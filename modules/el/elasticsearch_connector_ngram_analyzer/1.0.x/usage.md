Elasticsearch Connector Ngram Analyzer implements an Ngram analyzer.

---

Elasticsearch Connector Ngram Analyzer **implements an Ngram analyzer for the Elasticsearch Connector** —
adding n-gram tokenization to Elasticsearch indexes so searches match partial words/substrings (autocomplete-
style). It depends on the Elasticsearch Connector module, in the Elasticsearch package.

Use it for substring/partial-match search with Elasticsearch. It is a site-search/integration feature affecting
index analysis; results follow the search index's access handling and it has no access-control role. Configure
the Ngram analyzer on your index.

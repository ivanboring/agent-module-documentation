Elevate Image Zoom (project elevatezoom) uses the ElevateZoom JS library to add zoom to images on node pages.

---

Elevate Image Zoom (project `elevatezoom`) integrates the ElevateZoom JavaScript library to add a
zoom effect to images on node pages — magnifying images on hover/interaction, useful for product or
detail images. It is functionally similar to the separate `elevate_image_zoom` project; this is a distinct
project providing the same kind of feature. It is in the Media package.

Use it to add image zoom on content pages. It is a front-end/media presentation feature applied to images;
it does not change media or access. Enable it for the relevant image displays.

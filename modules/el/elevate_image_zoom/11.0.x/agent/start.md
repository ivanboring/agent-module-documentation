# Elevate Image Zoom — agent index

Adds an **image-zoom** JS effect (Elevate Zoom) to images on **node pages** (magnify on hover/click —
product/detail images). Version **11.0.0**. Core `^9||^10||^11`.

Front-end/media presentation (no media/access change). Enable for the relevant image displays.

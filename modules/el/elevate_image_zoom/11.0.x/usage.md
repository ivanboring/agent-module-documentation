Elevate Image Zoom uses the Elevate Zoom JS library to add zoom-on-hover/click to images on node pages.

---

Elevate Image Zoom integrates the Elevate Zoom JavaScript library to add a zoom effect to images on
node pages — hovering or interacting with an image shows a magnified view, useful for product images,
detailed photos or artwork where visitors need to see detail. It is in the Media package.

Use it on content (typically product or detail pages) where image zoom improves the experience. It is a
front-end/media presentation feature applied to images; it does not change media or access. Enable it
for the relevant image displays/content.

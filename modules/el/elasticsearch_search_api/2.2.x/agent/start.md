# Elasticsearch Search API (elasticsearch_search_api) — agent index

**Search API backend** indexing into **Elasticsearch** (alternative to Solr). Version **2.2.1**.
Core `^10.2 || ^11`. Submodules `elasticsearch_search_api_example`, `esa_pager`.

For sites choosing Elasticsearch over Solr as their Search API server. Needs an ES cluster to connect
to. Slots into Search API's index/server configuration.

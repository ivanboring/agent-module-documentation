Entity Association lets you relate entities with configurable behaviors, landing pages and contexts.

---

Entity Association provides a structured way to associate entities with one another using definable behaviors, generating landing pages and contexts from those associations. It's a content-building tool for expressing relationships (e.g. grouping, linking, contextual navigation) beyond plain entity reference fields.

Permissions gate configuration (`administer entity association configurations`) and the overview page (`access entity association overview page`). Depends on core `node`, `token`, and `toolshed`; supports Drupal 10.2+ and 11.

Asset Purge Manager efficiently manages purging unused assets.

---

Asset Purge Manager **efficiently manages purging/cleanup of unused assets** — identifying and removing
files/media no longer referenced, to reclaim storage and keep the assets directory tidy. It provides its own
permissions, in the Content package.

Use it to clean up orphaned assets. It is a media/administration tool run by privileged users. Security caution:
purging assets is **destructive and irreversible** — a mis-identified "unused" asset (e.g. referenced only in
ways the scan misses) can be deleted and break content, so verify what will be purged, back up first, and gate
its permission to trusted admins. It has no access-control role beyond its permission. Configure and run the
purge.

Astrology provides daily/weekly/monthly/yearly horoscope content.

---

Astrology **provides daily, weekly, monthly and yearly horoscope content** — showing zodiac/horoscope
information (via a block/feed), for lifestyle/entertainment sites. It works across core 10–11.

Use it to display horoscopes. It is a content-display/integration feature; if it fetches horoscope data from an
external source, that's public content over HTTPS, and it has no content or access role. Configure the horoscope
display.

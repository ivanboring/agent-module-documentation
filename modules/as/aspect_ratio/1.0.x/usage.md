Aspect Ratio provides image aspect-ratio tagging.

---

Image Aspect Ratio Tagging **tags images with their aspect ratio** — computing and attaching an image's
aspect ratio (as a class/attribute/data value) so themes/CSS can reserve space or lay out images consistently
(reducing layout shift). It is in the Media package.

Use it to add aspect-ratio info to images. It is a media/content-display feature affecting image rendering;
images follow core media/image access and it has no access-control role. Configure the aspect-ratio tagging.

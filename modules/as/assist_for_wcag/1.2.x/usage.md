Assist For WCAG embeds a third-party accessibility widget via a token-authenticated script.

---

Assist For WCAG ensures accessibility by injecting an external accessibility-widget script (authenticated with a token) — embedding a third-party accessibility overlay/toolbar that offers users assistive features (font size, contrast, etc.) to help meet WCAG expectations.

The script loads a third-party accessibility widget (the token/account should be stored securely; be aware third-party overlays have their own privacy/effectiveness considerations). Supports Drupal 10, 11, and 12.

AGLS allows users and the system to add AGLS (Australian Government Locator Service) meta tags to Drupal pages, built on the Metatag module.

---

AGLS adds AGLS (Australian Government Locator Service) metadata to Drupal pages — a metadata standard
required for many Australian government websites to describe resources (creator, publisher, availability,
jurisdiction, etc.). It builds on the Metatag module, exposing AGLS meta tags that can be set per content
and site-wide. It requires PHP 8.0 and depends on `metatag`.

Use it on Australian government sites that must emit AGLS-compliant metadata. It is an SEO/metadata
feature producing meta tags; keep the emitted metadata accurate to the content, and it has no
access-control role. Configure the AGLS meta tags through Metatag's per-entity and default settings.

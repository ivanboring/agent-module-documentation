# AGLS — agent index

Adds **AGLS (Australian Government Locator Service)** metadata tags via **Metatag** — the metadata
standard for AU government sites (creator/publisher/jurisdiction/availability). Requires PHP 8.0;
depends on `metatag`. Version **2.0.0**. Core `^9.3||^10||^11`.

SEO/metadata (meta tags; no access role). Keep emitted metadata accurate; configure through Metatag.

AGROVOC Field auto-suggests AGROVOC agricultural taxonomy tags for content.

---

AGROVOC Field suggests AGROVOC taxonomy tags for content by calling a self-hosted AGROVOC (FAO's agricultural multilingual thesaurus) service — so content about agriculture/food can be tagged with standardized AGROVOC concepts, improving classification and interoperability for agricultural research/data sites.

The AGROVOC endpoint is admin-configured (self-hosted). Depends on core `taxonomy` and `field`; supports Drupal 10.3+ and 11.

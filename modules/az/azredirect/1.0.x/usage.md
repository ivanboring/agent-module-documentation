AZRedirect sends users to Azure AD login using openid_connect_windows_aad.

---

AZRedirect redirects to the Azure login portal with the OpenID Connect Windows AAD module — so a site can send users to Azure Active Directory (Entra ID) for authentication, automating the redirect to the Azure OIDC login flow for single sign-on.

Authentication and token validation are handled by the underlying `openid_connect_windows_aad` module (store client credentials securely, env-backed). Depends on `openid_connect_windows_aad`; supports Drupal 9, 10, and 11.

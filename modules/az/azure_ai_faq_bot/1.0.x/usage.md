Azure AI FAQ Bot answers FAQs using Azure Cognitive Services.

---

Azure AI FAQ Bot is a chatbot that leverages Azure Cognitive Services to understand and answer FAQ-style questions — providing a chat widget (block) that responds to visitor questions using Azure's language/QnA services, for automated support.

Azure credentials should be stored securely (env-backed); questions are sent to Azure (cost + egress). Administration is gated by `administer azure_ai_faq_bot`. Depends on core `block`; supports Drupal 10 and 11.

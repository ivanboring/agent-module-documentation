Media Download All provides a field formatter and block that offer a 'download all' link, bundling a node's media/files into a single archive download.

---

A page with several attachments — a gallery, a document set — benefits from a single 'download all' rather than clicking each file. Media Download All provides a formatter and block that bundle the media/files into one archive for download. The consideration is that the archive is generated from the referenced files, so it should honour those files' access — a download-all must not bundle files the user could not otherwise access. Confirm the generated archive respects file access, and be aware that bundling many/large files is a server-resource operation.

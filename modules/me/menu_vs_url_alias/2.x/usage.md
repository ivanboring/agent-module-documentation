Menu vs URL Alias adds conditional validation between a node's menu-item settings and its URL alias, catching inconsistencies between them.

---

A node can have both a menu link and a URL alias, and they can drift out of sync in ways that confuse navigation. Menu vs URL Alias adds validation between the two, flagging inconsistencies at save. It is an editorial/content-quality tool with no security surface. Confirm the validation rules match your site's menu/alias conventions.

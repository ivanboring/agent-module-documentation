Dynamic Links provides the ability to create dynamic links.

---

Dynamic Links **provides configurable dynamic links** — links whose target is built from tokens/parameters
(e.g. current user, current node) so a single link definition resolves per-context, usable in menus/blocks/
fields. It provides its own permissions.

Use it to create context-aware links. It is a site-building feature; link targets resolve from tokens (which
respect access), and it has no access-control role beyond its permission. Configure the dynamic links.

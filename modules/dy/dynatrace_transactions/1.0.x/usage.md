Dynatrace Transactions names Dynatrace transactions by route, bundle and highest-weight role.

---

Dynatrace Transactions **names Dynatrace transactions meaningfully** — labeling transactions in the Dynatrace
APM tool based on the request route, entity bundle and the user's highest-weight role, for clearer performance
monitoring. It works across core 8–11.

Use it to improve Dynatrace transaction naming. It is a monitoring/APM integration. Privacy note: it includes the
**user's role** in transaction names sent to Dynatrace (operational metadata) — that's low-sensitivity but keep the
Dynatrace destination trusted. It has no access-control role. Configure the transaction naming.

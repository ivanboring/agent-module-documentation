Dynamic Local Tasks lets you create dynamic local tasks for any route.

---

Dynamic Local Tasks lets administrators create local tasks (the tabs on entity/admin pages) for any
route through configuration — so custom tabs can be added to pages without code, pointing at any route. It is
configured at the `local_task` collection and provides its own permissions.

Use it to add custom tabs to routes without code. It is an administration/UI feature adding local-task links;
the tabs point to routes that enforce their own access (a tab to a route doesn't grant access to it), and it
has no access-control role beyond its permission (gating who can create tasks). Configure the dynamic local
tasks.

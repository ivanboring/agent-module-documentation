Configurable rotating placeholder text for text inputs.

---

Dynamic Placeholder provides configurable rotating placeholder text for text inputs — cycling through a set of placeholder strings in a form field (e.g. a search box) to suggest example queries or hints, a small UX enhancement. Supports Drupal 10 and 11.

Dynamic Library Loader dynamically loads libraries conditionally on entities.

---

Dynamic Library Loader **conditionally attaches asset (CSS/JS) libraries** to entity displays based on
configured conditions — so a library is only loaded where it's actually needed (e.g. on certain content types
or when a field has a value), improving front-end performance by avoiding always-on assets. It is a developer/
performance feature.

Use it to load libraries only where needed. It is a developer/theming feature; the libraries attached are
admin/developer-configured (declared libraries) and it has no content or access role. Configure the
conditional library attachments.

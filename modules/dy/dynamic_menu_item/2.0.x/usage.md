Dynamic Menu Item creates dynamic menu items.

---

Dynamic Menu Item lets you **create dynamic menu items** — menu links whose target or label is resolved
dynamically (e.g. from tokens/context) rather than being a fixed URL, for context-aware navigation. It depends
on core Menu UI and Menu Link Content, provides its own permissions, in the Menu package.

Use it for context-aware menu links. It is a site-structure/navigation feature; targets resolve from tokens/
context (which respect access) and it has no access-control role beyond its permission. Configure the dynamic
menu items.

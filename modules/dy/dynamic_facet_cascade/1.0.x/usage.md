A block with AJAX dependent dropdowns to pre-filter Search API facets.

---

Dynamic Facet Cascade provides a customizable block with AJAX dependent (cascading) dropdowns to pre-filter Search API facets — so selecting a value in one dropdown narrows the options in the next, letting visitors drill into faceted search results with linked select lists. Depends on core `views`, `search_api`, and `facets`; supports Drupal 10 and 11.

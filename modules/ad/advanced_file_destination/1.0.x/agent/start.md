# Advanced File Destination — agent index

**Destination-directory selection** for file uploads, with granular permissions. Version **1.0.11**. Core `^10||^11`.

Permissions include private-file access and directory creation — restrict those to trusted roles (path-handling near private storage). Requires core `file`, `system`, `config`.

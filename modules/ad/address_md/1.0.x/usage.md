Address for Rep. of Moldova adds a city field and a predefined list of districts for the Republic of Moldova.

---

Address for Rep. of Moldova extends the Address module with Moldova-specific address handling — adding a
city field and a predefined list of Moldovan districts, so addresses for the Republic of Moldova can be
entered with the correct administrative divisions. It depends on the Address module.

Use it on sites collecting Moldovan addresses. It is a content-editing/address feature providing localized
address fields; it has no access-control role. Configure the address field for Moldova.

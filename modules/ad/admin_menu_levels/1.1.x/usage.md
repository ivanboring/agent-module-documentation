Admin Menu Levels enhances the menu administration UI with options to filter/limit which menu items are displayed, easing management of large menus.

---

Admin Menu Levels enhances Drupal's menu administration interface with options to filter which menu
items are shown — for example limiting the displayed depth/levels — so editing very large or deep menus
is more manageable. It is an admin-UI convenience for the menu editing screens.

Use it on sites with large menu trees where the full list is unwieldy to work with. It is an
administration/UI feature affecting the menu admin display; it does not change menus, content or access,
only how the admin list is presented. No special configuration beyond enabling.

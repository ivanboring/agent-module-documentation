Admin status report shows configurable status reports/reminders to permitted admins.

---

Admin status report displays site status reports and reminders based on predefined permissions — surfacing operational status and to-do reminders to administrators (who hold the right permission), so important site conditions/tasks aren't missed.

Administration is gated by `administer admin status report`. It's an operations/admin tool with no content role. Supports Drupal 10 and 11.

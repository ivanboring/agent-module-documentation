---

Advanced Toast Messages provides customizable toast notifications — small floating notices — built with
Single Directory Components (SDC), supporting custom toast types and animations. It gives a modern,
component-based way to show dismissible toast messages (beyond the default status messages). It depends on
core SDC.

Use it to present status/notification messages as styled, animated toasts. It is a front-end/UI feature
built on SDC; it affects message presentation and has no content or access role. Configure the toast types
and animations.

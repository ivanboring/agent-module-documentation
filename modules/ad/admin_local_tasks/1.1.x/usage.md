Admin Local Tasks overrides the core local task style to a fixed one, changing how local-task tabs are displayed.

---

Admin Local Tasks changes the styling of local tasks (the tabs shown on entity pages, e.g. View/Edit/
Delete) to a fixed style — a presentation adjustment for the local-task tabs in the admin/editorial UI. It
is configured at `admin_local_tasks.settings` and provides its own permissions.

Use it to adjust local-task tab styling. It is an administration/theming feature affecting tab presentation;
it does not change content or access (local tasks still reflect the user's permissions). Configure the tab
style.

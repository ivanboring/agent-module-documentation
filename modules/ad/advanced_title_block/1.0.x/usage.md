Advanced Page Title Block provides a custom page-title block with copy text and a fixed or node-inherited background image.

---

Advanced Page Title Block provides a customizable page-title block — rendering the page/node title
with additional options such as copy text and a background image that is either fixed or inherited from
the node (e.g. the node's own image field). It is used to build richer page headers/hero titles without
custom theming. It depends on core Block and Image.

Use it to create styled title banners on pages that pull their background from node content. It is a
content-display/site-building block; the title and background derive from content and configuration,
rendered through Drupal's layers, with no access-control role. Place and configure the block where the
page header should appear.

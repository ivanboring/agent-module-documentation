Address Country Unknown lets Address fields have an empty or unknown country value.

---

Address Country Unknown provides custom Address (module) widgets and formatters that allow an empty / unknown country — so an address field can be filled in without forcing a country selection, useful when the country is genuinely unknown or not required, which the standard Address widget doesn't easily allow.

It's an Address-field enhancement with no content or access role of its own. Depends on `address`; requires Drupal 11.

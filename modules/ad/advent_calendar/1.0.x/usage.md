Advent Calendar formats a view as an advent calendar.

---

Advent Calendar **formats a View as an advent calendar** — rendering view rows as dated "door" tiles that
reveal content on their day, for seasonal campaigns/promotions. It depends on core Views.

Use it to build an advent-calendar display. It is a content-display/user-engagement feature; the tiles show
view content (which respects access) and it has no access-control role. Note the reveal-by-date is a
presentation convenience (client/time-based) — don't rely on it to embargo sensitive content. Configure the
advent-calendar view.

Advanced Language Negotiation allows language negotiation based on both domain and path prefix.

---

Advanced Language Negotiation lets Drupal determine the active language from a combination of **domain
and URL path prefix** — so a multilingual, multi-domain site can map languages by domain and by path prefix
together (e.g. a language per domain, plus sub-language paths), beyond core's single-method negotiation. It
is in the Multilingual package.

Use it where language must be derived from both domain and path. It is a multilingual/routing feature
affecting which language is active; it does not change content or access and has no access-control role.
Configure the negotiation rules.

# Advanced Language Negotiation — agent index

Negotiates the site language based on **both domain and URL path prefix** (map languages per domain + path —
beyond core's single-method negotiation). Version **1.0.0-beta3**. Core `^9||^10||^11`.

Multilingual/routing — affects which language is active; no content/access change. No access role.

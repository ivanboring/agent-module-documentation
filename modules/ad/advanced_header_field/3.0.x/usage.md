Advanced Header Field provides a customizable field type for heading text and an optional subtitle.

---

Advanced Header Field provides a field type for headings — storing heading text plus an optional
subtitle, with configurable heading level/markup, so editors can add structured headings (title + subtitle)
as a field rather than in the body. It ships an `advanced_header_field_navigation` submodule and is in the
Field types package.

Use it for structured heading/subtitle fields. It is a content-editing/fields feature; the heading text is
authored content output through Drupal's rendering (escaped normally), and it has no access-control role.
Add the field and configure the heading level.

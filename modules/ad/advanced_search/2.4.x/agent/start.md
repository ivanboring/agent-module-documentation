# Advanced Search (advanced_search) — agent index

Advanced Search **block** + enhancements over **Search API / Facets / Search API Solr**.
Version **2.4.2**. Core `^8.8 || ^9 || ^10 || ^11`. Depends on `facets`, `facets_summary`,
`search_api_solr`.

For sites **already running Search API against Solr** — it enhances a Solr-backed index, does not
provide one. Confirm the index exposes the facets you want to offer.

Advanced Image Media Attributes Formatter adds fetchpriority and decoding attributes to image and media fields.

---

Advanced Image Media Attributes Formatter adds performance-related HTML attributes to image/media field
output — `fetchpriority` (hint the browser to prioritize/deprioritize an image, e.g. `high` for the LCP hero)
and `decoding` (`async`/`sync`) — improving perceived load performance. It is in the Custom package.

Use it to tune image loading with fetchpriority/decoding. It is a content-display/formatter feature affecting
image markup attributes; it does not change content or access and has no access-control role. Select the
formatter and configure the attributes.

Admin List Filter adds a quick client-side filter box to admin tables.

---

Admin List Filter adds client-side filtering to admin listing pages — a search/filter box that instantly narrows rows in admin tables (content, users, config lists) as you type, without a page reload, speeding up finding items in long admin lists.

It's an admin-UX enhancement with no content or access role of its own. Supports Drupal 10.3+ and 11.

Advanced Gutenberg Blocks provides additional (addon) blocks for the Gutenberg editor in Drupal.

---

Advanced Gutenberg Blocks extends the Gutenberg editor integration with a set of additional blocks
beyond the defaults — richer content components editors can drop into Gutenberg-authored content. It
depends on the Gutenberg module and core Media / Media Library (several of its blocks work with media).

Use it on a Gutenberg-based editing experience to give authors more building blocks (layout, media and
content components) without custom development. It is a content-editing/site-building feature; blocks
render authored content through Drupal's render layer and have no access-control role.

Admin Theme by Content Type sets whether to use the admin theme per content type.

---

Admin Theme by Content Type **chooses whether the admin theme is used per content type** — so node add/edit
forms for some content types can use the admin theme while others use the front-end theme, per-type. It depends
on core Node, in the Administration package.

Use it to control the edit-form theme per content type. It is an administration/theming feature affecting the
edit-form theme; it has no content or access role. Configure the per-type admin-theme setting.

Advanced FileSystem is a broad enterprise file-management suite with many processors and integrations.

---

Advanced FileSystem is an enterprise file-management suite for Drupal 10/11/12 — providing pluggable path strategies, batch migration (with dry-run), orphan detection, retention/lifecycle rules, deduplication (hash + perceptual), quota enforcement, file backup to S3/FTP/GCS/R2, metadata extraction (EXIF/PDF/audio/video), AI features (transcription, alt text, smart filenames, embeddings), image optimizer, CDN integration, HMAC-signed URLs, ClamAV antivirus, LGPD/GDPR auditing, webhooks, and enterprise processors (PDF/Video/Document/Presentation) exposed as Media Source plugins with Views integration.

Given its breadth (external storage, AI, antivirus, signed URLs), configure each integration's credentials securely (env-backed) and review the features you enable; administration is gated by `administer advanced filesystem`. Supports Drupal 10, 11, and 12.

- Provide pluggable path strategies.
- Batch-migrate files with dry-run.
- Detect orphans.
- Enforce retention/lifecycle rules.
- Deduplicate (hash + perceptual).
- Enforce quotas.

- Optimize images + CDN integration.

Admin Toolbar Entity Version displays version information about the entity being viewed in the site Toolbar.

---

Admin Toolbar Entity Version shows version/revision information about the entity currently being viewed —
in the admin Toolbar — so editors/developers can see which revision/version of a node (etc.) they're looking
at at a glance. It depends on core Toolbar, in the Administration package.

Use it to surface the current entity's version in the toolbar. It is an administration/UI feature; the
information reflects the viewed entity (admin/editor context) and it has no access-control role. Enable it to
show version info in the toolbar.

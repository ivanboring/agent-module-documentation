Adopt.io provides integration with the GoAdOpt cookie-consent service.

---

Adopt.io **integrates the GoAdOpt (Adopt.io) cookie-consent banner** — adding GoAdOpt's cookie/consent
management platform (CMP) so the site can present a compliant cookie banner and collect visitor consent. It is in
the Web services package.

Use it for cookie-consent compliance via GoAdOpt. It is a privacy/compliance feature. Data-handling: it loads
**GoAdOpt's third-party CMP script** (which manages consent and may set cookies / contact GoAdOpt), and consent
decisions should govern whether other tracking runs — wire your analytics/marketing tags to respect the CMP's
signal. It has no content or access role. Configure the GoAdOpt CMP.

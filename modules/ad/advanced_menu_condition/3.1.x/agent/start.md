# Advanced Menu Condition — agent index

Condition plugin based on the **active menu trail** — multi-select + inheritance, so blocks/layouts
show across a whole menu branch (parent + descendants), not page-by-page. Provides **Drush commands**.
Version **3.1.0**. Core `^10||^11`.

Display/visibility (Drupal condition system) — governs where things appear, not access.

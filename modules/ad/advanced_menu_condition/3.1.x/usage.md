Advanced Menu Condition provides a condition plugin based on the active menu trail, allowing multiple selections and inheritance to child items.

---

Advanced Menu Condition adds a condition plugin that evaluates against the active menu trail — which
menu items are active for the current page. Unlike a simple "current path" check, it supports selecting
multiple menu items and inheritance, so a block (or any condition-aware feature) can be shown across a
whole menu branch (a parent and all its descendants) rather than page by page. It provides Drush
commands.

Use it for section-based visibility: show a sidebar, banner or block on an entire menu section without
listing every path. It is a display/visibility feature built on Drupal's condition system; it governs
where things appear, not access to them. The condition is configured where Drupal conditions are used
(block visibility, Layout Builder, etc.).

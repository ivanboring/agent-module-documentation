Admin Tooltips adds an extra field in the fields config to add text used as a tooltip.

---

Admin Tooltips adds an extra setting to field configuration for a tooltip text — so site builders can
attach helpful tooltip/guidance text to fields that is shown to editors, aiding content entry. It is in the
Fields package.

Use it to give editors field-level tooltips. It is a content-editing/UX feature adding guidance text to
fields; it does not change content or access and has no access-control role. Configure the tooltip on the
field.

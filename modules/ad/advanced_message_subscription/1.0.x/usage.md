Advanced Message Subscription provides fine-grained control over subscription to messages.

---

Advanced Message Subscription provides fine-grained subscription control for the Message module — letting
users/administrators control which message notifications they subscribe to (per type/category), so
notification delivery can be tailored. It provides its own permissions, in the Message package.

Use it to give users granular notification-subscription control. It is a user-engagement/messaging feature
governing notification subscriptions; it has no content or access role beyond its permission. Configure the
subscription options.

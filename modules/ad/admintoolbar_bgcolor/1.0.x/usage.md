Admin Toolbar Background Color changes the toolbar background color.

---

Admin Toolbar Background Color **changes the admin toolbar's background color** — letting you set a distinct
toolbar color, commonly used as a per-environment indicator (e.g. red on production, green on dev) so operators
know which environment they're editing. It depends on the Color Field module, in the Administration package.

Use it to color-code environments in the toolbar. It is an administration/UX feature affecting the admin toolbar
appearance; it has no content or access role. Configure the toolbar color.

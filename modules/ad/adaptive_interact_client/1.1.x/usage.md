Interact client provides the Adaptive Interact client integration, connecting a Drupal site to the Adaptive Interact platform.

---

Interact client (adaptive_interact_client) is the client-side integration for Adaptive Interact — a
personalization/engagement platform — connecting a Drupal site to that service so its personalization/
interaction features can run on the site. It is in the Adaptive Interact package.

Use it on sites using the Adaptive Interact platform. As an engagement/personalization integration it
typically loads the platform's client (JavaScript) and may send visitor/interaction data to the service —
so store any API credentials as secrets, and consider the privacy/consent implications of the data sent to
the platform (obtain consent and disclose where required). It is an integration feature; configure the
platform connection.

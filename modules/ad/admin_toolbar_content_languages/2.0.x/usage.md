Administration Toolbar - Content languages adds a dropdown of available languages when adding content, in the Administration toolbar.

---

Administration Toolbar - Content languages enhances the Admin Toolbar with a language dropdown — for
content types that default to the current language, it adds a menu of available languages so editors can
quickly start creating content in a specific language directly from the toolbar. It depends on Admin
Toolbar and Admin Toolbar Tools.

Use it on multilingual sites to speed up creating content in different languages. It is an administration/
UI convenience for multilingual content creation; it respects existing content-creation permissions and
has no access-control role. Enable it alongside Admin Toolbar.

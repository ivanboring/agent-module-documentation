# Administration Toolbar - Content languages — agent index

Adds a **language dropdown to the Admin Toolbar** for creating content in available languages (content
types defaulting to current language). Depends on `admin_toolbar`, `admin_toolbar_tools`. Version
**2.0.1**. Core `^10||^11`.

Admin/UI convenience for multilingual content — respects content-creation permissions; no access role.

Advanced Mega Menu provides a grid-based layout builder for creating dynamic multi-column mega menus using Views and Blocks.

---

Advanced Mega Menu provides a grid-based layout builder for mega menus — letting site builders create
dynamic, multi-column mega-menu dropdowns populated with Views and Blocks, arranged in a grid. This supports
rich navigation menus (featured content, images, columns of links) beyond simple link lists. It is
configured at `advanced_mega_menu.megamenu_content.settings` and provides its own permissions.

Use it to build rich mega menus. It is a site-structure/navigation feature; the menu content comes from
Views/Blocks (which respect their own access) and it has no access-control role. Configure the mega-menu
grid and content.

Analog Digital Clock Block provides configurable SVG and CSS-based clock blocks.

---

Analog Digital Clock Block provides **configurable analog and digital clock blocks** — SVG/CSS-based
clocks (with multiple styles/timezones) that can be placed in any block region. It depends on core Block, in
the Analog Digital Clock package.

Use it to display clocks on the site. It is a content-display feature; the clock is admin-configured
presentation (client-side time) and it has no content or access role. Place and configure a clock block.

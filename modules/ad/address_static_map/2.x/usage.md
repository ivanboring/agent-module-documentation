Address Static Map displays a Google Static Map image based on an entity's Address field value.

---

Showing a map for an address is a common display need. Address Static Map renders a Google Static Maps image from an Address field. It needs a Google Maps API key (a credential to keep out of plain config; restrict it by referrer). Static Maps is a paid Google service past a free tier, so watch usage. As a static image it does not load interactive third-party map scripts (less tracking than an embedded interactive map). Confirm the address data is intended to be shown publicly.

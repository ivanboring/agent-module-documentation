# Adnuntius — agent index

Displays **Adnuntius.com ads** in Drupal as configurable **ad blocks**. Depends on core `block`,
`field`. Config at `adnuntius.settings`; provides permissions. Version **8.x-1.0-beta6**. Core
`^9.1||^10||^11||^12`.

Advertising integration — embeds third-party ad JS (privacy/consent + CSP considerations). Configure
account/ad units; place blocks.

Add to Calendar provides a computed field that renders add-to-calendar links (Google, Outlook, iCal) from an event's date fields.

---

Event pages want an 'add to calendar' button that drops the event into the visitor's calendar. Add to Calendar provides a computed field that generates those links — Google Calendar, Outlook, iCal download — from the event's date/title/location fields, so no manual link-building. It is a display-layer field with no security surface; the links are generated from the event's own field data.

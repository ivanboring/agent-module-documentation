A block with an icon button to switch to dark mode.

---

Dark Mode Button (dmb) provides a block with an icon button to switch to dark mode — a simple toggle block so visitors can switch the site between light and dark appearance, persisting their choice. It's a theming/frontend feature. Depends on core `block`; supports Drupal 8 through 11.

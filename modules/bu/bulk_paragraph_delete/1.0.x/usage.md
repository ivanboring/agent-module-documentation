Bulk Paragraph Delete lets admins delete multiple paragraph types at once.

---

Bulk Paragraph Delete provides bulk deletion for paragraph types from the admin UI — so administrators can remove multiple Paragraphs types in one operation instead of deleting them one at a time, useful when cleaning up a site's paragraph configuration.

Deleting paragraph types is destructive (affects config/content); it follows Paragraphs administration access — restrict to trusted admins and back up first. Depends on `paragraphs`; supports Drupal 10.3+ and 11.

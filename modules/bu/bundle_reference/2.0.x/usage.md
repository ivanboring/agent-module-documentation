Bundle Reference defines a field type where a user can reference entity bundles.

---

Bundle Reference defines a **field type that references entity bundles** — the *types* (e.g. content
types, vocabularies, paragraph types) rather than individual entities — so content can point at a bundle
definition, useful for configuration-driven behaviour and site-building. It is in the Field types package.

Use it where content needs to reference a bundle/type. It is a fields/site-building feature; it stores a
bundle machine name and has no content or access role. Add the bundle-reference field to a bundle.

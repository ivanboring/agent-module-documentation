Bundle name in tabs changes the title of admin tabs to include the bundle name.

---

Bundle name in tabs changes admin local-task (tab) titles to include the bundle name — so on admin
listings/edit screens the tabs show which bundle they relate to (e.g. "Manage fields (Article)"),
disambiguating tabs when working across multiple bundles. It is in the Administration package.

Use it to make admin tabs clearer about their bundle. It is an administration/UI feature affecting tab
titles; it does not change content or access and has no access-control role. Enable it to include bundle
names in tab titles.

Bundle Redirect allows setting a redirect from a node itself.

---

Bundle Redirect lets you **set a redirect from a node to another destination** — configured per bundle, so
nodes of a type automatically redirect (e.g. a "link" content type that just forwards elsewhere). It depends on
the Redirect module, provides its own permissions, in the Other package.

Use it to make bundles redirect. It is a site-structure/URL feature; the redirect destination is
**admin/editor-configured** (trusted input, per the Redirect module) and it has no access-control role beyond
its permission. Configure the bundle redirect. (As with any editor-set redirect target, keep destinations
internal/expected to avoid confusing off-site forwards.)

Bulk Term Delete lets users delete multiple taxonomy terms at once from the taxonomy terms list page.

---

Bulk Term Delete adds the ability to delete multiple taxonomy terms in one operation from the terms
list page — selecting several terms and removing them together, instead of deleting each individually. It
depends on core Taxonomy.

Use it to clean up or reorganize large vocabularies efficiently. It is an administrative/taxonomy tool;
deleting terms is a destructive operation, so it respects taxonomy administration permissions (a user can
only bulk-delete terms they'd be allowed to delete) and — as with any bulk delete — use it deliberately,
since removing terms can affect content referencing them. Be mindful of term deletion's impact on tagged
content.

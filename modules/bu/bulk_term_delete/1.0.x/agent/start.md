# Bulk Term Delete — agent index

Delete **multiple taxonomy terms at once** from the terms list page (vs one by one). Depends on core
`taxonomy`. Version **1.0.6**. Core `^10.3||^11`.

Admin/taxonomy tool — respects taxonomy admin permissions; destructive (mind impact on content
referencing deleted terms) — use deliberately.

Buster provides a cache buster for public file URLs.

---

Buster provides a **cache buster for public file URLs** — appending a changing token/version to public
file links so browsers and CDNs fetch the current file after it changes, instead of serving a stale cached
copy. It works across core 8–11.

Use it to bust stale caches on updated public files. It is a performance/media feature affecting how file URLs
are generated; it has no content or access role. Enable it to cache-bust public file URLs.

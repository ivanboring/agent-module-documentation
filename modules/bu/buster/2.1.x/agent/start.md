# Buster — agent index

Provides a **cache buster for public file URLs** (append a changing token so browsers/CDNs fetch the current
file after it changes — no stale copies). Version **2.1.0**. Core `^8||^9||^10||^11`.

Performance/media — affects file-URL generation; no content/access role.

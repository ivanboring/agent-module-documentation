# Buttons Config (buttons_config) — agent index

Changes the **submit button label** on content and media type forms.
Version **1.0.9**. Core `^10 || ^11`.

Small change, real effect: an application form whose button says "Save" leaves people unsure
whether they have applied.

**The label is a promise about what happens — make it accurate, not merely friendlier.** "Publish"
on a moderated content type that actually sends the item to review has made the interface *less*
truthful. Match the word to the outcome including what moderation does.

Button text is **user-facing copy** — it needs translating on a multilingual site, through the usual
route rather than typed once in one language.

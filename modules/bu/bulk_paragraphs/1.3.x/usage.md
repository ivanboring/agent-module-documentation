Bulk Paragraphs quickly creates many paragraph items with default/incrementing values.

---

Bulk Paragraphs bulk-generates paragraphs with configurable default values and incrementing — so editors can quickly create many paragraph items at once (with default field values, optionally incrementing) instead of adding them individually, speeding up building repetitive paragraph-based content.

Usage is gated by `use bulk paragraphs`. Depends on `paragraphs` and core `datetime`; supports Drupal 10.2+ and 11.

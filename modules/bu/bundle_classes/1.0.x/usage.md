Bundle Classes shows how to use bundle classes via the bca module (examples only).

---

Bundle Classes contains examples of how bundle classes can be used — a demonstration/reference module (built on the bca module) showing developers how to implement per-bundle entity classes. It is explicitly NOT for use on production sites; it's for learning/reference.

It's a developer/example module with no content or access role of its own. Depends on `bca`; supports Drupal 10.5+, 11.2+, and 12.

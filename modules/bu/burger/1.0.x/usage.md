Burger Menu adds a hamburger-toggle fullscreen navigation menu.

---

Burger Menu provides a hamburger menu with fullscreen navigation — a mobile-friendly toggle button that opens a fullscreen overlay navigation (based on the Burger JS plugin), placed via a block, for clean responsive navigation.

It's a navigation/theming enhancement with no content or access role of its own. Depends on core `block`; requires Drupal 11.

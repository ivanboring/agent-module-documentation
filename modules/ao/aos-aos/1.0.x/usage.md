AOS provides integration with the AOS javascript library.

---

AOS integrates the **AOS (Animate On Scroll)** JavaScript library into Drupal — so elements animate as
they scroll into view (fade, slide, zoom, etc.). The project directory is `aos-aos`; the **module machine name
is `aos`**, in the Other package.

Use it to add scroll animations. It is a theming/front-end feature that attaches the AOS library and animation
attributes; it has no content or access role. Enable it and apply AOS animations to elements.

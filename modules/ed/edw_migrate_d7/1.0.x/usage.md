EDW Migrate D7 provides helpful classes for migrating from Drupal 7.

---

EDW Migrate D7 provides **helper classes for migrating from Drupal 7** — reusable process plugins/source
utilities that ease building D7-to-current migrations, on top of Migrate Plus/Tools/Drupal. It depends on core
Migrate and Migrate Plus/Tools/Drupal, in the Migration package.

Use it as a developer aid for D7 migrations. It is a developer/migration tool run by privileged users; it
processes D7 source data with migration privileges (validate sources; run as a trusted operator) and it has no
access-control role. Build your D7 migration using its helpers.

# Editor Advanced Table — agent index

**Adds ID, Language Direction, and CSS classes to CKEditor 5 tables**. Depends on core `ckeditor5`. Version
**1.0.2**. Core `^10||^11`.

Content-editing/WYSIWYG — table markup passes through the text format (allow/sanitize); no access role.

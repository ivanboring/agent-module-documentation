Editor Advanced Table adds ID, direction and CSS classes to CKEditor 5 tables.

---

Editor Advanced Table **enriches CKEditor 5 tables** — letting editors set an ID, language direction and CSS
classes on tables in CKEditor 5, for more control over table markup. It depends on core CKEditor 5.

Use it for richer table attributes in content. It is a content-editing/WYSIWYG feature; table markup passes through
the text format (allow/sanitize the attributes) and it has no access-control role. Configure the table tool.

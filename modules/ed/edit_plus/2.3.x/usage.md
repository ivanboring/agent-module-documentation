Edit + provides inline editing, letting users edit content in place on the rendered page.

---

Edit + (edit_plus) provides inline / in-place editing — letting authorized users edit content directly
on the rendered front-end page rather than going to a separate edit form, with block/landing-page/layout
building helpers. It ships numerous submodules (CTA/header/image/teaser blocks, landing page, layout block,
Layout Builder integration), depends on Tempstore Plus and Twig Events, provides Drush commands and its own
permissions, in the Page Building package.

Use it for a front-end inline-editing experience. It is a content-editing/page-building feature. As with any
in-place editing, editing capability is governed by its permissions plus the underlying entity/field edit
access — so only users who may edit the content can change it; verify the permissions are granted
appropriately (inline editing shouldn't expose editing to users who lack edit access). Configure the inline
editing and permissions.

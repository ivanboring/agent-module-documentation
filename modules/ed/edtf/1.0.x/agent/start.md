# EDTF — agent index

Provides **date fields supporting the Extended Date/Time Format (EDTF)** (uncertain/approximate/partial/ranged
dates; archival metadata). Version **1.0.0-beta4**. Core `^9||^10||^11`.

Fields/content — values follow normal field handling; no content/access role.

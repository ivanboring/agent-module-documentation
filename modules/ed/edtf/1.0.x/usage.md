EDTF provides date fields with Extended Date/Time Format support.

---

EDTF provides **date fields supporting the Extended Date/Time Format (EDTF)** — storing and displaying dates
that are uncertain, approximate, partial or ranged (e.g. "1920?", "19XX", seasons), as used in archives/library
metadata. It is in the Field types package.

Use it for scholarly/archival date modeling. It is a fields/content feature; values follow normal field handling
and it has no content or access role. Add the EDTF field.

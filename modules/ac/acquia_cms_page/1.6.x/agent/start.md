# acquia_cms_page — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides an unstructured Page content type and related configuration. Version — see
`acquia_cms_page`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_image:acquia_cms_image`, `drupal:path`, `field_group:field_group`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

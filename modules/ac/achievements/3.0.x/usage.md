Achievements lets users unlock achievements and earn points based on milestones.

---

Achievements is a **gamification** framework — users **unlock achievements** and **earn points** as they
hit milestones (posting content, commenting, logging in, custom events), with leaderboards
(`achievement_totals`, `achievement_unlocks` Views) and a per-user achievements page. Developers define
achievements and award them from their own code/events. It depends on core File and the jQuery UI
effects/dialog modules, is configured at `achievements.settings`, in the Achievements package.

Use it to add points/badges and drive user engagement. It is a user-engagement feature; achievement progress
is per-user and its leaderboard/pages are governed by normal Views/entity access — it has no access-control
role. Note leaderboards can expose usernames and activity (a minor privacy consideration). Configure and
define achievements.

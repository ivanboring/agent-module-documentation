# Achievements — agent index

A **gamification framework** — unlock achievements + earn points on milestones (leaderboards via
`achievement_totals`/`achievement_unlocks` Views, per-user page; developers define/award from code). Depends
on core `file`, jQuery UI effects/dialog. Config at `achievements.settings`. Version **3.0.3**. Core
`^9||^10||^11||^12`.

User-engagement — per-user progress; pages governed by Views/entity access (leaderboards expose usernames/
activity — minor privacy note); no access role.

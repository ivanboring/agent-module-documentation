# acquia_cms_article — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides an Article content type and related configuration. Version — see
`acquia_cms_article`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_person:acquia_cms_person`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

# acquia_cms_site_studio — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Module for Site Studio Installation Code. Version — see
`acquia_cms_site_studio`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_common:acquia_cms_common`, `cohesion_base_styles # phpcs:ignore`, `cohesion_custom_styles # phpcs:ignore`, `cohesion_elements # phpcs:ignore`, `cohesion_style_helpers # phpcs:ignore`, `cohesion_sync # phpcs:ignore`, `cohesion_website_settings # phpcs:ignore`, `collapsiblock:collapsiblock`, `drupal:media_library`, `sitestudio_page_builder # phpcs:ignore`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.
**Requires the proprietary Site Studio (Cohesion) platform.**

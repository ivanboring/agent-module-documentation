Accessibility Block provides accessibility tools like resize.

---

Accessibility Block provides a **block of visitor accessibility tools** — controls such as text resize,
contrast adjustment and similar aids to help users adapt the page to their needs. It works across core 10–11.

Use it to offer visitor accessibility controls. It is an accessibility/front-end feature affecting presentation;
settings are client-side preferences and it has no content or access role. Place and configure the accessibility
block.

# acquia_cms_place — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides a Place content type and related configuration. Version — see
`acquia_cms_place`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_image:acquia_cms_image`, `address:address`, `drupal:path`, `scheduler:scheduler`, `drupal:telephone`, `field_group:field_group`, `geocoder:geocoder_address`, `geocoder:geocoder_geofield`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

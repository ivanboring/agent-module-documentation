# Accessible Menu — agent index

JS library for **WCAG-compliant, accessible menus** (keyboard nav, ARIA, focus). Depends on core
`menu_ui`; `accessible_menu_bootstrap_5` submodule. Version **1.0.1**. Core `^10||^11`.

Accessibility/front-end feature — enhances menu markup/behaviour; no content/access role.

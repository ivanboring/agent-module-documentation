# acquia_cms_image — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides an Image media type and related configuration. Version — see
`acquia_cms_image`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_common:acquia_cms_common`, `drupal:media`, `drupal:media_library`, `imce:imce`, `drupal:image`, `field_group:field_group`, `focal_point:focal_point`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

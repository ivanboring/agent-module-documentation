# Acquia CMS Audio — agent index

Provides an **Audio media type** + config (incl. **SoundCloud** via `media_entity_soundcloud`) for Acquia
CMS. Depends on `acquia_cms_common`, core `media`, `media_library`; provides permissions. Version
**1.5.2**. Core `^9.4||^10||^11`.

Media/config feature — media access via core media/entity access; no special access role.

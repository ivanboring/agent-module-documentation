Acquia CMS Audio provides an Audio media type and related configuration, including SoundCloud support, for Acquia CMS.

---

Acquia CMS Audio provides an Audio media type and its configuration for Acquia CMS — letting editors
manage audio as media, including SoundCloud-hosted audio (via `media_entity_soundcloud`). It depends on
Acquia CMS Common, core Media and Media Library, and provides its own permissions. It is part of the
Acquia CMS component set.

Use it on Acquia CMS sites that need audio media. It is a media/configuration feature adding an audio
media type; media access is governed by core media/entity access, and it has no special access role.
Configure the audio media type and its source (file/SoundCloud).

ActiveNet provides a basic ActiveNet integration, typically for YMCA Website Services.

---

ActiveNet provides a basic integration with ActiveNet — the Active Network activity-registration/
management platform — commonly used by YMCA Website Services sites to surface programs/activities from
ActiveNet in Drupal. It provides its own permissions, in the YMCA Website Services package.

Use it to integrate ActiveNet data. Security note: it authenticates to the ActiveNet API with credentials —
**store those as secrets** (not in exported config), and operate over HTTPS. Fetched program/activity data is
external content (escape on display). It has no access-control role beyond its permission. Configure the
ActiveNet connection.

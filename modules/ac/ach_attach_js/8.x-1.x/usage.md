ACH Attach JS helps run Drupal.attachBehaviors on content injected into the DOM.

---

ACH Attach JS provides a JavaScript library for calling `Drupal.attachBehaviors` on content added dynamically to the DOM — so behaviors (widgets, event handlers) are correctly attached to AJAX-loaded or JS-injected markup that Drupal's automatic behavior attachment doesn't cover. It's a developer helper.

It's a front-end/developer library with no content or access role of its own. Supports Drupal 9.2+, 10, and 11.

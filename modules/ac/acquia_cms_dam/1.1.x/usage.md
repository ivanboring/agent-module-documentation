Acquia CMS DAM provides Acquia DAM related configuration, integrating Acquia's digital-asset-management with Acquia CMS media.

---

Acquia CMS DAM provides configuration to integrate Acquia DAM (Acquia's digital-asset-management
platform) with Acquia CMS — so editors can use Acquia DAM-hosted assets within the Acquia CMS media system.
It depends on Acquia CMS Image and is part of the Acquia CMS component set.

Use it on Acquia CMS sites using Acquia DAM for centralized asset management. The connection uses Acquia DAM
credentials — store them as secrets. It is a media/DAM integration; it governs asset sourcing/display, not
content access. Configure the Acquia DAM connection.

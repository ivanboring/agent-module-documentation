# Acquia CMS DAM — agent index

Provides **Acquia DAM** integration/config for Acquia CMS (DAM-hosted assets as media). Depends on
`acquia_cms_image`. Version **1.1.1**. Core `^9.4||^10||^11`.

Store Acquia DAM credentials as secrets. Media/DAM integration — governs asset sourcing, not content
access.

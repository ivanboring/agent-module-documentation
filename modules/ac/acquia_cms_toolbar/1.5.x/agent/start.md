# acquia_cms_toolbar — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Acquia CMS styling brought to admin toolbar. Version — see
`acquia_cms_toolbar`'s release. Core `^10.3 || ^11`. Depends on: `admin_toolbar:admin_toolbar`, `admin_toolbar:admin_toolbar_tools`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

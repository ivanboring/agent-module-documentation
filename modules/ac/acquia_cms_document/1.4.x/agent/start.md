# acquia_cms_document — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides a Document media type and related configuration. Version — see
`acquia_cms_document`'s release. Core `^10.3 || ^11`. Depends on: `drupal:media`, `drupal:media_library`, `acquia_cms_common:acquia_cms_common`, `field_group:field_group`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

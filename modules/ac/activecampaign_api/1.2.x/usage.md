ActiveCampaign API is the base client for connecting Drupal to ActiveCampaign.

---

ActiveCampaign API provides an ActiveCampaign API implementation for Drupal — the connectivity layer to ActiveCampaign (email marketing/CRM automation), so other modules/custom code can sync contacts, manage lists, and trigger automations via the ActiveCampaign API.

ActiveCampaign API credentials are configured under `manage activecampaign_api settings` and should be stored securely (env-backed). Supports Drupal 9, 10, and 11.

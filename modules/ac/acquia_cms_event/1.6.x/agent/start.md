# acquia_cms_event — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides an Event content type and related configuration. Version — see
`acquia_cms_event`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_place:acquia_cms_place`, `drupal:datetime`, `schema_metatag:schema_event`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

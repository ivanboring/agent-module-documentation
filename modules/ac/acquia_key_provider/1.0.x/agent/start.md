# Acquia Key Provider — agent index

A **Key module provider that reads secrets from Acquia hosting's secret storage** (source keys from the
platform vs config/files). Depends on `key`. Version **1.0.0**. Core `^10.4||^11.1`.

**Security-positive** secrets pattern (platform-managed secrets via Key). Security rests on Acquia's platform
controls. No access role.

ActiveTickets Client provides an ActiveTickets client interface.

---

ActiveTickets Client provides a **client interface to the ActiveTickets** ticketing/events platform —
connecting Drupal to ActiveTickets to fetch/manage events and ticketing data. It is in the ActiveTickets
package.

Use it to integrate ActiveTickets. It is an integration feature. Security/data handling: it calls the
**ActiveTickets API** with **credentials** (store as secrets — env/Key — over HTTPS) and may exchange
customer/booking data (PII) — handle per privacy obligations. It has no access-control role. Configure the
ActiveTickets credentials.

Account Name replaces the 'My account' menu item with the user's name and avatar.

---

Account Name changes the My Account menu item so it displays the logged-in user's name and picture instead of the generic 'My account' text — a small personalization that makes the account menu clearer and more personal.

It's a UI/theming enhancement with no content or access role of its own. Supports Drupal 8.9 through 11.

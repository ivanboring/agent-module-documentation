Acquia CMS Component provides reusable components and related configuration for Acquia CMS sites.

---

Acquia CMS Component provides a set of reusable components (and their configuration) for Acquia CMS —
building blocks editors can use to compose pages within the Acquia CMS ecosystem. It depends on Acquia CMS
Common and is part of the Acquia CMS component set.

Use it on Acquia CMS sites to get the standard component library. It is a content-editing/site-building
feature providing components; components are authored content rendered through Drupal's layers, and it has
no access-control role. Enable it as part of the Acquia CMS setup.

# acquia_cms_person — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides a Person content type, a structured data representation of people associated with a website or organization. Version — see
`acquia_cms_person`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_place:acquia_cms_place`, `scheduler:scheduler`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

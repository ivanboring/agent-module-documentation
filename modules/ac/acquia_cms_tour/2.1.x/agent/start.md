# acquia_cms_tour — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Provides a tour page for Acquia CMS. Version — see
`acquia_cms_tour`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_common:acquia_cms_common`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

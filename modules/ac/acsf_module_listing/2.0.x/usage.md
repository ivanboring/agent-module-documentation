ACSF Modules Listing reports enabled modules across ACSF sites for the factory.

---

ACSF Modules Listing provides a modules listing for Acquia Cloud Site Factory (ACSF) — surfacing which modules are enabled across the sites in an ACSF environment, so factory operators can audit module usage/consistency across a large multi-site fleet.

Administration is gated by `administer acsf_environment_entity`. It's an ACSF ops/reporting tool with no content role. Supports Drupal 8 through 11.

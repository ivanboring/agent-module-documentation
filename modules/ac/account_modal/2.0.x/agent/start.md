# Account Modal — agent index

Opens **account links (login/register/reset) in a modal window** (in-context account UX vs a separate page).
Config at `account_modal.admin_settings`. Version **2.0.0**. Core `^10||^11`.

UI/display — the underlying login/registration forms still enforce normal auth/access (modal is
presentation). No access role.

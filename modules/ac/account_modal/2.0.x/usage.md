Account Modal adds the ability to open account links in a modal window.

---

Account Modal lets account-related links (login, register, password reset) open in a modal/dialog
instead of navigating to a separate page — for a smoother, in-context account UX. It is configured at
`account_modal.admin_settings`, in the User interface package.

Use it to present account forms as modals. It is a UI/display feature affecting how account links open; the
underlying login/registration forms still enforce Drupal's normal authentication and access (the modal is
just presentation), and it has no access-control role. Configure which account links open in a modal.

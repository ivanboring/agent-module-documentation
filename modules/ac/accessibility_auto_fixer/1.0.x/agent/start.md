# Accessibility Auto Fixer — agent index

A **WCAG accessibility scanner** with a UI dashboard, batch scanning, and CI support. Version **1.0.1**. Core `^10.3||^11`.

Permissions: `access accessibility reports`, `administer accessibility settings`. Depends on core `node`. Reports are authenticated admin UI — restrict to editors/QA and trusted admins.

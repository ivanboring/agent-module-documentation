Style Options Media adds an extra style option for media elements within the Style Options layout/styling system.

---

Style Options lets site builders attach styling choices to layout components; Style Options Media extends that with an option for media elements, so media placed in a layout can carry a style choice (a treatment, a size, an alignment) from the Style Options UI. It is a theming/layout convenience for sites using the Style Options ecosystem, with no security surface.

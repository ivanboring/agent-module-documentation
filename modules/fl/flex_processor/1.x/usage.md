Flex Processor is a framework module for handling configurable data processing pipelines.

---

Some sites need to transform data through configurable steps — clean, map, enrich — without hard-coding a pipeline. Flex Processor provides a framework for such data-processing pipelines. It is developer/site-builder infrastructure; what it does depends entirely on the processors configured, so its security posture is that of the processors and the data they handle. As a framework it has no fixed surface; review what a given pipeline does and where its data comes from.

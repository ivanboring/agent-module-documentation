Flag Block makes a Flag link available as a block, so a flag action (bookmark, favourite) can be placed anywhere a block can go.

---

Flag provides flag/unflag links, usually on the flagged content. Flag Block exposes a flag link as a block for placement elsewhere. It is a UI convenience built on the Flag module; the flag action itself has Flag's access model, so the block does not bypass it (a user who cannot flag will not get a working link). Confirm the block's context resolves the right entity to flag.

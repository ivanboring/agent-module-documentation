JS Timer provides a JavaScript timer API and widgets — a live clock and a countdown timer — for dynamic time displays.

---

Displaying live time — a running clock, a countdown to a deadline — needs client-side updating. JS Timer provides a timer API plus `jst_clock` (a live clock) and `jst_timer` (a countdown) widgets. It is a front-end display utility with no security surface. Confirm timezone handling matches intent, since a clock or countdown is only useful if it shows the right time.

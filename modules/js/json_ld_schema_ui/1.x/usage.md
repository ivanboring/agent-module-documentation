JSON-LD Schema UI adds a UI for configuring JSON-LD structured-data schema output on content, for SEO rich results.

---

Structured data (JSON-LD schema.org) drives search rich results. JSON-LD Schema UI lets site builders configure JSON-LD output on content through a UI. It is an SEO feature. No unusual security surface; the JSON-LD is generated from content fields. Confirm the schema mappings output accurate data (incorrect structured data can cause search penalties) and do not expose fields you would not want in the page source.

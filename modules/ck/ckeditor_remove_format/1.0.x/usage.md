CKEditor Remove Format provides a CKEditor plugin to remove formatting from selected content.

---

CKEditor Remove Format adds a "remove formatting" button to CKEditor — letting editors strip inline
formatting (bold, italic, styles) from selected text, useful for cleaning up pasted content. It is in the
User interface package.

Use it to give editors a clear-formatting tool. It is a content-editing/CKEditor feature affecting inline
markup on the edited content; it has no access-control role. Add the remove-format button to the toolbar.

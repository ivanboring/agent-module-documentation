CKEditor5 Table Fix adds support for table elements in CKEditor 5, including <tfoot> and others not handled by default.

---

CKEditor5 Table Fix improves CKEditor 5's table handling — adding support for table elements such as
`<tfoot>` (and other structural table elements) that CKEditor 5 doesn't preserve by default, so richer
table structures survive editing. It depends on core CKEditor 5.

Use it where content tables need footer rows or other structural elements preserved. It is a content-
editing/CKEditor feature affecting table markup handling; ensure the text format's allowed tags permit the
table elements so they survive filtering. No access-control role. Enable it on the relevant text format's
CKEditor 5 configuration.

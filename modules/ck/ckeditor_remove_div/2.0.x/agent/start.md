# CKEditor Remove Div — agent index

Adds a **"Remove Div" plugin to CKEditor 5** (unwrap/remove `<div>` containers). Depends on core `ckeditor5`.
Version **2.0.1-rc1**. Core `^9||^10||^11`.

Content-editing — output goes through the text format's filtering; no content/access role.

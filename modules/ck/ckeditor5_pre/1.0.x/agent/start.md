# CKEditor 5 Pre — agent index

Adds a **`<pre>` (preformatted) option to the CKEditor 5 headings/format dropdown** (mark blocks
preformatted — code/fixed-width text). Depends on core `ckeditor5`. Version **1.0.1**. Core `^10||^11`.

Content-editing/CKEditor — `<pre>` becomes markup; ensure the text format allows `<pre>`. No access role.

CKEditor 5 Pre updates CKEditor 5 to add a <pre> tag to the headings list.

---

CKEditor 5 Pre extends CKEditor 5 to add a `<pre>` (preformatted text) option to the headings/paragraph
format dropdown — so editors can mark a block as preformatted (e.g. for code or fixed-width text) directly
from the block-format menu. It depends on core CKEditor 5.

Use it to let editors create `<pre>` blocks in CKEditor 5. It is a content-editing/CKEditor feature; the
`<pre>` becomes markup in the content, so ensure the text format's allowed tags include `<pre>` (so it
survives filtering). It has no access-control role. Add the option via the CKEditor 5 configuration.

# CKEditor Autosave History Log — agent index

Autosaves **CKEditor text to browser local storage** (restore recent unsaved content after a crash/lost
page). Depends on core `ckeditor5`. Version **1.0.0-alpha6**. Core `^10||^11`.

Content-editing/CKEditor. **Note:** drafts persist in the **browser's local storage** — on a shared/public
computer that's a data-remnant/privacy consideration for sensitive content. No access role.

CKEditor 5 Aside updates CKEditor 5 to add an aside to the headings list.

---

CKEditor 5 Aside adds an **`<aside>`** option to the CKEditor 5 block/headings dropdown — so editors can
mark a block of content as an `<aside>` (semantic sidebar/tangential content) directly in the editor. It
depends on core CKEditor 5.

Use it to let editors create semantic `<aside>` elements. It is a content-editing/CKEditor feature; it inserts
`<aside>` markup (ensure the text format allows the tag) and has no access-control role. Enable it in the
CKEditor 5 configuration.

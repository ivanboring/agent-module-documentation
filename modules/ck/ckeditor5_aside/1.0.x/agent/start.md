# CKEditor 5 Aside — agent index

Adds an **`<aside>` option to the CKEditor 5 headings/block list** (mark content as a semantic aside). Depends
on core `ckeditor5`. Version **1.0.1**. Core `^10||^11`.

Content-editing/CKEditor — inserts `<aside>` markup (ensure the format allows the tag); no access role.

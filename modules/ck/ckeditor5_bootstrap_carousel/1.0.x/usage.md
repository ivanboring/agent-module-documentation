Inserts and edits a Bootstrap 5 carousel in CKEditor 5.

---

CKEditor 5 Bootstrap Carousel is a CKEditor 5 plugin that inserts and edits a Bootstrap 5 carousel in CKEditor 5. — extending the rich-text editor so editors can use this feature directly in the WYSIWYG.

It's a CKEditor 5 plugin (and, where relevant, a text-format filter); ensure any filter is enabled on the relevant text formats. Depends on `ckeditor5`; supports Drupal per ^10.6 || ^11.3.

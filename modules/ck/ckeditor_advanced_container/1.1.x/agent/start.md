# CKEditor Advanced Container — agent index

Adds **div-based container/columns layouts to CKEditor 5** (multi-column/container structures with
responsive options). Depends on core `ckeditor5`. Version **1.1.1**. Core `^10||^11`.

Content-editing/CKEditor — layout becomes div markup/classes; ensure the text format allows it (survives
filtering). No access role.

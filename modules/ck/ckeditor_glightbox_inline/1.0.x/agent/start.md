# CKEditor GLightbox Inline — agent index

A **text filter that opens inline images in a GLightbox** lightbox (embedded images pop up in an overlay).
Depends on `glightbox`. Version **1.0.1**. Core `^10.1||^11||^12`.

Content-display/filter — affects inline-image rendering on output; no content/access role.

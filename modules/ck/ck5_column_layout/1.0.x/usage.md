CKEditor 5 Column Layout adds a CKEditor 5 tool to wrap text in resizable Flexbox columns.

---

CKEditor 5 Column Layout **adds column layouts in CKEditor 5** — a tool to wrap selected text in resizable,
responsive Flexbox columns via a Drupal modal, for multi-column content. It depends on core CKEditor 5 and provides
its own permissions.

Use it to build column layouts in content. It is a content-editing/WYSIWYG feature; the column markup passes
through the text format — ensure the format allows/sanitizes the column HTML. It has no access-control role beyond
its permission. Configure the column tool on a text format.

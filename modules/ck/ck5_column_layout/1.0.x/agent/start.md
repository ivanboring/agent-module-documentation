# CKEditor 5 Column Layout — agent index

**Adds a CKEditor 5 tool to wrap text in resizable, responsive Flexbox columns** (via a modal). Depends on core
`ckeditor5`. Provides permissions. Version **1.0.1**. Core `^10||^11`.

Content-editing/WYSIWYG — column markup passes through the text format (allow/sanitize the HTML); no access role
beyond permission.

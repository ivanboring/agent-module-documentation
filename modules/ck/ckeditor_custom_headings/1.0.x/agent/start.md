# CKEditor 5 Custom Headings — agent index

Lets you **configure custom heading styles in CKEditor 5** (additional heading options with tags/classes in
the format dropdown). Depends on core `ckeditor5`. Version **1.0.0**. Core `^9.4||^10||^11`.

Content-editing/CKEditor — headings become markup; ensure the text format allows the configured heading
markup/classes (keep attributes reasonable). No access role.

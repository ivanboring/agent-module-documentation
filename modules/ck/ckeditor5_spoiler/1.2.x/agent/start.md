# CKEditor5 Spoiler — agent index

Adds a **spoiler (hide/reveal) plugin** to CKEditor 5 (mark content hidden, revealed on click). Depends on
core `ckeditor5`. Version **1.2.0**. Core `^10.2||^11||^12`.

Content-editing/CKEditor — spoiler is a **display toggle, NOT access control** (hidden content is still in
the page source). Ensure the text format allows the markup. No access role.

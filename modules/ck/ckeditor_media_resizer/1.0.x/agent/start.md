# CKEditor 5 Media Resizer — agent index

Lets editors **resize embedded media images in CKEditor 5** (drag handles / enter dimensions). Depends on core
`ckeditor5`. Version **1.0.3**. Core `^10||^11`.

Content-editing/CKEditor — adds width/height/style to embedded media (ensure the format allows the sizing
markup); no access role.

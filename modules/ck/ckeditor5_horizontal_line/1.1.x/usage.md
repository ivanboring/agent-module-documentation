CKEditor5 horizontal line lets editors insert horizontal lines (rules) to divide content into sections.

---

CKEditor5 horizontal line adds a horizontal-line (horizontal rule / `<hr>`) feature to CKEditor 5 —
letting editors visually divide content into sections by inserting horizontal lines, an easy way to organize
content or indicate a topic change. It depends on core CKEditor 5.

Use it to let editors add horizontal rules. It is a content-editing/CKEditor feature; the `<hr>` becomes
markup, so ensure the text format allows `<hr>`. It has no access-control role. Add the button to the
CKEditor 5 toolbar.

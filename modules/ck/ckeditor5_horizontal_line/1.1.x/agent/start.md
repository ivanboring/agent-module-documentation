# CKEditor5 horizontal line — agent index

Adds a **horizontal-line (`<hr>`) button to CKEditor 5** (divide content into sections). Depends on core
`ckeditor5`. Version **1.1.2**. Core `^9||^10||^11`.

Content-editing/CKEditor — `<hr>` becomes markup; ensure the text format allows `<hr>`. No access role.

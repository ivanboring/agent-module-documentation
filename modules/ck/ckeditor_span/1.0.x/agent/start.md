# CKEditor Span — agent index

Adds **`<span>` tag support to CKEditor 5** (wrap inline text in spans with classes — styling hooks). Depends
on core `ckeditor5`. Version **1.0.5**. Core `^9||^10||^11`.

Content-editing/CKEditor — `<span>` becomes markup; ensure the text format allows `<span>`/classes, keep
allowed attributes reasonable (XSS surface). No access role.

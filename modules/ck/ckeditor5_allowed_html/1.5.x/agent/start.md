A **text-format filter declaring additional allowed HTML tags/attributes** for CKEditor 5. Version **1.5.x**
(dev). Core `^8.8||^9||^10||^11`.

need, avoid script/event-handler markup, keep permissive formats to trusted roles. No access role.

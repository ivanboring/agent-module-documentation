CKEditor 5 Audio Plugin adds a CKEditor 5 plugin for uploading and embedding audio files.

---

CKEditor 5 Audio Plugin adds a CKEditor 5 button/plugin for **uploading and embedding audio files** in
rich-text content — inserting an HTML5 `<audio>` player into the body. It depends on core CKEditor 5.

Use it to let editors add audio to content. It is a content-editing/CKEditor feature; audio is uploaded as a
file (managed by core file handling) and the plugin inserts `<audio>` markup — ensure the text format's
allowed tags permit `<audio>`/`<source>`, and restrict the plugin to trusted text formats. It has no
access-control role. Enable it in the CKEditor 5 toolbar for a format.

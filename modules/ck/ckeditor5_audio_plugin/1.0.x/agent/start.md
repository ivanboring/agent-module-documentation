# CKEditor 5 Audio Plugin — agent index

A CKEditor 5 plugin for **uploading and embedding audio files** (inserts an HTML5 `<audio>` player). Depends
on core `ckeditor5`. Version **1.0.5**. Core `^9||^10||^11`.

Content-editing/CKEditor — audio uploaded as a file (core file handling); inserts `<audio>` (ensure the format
allows `<audio>`/`<source>`; restrict to trusted formats). No access role.

CKEditor 5 - Dark Mode plugin adds a button to CKEditor 5 to switch between light and dark theme.

---

CKEditor 5 - Dark Mode plugin adds a toolbar button that switches the CKEditor 5 editing surface between
light and dark themes — a comfort/accessibility feature for editors who prefer a dark editing UI. It depends
on core CKEditor 5.

Use it to let editors toggle a dark editor theme. It is a content-editing/CKEditor UI feature affecting only
the editor's appearance; it does not change content or access and has no access-control role. Add the button
to the CKEditor 5 toolbar.

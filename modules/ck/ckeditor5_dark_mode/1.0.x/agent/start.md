# CKEditor 5 - Dark Mode plugin — agent index

Adds a **CKEditor 5 button to switch the editor between light/dark theme** (editor comfort/accessibility).
Depends on core `ckeditor5`. Version **1.0.2**. Core `^8.8||^9||^10||^11`.

Content-editing/CKEditor UI — affects only the editor's appearance; no content/access change. No access
role.

CKEditor 5 Table Colors provides customizable color palettes for CKEditor5 table and table cell properties including background and border colors.

---

CKEditor 5 Table Colors provides customizable color palettes for CKEditor 5 tables — letting editors set
background and border colors on tables and table cells from a configured palette. It is in the CKEditor 5
Plugin Pack package.

Use it to give editors table color controls in CKEditor 5. It is a content-editing/CKEditor feature; the
colors become inline style/markup on the table, so ensure the text format's allowed tags/attributes permit
the styling. It has no access-control role. Configure the color palettes.

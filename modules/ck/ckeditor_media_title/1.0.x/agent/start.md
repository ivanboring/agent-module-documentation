# CKEditor Media Title — agent index

Lets editors **override the `title` attribute of media embedded in CKEditor 5** (tooltip/accessibility). Depends
on core `ckeditor5`, `media`. Version **1.0.1**. Core `^10||^11`.

Content-editing — authored title output via core's (sanitizing) media embed; no content/access role.

# CKEditor5 Mentions — agent index

Adds **@/# mention autocomplete** to CKEditor 5 — typing a marker shows configurable suggestion feeds
(users/terms). Config via `entity.mention_feed.collection`; provides permissions. Version **2.0.0**. Core
`^9.4||^10||^11`.

Content-editing/CKEditor feature. Consider what the mention feed exposes (e.g. usernames revealed to
editors) — scope feeds appropriately.

# CKEditor 5 Word Count — agent index

A CKEditor 5 plugin that **tracks the word and character count** while editing (live count, optional limits).
Depends on core `ckeditor5`. Version **1.0.1**. Core `^10.3||^11`.

Content-editing/CKEditor — affects the editing UI only; no content/access role.

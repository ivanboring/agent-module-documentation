# CKEditor 5 Webform — agent index

A **CKEditor 5 plugin that lets editors embed Webforms into rich-text content**. Depends on core `ckeditor5`,
`webform`. Version **1.0.0**. Core `^10||^11`.

Content-editing — embedded webform renders through the webform system (its own access/handlers); no access
role.

Ckeditor 5 Inline Styles provides a CKEditor 5 plugin for applying configurable inline styles to selected text.

---

Ckeditor 5 Inline Styles provides a CKEditor 5 plugin for applying inline styles — letting editors
apply configured style classes/formatting to selected text within the rich-text editor (a "styles"
dropdown for inline formatting). It depends on core CKEditor 5.

Use it to give editors a controlled set of inline text styles in CKEditor 5. It is a content-editing/
CKEditor feature; applied styles become classes/markup in the content, so ensure the text format's allowed
tags/attributes permit the style classes for them to survive filtering. No access-control role. Configure
the available inline styles on the text format's CKEditor 5 toolbar.

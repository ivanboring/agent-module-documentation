# Ckeditor 5 Inline Styles — agent index

CKEditor 5 plugin for **applying configurable inline styles** to selected text (styles dropdown). Depends
on core `ckeditor5`. Version **1.x** (dev). Core `^10||^11`.

Content-editing/CKEditor — applied styles become classes/markup; ensure the text format allows the style
classes (survive filtering). No access role.

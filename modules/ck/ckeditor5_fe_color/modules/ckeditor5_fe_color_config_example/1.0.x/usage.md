CKEditor5 FeColor Config Example is a demonstration submodule shipping example configuration for the CKEditor5 FeColor color-picker plugin.

---

CKEditor5 FeColor Config Example is a small example/demo submodule for CKEditor5 FeColor. It ships
example configuration showing how to set up the font-color picker on a CKEditor 5 text format — a
starting point site builders can enable to see a working configuration and then adapt, rather than
configuring from scratch.

Use it only as a reference on non-production or during setup; example-config modules install demo
configuration and are generally not intended to remain enabled on a production site. Enable it to
inspect the provided setup, copy what you need into your own text-format configuration, then disable
it. It depends on the parent CKEditor5 FeColor plugin.

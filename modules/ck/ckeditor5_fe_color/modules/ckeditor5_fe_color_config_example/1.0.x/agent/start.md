# CKEditor5 FeColor Config Example — agent index

**Example/demo config** submodule for CKEditor5 FeColor — ships a working font-color-picker setup on a
CKEditor 5 text format as a starting point. Depends on parent `ckeditor5_fe_color`. Version **1.0.x**.
Core `^10||^11`.

Reference only — example-config modules aren't meant to stay enabled in production. Enable, copy what
you need, disable.

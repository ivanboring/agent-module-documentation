# CKEditor5 FeColor Plugin — agent index

Adds a **text (font) color picker** to **CKEditor 5** — editors apply colors in the WYSIWYG editor.
Depends on core `ckeditor5`. Optional `ckeditor5_fe_color_config_example` submodule ships example
config. Version **1.0.2**. Core `>=10.1`.

Enable the color button on the text format's CKEditor 5 toolbar; ensure the format's filters allow the
color attributes so they survive. Editorial/presentation only.

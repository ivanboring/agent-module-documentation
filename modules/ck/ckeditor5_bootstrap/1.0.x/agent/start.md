# CKEditor5 Bootstrap Integration — agent index

Adds **CKEditor 5 widgets for Bootstrap 5** — Bootstrap Div (class autocomplete/id/attributes/bg image) +
Bootstrap Table (caption/classes). Depends on core `ckeditor5`, `editor`. Version **1.0.1**. Core
`^11||^12`.

Content-editing/CKEditor — widgets emit HTML with classes/attributes; the text format's allowed tags/
attributes govern what survives (keep allowed attributes reasonable — XSS). No access role.

CKEditor5 Bootstrap Integration provides CKEditor 5 widgets for Bootstrap 5: a Bootstrap Div (class autocomplete, id, attributes, background image) and a Bootstrap Table (caption, table classes).

---

CKEditor5 Bootstrap Integration adds CKEditor 5 widgets for Bootstrap 5 — a Bootstrap Div widget (with
class autocomplete, id, attributes and background image) and a Bootstrap Table widget (with caption and
table classes) — so editors can build Bootstrap-structured markup directly in the rich-text editor. It
depends on core CKEditor 5 and Editor.

Use it to author Bootstrap 5 layout markup in CKEditor. It is a content-editing/CKEditor feature; the
widgets produce HTML with classes/attributes, so — as always with editor-generated markup — the text
format's allowed tags/attributes must permit the Bootstrap markup, and the format's filtering still governs
what attributes survive (keep the allowed attributes reasonable to avoid XSS via arbitrary attributes). It
has no access-control role. Add the widgets to the CKEditor 5 toolbar and configure the allowed classes.

# CKEditor5 colgroup — agent index

Adds **`colgroup`/`col` element support to CKEditor 5 tables** (for when the table-resize plugin isn't
enabled). Depends on core `ckeditor5`. Version **1.0.0**. Core `^10||^11`.

Content-editing/CKEditor — affects table markup; ensure the text format allows `colgroup`/`col` (survives
filtering). No access role.

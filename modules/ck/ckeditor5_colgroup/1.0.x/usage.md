CKEditor5 colgroup provides colgroup and col elements to CKEditor 5 for cases when the table resize plugin is not enabled.

---

CKEditor5 colgroup adds support for `colgroup` and `col` elements in CKEditor 5 tables — providing
column-group markup for tables in cases where CKEditor's table-resize plugin (which normally manages column
widths) is not enabled, so column widths/structure can still be represented. It depends on core CKEditor 5.

Use it where tables need colgroup/col markup without the resize plugin. It is a content-editing/CKEditor
feature affecting table markup; ensure the text format's allowed tags permit colgroup/col so they survive
filtering. No access-control role. Enable it on the relevant text format's CKEditor 5 configuration.

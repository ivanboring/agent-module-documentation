Imports CSV files into CKEditor 5 and generates clean, editable HTML tables.

---

CKEditor 5 CSV to Table is a CKEditor 5 plugin that imports CSV files into CKEditor 5 and generates clean, editable HTML tables. — extending the rich-text editor so editors can use this feature directly in the WYSIWYG.

It's a CKEditor 5 plugin (and, where relevant, a text-format filter); ensure any filter is enabled on the relevant text formats. Depends on `ckeditor5`; supports Drupal per ^10 || ^11.

Cesium provides the CesiumJS library for 3D map/globe rendering with Geofield.

---

Cesium integrates the CesiumJS library into Drupal — CesiumJS is a JavaScript library for world-class 3D globes and maps, so a site can render geospatial data (from Geofield) on an interactive 3D globe/map, useful for geospatial/scientific visualization.

It's a media/geospatial display feature with no content or access role of its own. Depends on `geofield`; supports Drupal 10 and 11.

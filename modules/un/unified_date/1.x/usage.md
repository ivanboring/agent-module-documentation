Unified Date stores date field values in a unified date format, normalising varied date inputs into one consistent stored representation.

---

Dates entered in different fields or formats are hard to query and compare consistently. Unified Date normalises date field values into a single stored format. It is a data-modelling/consistency field with no security surface. Confirm the unified format and timezone handling suit your querying and display needs, since the value of normalisation is in consistent downstream use.

Facebook Filter filters content in preparation for display.

---

Facebook Filter provides a text-format filter that processes Facebook-related content for display —
typically converting Facebook post/video URLs or embed markers in content into proper Facebook embeds. It is
in the Other package.

Use it to render Facebook embeds from content. It is a content-display/text-filter feature that transforms
content on output; the embedded Facebook content is third-party (loads Facebook's script — a privacy/consent
consideration), and it has no access-control role. Add the filter to the appropriate text format.

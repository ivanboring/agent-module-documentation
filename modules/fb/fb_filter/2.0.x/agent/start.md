# Facebook Filter (fb_filter) — agent index

A text-format **filter that processes Facebook embeds/content for display** (convert FB URLs/markers → embeds).
Version **2.0.1**. Core `^9||^10||^11`.

Content-display/text-filter — transforms content on output; embedded FB content loads Facebook's third-party
script (privacy/consent). No access role.

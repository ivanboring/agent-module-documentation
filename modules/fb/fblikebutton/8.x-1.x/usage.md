Facebook Like Button adds a configurable Facebook Like button to selected node types and a configurable block with a Facebook Like box.

---

Facebook Like Button adds a Facebook Like button to selected content types (and a configurable block
with a Facebook Like box) — embedding Facebook's social plugin so visitors can like the page/site on
Facebook. It is configured at `fblikebutton.settings` and provides its own permissions.

Use it to add Facebook social engagement to content. Privacy caveat: the Facebook Like button embeds
Facebook's third-party script, which can track visitors (even without clicking) and set cookies — obtain
appropriate consent, integrate with cookie-consent, and disclose the third-party tracking per your
jurisdiction (GDPR). It is a social/integration feature with no access-control role. Configure which content
types show the button.

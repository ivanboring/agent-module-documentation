# Facebook Like Button — agent index

Adds a configurable **Facebook Like button** to selected content types + a Like-box block. Config at
`fblikebutton.settings`; provides permissions. Version **8.x-1.0**. Core `^8.8||^9||^10||^11`.

**Privacy:** embeds Facebook's third-party script (tracks visitors, sets cookies even without clicking) —
consent + cookie-consent + disclose (GDPR). No access role.

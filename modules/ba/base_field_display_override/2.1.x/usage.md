Base Field Display Configurability Override exposes base fields in Field UI even when the entity type didn't opt in.

---

Base Field Display Configurability Override makes an entity type's base fields configurable in the Field UI (display and form) even when the entity type did not declare them as display-configurable. This lets site builders reorder, hide or restyle base fields (like title, author, dates) through the UI instead of custom code.

It's a site-builder/developer tool that changes what appears in Field UI; it has no content access role of its own. Supports Drupal 8 through 11.

Batch Plugin provides a plugin framework for batch operations.

---

Batch Plugin provides a **plugin framework for batch operations** — letting developers define reusable
batch processes as plugins (with a discoverable, structured API) instead of ad-hoc batch arrays, in the Batch
Plugin package.

Use it as a developer foundation for structured batches. It is a developer/API module; batches it runs execute
with the privileges of whoever triggers them, and it has no access-control role of its own. Define and run batch
plugins.

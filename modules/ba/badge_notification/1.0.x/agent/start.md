# Badge Notification — agent index

Displays **dynamic, asynchronously-loaded count badges** (e.g. unread) on menu items. Depends on core `history`,
`views`, `menu_ui`. Provides permissions. Version **1.0.9**. Core `^8||^9||^10||^11`.

UI/user-engagement — counts driven by access-respecting Views; no access role of its own beyond permission.

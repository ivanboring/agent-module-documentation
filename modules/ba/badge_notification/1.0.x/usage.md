Badge Notification handles dynamic badges loaded asynchronously.

---

Badge Notification displays **dynamic badges** — small count indicators (e.g. unread items) loaded
**asynchronously** and shown on menu items, using core History, Views and Menu UI. It provides its own
permissions, in the User Interface package.

Use it to show live count badges in menus. It is a UI/user-engagement feature; badge counts are driven by
Views/queries that already respect access, and it has no access-control role of its own beyond its permission.
Configure the badge source and menu placement.

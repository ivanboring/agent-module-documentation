Barba JS adds the Barba.js library for fluid client-side transitions between pages.

---

Barba JS integrates the Barba.js JavaScript library to create smooth, fluid transitions between pages — loading page content via AJAX and animating the swap so navigation feels app-like rather than full-page reloads. It's a theming/UX enhancement for the front end.

It's a front-end library integration with no content or access role and no permissions. Supports Drupal 9.5, 10, and 11.

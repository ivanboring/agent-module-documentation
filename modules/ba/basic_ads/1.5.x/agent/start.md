# Basic Ads — agent index

Provides **simple ad management with placements, scheduling and image/link ads**. Depends on core `node`,
`taxonomy`, `views`, `block`, etc. Provides permissions. Version **1.5.0**. Core `^10.3||^11||^12`.

Content/marketing — admin/editor-managed ads (keep creation to trusted users; ads render on pages). No access
role beyond permission.

Basic Layouts provides basic layouts (layout plugins) for use with Layout Builder and layouts.

---

Basic Layouts provides a set of basic layout plugins — simple column/section layouts for use with
Layout Builder (or anywhere layouts are used), giving common arrangements (one/two/three columns etc.)
beyond core's defaults. It depends on core Layout Discovery and is configured at
`basic_layouts.basic_layouts_config`, in the Layout Builder package.

Use it for extra basic layouts in Layout Builder. It is a content-display/layout feature providing layout
plugins; the content within comes from blocks/fields (respecting their access), and it has no access-control
role. Select the layouts when building pages.

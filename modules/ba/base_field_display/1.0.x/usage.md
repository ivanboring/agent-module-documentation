Base Field Display exposes entity base fields in view modes.

---

Base Field Display **exposes entity base fields in Manage Display** — so base fields (created date, author,
sticky, etc.) that core hides from the display UI can be arranged and formatted in view modes like configurable
fields. It requires PHP 8.0 and depends on core Path.

Use it to display base fields via the UI. It is a content-display feature; base-field values follow normal
field access and it has no access-control role. Configure base fields in Manage Display.

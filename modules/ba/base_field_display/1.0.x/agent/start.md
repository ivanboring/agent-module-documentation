# Base Field Display — agent index

Exposes **entity base fields (created, author, etc.) in Manage Display view modes** (arrange/format base fields
like configurable ones). Requires PHP 8.0. Depends on core `path`. Version **1.0.1**. Core `^9||^10||^11`.

Content-display — base-field values follow normal field access; no access role.

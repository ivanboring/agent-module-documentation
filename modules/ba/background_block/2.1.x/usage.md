Background Block allows adding a background color to blocks.

---

Background Block lets you set a background color on blocks — adding a per-block background-color option
so blocks can be visually distinguished/styled without custom CSS. It depends on core Block and provides its
own permissions.

Use it to add background colors to blocks. It is a content-display/theming feature affecting block
presentation; it does not change content or access and has no access-control role. Configure the background
color per block.

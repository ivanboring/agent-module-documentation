Babel provides interface-string translation management for Drupal.

---

Babel helps translate the Drupal user interface — providing tools to manage and translate interface strings (the built-in and module-provided UI text) more efficiently than core's translate interface, for multilingual sites.

It builds on core Locale. It's a multilingual/translation tool; supports Drupal 10.4+, 11.1+, and 12.

Babel Brush provides tools to find and clean multilingual content/translations.

---

Babel Brush helps manage and clean multilingual content — providing a search/management interface to find and clean up translations (orphaned, inconsistent, or unused translation strings/content), keeping a multilingual site's translation data tidy.

It builds on core Locale. Administration of the search form is gated by `administer babel brush search form`. Supports Drupal 10 and 11.

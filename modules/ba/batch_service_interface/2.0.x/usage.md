Batch Service Interface provides a batch helper service and interface.

---

Batch Service Interface provides a **batch helper service and interface** — a structured, service-based way
to define and run Batch API operations (with an example submodule), so developers write batches as injectable
services rather than procedural batch arrays. It is in the Developer package.

Use it as a developer foundation for structured batches. It is a developer/API module; batches run with the
privileges of whoever triggers them, and it has no access-control role. Define batch services.

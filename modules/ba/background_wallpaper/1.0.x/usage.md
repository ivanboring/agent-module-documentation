Background Wallpaper provides an admin setting to change the website background image.

---

Background Wallpaper gives administrators a simple way to set or change the site's background wallpaper image from configuration, without editing theme CSS. It's a lightweight theming convenience for branding the site background.

It stores an admin-chosen image/config and applies it site-wide. A theming utility with no front-end access role; depends on core `system` and `config`. Supports Drupal 10 and 11.

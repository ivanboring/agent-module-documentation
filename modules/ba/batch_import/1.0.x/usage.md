Batch Import manages import migrations using batching.

---

Batch Import **manages import migrations using batching** — running Migrate imports in batches so large
data sets can be processed without timeouts/memory issues, with progress. It provides its own permissions, in
the Migration package.

Use it to run large migrations in batches. It is a developer/migration feature run by privileged users; it
processes source data with migration privileges (validate sources; run as a trusted operator) and it has no
access-control role beyond its permission. Configure and run the batched import.

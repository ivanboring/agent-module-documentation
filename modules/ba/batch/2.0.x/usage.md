Batch API (developer tools) provides developer tools for using Drupal's Batch API.

---

Batch API (batch) **provides developer tools for the Batch API** — helpers/utilities to make building and
running Drupal batch operations easier for developers. It depends on the Awareness module.

Use it as a developer aid for batch processing. It is a developer/framework feature; it wraps the core Batch API
and has no content or access role. Use its helpers in code.

Batch Messenger provides APIs to designate which Messenger messages appear during batch/queue processing.

---

Batch Messenger **provides APIs to control which Messenger messages appear during batch processing** — so
long-running batch/queue operations can surface (or suppress) status messages appropriately, improving batch UX.
It provides its own permissions (core 11.1+).

Use it as a developer API to manage batch messaging. It is a developer/UX module; it affects status messages and
has no content or access role beyond its permission. Use its APIs in batch operations.

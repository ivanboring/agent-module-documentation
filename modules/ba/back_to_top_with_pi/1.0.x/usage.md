Back to top with progress scrollbar provides a 'back to top' button block combined with a scroll-progress indicator.

---

Back to top with progress scrollbar provides a "back to top" block that combines a scroll-to-top button
with a scroll-progress indicator — showing how far down the page the visitor has scrolled and offering a
one-click return to the top. It depends on core Block.

Use it on long pages to aid navigation. It is a front-end/UI feature (a block); it has no content or access
role. Place the block where the back-to-top control should appear.

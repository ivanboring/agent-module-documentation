# Layout Components (layoutcomponents) — agent index

Large set of **ready Layout Builder components** (accordion, card, carousel, countdown, tabs,
timeline, video, iframe, …). Version **5.0.0-beta1**. ~23 component submodules + Slick.

Page-building toolkit. **Note:** the **iframe** component can embed arbitrary URLs — confirm who
configures it and whether embedded URLs are constrained. Components render authored content within
Layout Builder's normal access. Enable the submodules you use.

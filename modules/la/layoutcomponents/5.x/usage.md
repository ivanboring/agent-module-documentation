Layout Components provides a large set of ready-made blocks (accordion, button, card, carousel, countdown, tabs, timeline and more) for placing into Layout Builder.

---

Building rich pages in Layout Builder is faster with a library of ready components. Layout Components provides an extensive set — accordions, buttons, cards, carousels, countdowns, iframes, images, tabs, timelines, videos, view carousels and more (each a submodule, ~23 in total, plus a Slick integration). It is a page-building toolkit. The components render authored content, so they carry no unusual security surface beyond the standard ones: any component embedding an iframe or external content should be reviewed (an iframe component can embed arbitrary URLs — confirm who can configure it and whether embedded URLs are constrained), and components are placed by site builders/editors within Layout Builder's normal access. For a site building pages with Layout Builder, it is a broad component library; enable the submodules for the components you use.

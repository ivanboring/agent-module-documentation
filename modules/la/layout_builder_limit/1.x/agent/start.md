# Layout Builder Limit (layout_builder_limit) — agent index

Restricts which **components/layouts** editors may add in Layout Builder. Version **1.0.0-beta5**.

Governance/UX guardrail. **It is a UI restriction, not access control** — don't rely on it alone to
hide a sensitive block; pair with the block's own access.

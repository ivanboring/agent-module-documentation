Layout Builder Limit restricts which components (blocks) and layouts users may add in Layout Builder sections, constraining what editors can build.

---

Left unrestricted, Layout Builder lets editors add any block or layout, which can produce inconsistent or broken pages and exposes blocks not meant for editorial placement. Layout Builder Limit constrains the available components and layouts per section, so editors build within guardrails. It is a governance/UX control on the editing experience. The mild security angle is that it can hide components that should not be placed by editors — but it is a UI restriction, not an access control, so it should not be relied on as the sole barrier to a sensitive block; pair it with the block's own access where that matters.

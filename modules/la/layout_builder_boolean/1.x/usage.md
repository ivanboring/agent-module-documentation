Layout Builder Boolean provides Layout Builder layouts with conditional display based on a boolean value.

---

A layout section that appears only when a flag is set — a promo shown when 'featured' is on. Layout Builder Boolean adds layouts whose display is conditional on a boolean. Like other conditional-display Layout Builder tools, it controls whether a section renders, not access to its content — so it is a display condition, not a security boundary. Use it for conditional layout; back any sensitive content with real access control.

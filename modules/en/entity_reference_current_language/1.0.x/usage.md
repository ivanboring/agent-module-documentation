Entity Reference Current Language provides an entity-reference selection plugin that filters candidates by the current language.

---

Entity Reference Current Language **filters entity-reference candidates by the current language** — a
selection plugin so a reference field only offers entities that exist in (or are relevant to) the current
interface language, keeping references language-consistent. It depends on core Language.

Use it to make reference autocompletes language-aware. It is a content-editing/multilingual feature; it constrains
which entities are offered (respecting entity access on top) and has no access-control role. Configure the
selection plugin on a reference field.

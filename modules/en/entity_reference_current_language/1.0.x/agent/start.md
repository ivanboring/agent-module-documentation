# Entity Reference Current Language — agent index

Provides an **entity-reference selection plugin that filters candidates by the current language**. Depends on core
`language`. Version **1.0.0-beta1**. Core `^10||^11`.

Content-editing/multilingual — constrains offered entities (entity access still applies); no access role.

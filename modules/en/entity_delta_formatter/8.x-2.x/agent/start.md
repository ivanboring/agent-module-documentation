# Entity Delta Formatter — agent index

A field formatter that **displays a specified delta (item index) of a multi-value field** (render just the Nth
value). Version **8.x-2.2**. Core `^8||^9||^10||^11`.

Content-display — values follow normal field sanitization; no content/access role.

# Entity Import (entity_import) — agent index

Configurable framework to **import entities from CSV/JSON/other sources**. Version **8.x-1.0-alpha8**.
Submodule `entity_import_plus` (more source types).

**Write capability** — importing creates/overwrites entities. Restrict who configures/runs imports;
review mappings and source data; back up before running against production.

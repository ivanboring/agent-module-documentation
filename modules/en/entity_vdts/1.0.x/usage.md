Entity View Display Template Suggestions allows configuring template suggestions using entity view displays.

---

Entity View Display Template Suggestions (entity_vdts) adds Twig template suggestions derived from
entity view displays — so themers can target a template to a specific view display (e.g. a particular
"teaser" configuration), giving finer theming control keyed on the view display rather than only bundle/view
mode. It is in the User interface package.

Use it for view-display-specific theming. It is a theming/display feature adding template suggestions; it
does not change content or access and has no access-control role. Use the suggestions in your theme.

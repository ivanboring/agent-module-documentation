# Entity View Display Template Suggestions — agent index

Configures **Twig template suggestions based on entity view displays** (target a template to a specific view
display — finer theming than bundle/view mode). Version **1.0.2**. Core `^11.2||^12`.

Theming/display — adds template suggestions; no content/access change. No access role.

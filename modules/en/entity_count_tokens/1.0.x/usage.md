Tokens for the number of entities by type.

---

Entity Count Tokens extends the token system to be able to use the number of entities by type — so content/config can include a token that resolves to how many entities of a given type/bundle exist (e.g. total published articles), useful for counters and dynamic copy. Integrates with the Token system. Supports Drupal 8 through 11.

Entity Fields Search provides search of entity fields based on entity type.

---

Entity Fields Search (entitytype_filter) **provides searching of entity fields by entity type** — a
developer/admin utility to find fields across the site filtered by entity type, aiding field auditing and
site-building. It works across core 8–11.

Use it to locate fields by entity type. It is a developer/site-building tool; it surfaces field configuration
(admin-facing) and has no content or access role. Use it to search entity fields.

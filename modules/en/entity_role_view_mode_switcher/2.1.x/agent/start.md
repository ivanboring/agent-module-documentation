# Entity Role View Mode Switcher — agent index

Switches which **view mode an entity renders in based on the current user's role** (different display per
role). Version **2.1.0**. Core `^8||^9||^10||^11`.

Content-display — changes **which view mode renders**, **not** access control (a trimmed view mode doesn't
protect the entity; use real field/entity access for sensitive data). No access role.

# Entity Data — agent index

An **API to store arbitrary custom data per entity** (key/value store keyed by entity — attach extra data
without fields/schema changes). Requires PHP 8.1. Version **1.1.1**. Core `^10||^11`.

Developer/API — stores whatever calling code puts there (no UI; access/sensitivity is the caller's
responsibility); no content/access role.

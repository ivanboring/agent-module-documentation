Entity Reference Overflow allows entity reference fields to overflow.

---

Entity Reference Overflow lets **entity-reference fields display an "overflow"** — showing a limited number
of referenced items and collapsing the rest into a "+N more" indicator, for tidier display of long reference
lists. It is in the Field types package.

Use it to truncate long reference displays. It is a content-display feature affecting field rendering;
referenced entities follow their own access and it has no access-control role. Configure the overflow on the
reference formatter.

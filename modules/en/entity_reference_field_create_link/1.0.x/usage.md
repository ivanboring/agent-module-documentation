Entity Reference Field Create Link adds a create link on reference fields.

---

Entity Reference Field Create Link **adds a "create new" link to entity-reference fields** — so an editor
can jump to creating a new referenced entity directly from the reference field, instead of leaving to create it
first. It depends on core Field.

Use it to speed up creating referenced entities. It is a content-editing/form-UI feature; creating the referenced
entity still goes through that entity's own create access, and it has no access-control role. Configure the
create link on a reference field.

Entity Admin Handlers provides admin UIs for entity types.

---

Entity Admin Handlers provides administrative UIs for entity types — adding the routing/list-builder/
handlers needed to give a custom or config entity type a usable admin management interface, without writing
that boilerplate. It depends on core Field UI.

Use it to give entity types admin UIs. It is a developer/administration feature that generates management
interfaces; those UIs expose entity management (view/edit/delete) governed by the underlying **entity access**
and admin permissions, so gate who can reach them. It has no access-control role of its own. Configure the
admin handlers for the entity types.

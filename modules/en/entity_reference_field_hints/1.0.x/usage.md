Editor-facing helper text for entity reference fields based on allowed bundles.

---

Entity Reference Field Hints shows editor-facing helper text for entity reference fields based on their allowed target bundles — so when filling a reference field, editors see which bundles/types are valid targets, reducing guesswork and wrong selections. Depends on core `field`; supports Drupal 10.3+, 11, and 12.

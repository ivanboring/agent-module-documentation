Entity Clone Simple Sitemap extends Entity Clone to also clone Simple Sitemap settings.

---

Entity Clone Simple Sitemap **extends Entity Clone to also clone Simple Sitemap settings** — so when an entity
is cloned, its per-entity XML-sitemap (Simple Sitemap) configuration is copied too, keeping sitemap inclusion
consistent on clones. It depends on the Entity Clone and Simple Sitemap modules.

Use it to preserve sitemap settings when cloning. It is a site-building/SEO glue feature; it follows Entity Clone's
permissions and has no access-control role. Enable it alongside Entity Clone and Simple Sitemap.

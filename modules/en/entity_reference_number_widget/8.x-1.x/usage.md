Entity Reference Number Widget lets editors enter an entity ID directly for reference fields.

---

Entity Reference Number Widget adds an entity-reference field widget where the editor enters the target entity's ID directly as a number, instead of using autocomplete or a select list. It's useful for data-entry workflows or imports where IDs are already known.

It's a field widget with no content or access role of its own; the reference still respects entity access on render. Supports Drupal 8 through 11.

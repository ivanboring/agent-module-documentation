Entity Translate Side by Side provides a side-by-side interface for translating entities in Drupal.

---

Entity Translate Side by Side provides a side-by-side translation interface — showing the source and
target language versions of an entity next to each other while translating, so translators can see the
original alongside their translation. It is configured at `entity_translate_side_by_side.admin_settings`,
provides its own permissions, in the Entity package.

Use it to improve the entity-translation UX. It is a multilingual/content-editing feature affecting the
translation form; translation capability is governed by core's content-translation permissions (this is a UI
improvement, not new access), and it has no access-control role beyond its permission. Configure the
side-by-side interface.

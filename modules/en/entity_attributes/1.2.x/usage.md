Entity Attributes provides a UI for managing HTML attributes on entities.

---

Entity Attributes **manages HTML attributes for entities** — a UI to define/attach HTML attributes (classes,
data-*, etc.) to different entities that can be passed to their render/template. It depends on core Field and
System, and provides its own permissions.

Use it to attach attributes to entities. It is a theming/site-building feature; attributes are admin-configured and
rendered into markup, and it has no access-control role beyond its permission. Note: attribute values rendered into
markup should be output safely. Configure the entity attributes.

# Entity Attributes — agent index

**Provides a UI for managing HTML attributes for entities** (passed to templates). Depends on core `field`,
`system`. Provides permissions. Version **1.2.0**. Core `^11`.

Theming/site-building — admin-configured attributes rendered into markup (output safely); no access role beyond
permission.

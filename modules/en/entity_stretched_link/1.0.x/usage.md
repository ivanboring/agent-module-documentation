Add a stretched (whole-card) link to an entity via Manage Display.

---

Entity Stretched Link adds a stretched link to the entity to handle in Manage Display — a formatter/pseudo-field that turns the whole entity teaser/card into a clickable link (the 'stretched link' Bootstrap pattern), so a click anywhere on the card navigates to the entity, configured on the Manage Display screen. Depends on core `field`; supports Drupal 10 and 11.

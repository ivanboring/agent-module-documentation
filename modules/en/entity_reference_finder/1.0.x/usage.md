Entity References Finder searches for all references of an entity, finding where it is referenced across the site.

---

Entity References Finder searches for all references to a given entity — finding everywhere an entity
(node, term, media, etc.) is referenced across content, so editors/admins can see what depends on it
before changing or deleting it. It provides its own permissions and is in the Administration package.

Use it before modifying or removing an entity to understand its usage/impact (avoiding broken references).
It is an administration/content-audit tool that reads content to build the reference report; it is
informational (surfaces references the viewer is entitled to see) and has no access-control role. Run the
finder to locate references.

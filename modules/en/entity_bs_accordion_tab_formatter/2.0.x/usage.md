Entity Bootstrap Accordion Tab Formatter provides a formatter to display entity reference targets as Bootstrap accordion or tab displays.

---

Entity Bootstrap Accordion Tab Formatter provides a field formatter that renders entity-reference field
targets as Bootstrap accordions or tabs — so a set of referenced entities displays as collapsible accordion
panels or tabbed sections (using Bootstrap markup), rather than a plain list. It is in the Entity package.

Use it to present referenced entities as accordions/tabs. It is a content-display/formatter feature; the
referenced entities are rendered respecting their own access (only accessible targets show), and it produces
Bootstrap markup (the theme should provide Bootstrap CSS/JS). It has no access-control role. Select the
formatter on the reference field.

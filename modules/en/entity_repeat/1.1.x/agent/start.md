# Entity Repeat — agent index

Repeats **entities by time/recurrence criteria** (recurring events/content) — uses Date Recur (rules) +
Replicate (cloning). `entity_repeat_group` submodule. Depends on `date_recur`, `date_recur_modular`,
`replicate`. Provides permissions. Version **1.1.4**. Core `^9.3||^10||^11`.

Content/automation — generated entities governed by normal entity access; no access role. Configure the
recurrence.

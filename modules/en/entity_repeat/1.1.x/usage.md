Entity Repeat repeats entities based on time criteria, using date-recur and replicate to generate recurring instances.

---

Entity Repeat repeats entities based on time/recurrence criteria — using Date Recur (recurrence rules)
and Replicate (entity cloning) to generate recurring instances of an entity (recurring events, repeated
content) from a base entity and a recurrence pattern. It ships an `entity_repeat_group` submodule, depends
on Date Recur, Date Recur Modular and Replicate, and provides its own permissions.

Use it for recurring events/content where instances follow a repeat pattern (weekly meetings, recurring
sessions). It is a content/automation feature that creates repeated entities; the generated entities are
content governed by normal entity access, and it has no access-control role of its own. Configure the
recurrence and which entities repeat.

Entity Reference Field Autocomplete Filter filters reference autocomplete by a field.

---

Entity Reference Field Autocomplete Filter provides an **entity-reference widget that filters autocomplete
results by another field's value** — narrowing the selectable referenced entities based on a field on the host
(or a chosen field), for context-appropriate reference selection. It is in the Custom package.

Use it to constrain reference autocomplete options. It is a site-building/fields feature; the underlying
reference still respects the field's target/selection settings and it has no access-control role. Configure the
filtering on the reference field.

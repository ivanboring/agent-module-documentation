Entity Reference Deck provides a card/deck-style widget for managing entity-reference values.

---

Entity Reference Deck **provides a card/deck-style widget for entity references** — presenting referenced
entities as a manageable "deck" of cards (for arranging/selecting references) as an alternative reference widget.
It depends on core Field, and provides its own permissions.

Use it for a visual reference-management widget. It is a content-editing feature; selection/ordering follows normal
field handling and it has no access-control role beyond its permission. Configure the deck widget on a reference
field.

Entity Options provides an API for defining and managing options on entities.

---

Entity Options provides a developer API for managing reusable option sets on entities — a structured way to define, store and retrieve named options associated with content, using a plugin/form-alter mechanism. Other modules build on it to attach configurable options to entities.

It's a developer API with no content or access role of its own. Depends on `pluginformalter`; supports Drupal 10 and 11.

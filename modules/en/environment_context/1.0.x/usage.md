Environment Context provides a context for the current environment.

---

Environment Context **provides a context plugin for the current environment** — exposing the active
environment (e.g. dev/stage/prod) as a Context so blocks/behaviour can vary by environment (e.g. show a debug
banner only on staging). It works across core 10–11.

Use it to condition behaviour on the environment. It is a developer/site-building feature; environment is a
site-config value and it has no content or access role. Configure the environment context.

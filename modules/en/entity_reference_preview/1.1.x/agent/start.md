# Entity Reference Preview — agent index

Previews **embedded entity references at their latest (draft) revision** when viewing the parent's
latest revision — so moderated, reference-composed content shows its full draft state in preview.
Config at `entity_reference_preview.settings`; provides permissions. Version **1.1.0-beta1**. Core
`^9||^10||^11`.

Editorial/preview feature — changes which revision renders, respects viewer access (reference access
unchanged).

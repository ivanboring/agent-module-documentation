Environment Indicator Header displays the environment indicator version in a header.

---

Environment Indicator Header **shows the environment indicator in a header** — extending the Environment
Indicator module to display the current environment's version/name in an HTTP or page header, making the active
environment obvious. It depends on the Environment Indicator module.

Use it to surface the environment in headers. It is a development aid; it displays environment info (which is a
mild fingerprinting detail — keep environment names non-sensitive) and has no content or access role. Configure the
header display.

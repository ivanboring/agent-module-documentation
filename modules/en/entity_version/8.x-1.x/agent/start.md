# Entity Version (entity_version) — agent index

Stores/tracks a **version number (major.minor.patch)** on content entities. Version **8.x-1.5**.
Submodules `entity_version_history`, `entity_version_workflows` (content-moderation integration).
Metadata feature, no unusual security surface. Confirm increment rules match policy.

Entity Fallback Value adds a fallback system to get an entity value from a prioritized list of fields.

---

Entity Fallback Value **adds a fallback system for entity values** — returning a value from the first
non-empty field in a configured priority list (e.g. use field A, else field B, else field C), so displays/logic can
rely on a single "effective" value. It works across core 8–11.

Use it to define fallback chains for fields. It is a content-display/developer feature; it resolves values from
existing fields (respecting their storage) and has no access-control role. Configure the field priority list.

Entity Hierarchy Widgets provides widgets to display and manage hierarchical structures from Entity Hierarchy.

---

Entity Hierarchy Widgets **provides widgets to manage hierarchical structures** — UI widgets to view and edit
the parent/child hierarchies provided by the Entity Hierarchy module (drag-and-drop / tree management). It depends
on the Entity Hierarchy module and provides its own permissions.

Use it to manage entity hierarchies visually. It is a content-editing/site-building feature; hierarchy edits
follow Entity Hierarchy's data model and permissions, and it has no access-control role beyond its permission.
Configure the hierarchy widgets.

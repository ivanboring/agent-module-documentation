Entity Dialog Formatter provides a formatter to display entities in a dialog.

---

Entity Dialog Formatter provides a field formatter that opens referenced entities in a dialog/modal —
so clicking an entity reference shows the entity rendered in a modal overlay rather than navigating to it,
for quick in-context viewing. It depends on core Field, provides its own permissions, in the Fields package.

Use it to show referenced entities in a modal. It is a content-display/formatter feature; the referenced
entity is rendered respecting its own access (only accessible entities render in the dialog), and it has no
access-control role. Select the dialog formatter on the reference field.

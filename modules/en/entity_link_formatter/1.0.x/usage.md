Entity Link Formatter provides a field formatter that renders an entity reference as a link.

---

Entity Link Formatter **provides a field formatter that renders an entity reference as a link** — displaying
a referenced entity as a hyperlink (to its canonical URL) rather than its full rendered content, for compact
reference display. It works on core 10–11.

Use it to show references as links. It is a content-display/field-formatter feature; the link points to the
referenced entity (whose access still applies when followed) and it has no access-control role. Configure the
formatter on a reference field.

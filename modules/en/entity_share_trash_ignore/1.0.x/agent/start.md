# Entity Share Trash Ignore — agent index

Makes **Entity Share ignore entities in the Trash when syncing** (don't re-share trashed content). Depends on
`entity_share_client`, `trash`. Version **1.0.0-rc2**. Core `^10||^11`.

Content-sync/integration — sharing access follows Entity Share; no access role of its own.

Entity Slug provides a field that stores a URL-friendly slug for an entity, generated from a source field.

---

URLs, API identifiers and anchors want a clean slug — lowercased, hyphenated, ASCII — derived from a title or name. Entity Slug provides a field that stores such a slug, generated from a source field. It is a content-modelling convenience with no security surface. Confirm slug uniqueness handling suits your use if slugs must be unique (a slug used in a URL should not collide).

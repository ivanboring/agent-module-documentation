Entity Markup provides a user interface to control the output markup (wrappers/HTML) of entities and their fields.

---

Entity Markup gives site builders a UI to control the output markup wrapping entities and their
fields — adjusting the HTML/wrappers around rendered field and entity output without writing template
overrides. It is useful for tailoring markup to a design system or removing unwanted wrapper elements
through configuration. It depends on core Field.

Use it to shape entity/field render markup from the admin UI instead of theme templates, keeping markup
tweaks as configuration. It is a display/theming feature affecting rendered HTML structure; it does not
change field data or access. Configure the desired markup on the entity/field display.

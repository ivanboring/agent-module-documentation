# Entity Weight — agent index

**Adds a weight field to any entity type** (nodes/terms/media/paragraphs) for custom ordering. Provides
permissions. Version **1.0.2**. Core `^10.1||^11`.

Content-editing/site-building — stores a weight value; no access role beyond permission.

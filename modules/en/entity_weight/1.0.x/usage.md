Entity Weight adds a weight field to any entity type for custom ordering.

---

Entity Weight **adds a weight field to any entity type** — nodes, taxonomy terms, media, paragraphs, etc. —
so items can be given a manual sort weight for custom ordering in listings/Views. It provides its own permissions.

Use it to manually order entities. It is a content-editing/site-building feature; it stores a weight value and has
no access-control role beyond its permission. Configure the weight field per entity type.

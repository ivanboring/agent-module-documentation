Entity Reference Display Formatter renders an entity reference using a selectable display/view mode.

---

Entity Reference Display Formatter **renders an entity reference using a chosen display** — a field formatter
that outputs the referenced entity in a selectable view mode/display, giving control over how references render. It
works on core 10–11.

Use it to render references in a specific view mode. It is a content-display/field-formatter feature; the
referenced entity renders per the chosen display (and its access still applies) and it has no access-control role.
Configure the formatter and view mode.

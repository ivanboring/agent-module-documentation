Entity body class provides functionality to add CSS classes to the page <body> based on the entity being viewed.

---

Entity body class adds CSS classes to the page `<body>` element based on the entity being viewed —
so themes can target styling by entity type, bundle or other entity-derived attributes without custom
preprocessing. It is configured at `entity_body_class.settings` and provides its own permissions.

Use it to drive theme styling from entity context (e.g. a body class per content type or per specific
node) cleanly through configuration. It is a theming feature adding CSS hooks; it affects markup
(body classes), not content or access. Configure which entity attributes become body classes.

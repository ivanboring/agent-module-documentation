# Entity body class — agent index

Adds configurable **CSS classes to the page `<body>` derived from the viewed entity** (type/bundle/
attributes) — theme styling hooks without custom preprocessing. Config at `entity_body_class.settings`;
provides permissions. Version **2.0.3**. Core `^8.8||^9||^10||^11`.

Theming feature — affects markup (body classes), not content/access.

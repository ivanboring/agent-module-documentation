A framework of entity change plugins.

---

Entity Change provides the framework for entity change plugins — a pluggable system for detecting and reacting to changes on entities (what changed, by whom), so other modules can build change-tracking/notification features on a common API. It's a developer/framework module. Supports Drupal 10 and 11.

Attach internal notes to any entity via a block.

---

Entity Note Block lets you attach internal notes to any entity using a block — so editors/admins can leave private notes on a node/term/user (shown via a block on the entity's page) that aren't part of the public content, useful for editorial coordination.

Notes are internal — gate the block/permission so only staff can see and edit them. Supports Drupal 10, 11, and 12.

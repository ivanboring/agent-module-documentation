Entity Reference Labels provides more descriptive labels for entity reference fields.

---

Entity Reference Labels provides more descriptive labels for entity-reference fields — so a reference's
displayed label can include extra context (beyond the target's plain title), making referenced items easier
to identify in forms/displays. It is a fields/UX feature.

Use it to improve entity-reference labels. It is a content-editing/display feature affecting how referenced
entities are labelled; the referenced entities respect their own access and it has no access-control role.
Configure the descriptive labels.

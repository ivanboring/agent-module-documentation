Entity Fields Report provides a report of entity fields.

---

Entity Fields Report **provides a report of entity fields across the site** — listing fields, their types,
and where they're used (including within Paragraphs), for site builders auditing the content model. It depends
on core Node and Paragraphs, provides its own permissions, in the Content package.

Use it to audit the field/content model. It is a developer/site-building reporting tool; its report is gated by
its permission (admin/site-builder) and it has no access-control role beyond that. View the entity-fields
report.

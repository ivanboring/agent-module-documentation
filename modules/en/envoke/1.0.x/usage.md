Envoke provides a mail/mailing-system integration with the Envoke platform.

---

Envoke **provides a mailing-system integration with Envoke** — sending email/newsletters through the Envoke
marketing platform's API and managing subscribers. It provides its own permissions, in the Mail package.

Use it to send mail via Envoke. It is a mail/integration feature. Security/data handling: it **sends recipient/
subscriber data (PII) and message content to the Envoke API** (egress — disclose per privacy policy) and
authenticates with an **Envoke API key** (store as a secret — env/Key — over HTTPS). It has no access-control role
beyond its permission. Configure the Envoke credentials.

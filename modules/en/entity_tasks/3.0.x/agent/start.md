# Entity Tasks — agent index

A **block that displays the available local tasks (tabs) for the current page** (place View/Edit/Delete
operations anywhere in the layout). Config at `entity_tasks.config`; provides permissions. Version **3.0.1**.
Core `^10||^11`.

Admin/UI — tasks shown reflect the user's permissions (only accessible tasks appear); no access role beyond
permission.

Entity Tasks exposes a block that displays the available tasks for the current page.

---

Entity Tasks exposes a block that shows the available local tasks (the View/Edit/Delete tabs) for the
current page — so the entity's operations can be placed as a block anywhere in the layout, rather than only
in the default local-tasks region. It is configured at `entity_tasks.config`, provides its own permissions,
in the Utility package.

Use it to place the current page's tasks as a block. It is an administration/UI feature; the tasks shown
reflect the user's permissions (only tasks they can access appear), and it has no access-control role beyond
its permission. Place the tasks block.

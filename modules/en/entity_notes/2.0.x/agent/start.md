# Entity Notes — agent index

Lets editors **add notes to content entities** (internal annotations/editorial comments). Depends on
`views`; provides permissions. Version **2.0.2**. Core `^9||^10||^11`.

**Security:** notes are internal info — gate viewing/adding with permissions so sensitive remarks don't
leak; confirm notes aren't exposed on public displays.

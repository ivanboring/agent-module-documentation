Entity Display Processor provides a plugin type to alter and decorate entity displays.

---

Entity Display Processor **provides a plugin type to alter and decorate entity displays** — a developer
framework for writing plugins that post-process/decorate how entities render (adjusting the built render array),
for reusable display customizations. It works on core 11.

Use it as a developer extension point for display logic. It is a developer/content-display framework; plugins
affect rendering and it has no content or access role of its own. Implement processor plugins as needed.

Entity Reference Link is a field formatter that renders entity-reference fields as simple links to the referenced entities.

---

Sometimes a reference field should just be a link to the referenced entity, not a rendered teaser. Entity Reference Link formats reference fields as links. It is a display formatter with no security surface; the link respects the referenced entity's access (a link to content the user cannot view still leads to an access-denied page, so it does not itself bypass access).

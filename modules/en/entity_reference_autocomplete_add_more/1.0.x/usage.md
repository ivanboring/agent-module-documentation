Entity Reference Autocomplete Add More adds an add-more capability to reference autocomplete.

---

Entity Reference Autocomplete Add More **adds an "add more" capability to entity-reference autocomplete
widgets** — letting editors add multiple referenced entities in one autocomplete field more fluidly, without the
default add-another round-trips. It is in its own package.

Use it to speed up multi-value reference entry. It is a content-editing/form-UI feature affecting the widget; it
has no content or access role. Use it on multi-value reference fields.

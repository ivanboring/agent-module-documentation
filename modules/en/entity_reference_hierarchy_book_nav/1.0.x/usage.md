---

Entity Reference Hierarchy Book Navigation **provides book-style navigation for Entity Reference Hierarchy** —
rendering previous/next/up and tree navigation (like core Book) over hierarchies defined with the Entity Reference
Hierarchy module. It depends on that module.

Use it to add book-like navigation to reference hierarchies. It is a content-display/navigation feature;
navigation follows the hierarchy and entity access, and it has no access-control role. Enable it for hierarchy book
navigation.

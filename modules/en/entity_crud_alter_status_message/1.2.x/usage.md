Entity CRUD Alter Status Message alters the message shown after entity CRUD.

---

Entity CRUD Alter Status Message lets you **customize the status message shown after entity create/update/
delete** — replacing the default "X has been created/updated/deleted" messages with token-driven custom text,
per entity type. It depends on the Token module, provides its own permissions, in the Other package.

Use it to tailor post-CRUD feedback messages. It is an administration/UX feature affecting messages; message
text is admin-configured (tokens resolve against access-respecting data) and it has no content or access role
beyond its permission. Configure the messages.

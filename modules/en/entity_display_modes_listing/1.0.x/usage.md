Entity Display Modes Listing shows entity display modes as additional operation links.

---

Entity Display Modes Listing **shows entity display modes as operation links** — surfacing the available view/
form display modes for an entity type as extra operations (e.g. in admin listings) so builders can jump to
managing each display. It works across core 8–11.

Use it to navigate display modes quickly. It is a site-building/administration convenience; it adds operation links
for admins and has no content or access role. Enable it for display-mode operation links.

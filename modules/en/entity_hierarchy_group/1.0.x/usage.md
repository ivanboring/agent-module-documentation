Group module support for Entity Hierarchy.

---

Entity Hierarchy Group Support provides Group support for entity_hierarchy — so hierarchical (tree-structured) entities managed by Entity Hierarchy work correctly within the Group module's group-content model, aligning the two systems. Depends on `entity_hierarchy` and `group`; supports Drupal 10.5+ and 11.2+.

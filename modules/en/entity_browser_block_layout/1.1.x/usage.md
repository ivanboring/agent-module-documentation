Entity Browser Block Layout provides adjustments to make it easier to use Entity Browser blocks in Layout Builder.

---

Entity Browser Block Layout provides adjustments that make Entity Browser blocks work better within
Layout Builder — smoothing the use of entity-browser-based block placement in the Layout Builder UI (so
editors can browse and place entities as blocks more easily).

Use it on sites combining Entity Browser and Layout Builder. It is a content-editing/site-building UX feature;
it affects the block-placement experience and has no content or access role. Enable it where Entity Browser
blocks are used in Layout Builder.

Entity Reference Select Create adds a modal 'create new' button to a select-list reference widget.

---

Entity Reference Select Create provides an entity-reference field widget rendered as a select list, plus a modal 'create' button so editors can create a new target entity inline without leaving the form. It streamlines referencing content that doesn't exist yet.

It's a field widget with no access role of its own; entity creation still respects the user's create access. Supports Drupal 10 and 11.

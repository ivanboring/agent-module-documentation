Safely merge taxonomy terms, nodes, and media entities.

---

Entity Reference Manager lets you safely merge taxonomy terms, nodes, and media entities — combining duplicate entities into one and re-pointing all references from the merged-away entities to the survivor, so content stays linked correctly (no broken references) after de-duplication.

Because merging rewrites references and deletes entities, restrict it to trusted administrators. Supports Drupal 10 and 11.

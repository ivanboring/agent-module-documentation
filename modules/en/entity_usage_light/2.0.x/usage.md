Entity Usage Light displays a list of media attached to an entity, a lightweight way to see media usage per entity.

---

Entity Usage Light provides a lightweight view of media usage — displaying the list of media items
attached to (referenced by) an entity, so editors can see which media a piece of content uses. It is a
lighter alternative to the full Entity Usage module for the media-per-entity case. It is configured at
`entity_usage_light.settings` and provides its own permissions.

Use it to surface attached media on content for editorial awareness. It is an administration/content view
that reads references; it is informational and has no access-control role. Configure which entities/fields
it reports on.

# Entity Copy with Reference — agent index

Configurable **one-click copy/clone of nodes** (duplicate a node + optionally its referenced entities). Config
at `entity_copy_reference.form`; provides permissions. Version **1.0.3**. Core `^9||^10||^11`.

Content-editing — creates a new node (governed by normal create access + its permission; gate who can clone).
No access role beyond that.

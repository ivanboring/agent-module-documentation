Entity Copy with Reference is a module for configurable one-click node copy/clone creation.

---

Entity Copy with Reference provides configurable one-click copying/cloning of nodes — duplicating a node
(and, per configuration, its referenced entities) to quickly create a copy. It is configured at
`entity_copy_reference.form`, provides its own permissions, in the Node package.

Use it to clone nodes with one click. It is a content-editing feature that creates a new node from an
existing one; cloning creates content, so it is governed by normal create access plus its permission — gate
who can clone (cloning respects the user's create permissions for the resulting content). It has no
access-control role beyond that. Configure which content types can be copied and how references are handled.

Entity Browser Multi Widget provides multiple native Entity Browser launchers sharing one selection target.

---

Entity Browser Multi Widget **provides multiple Entity Browser launchers sharing one selection target** — so
a single reference field can offer several entity-browser buttons (e.g. different browsers/sources) that all add to
the same selection. It depends on core Field and the Entity Browser module.

Use it to give editors multiple browse options for one field. It is a content-editing feature; selection follows
Entity Browser's normal access/selection handling and it has no access-control role. Configure the multi-widget on
a reference field.

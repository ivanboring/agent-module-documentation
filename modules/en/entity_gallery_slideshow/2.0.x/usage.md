Entities Gallery To Slideshow displays entities as a gallery view and a slideshow.

---

Entities Gallery To Slideshow renders a set of entities as a gallery and slideshow — presenting
entity content (typically image-bearing entities) in a grid gallery that can be viewed as a slideshow.
It is used to build image/media galleries with slideshow navigation from entity content. It is in the
Fields package.

Use it to present collections of entities (portfolios, product images, media sets) as an interactive
gallery/slideshow. It is a content-display/presentation feature; the entities and their access are
unchanged — it only controls how they are displayed. Configure the gallery/slideshow on the relevant
display.

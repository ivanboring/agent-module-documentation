Export and import entity data as JSON files.

---

Entity IO exports/imports entity data as JSON files — letting an administrator serialize entities (nodes, media, taxonomy, users, blocks, comments) to a JSON file and import them back, useful for moving content between sites or backups.

Because it can export/import content (including potentially sensitive user data), restrict it to trusted administrators and handle exported files carefully. Depends on core `media`, `user`, `node`, `taxonomy`, `block`, and `comment`; supports Drupal 10, 11, and 12.

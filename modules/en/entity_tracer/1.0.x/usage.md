Entity Tracer is a tracer of all entity relationships.

---

Entity Tracer **traces entity relationships** — mapping how entities reference each other (which entities
point to a given entity and vice versa), useful for understanding/debugging content structure. It provides its
own permissions, in the Custom package.

Use it to inspect entity reference graphs. It is a developer/administration tool that surfaces relationship
detail (which can reveal that referencing content exists); gate its permission to trusted admins/developers,
and it has no access-control role beyond that. Use it to trace relationships.

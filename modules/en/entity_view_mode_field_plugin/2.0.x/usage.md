A field plugin exposing an entity's view mode.

---

Entity View Mode Field Plugin provides a field plugin for the view mode of an entity — so the current view mode can be exposed/used as a field (e.g. in Views or displays), letting site builders vary output or logic based on which view mode is rendering. It's a developer/display helper. Supports Drupal 8 through 11.

Entity Confirmation changes entity save confirmation messages and redirects.

---

Entity Confirmation lets you **customize the confirmation message and redirect shown after saving an
entity** — replacing the default "X has been created/updated" message and controlling where the user lands, per
entity type/bundle. It is a UX feature.

Use it to tailor post-save feedback. It is an administration/UX feature affecting messages and redirects; it has
no content or access role. Configure the confirmation messages and redirects.

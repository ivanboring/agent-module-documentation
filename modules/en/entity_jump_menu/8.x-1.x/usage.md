Entity Jump Menu adds a toolbar jump menu to view the current page's entity and jump to another entity.

---

Entity Jump Menu **adds a jump menu to the admin toolbar** — letting administrators quickly view the current
page's entity and jump to a different entity (by type/ID), speeding up admin navigation. It provides its own
permissions, in the Utility package.

Use it for fast entity navigation in admin. It is an administration convenience; it navigates to entities (whose
access still follows normal entity access) and is gated by its permission. Enable it for the toolbar jump menu.

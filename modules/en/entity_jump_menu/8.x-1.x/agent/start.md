# Entity Jump Menu — agent index

**Adds a toolbar jump menu** to view the current page's entity and jump to another. Provides permissions. Version
**8.x-1.3**. Core `^9.3||^10||^11`.

Administration convenience — navigates to entities (access follows normal entity access); gated by its
permission.

Engaging Networks provides an API client for the Engaging Networks fundraising/advocacy platform.

---

Engaging Networks **provides an API client for the Engaging Networks platform** — connecting Drupal to
Engaging Networks (nonprofit fundraising/advocacy) to submit supporter data and integrate campaigns via its API.
It stores credentials via the **Key** module and provides its own permissions, in the Web services package.

Use it to integrate Engaging Networks. It is an integration feature. Security/data handling: it **sends supporter
data (PII — names, emails, potentially donation info) to the Engaging Networks API** (egress — disclose per your
privacy policy) and authenticates with **credentials stored via the Key module** (secret handling, a positive).
Serve over HTTPS. It has no access-control role beyond its permission. Configure the Engaging Networks credentials
(via Key).

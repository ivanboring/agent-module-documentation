Trash (soft-delete) support for Entity Hierarchy.

---

Entity Hierarchy Trash Support provides Trash support for entity_hierarchy — so hierarchical entities work correctly with the Trash module's soft-delete/recycle-bin model (a deleted tree node goes to trash rather than hard-deleting, preserving the hierarchy for restore). Depends on `entity_hierarchy` and `trash`; supports Drupal 10.5+ and 11.2+.

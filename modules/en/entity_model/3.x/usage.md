Entity Model adds annotation-based entity type and bundle modelling, letting entity types and bundles be defined via annotations.

---

Defining custom entity types and bundles in Drupal is verbose. Entity Model provides an annotation-based approach to modelling them. It is developer infrastructure for building entities. Because it defines entity types (which carry access implications), the generated entities' access handlers should be reviewed, and it is a developer capability — the modelling is done in code by developers. No unusual runtime security surface beyond that of the entities it helps define.

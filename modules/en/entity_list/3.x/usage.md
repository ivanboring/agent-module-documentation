Entity List provides an entity type for displaying configurable lists of entities, an alternative to Views for simple entity listings.

---

Views is powerful but heavy for a simple 'list these entities' need. Entity List provides an entity type to define configurable entity listings more directly. It is a content-display/site-building tool. The listings display access-controlled entities, so the standard caveat for any listing applies: confirm that the list respects entity access (an entity the user cannot view should not appear), particularly since a custom listing mechanism must call entity access itself where Drupal does not enforce it automatically. Configure the lists and verify their access behaviour.

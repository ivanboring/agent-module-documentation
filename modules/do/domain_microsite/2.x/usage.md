Domain Microsite by Path makes microsites using Domain records at subpaths of existing domains, so a subpath behaves like a domain.

---

Domain Microsite by Path lets you create microsites at subpaths of existing domains using Domain
records — so instead of (or in addition to) a separate domain, a subpath (e.g. `example.com/microsite`)
behaves like a Domain-module domain, with its own content/context. It depends on the Domain module. This
suits microsites/sections that should have domain-like isolation but live under a shared domain.

Use it to build path-based microsites on Domain-based sites. It is a site-structure/multi-domain feature
that maps subpaths to Domain records; because Domain records carry content/access context, verify the
microsite mapping matches your intended content isolation (Domain's access controls still govern what each
microsite shows). It has no access-control role of its own. Configure the microsite paths.

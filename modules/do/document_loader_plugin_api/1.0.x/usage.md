Load data from API endpoints via Document Loader.

---

Document Loader Plugin - API is a Document Loader plugin for loading data from API endpoints — so Document Loader can pull content from a remote HTTP API (as a document source) for indexing/import/AI use. The endpoint and any credentials are admin-configured; store credentials securely (env-backed). Depends on `document_loader`; supports Drupal 10.3+ and 11.

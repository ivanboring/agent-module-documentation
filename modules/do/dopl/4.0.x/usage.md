A text filter for easy linking to Drupal.org projects and nodes.

---

Drupal.org project link filter (dopl) provides a filter to facilitate linking to Drupal.org projects and nodes — so authors can write a short token/syntax in rich text and have it rendered as a proper link to a drupal.org project or issue/node, useful for documentation and community sites. Depends on core `filter`; supports Drupal 9.3+, 10, and 11.

# Domain Site Settings (domain_site_settings) — agent index

Per-domain **basic site settings** (name, slogan, email, logo…) for **Domain**-module multisites.
Version **8.x-1.6**. Depends on the Domain module. Permission `domain site settings`.

Each domain presents its own identity from one Drupal install. Restrict the permission to trusted
per-domain editors.

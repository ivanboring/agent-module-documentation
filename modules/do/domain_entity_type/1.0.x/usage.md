Domain Access Entity Type controls entity-type domain access (list builders and menus) for the Domain module.

---

Domain Access Entity Type **controls entity-type access by domain** — extending Domain Access so entity-type
list builders and menus are scoped per domain, in multi-domain setups. It depends on the Domain module and provides
its own permissions.

Use it to scope entity-type admin by domain. It is an access/site-building feature within the Domain ecosystem: it
affects which domains see which entity-type listings/menus. Verify it composes with your overall Domain Access
configuration (it complements, not replaces, Domain Access's content access). It has its own permissions. Configure
the domain entity-type access.

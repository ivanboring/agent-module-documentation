Domain Menu Links adds links to each domain in the admin toolbar on a Domain-module multisite, for quick switching between domains.

---

On a Domain-module multisite, an administrator often needs to jump between domains. Domain Menu Links adds per-domain links to the admin toolbar. It is an admin-UX convenience with no unusual security surface — it is admin-facing navigation. Confirm it is restricted to users who should see/switch between domains.

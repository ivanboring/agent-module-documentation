# Domino — agent index

An **opinionated set of configs/features to speed up Drupal project setup** (bundles Config Split, Reroute
Email, an SMS submodule for a consistent baseline). Depends on `config_split`, `reroute_email`. Version
**4.0.0**. Core `^10.1||^11`.

Admin/site-setup — pulls in **Reroute Email** (configure per environment so mail isn't mis-routed). No access
role.

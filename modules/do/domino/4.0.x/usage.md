---

Domino provides an **opinionated set of configuration and features to speed up project setup** — bundling
sensible defaults and helper features (Config Split, Reroute Email, an SMS submodule) so new Drupal projects
start from a consistent baseline. It depends on Config Split and Reroute Email, in the Domino package.

Use it to bootstrap a project with opinionated defaults. It is an administration/site-setup feature. Note it
pulls in **Reroute Email** (which redirects outgoing mail — a safety feature for non-production, but ensure it
is configured correctly per environment so production mail isn't rerouted or non-production mail isn't sent to
real users). It has no access-control role. Configure the Domino features per environment.

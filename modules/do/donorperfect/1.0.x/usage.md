DonorPerfect Base Module provides the foundation for integrating Drupal with DonorPerfect.

---

DonorPerfect Base Module is the foundation for integrating Drupal with DonorPerfect — a fundraising and donor management (CRM) platform — providing the shared services, configuration and entities other DonorPerfect submodules/integrations use to sync donors, gifts and related data.

Permissions separate user (`donorperfect user`) and admin (`donorperfect admin`) roles. DonorPerfect API credentials should be stored securely (env-backed). Depends on core `datetime`, `options`, and the `address` and `entity` modules; supports Drupal 10 and 11.

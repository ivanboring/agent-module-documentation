# Domain Twig — agent index

Provides a **Twig function to get the current domain** (Domain module) — read the active domain in templates
without a preprocess hook. Depends on `domain`. Version **1.0.1**. Core `^8||^10||^11`.

Theming/developer utility — reads domain context; no content/access role.

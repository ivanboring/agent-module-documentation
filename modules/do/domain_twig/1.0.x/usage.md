Domain Twig provides a Twig function to get the current domain.

---

Domain Twig provides a **Twig function to get the current domain** — so templates on a Domain-module
multi-domain site can read the active domain (id/hostname/label) and render domain-specific markup without a
preprocess hook. It depends on the Domain module, in the Custom package.

Use it in templates to branch on the current domain. It is a theming/developer utility exposing a Twig
function; it reads domain context and has no content or access role. Use the function in your Twig
templates.

DOI Field adds a DOI type field for storing Digital Object Identifiers.

---

DOI Field adds a DOI field type — a field for storing and validating Digital Object Identifiers (the
persistent identifiers used for scholarly publications and datasets), so content can carry structured DOI
references. It depends on the DOI Search module, in the Field types package.

Use it to add DOI fields to content. It is a content-editing/fields feature; the DOI value is authored data
(a reference/identifier) and it has no access-control role. Add the DOI field to the relevant content
types.

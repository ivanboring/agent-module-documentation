# DOI Field — agent index

Adds a **DOI (Digital Object Identifier) field type** (store/validate persistent identifiers for scholarly
publications/datasets). Depends on `doi_search`. Version **2.0.2**. Core `^8.8||^9||^10||^11`.

Content-editing/fields — DOI value is authored data; no access role.

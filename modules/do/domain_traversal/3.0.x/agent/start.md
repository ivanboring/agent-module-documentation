# Domain Traversal — agent index

Adds **per-domain menu items to navigate between domains** on a multi-domain (Domain module) site.
("Traversal" = navigating domains, **not** path traversal.) Depends on `domain`; provides permissions.
Version **3.0.0-rc2**. Core `^9.0||^10.0||^11.0`.

Site-structure/navigation convenience — Domain's access controls still govern each domain; no access role.

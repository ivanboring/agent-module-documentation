Domain Traversal adds new menu items per domain to easily traverse (navigate) between the domains of a multi-domain (Domain module) site.

---

Domain Traversal adds per-domain menu items that let administrators/editors easily navigate between
the domains of a multi-domain site — so from one domain you can jump to the equivalent context on another
domain without manually editing the URL. (Despite the name, "traversal" here means navigating between
domains, not path traversal.) It depends on the Domain module and provides its own permissions.

Use it on Domain-module multi-domain sites to speed up cross-domain navigation/administration. It is a
site-structure/navigation convenience for multi-domain setups; it adds navigation items and has no
access-control role of its own (Domain's access controls still govern what each domain shows). Configure
which domains appear.

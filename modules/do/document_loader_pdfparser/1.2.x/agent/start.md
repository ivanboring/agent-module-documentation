# Document Loader: PDF Parser — agent index

**Extracts content from PDFs** for Document Loader (PdfParser PHP library). Depends on `document_loader`. Version
**1.2.0**. Core `^10.4||^11||^12`.

Web-services/developer — parses **untrusted uploaded PDFs** (malformed files stress parsers; extracted content can
be sensitive); no access role.

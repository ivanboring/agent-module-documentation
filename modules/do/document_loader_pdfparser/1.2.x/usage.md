Document Loader: PDF Parser extracts text/content from PDFs for Document Loader using the PdfParser PHP library.

---

Document Loader: PDF Parser **extracts content from PDFs** — a Document Loader plugin that reads PDF files and
extracts their text/content (via the PdfParser PHP library) so PDFs can be ingested into content/AI pipelines. It
depends on the Document Loader module.

Use it to pull text out of PDFs. It is a web-services/developer feature. Data-handling note: PDF parsing runs on
**uploaded/supplied files** — treat input PDFs as untrusted (malformed files can stress a parser), and be mindful
that extracted content may contain sensitive data. It has no access-control role. Configure the PDF loader.

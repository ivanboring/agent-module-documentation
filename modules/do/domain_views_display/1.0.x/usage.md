Domain Views Display allows views to be configured per domain.

---

Domain Views Display **lets Views displays be configured per domain** — so a view can show different
displays/results depending on the active domain in a Domain-module multi-domain setup. It depends on core Views
and the Domain module, in the Domain package.

Use it to vary views by domain. It is a site-building/multi-domain feature; results follow the view's access and
it has no access-control role. Configure the per-domain view displays.

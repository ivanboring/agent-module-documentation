DOM Processor API offers a framework for plugins that manipulate the DOM of rendered output.

---

DOM Processor API provides a developer framework for registering DOM processors — plugins that transform the DOM of rendered HTML (e.g. rewriting elements, injecting attributes, post-processing markup). Other modules build on it to apply structured HTML transformations.

It's a developer API with no content or access role of its own; transformations run server-side on rendered output. Supports Drupal 9, 10, and 11.

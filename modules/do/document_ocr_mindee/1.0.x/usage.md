Document OCR integration with the Mindee document-parsing API.

---

Document OCR Mindee provides Document OCR integration with Mindee — a Document OCR provider that sends uploaded documents/images to Mindee's document-parsing API and returns extracted/parsed data (OCR), for automated document data capture.

The Mindee API key is admin-configured and should be stored securely (env-backed), never committed; documents are sent to Mindee's API over HTTPS. Depends on `document_ocr`; supports Drupal 9.5+, 10, and 11.

DOI Publications provides a search and service for DOI publications, looking up publication metadata by DOI.

---

DOI Publications provides a search and service for DOI (Digital Object Identifier) publications —
looking up scholarly publication metadata by DOI and offering a search interface/service, useful for
academic/library sites that reference publications by DOI. It provides its own permissions and is in the
Custom package.

Use it to search/resolve DOI publications. It typically queries an external DOI resolver/metadata service
for publication data; the returned metadata is external content surfaced in the site. It is a search/
integration feature with no access-control role beyond its permission. Configure the DOI search/service.

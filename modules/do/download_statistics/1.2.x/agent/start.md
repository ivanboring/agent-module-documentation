# Download Statistics — agent index

Logs **file-download statistics** (how often files are downloaded) — popularity of downloadable
content. Depends on core `node`, `field`, `file`. Config at `download_statistics.settings`; provides
permissions. Version **1.2.1**. Core `^10.3||^11||^12`.

Admin/reporting — mind privacy/retention of per-download logging. Stats access gated by permission (no
content-access change).

Extract content from Word and RTF documents via PHPWord.

---

Document Loader: PHPWord extracts content from Word and RTF documents with Document Loader, using the PHPWord library — a Document Loader plugin that reads `.doc`/`.docx`/`.rtf` files and extracts their text/content for downstream use (indexing, import, AI). Depends on `document_loader`; supports Drupal 10.4+, 11, and 12.

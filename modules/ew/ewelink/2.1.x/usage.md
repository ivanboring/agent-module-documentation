eWeLink connects Drupal to the eWeLink API to control smart devices, with an activity log.

---

eWeLink integrates the eWeLink smart-home API so a Drupal site can manage and control eWeLink devices — for example an 'open the door' action gated by a permission — and records device activity as entities. It bridges physical IoT devices to Drupal-based access/automation.

Because it can trigger physical actions (e.g. open a door), the `access ewelink open-the-door` permission and activity-entity permissions must be tightly restricted. eWeLink API credentials should be stored securely (env-backed). Supports Drupal 10 and 11.

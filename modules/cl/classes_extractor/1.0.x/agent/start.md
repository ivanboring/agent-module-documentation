# Classes Extractor — agent index

Dynamically **collects/exports the CSS classes used on the site** via a plugin system (Tailwind/PurgeCSS
safelisting / used-class manifest). Drush commands. Config at `classes_extractor.settings`. Version **1.0.1**.
Core `^10||^11`.

Developer utility — gathers class names (renders nothing); no content/access role.

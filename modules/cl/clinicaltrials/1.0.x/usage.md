Clinical Trials pulls clinical-trial data from the ClinicalTrials API into Drupal.

---

Clinical Trials integrates the ClinicalTrials (e.g. ClinicalTrials.gov) API into Drupal — fetching and displaying clinical-trial data so medical/research/hospital sites can present trial listings and details sourced from the public ClinicalTrials registry.

It fetches from the ClinicalTrials API (public data). Administration is gated by `administer clinical trials config`. Depends on core `language`; supports Drupal 8 through 11.

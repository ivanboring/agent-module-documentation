YASM provides site statistics dashboards — content, users, and other metrics — as admin reports, blocks and charts.

---

Operators want an at-a-glance picture of a site: how much content, how many users, activity over time. YASM ('Yet Another Statistics Module') provides that as dashboards, with `yasm_blocks` and `yasm_charts` submodules for placeable stats and visualisations. It reads and aggregates site data for display; the statistics can include user counts and activity that are mildly sensitive in aggregate, so the reports are admin-facing and should stay restricted to staff. It is a reporting tool with no write surface.

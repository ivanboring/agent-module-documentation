Date Recur Interactive Widget provides an interactive recurring date widget.

---

Date Recur Interactive Widget provides an interactive UI for entering recurring dates on Date Recur
fields — a friendlier widget (visual repeat rules, occurrence preview) for building RRULE-based recurrence
without editing raw rules. It depends on the Date Recur module, in the Field types package.

Use it for a friendly recurring-date input experience. It is a content-editing/form-widget feature affecting
recurring-date input; it has no content or access role. Select the interactive widget on the date_recur
field.

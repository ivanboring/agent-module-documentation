An API to help write automated tests involving dates and times.

---

Datetime testing provides an API to help develop automated tests that involve dates and times — letting tests set/freeze/advance the system's notion of 'now' so date/time-dependent behaviour is deterministic and testable. It's a development/testing tool (not for production). Supports Drupal 10 and 11.

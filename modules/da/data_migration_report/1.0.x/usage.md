A Drush command to verify migrated data.

---

Data Migration Report provides a Drush command to verify the migrated data — comparing/reporting on migrated content so a developer can validate that a migration produced the expected results (counts, mappings), useful during and after a Drupal migration. It's a migration QA tool. Depends on core `migrate_drupal`; supports Drupal 10.3+ and 11.

Data Structures provides Drush generators and default classes to replace most uses of arrays.

---

Data Structures provides Drush generators and default classes to replace ad-hoc arrays in code with
typed data-structure objects — helping developers write more robust, self-documenting code (typed
collections/structures) instead of loosely-typed arrays. It provides Drush commands, in the Development
package.

Use it as a developer tooling/library for typed data structures. It is a developer utility providing code
scaffolding and classes; it has no content or access role. Use the generators/classes in your code.

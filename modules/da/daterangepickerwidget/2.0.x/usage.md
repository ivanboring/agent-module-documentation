jQuery UI DateRangePicker Widget provides a jQuery UI widget similar to the date range picker used in Google Analytics.

---

jQuery UI DateRangePicker Widget provides a date-range picker — a jQuery UI widget resembling the
Google Analytics date-range picker (with presets like "last 7 days", custom ranges), usable as a field widget
and (via submodules) in Views exposed filters / better exposed filters. It ships `drpw_bef` and `drpw_field`
submodules, in the Field types package.

Use it for a friendly date-range picker on fields/filters. It is a content-editing/form-widget feature
affecting date-range input; it has no content or access role. Select the widget on the date-range field or
exposed filter.

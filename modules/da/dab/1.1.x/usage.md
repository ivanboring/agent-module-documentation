Drupal Atomic Builder (DAB) scaffolds and manages SDC-based atomic components.

---

Drupal Atomic Builder (DAB) helps developers build UI components following the atomic/component design pattern on top of the core Single Directory Component (SDC) module — scaffolding, organizing and managing components so a design system can be assembled from reusable pieces. It provides an admin UI for components.

Permissions cover configuration (`administer dab configuration`), component management (`administer dab components`), and access (`access dab components`) — restrict the administer permissions to developers. Depends on core `sdc`; supports Drupal 10.3+ and 11.

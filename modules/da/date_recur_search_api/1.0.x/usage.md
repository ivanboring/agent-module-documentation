Recurring Dates Field Search API provides Search API support for recurring date fields.

---

Recurring Dates Field Search API adds Search API support for recurring date fields (the Date Recur
module) — so recurring-date field values (with their expanded occurrences) can be indexed and searched/
filtered in Search API, enabling event-style searches over recurring dates. It depends on the Date Recur and
Search API modules, in the Search package.

Use it to index/search recurring dates. It is a site-search/indexing feature; the indexed dates come from
content (respecting the index/entity access) and it has no access-control role. Configure the recurring-date
fields on the Search API index.

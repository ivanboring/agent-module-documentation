Database SSL Check displays the SSL connection parameters to your database.

---

Database SSL Check displays the SSL/TLS parameters of Drupal's database connection — showing whether (and
how) the connection to the database is encrypted, so administrators can verify that DB traffic is protected
in transit. It is in the Administration package.

Use it to confirm the database connection is using SSL/TLS. This is a **positive** diagnostic that supports
a security best practice (encrypting DB connections, especially to a remote/managed DB). Note the information
it shows is operational/sensitive (DB connection details), so it should remain admin-gated (shown in the
admin area) and not exposed publicly. It has no access-control role. View the DB SSL status.

Data Fixtures generates data fixtures for development and testing.

---

Data Fixtures generates data fixtures — reproducible sample/test content and data — for development and
testing, so developers can populate a site with known data for testing features or demos. It provides Drush
commands, in the Development package.

Use it to generate test data during development. It is a developer/testing tool that creates content/data;
because it generates data, use it on **development/testing environments, not production** (it creates
sample/fixture content). It has no access-control role. Run the fixture generation via Drush.

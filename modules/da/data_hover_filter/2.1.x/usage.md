A text filter that adds a data-hover attribute to links.

---

Data hover Filter is a custom text filter to add a `data-hover` attribute to links — so a text format can automatically attach a `data-hover` attribute (mirroring the link text or title) to anchor tags, which themes/JS can use for hover effects/tooltips. It's a small text-format filter. Supports Drupal 8 through 12.

Date Range Availability manages entity availability based on date ranges.

---

Date Range Availability **manages availability for entities based on date ranges** — tracking when things
(events, products, resources) are available/unavailable across date ranges, usable in Views. It depends on core
Datetime Range and Views.

Use it to model date-range availability. It is a content/site-building feature; it stores and queries availability
windows and has no access-control role. Configure the availability date ranges.

DateTime Reset provides the option to display a reset button in datetime fields, letting users clear the value.

---

DateTime Reset adds an optional reset button to datetime field widgets — so users can clear a datetime
field's value with one click, useful for optional date fields where clearing is common. It depends on core
Datetime.

Use it on datetime fields where a clear/reset control improves UX. It is a content-editing/form-widget
feature affecting the datetime input; it has no content or access role. Enable the reset button on the
relevant datetime field widgets.

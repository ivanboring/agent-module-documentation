# DateTime Reset — agent index

Adds an optional **reset button to datetime field widgets** (clear the value in one click — for optional
date fields). Depends on core `datetime`. Version **1.0.2**. Core `^9.5||^10||^11`.

Content-editing/form-widget — affects datetime input; no content/access role.

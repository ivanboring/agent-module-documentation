# Date Range Simplify — agent index

Field **formatter** that renders a **date range concisely**, collapsing parts shared by start/end
(e.g. "1–30 June 2026"). Depends on core `datetime`. Version **2.0.6**. Core `^10.1||^11`.

Pure display/formatter (no value or access change). Select it on the daterange field's display
settings.

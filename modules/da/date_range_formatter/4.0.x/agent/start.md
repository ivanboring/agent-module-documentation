# Date Range Formatter (date_range_formatter) — agent index

Flexible **field formatter for date-range fields** — separate start/end formatting, same-day
collapse, configurable separators. Version **4.0.3**. Core `^8 || ^9 || ^10 || ^11`.
Depends on core `datetime_range`.

Display-only (changes rendering, not data). Turns "10 June – 10 June" into "10 June", "10–12 June
2026", etc. Configure same-day collapse and separators to your locale.

Date/Time Format Help adds a reference of PHP date() format characters to the formatter page.

---

Date/Time Format Help improves the date-format admin page by adding a friendly, inline copy of the PHP `date()` format-character reference from the PHP manual — so site builders configuring custom date formats can see what each token means without leaving the page.

It's a documentation/UX helper for admins with no content or access role. Supports Drupal 10 and 11.

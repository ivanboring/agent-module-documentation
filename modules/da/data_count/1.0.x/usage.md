Data Count helps administrators count all existing nodes and users on the website, showing content/user totals.

---

Data Count provides administrators a count of the site's data — totals of existing nodes and users —
giving a quick overview of content and user volume without running queries manually. It is a small
reporting/administration utility.

Use it to see content/user counts at a glance. It is an administration/reporting feature that reads
aggregate counts; it is informational and has no access-control role. View the counts in the admin
interface.

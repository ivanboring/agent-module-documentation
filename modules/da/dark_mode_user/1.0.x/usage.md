Dark Mode User adds site-wide dark mode with per-user light/dark/system preference.

---

Dark Mode User provides a standalone dark-mode system for Drupal — not tied to a specific theme — with a global default and per-user preferences (light, dark, or follow-system). Authenticated users choose their mode and it persists across sessions.

Access to the per-user setting is gated by `access dark mode user`. It's a theming/UX feature with no content role of its own. Requires Drupal 11.1+.

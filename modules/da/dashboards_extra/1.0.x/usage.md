Dashboards Extra adds a Multi Statistics block to Dashboards.

---

Dashboards Extra **adds extra blocks to the Dashboards module** — notably a multi-statistics block that
surfaces several site metrics at once on an admin dashboard. It depends on the Dashboards module.

Use it to enrich admin dashboards with more widgets. It is an administration feature; dashboard blocks show data
the viewer can access (following normal access) and it has no access-control role. Add the extra blocks to a
dashboard.

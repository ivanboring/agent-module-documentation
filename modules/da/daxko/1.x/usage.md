Daxko provides a basic integration with Daxko, the membership-management and payment platform used by YMCAs and similar organisations.

---

Daxko is a membership/operations platform for YMCAs, gyms and similar. Daxko provides a basic Drupal integration. It connects to Daxko's API, which handles member data and payments, so the API credentials are sensitive (keep out of plain config) and the data exchanged (member records, potentially payment-related) is personal/financial — handle the integration accordingly. It is infrastructure for a Daxko-using organisation. Protect the credentials and confirm what member data flows between the systems.

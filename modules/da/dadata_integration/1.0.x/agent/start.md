# DaData Integration — agent index

**Integrates the DaData API for form autocomplete** (country/city/address). Depends on core `system`. Version
**1.0.1**. Core `^10.1||^11||^12`.

Integration/forms — sends typed values to the **DaData API** (egress; partial addresses/PII); **API key** as a
secret (env/Key, HTTPS); disclose per policy. No access role.

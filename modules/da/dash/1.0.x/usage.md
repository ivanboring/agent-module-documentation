Dash provides a modern, React-powered administrative dashboard with key metrics.

---

Dash provides a **React-powered administrative dashboard** — a modern admin landing page surfacing key
site metrics/at-a-glance information for administrators. It depends on core System, provides its own
permissions, in the Administration package.

Use it as an admin dashboard. It is an administration/UI feature; the metrics it shows are administrative
information, so gate its permission to trusted admins (a dashboard can surface operational/site data), and it
has no access-control role beyond its permission. Configure the dashboard.

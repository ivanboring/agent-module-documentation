Days Ago provides a days-ago field formatter for datetime and timestamp fields.

---

Days Ago provides a **"days ago" field formatter** for datetime and timestamp fields — rendering a date
as a relative time (e.g. "3 days ago") instead of an absolute date, for more human-friendly date display. It
is in the Custom package.

Use it to show relative dates. It is a content-display/formatter feature affecting date presentation; it has no
content or access role. Choose the Days Ago formatter on a date field.

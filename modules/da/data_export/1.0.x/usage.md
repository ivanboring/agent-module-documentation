Data Export exports data in various formats like PDF, DOCX, CSV and XLS.

---

Data Export **exports data in various formats** — PDF, DOCX, CSV and XLS — providing a way to output site
data as downloadable documents/spreadsheets. It is in the Custom package.

Use it to export data to documents. It is a data-export/administration feature with an access angle: an export
tool **turns data into files**, so ensure (1) the exported data set **respects access** (only export content
the requester is allowed to see — an export that bypasses access is an information-disclosure risk), and (2)
**who can trigger exports** is gated to appropriate roles. It has no access-control role of its own. Configure
the export sources and permissions carefully.

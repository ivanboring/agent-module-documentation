# Book Organizer — agent index

A **Views-powered hierarchical overview for managing Drupal core Book content** (see/organize the book tree
vs the default book admin). Depends on core `book`; provides permissions. Version **1.0.3**. Core `^10||^11`.

Admin/content over Book — reflects book content (respects book/node access); no access role beyond
permission.

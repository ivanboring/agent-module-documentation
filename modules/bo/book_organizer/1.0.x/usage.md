Book Organizer provides a Views-powered hierarchical overview for managing Drupal books.

---

Book Organizer provides a Views-powered hierarchical overview for managing Drupal core Book content —
showing the book tree in a manageable interface so editors can see and organize book pages/hierarchy more
easily than the default book admin. It depends on core Book and provides its own permissions, in the Content
package.

Use it to manage book structure more effectively. It is an administration/content feature over Book; it
reflects book content (respecting book/node access) and has no access-control role beyond its permission.
View and organize books.

Body Attributes lets site builders add classes/attributes to the body (and other) tags.

---

Body Attributes allows adding classes and HTML attributes to the body tag (and other tags) through configuration — so site builders can attach styling/behavior hooks (classes, data-attributes) to page markup without editing theme templates, useful for JS/CSS targeting and integrations.

The attributes are admin-configured; administration is gated by `administer body attributes` — restrict to trusted roles (arbitrary attributes are markup-affecting). Supports Drupal 10.3+ and 11.

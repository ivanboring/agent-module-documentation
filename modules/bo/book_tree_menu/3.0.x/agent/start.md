# Book Tree Menu (book_tree_menu) — agent index

Alternative **book navigation block** rendering a book as a **tree**. Version **3.0.1**.
Core `^10 || ^11`. Depends on core `book`. Only useful on book-using sites.

Display alternative to core's minimal book block — shows the full hierarchy from any page. Compare
`custom_book_block` (same wave) for a more configurable take. Confirm the depth/branch it renders
suits large books.

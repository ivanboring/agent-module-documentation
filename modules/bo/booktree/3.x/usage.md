Book Tree provides a tree representation of one or more books, showing book structure as a navigable tree.

---

Core's Book module builds hierarchical content; a whole-tree view aids navigation of large books. Book Tree renders one or more books as a navigable tree. It is a display/navigation feature for book-using sites with no security surface — it renders the structure of access-controlled books, and a book page the user cannot view is subject to its own access. Confirm the tree renders the books you intend.

Bootstrap Components provides lightweight Bootstrap 5 SDC components.

---

Bootstrap Components provides **lightweight Bootstrap 5 Single Directory Components (SDC)** — reusable
front-end components (cards, buttons, accordions, etc.) built with Bootstrap 5 markup as SDC, usable in
templates/Layout Builder. It is in the User Interface package.

Use it to build UIs with Bootstrap 5 components. It is a theming/front-end feature; components are theme/
authoring constructs and it has no content or access role. Use the components in your theme/layouts.

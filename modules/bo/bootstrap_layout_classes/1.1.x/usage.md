Bootstrap Layout Classes provides a field widget and formatter for selecting and outputting Bootstrap layout (grid/utility) classes.

---

Bootstrap Layout Classes provides a field widget and formatter for selecting Bootstrap layout classes —
so editors can pick Bootstrap grid/utility classes (columns, spacing) on a field and have them output as
classes, driving Bootstrap-based layout from content without hand-writing class strings. It depends on
core Field.

Use it on Bootstrap-themed sites where editors should choose layout classes per item. It is a fields/
theming feature affecting output classes; the stored value is the chosen classes and it has no
access-control role. Configure the widget/formatter on the relevant field.

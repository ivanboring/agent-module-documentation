Bootstrap select picker provides the bootstrap-select JS widget for option field types.

---

Bootstrap select picker integrates the bootstrap-select JavaScript widget — rendering option/select
form fields as a searchable, styled Bootstrap dropdown (with search, multi-select, styling) instead of the
plain HTML select. It applies to option field types.

Use it to enhance select fields with bootstrap-select. It is a content-editing/form-widget feature affecting
select presentation; it does not change the options, data or access and has no access-control role. Select
the bootstrap-select widget on the option field.

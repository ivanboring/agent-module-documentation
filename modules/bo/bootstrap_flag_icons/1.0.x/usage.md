Flag icons Bootstrap CkEditor provides two flag-icon features — a Bootstrap 5 dropdown button language
switcher (switch between available site languages, shown with flag icons) and a CKEditor tool to insert flag
icons into content. It is in the Multilingual package.

Use it for a flag-based language switcher and in-content flag icons. It is a multilingual/UI feature; the
switcher reflects the site's configured languages and it has no access-control role. Place the switcher and
enable the CKEditor tool.

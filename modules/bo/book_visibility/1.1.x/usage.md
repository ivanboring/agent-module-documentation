Book Visibility enables block visibility control by book.

---

Book Visibility **adds block-visibility conditions based on the current book** — so a block (e.g. the book
navigation) can be shown/hidden depending on which book the current page belongs to. It is in the Book package.

Use it to show blocks only within certain books. It is a site-structure/block feature and it controls
**block visibility (presentation), not book content access** — it decides whether a *block* renders, not who can
read a book; use core node access for book content protection. It has no access-control role. Configure the
block's book-visibility condition.

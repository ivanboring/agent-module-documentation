Bookmark Field lets you access an entity by its bookmark.

---

Bookmark Field lets an entity be **accessed by a bookmark** — it provides a field (and a block) that
gives content a shareable bookmark identifier/URL, so users can bookmark and return to a specific entity via
that reference. It depends on core Field and Block.

Use it to give content shareable bookmark links. It is a content-display/navigation feature. Security note: a
bookmark URL is a **way to reach the entity**, but it does **not** grant access — the entity's normal access
control still applies when the bookmark is followed (so a bookmark to restricted content won't bypass
permissions); just avoid treating an unguessable bookmark as a secret capability for truly sensitive content.
It has no access-control role. Add the bookmark field/block.

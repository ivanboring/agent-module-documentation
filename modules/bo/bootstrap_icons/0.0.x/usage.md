Bootstrap Icons provides the Bootstrap Icons library as an icon pack.

---

Bootstrap Icons **provides the Bootstrap Icons library as an icon pack** — making Bootstrap's open-source SVG
icons available through Drupal's icon API for use in themes/components. It is in the Media package (core 11.1+).

Use it to use Bootstrap icons. It is a theming/media feature; icons are static assets and it has no content or
access role. Use Bootstrap icons via the icon API.

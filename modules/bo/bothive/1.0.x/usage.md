Bothive Chatbot embeds the Bothive chatbot widget on the site.

---

Bothive Chatbot provides chatbot integration for Drupal using bothive.be — embedding the Bothive chatbot widget so visitors can interact with an automated assistant for support/lead capture, popular for Belgian/accountancy sites.

The widget loads Bothive's third-party script (review privacy/data-flow); configuration is gated by `administer bothive configuration`. Supports Drupal 8.8 through 11.

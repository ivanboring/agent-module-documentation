Bootstrap Colors applies colors to Barrio based themes using Material Design color concepts.

---

Bootstrap Colors lets you **apply colors to Bootstrap Barrio-based themes** using Material Design color
concepts — configuring a color palette that maps onto the theme's Bootstrap variables, so a Barrio subtheme
can be recolored without writing SCSS. It provides its own permissions, in the Bootstrap package.

Use it to recolor Barrio-based Bootstrap themes. It is a theming/administration feature affecting appearance;
it has no content or access role beyond its permission. Configure the color palette.

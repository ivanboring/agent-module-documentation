# Bootstrap Site Alert (bootstrap_site_alert) — agent index

Site-wide **alert banners** in Bootstrap styling, dismissible (via **`js_cookie`**).
Version **3.0.5**. Core `^10 || ^11`.
Permissions: `administer bootstrap site alerts`, `view bootstrap site alerts` — set who creates and
who sees (some alerts may be authenticated-only).

Bootstrap dependency is stylistic — emits Bootstrap classes; on a non-Bootstrap theme give them
meaning. Editor-managed operational/promotional messaging.

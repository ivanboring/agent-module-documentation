Bootstrap UI integrates the Bootstrap CSS framework along with a user interface for configuring and customizing components, variables and plugins.

---

Bootstrap UI integrates the Bootstrap CSS framework into Drupal with a configuration UI — letting site
builders enable/customize Bootstrap components, variables and plugins from an admin interface rather than
editing theme files. It is configured at `bootstrap.settings` and provides its own permissions, in the
Bootstrap package.

Use it to bring Bootstrap and configure it via the UI. It is a theming/front-end feature affecting site
presentation; it does not change content or access and has no access-control role. Configure the Bootstrap
components/variables.

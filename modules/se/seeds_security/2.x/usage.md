Seeds Security is a starter module that enables a curated set of security modules for the Seeds distribution.

---

Hardening a Drupal site means enabling and configuring a set of well-known security modules. Seeds Security is a convenience aggregator — a starter that pulls in and enables a curated set of security modules for the Seeds distribution, so a new site gets a baseline of protections in one step. It adds security rather than posing a risk; the thing to know is that it is an opinionated bundle, so review which modules it brings and whether their configuration matches your needs (a bundle is a starting point, not a substitute for understanding each control). On a non-Seeds site it is still usable as a curated security starter, subject to that review.

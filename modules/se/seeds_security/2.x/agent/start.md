# Seeds Security (seeds_security) — agent index

Starter/aggregator that **enables a curated set of security modules** (Seeds distribution). Version
**2.0.2**.

Adds security (not a risk itself). It's an **opinionated bundle** — review which modules it brings
and their config; a bundle is a starting point, not a substitute for understanding each control.

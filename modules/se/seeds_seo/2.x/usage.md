Seeds SEO is a starter module that enables and configures a curated set of SEO modules for the Seeds distribution.

---

Good SEO on Drupal means enabling and configuring several modules — metatag, pathauto, sitemap, redirects. Seeds SEO is a convenience aggregator that pulls in and configures a curated SEO stack for the Seeds distribution, so a new site gets an SEO baseline in one step. It adds functionality, not risk; the thing to know is that it is an opinionated bundle, so review which SEO modules it brings and whether their configuration suits your site. On a non-Seeds site it is still usable as a curated SEO starter subject to that review.

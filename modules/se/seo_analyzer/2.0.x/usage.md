SEO analyzer runs a set of on-page SEO checks against a node and reports what it finds to the editor.

---

The category is familiar from WordPress, where a traffic-light SEO panel beside the editor is standard, and its value is the same here: most on-page problems are mechanical — a missing meta description, an unset alt attribute, a title that is too long for a result snippet, a heading hierarchy that skips a level, a page with no internal links pointing at it — and every one of them is cheap to fix at the moment of writing and expensive to find six months later across a thousand pages. Showing them in the edit form puts the fix next to the cause. Version **2.0.1** on **`^11`** — Drupal 11 only — behind an `access seo analyzer` permission, and note the description says "a given node or **canvas page**", which suggests awareness of Drupal's newer page-building work and is worth confirming against the site's actual content model. Three things to say when recommending it. **On-page checks are the smallest part of ranking**, which is dominated by content quality, links and site performance, so a page scoring green is not a page that ranks — the tool measures what is measurable. **Advice ages faster than modules do**: keyword density, exact-match phrases and meta keywords were once standard recommendations and are now neutral or harmful, so check what the checks actually assert rather than trusting the category. And **an editorial checklist works better as guidance than as a gate**, because writing to satisfy a scoring rule produces text optimised for the rule, which is precisely what search engines have spent two decades learning to discount.

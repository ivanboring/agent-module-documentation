Seeds Performance is a starter module that enables a curated set of performance modules for the Seeds distribution.

---

Performance tuning means enabling and configuring several modules — caching, aggregation, lazy-loading. Seeds Performance is a convenience aggregator that pulls in a curated performance stack for the Seeds distribution, giving a new site a performance baseline in one step. It adds functionality, not risk; it is an opinionated bundle, so review which modules it brings and whether their configuration suits your site. Usable as a curated performance starter on non-Seeds sites too, subject to that review.

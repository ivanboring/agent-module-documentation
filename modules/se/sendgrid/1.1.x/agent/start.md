# SendGrid (sendgrid) — agent index

Sends Drupal email through **SendGrid (Twilio)**. Version **1.1.0**. Core `^9 || ^10 || ^11`.
Permission `administer sendgrid`.

Configure as the mail plugin with a SendGrid API key — keep the key out of plain config (Key
entity / env). Deliverability + tracking over local mail.

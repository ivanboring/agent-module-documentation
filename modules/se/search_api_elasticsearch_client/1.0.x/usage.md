Search API Elasticsearch Client provides an Elasticsearch backend for Search API using the official Elasticsearch client library.

---

Another Elasticsearch backend for Search API, built on the official Elasticsearch PHP client. It lets Search API indexes be served from an Elasticsearch cluster, for sites choosing Elasticsearch over Solr. It needs an Elasticsearch cluster to connect to, and the connection credentials (if the cluster is secured) are configuration to keep out of plain config. It slots into Search API's server/index configuration like any backend.

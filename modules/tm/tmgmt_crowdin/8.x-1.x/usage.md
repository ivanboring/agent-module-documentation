TMGMT Crowdin is a Translation Management Tool (TMGMT) plugin that sends translation jobs to the Crowdin localization platform.

---

TMGMT manages the Drupal-side translation workflow and delegates the actual translation to a provider. TMGMT Crowdin is the plugin for Crowdin, a commercial localization platform. If a site's translation work is done in Crowdin, this connects the two. It needs Crowdin API credentials (a credential to keep out of plain config, stored in TMGMT translator settings — check config exports for it), and it forwards content to Crowdin for translation (external processing). Configure the Crowdin project mapping and protect the API token.

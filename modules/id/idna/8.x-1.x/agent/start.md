# IDNA Convert (idna) — agent index

**IDNA (Internationalized Domain Name)** conversion service (Unicode ↔ Punycode) + demo page.
Version **8.x-1.11**. Developer utility, no security surface. (General note: IDN homographs are a
phishing vector — this provides conversion, not a phishing defence.)

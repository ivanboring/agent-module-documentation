# Perplexity AI Provider — agent index

AI **provider plugin for Perplexity AI** (route Drupal AI operations to Perplexity models). Depends on `ai`.
Machine name `ai_perplexity`. Version **1.0.0-beta2**. Core `^10.2||^11`.

**Security:** store the Perplexity API key as a **secret**; prompts sent leave the site (data-handling). No
access role.

---

AI Content Assistant provides AI-powered content generation using reusable prompt patterns. It builds on Drupal's AI module and depends on `node`, `ai`, in the AI package.

Use it for AI-assisted content generation. It is an AI/integration feature. Security/data handling: it **sends
content/prompts to the configured AI provider** (external egress — confirm acceptable for the content), the provider **API key** is stored via the AI module's Key config (secret),
over HTTPS and AI output should be **reviewed** before use/publishing. It has no access-control role beyond its permission. Configure the AI
provider.

AI Translate LB Asymmetric provides AI translation for asymmetric Layout Builder.

---

AI Translate LB Asymmetric provides **AI translation for asymmetric Layout Builder translations** — letting
editors translate Layout Builder content (where translations can have different layouts per language) via the AI
Translate module. It depends on AI Translate, core Content Translation and Layout Builder Asymmetric
Translation.

Use it to AI-translate asymmetric Layout Builder content. It is an AI/multilingual feature. Security/data
handling: content is **sent to the configured AI provider** to translate (external egress — confirm acceptable;
key via AI/Key secret), and AI translations should be **reviewed** before publishing (don't publish machine
output unchecked). It has no access-control role. Configure the AI provider and translation.

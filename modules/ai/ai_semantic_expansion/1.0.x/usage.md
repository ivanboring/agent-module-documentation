AI Semantic Expansion adds AI-generated synonyms and intents to Search API indexes for semantic matching.

---

AI Semantic Expansion improves search recall by using AI to generate semantic synonyms and search intents, then enriching Search API index data with them. Because the expansion happens at index/query time as extra terms, it enables semantic-style matching without requiring a vector database — it stays database-agnostic and works with standard Search API backends.

AI generation runs against the configured provider (cost at indexing). Depends on `ai` and `search_api`; supports Drupal 10.4+ and 11.

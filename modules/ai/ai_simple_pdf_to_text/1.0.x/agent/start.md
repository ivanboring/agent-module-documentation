# AI Simple PDF to Text — agent index

Provides **AI automators/agents to convert PDF documents to text** (extract PDF text for indexing/summarizing/
AI processing). Version **1.0.0-alpha3**. Core `^10||^11`.

**Data-handling:** PDF content is typically sent to the configured AI provider (external) — don't send
confidential PDFs; store the provider key as a secret. No access role.

AI Drush Agents exposes Drush commands that drive AI Agents from the CLI.

---

AI Drush Agents lets developers and operators interact with the AI Agents framework from the command line — running agents, issuing prompts, and inspecting agent output via Drush. This is useful for scripting, testing agent behaviour, and integrating AI agent tasks into deployment/automation pipelines.

Drush commands run with full site privileges, and agents can invoke tools (function calls) that may read or modify site data, so treat CLI access as trusted-operator-only. Depends on `ai_agents`; supports Drupal 10.3+ and 11.

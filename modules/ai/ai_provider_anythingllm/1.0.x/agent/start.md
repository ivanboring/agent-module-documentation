# AnythingLLM Provider — agent index

An **AI provider routing the Drupal AI module to an AnythingLLM instance** (self-hostable LLM/RAG). Depends on
`ai`, `key`. Version **1.0.0**. Core `^10.2||^11`.

AI/integration — API key **via the Key module** (store as a Key/secret, HTTPS endpoint); self-hosting can keep
prompts on your infrastructure. No access role.

AI Sorting provides an AI/reinforcement-learning sort plugin for Views.

---

AI Sorting **sorts Views with reinforcement learning** — a Views sort plugin that orders results using an
AI/reinforcement-learning model (learning from interactions) for adaptive relevance ordering. It depends on core
Views and the RL module.

Use it for adaptive AI-driven view ordering. It is a Views/AI feature. Data-handling note: reinforcement learning
learns from **user interactions** (behavioral data) — handle that data per your privacy policy, and any external
model calls are egress. It has no access-control role. Configure the AI sort on a view.

# AI Chat — agent index

**Places a floating AI chat widget** powered by AI Agents / AI Assistant API. Depends on `ai_agents`,
`ai_assistant_api`, core `user`. Version **1.0.0-alpha6**. Core `^10.3||^11`.

AI — conversations **sent to the AI provider** (egress; key via AI/Key); **scope** the assistant's tools/agents
so chatters can't trigger privileged actions. No access role of its own.

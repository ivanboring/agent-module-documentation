AI Featured Image auto-generates a node's featured image via AI.

---

AI Featured Image generates featured images for nodes using AI — creating an image (via an AI image-generation provider) to use as a node's featured/hero image, so content without a suitable image gets an AI-generated one automatically.

Image generation runs through the configured AI provider (cost + data egress). Depends on core `node` and `file`; requires Drupal 11.

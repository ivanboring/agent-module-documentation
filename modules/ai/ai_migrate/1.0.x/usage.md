AI Migrate provides AI-enabled Migrate process plugins (transform/enrich data during migration with AI). It builds on Drupal's AI module and depends on `ai`, `migrate_plus`, in the AI package.

Use it for AI-assisted migrate process. It is an AI/integration feature. Security/data handling: it **sends
source data to the configured AI provider** (external egress — confirm acceptable for the content), the provider **API key** is stored via the AI module's Key config (secret),
over HTTPS. It has no access-control role. Configure the AI
provider.

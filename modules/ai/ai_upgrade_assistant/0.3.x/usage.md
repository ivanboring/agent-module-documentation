AI Upgrade Assistant uses AI + Upgrade Status to help fix deprecations and upgrade modules.

---

AI Upgrade Assistant uses AI to assist with Drupal upgrades and module updates — building on Upgrade Status to detect deprecations/compatibility issues and using AI to suggest or generate fixes, speeding up the work of moving custom/contrib code to newer Drupal versions.

AI operations run through the configured provider (cost). Permissions cover access (`access upgrade assistant`) and administration (`administer upgrade assistant`). Depends on core `system`, `update`, and `upgrade_status`; supports Drupal 9, 10, and 11.

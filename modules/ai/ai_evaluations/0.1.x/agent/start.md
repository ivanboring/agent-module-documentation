# AI Evaluations — agent index

**Runs evaluations on AI Chatbot / AI Assistant responses** (quality/accuracy testing). Depends on core `views`,
`ai_assistant_api`, `ai_chatbot`. Provides permissions. Version **0.1.0**. Core `^10.2||^11`.

AI/developer — evaluations **send prompts to the AI provider** (egress); gate to trusted devs/admins. No access
role beyond permission.

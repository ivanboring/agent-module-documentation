AI Providers API offers a provider plugin system for wiring in AI providers.

---

AI Providers API provides an AI provider plugin system — a framework for defining and managing AI providers (originally for an LMS context) so applications can register and use multiple AI providers through a common plugin interface, separate from or alongside the core AI module's provider system.

Provider credentials should be stored securely (env-backed). Administration is gated by `administer ai providers`. Requires Drupal 11.

# ai.txt — agent index

Generates/edits an **`ai.txt`** file (AI-crawler usage directives, robots.txt-analogous) from the web UI.
Config at `aitxt.admin_settings_form`; provides permissions. Version **1.0.0**. Core `^10.1||^11`.

SEO/crawler-control — advisory declaration to AI crawlers (compliance is up to them); no access role.

# Google Vertex (AI provider) — agent index

**AI provider plugin** letting the Drupal **AI module** use **Google Vertex** (Vertex AI Studio).
Depends on `ai`, `key`. Configure at `ai_provider_google_vertex.settings_form`. Version **1.1.1**.
Core `^10.3||^11`.

**Credentials via the Key module** — store the Vertex service-account key as a Key (env/secure
provider), never plaintext config.

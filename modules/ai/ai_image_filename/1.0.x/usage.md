AI Image Filename renames uploaded images using AI vision (descriptive filenames for SEO/accessibility). It builds on Drupal's AI module and depends on `file`, `ai`, in the AI Tools package.

Use it for AI-assisted image handling. It is an AI/integration feature. Security/data handling: it **sends
images to the configured AI provider** (external egress — confirm acceptable for the content), the provider **API key** is stored via the AI module's Key config (secret),
over HTTPS. It has no access-control role. Configure the AI
provider.

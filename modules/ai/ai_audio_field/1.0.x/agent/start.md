# AI Audio Field — agent index

Adds an audio field enriched by ai (e.g. ai-generated audio/transcription). Depends on `ai`, `file`. Version **1.0.x**. Core `^10.2||^11`.

AI/integration — **sends audio/text to the AI provider** (egress; key via AI/Key, secret). No access role.

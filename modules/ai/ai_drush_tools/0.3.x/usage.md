AI Drush Tools adds Drush commands for upgrade checks and project inspection.

---

AI Drush Tools provides Drush commands for module upgrade checks, Drupal.org project inspection, and related developer tasks — helping developers assess module compatibility, inspect project metadata, and support upgrade workflows from the command line (with optional AI assistance).

It's a developer/CLI tool with no content or access role of its own. Supports Drupal 10.3+ and 11.

# AI Webform Sentiment — agent index

Analyzes webform submissions for sentiment using ai (with chart.js visualization). Depends on `ai`, `webform`, `chartjs_api`. Version **1.0.x**. Core `^10.2||^11`.

AI/integration — **sends submission text to the AI provider** (egress; key via AI/Key, secret). No access role beyond permission.

AI CKEditor CEFR lets editors rewrite text to a target CEFR language level via AI.

---

AI CKEditor CEFR adds a CEFR rewrite plugin for AI CKEditor — so editors can prompt AI to rewrite selected text to a target CEFR (Common European Framework of Reference for Languages) proficiency level (A1–C2), useful for producing content at a controlled reading/language level (accessibility, language learning).

AI rewrites run through the configured AI provider (cost). Depends on `ai_ckeditor` and core `taxonomy`; supports Drupal 10.4+ and 11.

# AI Agent Modes — agent index

**Adds a Mode selector that steers an AI agent toward a curated subset of its sub-agents** (scoped instruction).
Depends on `ai`, `ai_agents`, `canvas`. Provides permissions. Version **1.0.0-alpha4**. Core `^11`.

AI/orchestration — operates in the AI agent stack (sends prompts to the AI provider — egress; credentials as
secrets). No access role beyond permission.

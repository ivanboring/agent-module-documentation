AI RAG Search grounds AI answers in Search API results (retrieval-augmented).

---

AI RAG Search integrates an AI chat model (e.g. ChatGPT) with Search API to provide contextual, retrieval-augmented (RAG) answers — retrieving relevant indexed content and using AI to answer questions grounded in it, so search returns answers rather than just result lists.

AI operations run through the configured provider (cost). Permissions cover administration (`administer ai search settings`) and API access (`access ai search api`). Depends on `search_api`; supports Drupal 10 and 11.

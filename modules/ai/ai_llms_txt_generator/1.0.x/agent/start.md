# AI LLMs.txt Generator — agent index

**AI-powered generation of spec-compliant llms.txt from sitemap.xml**. Depends on `ai`, `simple_sitemap`. Provides
permissions. Version **1.0.1**. Core `^10||^11`.

SEO/AI — **sends sitemap/content to the AI provider** (egress); publishes **llms.txt for LLM crawlers** (only public
content); AI credentials as secrets. No access role beyond permission.

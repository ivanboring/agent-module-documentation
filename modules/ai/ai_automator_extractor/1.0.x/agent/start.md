# AI Automator Extractor — agent index

An **AI Automators plugin for extracting structured data from text** via an AI model. Depends on `ai_automators`.
Version **1.0.0-beta2**. Core `^10.3||^11`.

AI/automation — **sends text to the AI provider** (egress; key in AI/Key); **validate** extracted values before
use. No access role.

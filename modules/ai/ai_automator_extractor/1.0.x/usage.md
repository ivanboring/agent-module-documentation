AI Automator Extractor extracts data from text using AI.

---

AI Automator Extractor provides an **AI Automators plugin for extracting structured data from text** —
running text through an AI model to pull out fields/values (e.g. entities, attributes) as part of an AI
Automators workflow. It depends on the AI Automators module, in the AI Tools package.

Use it to auto-extract data from content with AI. It is an AI/automation feature. Security/data handling: it
**sends text to the configured AI provider** (external egress — confirm acceptable), the provider **API key**
lives in the AI module's Key config (secret), and extracted values should be **validated** before use (don't
trust AI output as safe/structured without checking). It has no access-control role. Configure the extractor in
an Automators chain.

AI NL Test lets you write/run tests described in natural language via AI.

---

AI Natural Language Test provides AI-powered natural-language testing — letting developers/QA describe tests in plain language and have AI generate and/or execute automated tests against the site, lowering the barrier to writing test coverage.

AI operations run through the configured provider (cost); the API key is stored via the Key module (env-backed). Depends on core `system`, `serialization`, `file`, and `key`; supports Drupal 10 and 11.

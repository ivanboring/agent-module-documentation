# AI Eval — agent index

**Evaluation framework for AI agents** (graders, YAML datasets, judges). Version **1.0.0-beta2**. Core `^11.3`.

Runs via AI provider (cost). Perms: `operate`/`administer ai eval`, annotate results, validate judges. Depends on `ai`, core `options`/`file`.

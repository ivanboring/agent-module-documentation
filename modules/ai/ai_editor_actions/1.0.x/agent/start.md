# AI Editor Actions — agent index

Adds ai text actions to ckeditor 5 (rewrite/summarize/translate selected text). Depends on `ai`, `ckeditor5`. Version **1.0.x**. Core `^10.6||^11.3`.

AI/integration — **sends selected text to the AI provider** (egress; key via AI/Key, secret, review output). No access role beyond permission.

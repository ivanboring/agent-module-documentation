# AI README Generator — agent index

Generates readme.md files for drupal modules using ai. Depends on the AI module. Version **1.0.x**. Core `^10||^11`.

AI/integration — **sends module code to the AI provider** (egress; key via AI/Key, secret, review output). No access role.

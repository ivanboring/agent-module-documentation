AI README Generator generates README.md files for Drupal modules using AI.

---

AI README Generator generates README.md files for Drupal modules using AI. It builds on Drupal's AI module, in the Custom package.

Use it for AI-assisted documentation. It is an AI/integration feature. Security/data handling: it **sends
module code to the configured AI provider** (external egress — confirm acceptable for the content), the provider **API key** is stored via the AI module's Key config (secret),
over HTTPS and AI output should be **reviewed** before use/publishing. It has no access-control role. Configure the AI
provider.

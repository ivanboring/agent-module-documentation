AI Checklist provides a Checklist API checklist for tracking the setup and configuration of AI-related modules, oriented toward DXPR CMS.

---

AI Checklist provides a guided checklist (via the Checklist API module) for setting up and
configuring AI-related modules on a Drupal site, oriented toward DXPR CMS. It tracks the steps an
administrator should complete to get AI features configured — providers, keys, settings — and records
progress, so teams have a repeatable onboarding path for the AI stack rather than ad-hoc setup. It
depends on `checklistapi` and exposes the checklist at `checklistapi.checklists.ai_checklist`.

Use it as an administrative aid when standing up AI features, to ensure nothing (like credential
configuration or provider selection) is missed. It is a documentation/tracking tool — it does not
itself change AI configuration or enforce anything; it records which setup steps are done.

# OpenAI VDB Provider — agent index

**OpenAI as a vector-database** provider for AI Search (experimental). Version **1.0.0-alpha3**. Core `^10.4||^11`.

Key via Key+env; sends vectors/text to OpenAI (egress+cost). Depends on `ai`, `ai:ai_search` (^1.2), `key`, `ai_provider_openai`.

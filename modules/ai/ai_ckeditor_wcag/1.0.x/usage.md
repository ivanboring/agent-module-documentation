AI CKEditor WCAG adds an AI-powered WCAG accessibility check to CKEditor 5.

---

AI CKEditor WCAG adds a plugin for CKEditor 5 that lets editors prompt AI to check content for WCAG (accessibility) compliance — so editors can get AI feedback on accessibility issues (headings, link text, alt text, contrast hints) directly while editing, helping produce more accessible content.

AI checks run through the configured AI provider (cost). Depends on core `ckeditor5`, `ai`, and `ai_ckeditor`; supports Drupal 10.3+ and 11.

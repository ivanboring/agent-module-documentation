# AI Translate Plus — agent index

**Extends AI Translate** with per-entity-type/bundle prompts per language and per-field translation disabling.
Depends on `ai`, `ai_translate`. Provides permissions. Version **1.0.0-beta1**. Core `^11`.

AI/multilingual — **sends content to the AI provider** (egress, incl. drafts); AI credentials as secrets. No access
role beyond permission.

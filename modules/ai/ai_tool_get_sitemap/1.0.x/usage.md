AI Tool: Get Sitemap provides an AI Agents tool that fetches the site's sitemap for agent use. It builds on Drupal's AI module and depends on `ai`, `tool`, in the AI Tools package.

Use it for AI-assisted agents. It is an AI/integration feature. Security/data handling: it **sends
site URLs to the configured AI provider** (external egress — confirm acceptable for the content), the provider **API key** is stored via the AI module's Key config (secret),
over HTTPS. It has no access-control role. Configure the AI
provider.

AI Translate Paragraph Asymetric provides simple one-click AI-powered translations for asymmetric paragraphs, using the AI module's translate service.

---

AI Translate Paragraph Asymetric provides one-click AI-powered translation for asymmetric paragraphs —
paragraphs where the translation structure can differ from the source (asymmetric translation). It uses the
AI module's translate service (`ai:ai_translate`) to translate paragraph content with a single action,
easing multilingual editing of paragraph-based content.

Use it to speed up translating paragraph content with AI. The security/privacy-relevant point is that
paragraph content is sent to the configured AI provider for translation — store the provider credentials as
secrets (via the AI/Key modules) and treat content as leaving the site (a data-handling consideration for
sensitive content). It is a multilingual/content feature; access is governed by normal translation
permissions. Configure the AI provider and use the translate action.

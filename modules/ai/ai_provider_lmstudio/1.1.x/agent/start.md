# LM Studio Provider — agent index

AI **provider for LM Studio** (run LLMs **locally** via its OpenAI-compatible local server). Depends on `ai`.
Config at `ai_provider_lmstudio.settings_form`. Version **1.1.0**. Core `^10.2||^11`.

**Data:** local hosting keeps prompts on your infrastructure (advantage for sensitive content); point at a
**trusted local endpoint** and secure the LM Studio server if networked. No access role.

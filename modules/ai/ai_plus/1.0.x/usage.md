AI + integrates an AI chatbot/assistant into the Navigation Plus edit mode.

---

AI + (ai_plus) adds an AI chatbot tool to Edit Mode — integrating the AI Chatbot and AI Agents with the Navigation Plus edit experience and entity_blueprint, so editors can use an AI assistant to help build/edit content and configuration directly in edit mode.

AI operations run through the configured provider (cost) and can create/modify entities via agents; usage is gated by `use ai assistant` — keep it to trusted editors. Depends on `navigation_plus`, `ai_chatbot`, `ai_agents`, and `entity_blueprint`(+`_ai`); requires Drupal 11.

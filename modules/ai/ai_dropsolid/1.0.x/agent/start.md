A dropsolid-specific ai bundle providing preconfigured ai provider settings. Depends on `ai_provider_dropsolidai`. Version **1.0.x**. Core `^10||^11`.

AI/integration — **sends prompts/content to the AI provider** (egress; key via AI/Key, secret). No access role.

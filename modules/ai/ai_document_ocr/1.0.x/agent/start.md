# AI Document OCR — agent index

Provides a google document ai (ocr) provider to extract text from documents. Depends on `ai`, `key`, `ai_automators`. Version **1.0.x**. Core `^10.4||^11.1`.

AI/integration — **sends documents to the AI provider** (egress; key via the Key module, secret). No access role beyond permission.

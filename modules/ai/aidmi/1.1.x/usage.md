AIDmi auto-generates accessible alt text for images via an AI vision model.

---

AIDmi (AI Describe My Image) helps generate 508-compliant descriptions for images using AI — producing accessible alt text from image content via an AI vision provider, so editors can quickly add compliant descriptions for accessibility.

Generation runs through the configured AI provider (cost + images sent to the provider); the API key is stored via the Key module (env-backed). Gated by `generate aidmi accessibility`. Depends on `ai` and `key`; supports Drupal 10 and 11.

# AI Textfield Translation — agent index

**AI-powered translation of text field values** via the Drupal **AI module**. Depends on `ai`. Config at
`ai_translate_textfield.settings_form`; provides permissions. Version **2.0.0-alpha2**. Core `^10||^11`.

**Privacy:** field content is sent to the AI provider (store credentials as secrets via AI/Key; content
leaves the site — data-handling consideration).

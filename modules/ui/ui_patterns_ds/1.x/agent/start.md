# UI Patterns Display Suite (ui_patterns_ds) — agent index

Integrates **UI Patterns** with **Display Suite** — DS layouts/fields render through UI Patterns
components. Depends on `ui_patterns`, `ds`. Theming integration, no security surface (renders
access-controlled field data through theme-layer components). Part of the UI Patterns ecosystem.

(Installed here in a doubled-name dir `ui_patterns_ds-ui_patterns_ds/` — a packaging artifact; machine
name is `ui_patterns_ds`.)

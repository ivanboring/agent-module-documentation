UI Patterns Field Group connects the UI Patterns component system to Field Group, so a group of fields can render through a UI Patterns component instead of a plain wrapper.

---

Field Group organises fields into groups (tabs, fieldsets, accordions) on entity displays and forms; UI Patterns provides reusable components. This integration lets a field group render as a UI Patterns component — group the fields, render the group with a design-system component (a card, an accordion pattern). It is a theming/integration module with no security surface of its own; the grouped fields keep their own access, rendered through a theme-layer component.

It depends on both UI Patterns and Field Group and is only useful when both are present. It is part of the UI Patterns ecosystem of integrations.

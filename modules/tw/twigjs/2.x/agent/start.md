# Twig.js (twigjs) — agent index

Provides the **Twig.js** JS library (client-side Twig rendering) as a Drupal library. Version **2.0.4**.
Library-provider, no functionality of its own. (Consumers: rendering user input *as a template*
client-side is a client-side SSTI surface — a concern for code using it, not this provider.)

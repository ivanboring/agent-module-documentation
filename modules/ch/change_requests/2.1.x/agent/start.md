# Change Requests — agent index

Provides **field-by-field change requests (proposed edits) for nodes** (suggest edits → reviewer approves/
rejects). Provides permissions. Version **2.1.6**. Core `^9.3||^10||^11`.

Editorial-workflow — permissions gate **propose vs approve** (grant so proposers can't self-approve where
review is intended); approved changes follow normal node edit access. No other access role.

# Charts Text Filter — agent index

A **text filter for creating charts inline in content** (render charts from authored markup; CKEditor 5
integration). Depends on `charts`, core `ckeditor5`, `editor`, `filter`. Version **2.0.0**. Core
`^10.5||^11||^12`.

Content-editing/display — restrict to **trusted text formats** (chart authoring); no access role.

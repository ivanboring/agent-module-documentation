Charts Text Filter is a text filter allowing creation of charts through text.

---

Charts Text Filter provides a **text filter that renders charts from inline markup** — editors write
chart definitions in content and the filter turns them into rendered charts (via the Charts module), with
CKEditor 5 integration. It depends on Charts, core CKEditor 5, Editor and Filter.

Use it to let editors embed charts in content. It is a content-editing/display feature. Security note: as a
text filter that turns content markup into charts, restrict it to **trusted text formats** (chart definitions
are authored content; keep the filter on formats only trusted editors can use), and the chart data follows what
the editor supplies. It has no access-control role. Enable the filter on a text format.

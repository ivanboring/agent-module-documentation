# Character Generator — agent index

**Generates a random 10-character alphanumeric string** (a token) for use with Automatic Entity Labels. Depends on
`token`. Version **1.1.0**. Core `^10||^11`.

Content-authoring helper — the string is a **labeling convenience, not a secret** (not guaranteed unique/
unguessable). No access role.

ChatGPT Plugin generates content from OpenAI, giving editors AI content generation from within Drupal.

---

Generating draft content — a summary, a description, body text — from a prompt is a common editorial aid. ChatGPT Plugin calls OpenAI to generate content in Drupal. It needs an OpenAI API key (a credential to keep out of plain config), and prompts/content sent for generation leave your infrastructure to OpenAI — a governance decision for anything confidential. Generated text is a draft an editor accepts, passing through normal content handling. Watch API usage/cost, since generation calls are billed.

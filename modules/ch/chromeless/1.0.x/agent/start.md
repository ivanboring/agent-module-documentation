# Chromeless — agent index

**Adds a `chromeless` query parameter that renders only the main content** (no chrome). Version **1.0.0-alpha1**.
Core `^10.5||^11`.

Display/theming — removes surrounding chrome only (main content still enforces its own access — not an access
bypass); no access role.

Charts AI Agents adds AI agents that assist in configuring charts via the Charts module.

---

Charts AI Agents integrates the AI Agents framework with the Charts module so an AI agent can help build and configure charts within Drupal — turning natural-language intent into chart configuration for the Charts module. It's aimed at speeding up data-visualisation setup.

Because it uses the AI Agents framework, agent actions run through the configured AI provider (cost) and can modify chart configuration; keep agent usage to trusted editors. Depends on `ai_agents` and `charts`; supports Drupal 10.3+ and 11.

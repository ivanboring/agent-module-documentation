Checkbox Radio Buttons Multi Columns spreads options across columns.

---

Checkbox/Radio Multi-Columns lets **checkbox and radio option lists be displayed across multiple columns**
— arranging long lists of options into a multi-column grid for a tidier, more scannable form. It depends on core
Options, in the Fields package.

Use it to lay out long option lists in columns. It is a content-editing/form-UI feature affecting widget
rendering; it has no content or access role. Configure the columns on the options widget.

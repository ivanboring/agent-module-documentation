Checkall Widget provides a widget for options_buttons fields that adds a check-all / select-all control for multiple checkboxes.

---

Checkall Widget provides a field widget for options-buttons (checkbox list) fields that adds a
check-all / select-all control — letting editors toggle all options at once rather than clicking each
checkbox. It is a convenience for multi-value option fields with many choices. It is in the Field types
package.

Use it on checkbox-style option fields (categories, features, permissions-style selections) where
selecting/deselecting all is common. It is a content-editing/form-widget feature affecting input
ergonomics; the stored values are still the field's allowed options and it has no access implications.
Configure it as the widget on the relevant options field.

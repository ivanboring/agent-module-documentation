Changelog Preview provides an admin viewer to preview a project/module CHANGELOG.

---

Changelog Preview **provides an admin viewer to preview a CHANGELOG** — rendering a project's/module's
changelog (release notes) within the admin UI so maintainers can review what changed. It provides its own
permissions.

Use it to view changelogs in-site. It is a developer/administration convenience; the changelog is
maintainer-facing content and it has no content or access role beyond its permission (which should be limited to
trusted admins, since it reads project files). Configure and view the changelog.

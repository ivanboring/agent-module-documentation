Kendo UI Charts adds Kendo UI as a rendering library for the Charts module.

---

Kendo UI Charts **adds Kendo UI as a charting backend for the Charts module** — so charts/graphs defined via
Charts (from Views or fields) can be rendered using the Kendo UI JavaScript charting library. It depends on the
Charts module.

Use it to render Charts with Kendo UI. It is a data-visualization/theming feature. Licensing note: **Kendo UI is a
commercial library** — ensure you have the appropriate license to use it. Charts render on-page data and it has no
content or access role. Configure Charts to use the Kendo UI library.

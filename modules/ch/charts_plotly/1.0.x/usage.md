Charts Plotly provides Charts module integration with Plotly.

---

Charts Plotly provides a **Plotly.js charting provider for the Charts module** — rendering the Charts
module's chart configurations using the Plotly JavaScript library, with an API example submodule. It depends on
the Charts module, in the Charts package.

Use it to render charts with Plotly. It is a content-display/visualization feature; chart data comes from Views/
config (which respect access) and it has no access-control role. Select Plotly as the chart library.

# Change labels — agent index

Lets admins **modify labels shown on entity forms** (field labels/descriptions) via config, without
code. Version **1.4.1**. Core `^11.2`.

Admin/UI feature — changes label display only (not machine names, data, or access). Config-based
(exportable/deployable).

Change labels allows administrators to modify the labels displayed on entity forms without code.

---

Change labels lets administrators rename the labels that appear on entity forms — field labels,
descriptions and similar form text — through configuration rather than code or template overrides. It
is handy for tailoring the editorial UI wording to an organisation's terminology without touching field
definitions everywhere.

Use it to adjust form wording (renaming "Body" to "Article text", clarifying a field's label) for
editors. It is an administration/UI feature affecting how labels display on forms; it does not change
field machine names, data or access. Changes are configuration, so they can be exported/deployed like
other config.

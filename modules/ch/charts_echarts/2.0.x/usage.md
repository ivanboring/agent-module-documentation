Apache ECharts Charts integrates the Charts module with Apache ECharts.

---

Apache ECharts Charts (experimental) provides an Apache ECharts backend for the Charts module — so charts
defined via Charts (from Views, fields, or config) render using the Apache ECharts JavaScript library, an
alternative to other charting backends. It ships a `charts_echarts_api_example` submodule and depends on the
Charts module, in the Charts package.

Use it to render Charts-module charts with ECharts. It is a content-display/visualization feature; the chart
data comes from the source (respecting its access) and it has no access-control role. Select ECharts as the
Charts backend.

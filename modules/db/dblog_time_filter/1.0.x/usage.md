Dblog Time Filter adds quick time range filtering options to the Recent Log messages report.

---

Dblog Time Filter adds **quick time-range filters to the Recent Log Messages report** — so an admin can
narrow the dblog (watchdog) report to "last hour / today / last 7 days", making it easier to find recent events.
It is in the Custom package.

Use it to filter the log report by time. It is an administration/logging UI feature affecting the log report
only; the log report is already admin-gated (`access site reports`) and it has no access-control role. Enable
it to add the time filters.

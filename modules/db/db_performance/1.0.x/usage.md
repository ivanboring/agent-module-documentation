Monitors slow database queries and suggests indexes.

---

DB Performance monitors slow database queries and suggests indexes to improve Drupal performance — logging slow queries, reporting them, and recommending (and optionally creating) indexes that would speed them up, so developers/ops can find and fix DB bottlenecks.

Reports and index management are gated by dedicated permissions (`access db performance reports`, `manage db performance indexes`); restrict them to trusted admins. Supports Drupal 10 and 11.

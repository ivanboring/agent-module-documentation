Drush commands to search for text across the database.

---

Database Text Searcher provides custom Drush commands for database text searches — letting a developer search for a string across database tables/columns from the CLI, useful for finding where content or configuration referencing a value lives. It's a developer/CLI tool. Depends on `embed`; supports Drupal 10 and 11.

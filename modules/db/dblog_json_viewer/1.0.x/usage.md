An enhanced JSON viewer for Drupal dblog messages.

---

Dblog JSON Viewer is an enhanced JSON viewer for Drupal dblog messages with search, fullscreen and more features — rendering JSON-structured log message content in a readable, searchable viewer, easing inspection of structured log data. The settings page is gated by `administer site configuration`. Depends on core `dblog`; supports Drupal 9, 10, and 11.

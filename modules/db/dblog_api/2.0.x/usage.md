An API for adding custom Operations to core's Database Logging (dblog).

---

Database logging API provides an API for adding custom Operations to Core's Database logging module — it replaces the watchdog Views link-field handler so other modules can contribute custom operations (actions) on log entries via a plugin type, extending the dblog admin views. It's a developer/framework module. Depends on core `dblog`; supports Drupal 10.2+, 11, and 12.

DB Health provides database health information like table sizes for administrators.

---

DB Health reports database health information — such as table sizes and related metrics — so
administrators can see which tables are large/growing and diagnose database bloat. It provides Drush commands
and is configured at `db_health.settings`, in the Custom package.

Use it to monitor database size/health. It is an administration/reporting feature that reads database
metadata; the information (table sizes, structure) is operational detail, so keep the report gated to
administrators (it's shown in the admin UI, governed by admin access) and don't expose it publicly. It has
no access-control role. View the DB health report.

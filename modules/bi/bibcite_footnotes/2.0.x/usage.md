Bibcite Footnotes provides inline footnote links for BibCite references.

---

Bibcite Footnotes adds **inline footnote/citation links for BibCite references** — letting authors insert a
reference as an inline footnote in CKEditor content that links to the bibliography entry. It depends on BibCite,
BibCite Entity and core CKEditor 5, in the Bibliography & Citation package.

Use it to add academic-style inline citations. It is a content-editing/bibliography feature; references are
BibCite content and it has no access-control role. Insert footnote citations in the editor.

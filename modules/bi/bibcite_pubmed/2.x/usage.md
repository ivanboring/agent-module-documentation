Bibliography Citation PubMed provides PubMed import and lookup for the Bibliography & Citation (bibcite) module, importing references from PubMed.

---

Academic and medical sites managing bibliographies want to import references from PubMed. Bibcite PubMed adds PubMed import/lookup to the Bibliography & Citation module. It queries PubMed's public API (no credential typically needed for reads) and imports reference metadata. It is a bibliography feature with no unusual security surface; the imported data is public reference metadata. Confirm API usage stays within PubMed's rate limits and that imported data is validated before display.

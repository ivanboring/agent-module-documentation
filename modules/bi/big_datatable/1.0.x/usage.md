Big Data Table provides a Big Data Table configuration entity for large data tables.

---

Big Data Table **provides a Big Data Table config entity** — configuration for rendering large data sets as
performant, feature-rich data tables. It provides its own permissions, in the Big Data Table package.

Use it to display large tabular data. It is a content-display/site-building feature; it configures data-table
display and has no access-control role beyond its permission. Note: ensure the data shown respects the audience's
access (don't surface restricted data in a table). Configure the data table.

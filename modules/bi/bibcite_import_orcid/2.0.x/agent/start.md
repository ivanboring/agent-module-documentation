# Bibcite Import ORCID — agent index

Imports **bibliography/citation data from ORCID** into Bibcite (populate citations from a researcher's ORCID).
Depends on `bibcite`. Provides permissions. Version **2.0.11**. Core `^10.1||^11`.

Integration — calls the **ORCID API** (store any credentials as secrets, HTTPS); imported data is external. No
access role beyond permission.

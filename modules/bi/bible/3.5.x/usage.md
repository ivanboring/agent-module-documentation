Bible imports and lets you read Bible translations.

---

Bible **imports and displays Bible translations** — importing scripture texts and providing reading/
reference views (books, chapters, verses) as browsable content, for church/religious sites. It depends on core
Field, File, Filter, Text, User and Views, provides its own permissions, in the Church package.

Use it to publish and browse Bible content. It is a content/publishing feature; scripture is imported content
following core view access, and it has no access-control role beyond its permission. Import and configure the
Bible content.

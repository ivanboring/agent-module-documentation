Birthday Block displays upcoming users' birthdays in a block.

---

Birthday Block **displays upcoming users' birthdays** — a block showing which users have birthdays coming up
(from a user birthday field), for community/intranet sites. It depends on core User.

Use it to show upcoming birthdays. It is a user-engagement feature. Privacy note: birthdays are **personal data**
— showing users' birthdays (and by extension possibly age) is a privacy consideration, so ensure users consent to
displaying their birthday and restrict the block's audience appropriately. It has no access-control role.
Configure the birthday block.

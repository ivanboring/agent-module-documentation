Bibliocommons displays book lists fetched from the BiblioCommons API.

---

Bibliocommons Book List renders book lists from BiblioCommons — a library discovery platform — so a library website can display curated book lists (staff picks, new arrivals) pulled from its BiblioCommons catalog via the API, presented with UI Patterns.

BiblioCommons API credentials are stored via the Key module (env-backed). Administration is gated by `administer bibliocommons`. Depends on core `key`, `field`, `wsdata`, and `ui_patterns`; supports Drupal 9, 10, and 11.

# Bibcite Crossref — agent index

Provides **DOI lookup via Crossref** for Bibcite (auto-populate citations by DOI). Depends on `bibcite`,
`bibcite_entity`. Version **2.0.0-beta1**. Core `^9||^10||^11`.

Bibliography/integration — outbound requests to the **Crossref API** (DOI sent, metadata imported; HTTPS). No
access role.

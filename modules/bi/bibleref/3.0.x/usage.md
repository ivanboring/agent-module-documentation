Bibleref provides Bible reference handling.

---

Bible Reference (bibleref) provides **Bible-reference handling** — a field/format for scripture citations
(book/chapter/verse) with taxonomy-backed reference data, so content can store and display Bible references
consistently. It depends on core Taxonomy.

Use it to store and display scripture references. It is a fields/content-display feature; reference data is
admin/editor content and it has no content or access role. Add the Bible-reference field to content.

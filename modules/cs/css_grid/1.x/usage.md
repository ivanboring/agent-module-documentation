CSS Grid integrates CSS Grid layouts with Layout Builder, giving grid-based section layouts.

---

CSS Grid is the modern layout primitive; bringing it into Layout Builder lets editors build grid-based sections. CSS Grid provides those layouts for Layout Builder. It is a theming/layout integration with no security surface. Confirm the grid layouts render as intended across breakpoints, since responsive behaviour is where grid configurations most often need tuning.

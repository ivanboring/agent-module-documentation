CSS Size Field provides a field type to store a CSS size value (with unit).

---

CSS Size Field **provides a field type to store CSS size data** — a field for a length/size with a CSS unit
(e.g. `20px`, `1.5rem`), so editors can capture size values for use in templates/styling. It works across core
10–12.

Use it to store CSS size values on entities. It is a content-editing/field feature; the stored value is a
size+unit and it has no access-control role. Note: when a stored size is emitted into CSS/inline styles, output it
as a validated/sanitized value. Configure the CSS size field.

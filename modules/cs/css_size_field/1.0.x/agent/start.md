# CSS Size Field — agent index

Provides a **field type to store a CSS size value** (length + unit, e.g. `20px`). Version **1.0.1**. Core
`^10||^11||^12`.

Content-editing/field — stored value is a size+unit (emit as validated/sanitized when output to CSS); no access
role.

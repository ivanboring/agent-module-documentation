# CSS/JS Aggregate Retention — agent index

**Prevents deletion of recent CSS/JS aggregate files** so cached pages don't 404 on missing CSS/JS after an
aggregate rebuild. Version **1.0.0-alpha3**. Core `^10.2||^11`.

Performance/operations — affects the assets directory; no content/access role.

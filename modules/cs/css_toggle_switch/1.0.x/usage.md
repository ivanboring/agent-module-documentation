CSS Toggle Switch provides accessible, CSS-only toggle switch form elements.

---

CSS Toggle Switch provides an **accessible, CSS-only toggle-switch form element** — a styled on/off switch
(a themed checkbox) that works without JavaScript and is keyboard/screen-reader accessible, with a
`css_toggle_switch_webform` submodule. It is in the Field package.

Use it to render boolean inputs as toggle switches. It is a form/UI feature affecting how a checkbox renders;
it has no content or access role. Use the toggle-switch element/widget on boolean fields.

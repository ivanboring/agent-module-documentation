CSS Usage Analyzer finds unused CSS per page and suggests critical CSS.

---

CSS Usage Analyzer inspects a Drupal site's CSS to detect and report unused styles across themes, with per-page analysis, component maps, and critical-CSS suggestions — helping front-end developers trim CSS payload and improve rendering performance. It's a frontend-optimization/diagnostic tool.

Permissions cover access (`access css usage analyzer`) and administration (`administer css usage analyzer`). Depends on core `system` and `user`; supports Drupal 10.3+ and 11.

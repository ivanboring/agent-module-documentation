# CQRI (Container Query Responsive Image) — agent index

**Extends responsive images to support CSS container queries** (size by container, not viewport). Depends on core
`responsive_image`. Version **1.0.0-alpha2**. Core `^10||^11`.

Media/content-display — images follow core media/image access; no access role.

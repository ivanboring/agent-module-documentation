CQRI extends the capabilities of responsive images.

---

CQRI **extends responsive images to support CSS container queries** — so an image can pick its source based
on its **container's** size rather than the viewport, for component-based responsive design. It depends on core
Responsive Image, in the Media package.

Use it for container-query-based responsive images. It is a media/content-display feature affecting image
rendering; images follow core media/image access and it has no access-control role. Configure the responsive
image with container queries.

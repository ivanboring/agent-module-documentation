# FPDI Print (fpdi_print) — agent index

Prints **Views onto an existing PDF template** (FPDI library). Version **1.1.19**.
**Security:** printed data is subject to the view's field access (a PDF shouldn't contain data the
user can't see); generated PDFs may hold PII — serve with access control.

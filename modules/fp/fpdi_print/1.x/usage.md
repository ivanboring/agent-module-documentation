FPDI Print lets Views print to an existing PDF template using the FPDI library, overlaying view data onto a PDF.

---

Generating filled PDFs — certificates, forms, letters — from a template with data is a common need. FPDI Print lets a View print onto an existing PDF using FPDI. It is a document-generation feature. The consideration is that PDF generation from view data means the data placed on the PDF is subject to the view's field access (a printed PDF should not contain data the user could not see), and the generated PDFs may contain personal data, so handle them accordingly. Confirm the view's access and that generated PDFs are served with appropriate access control.

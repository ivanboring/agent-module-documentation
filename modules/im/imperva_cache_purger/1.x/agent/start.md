# Imperva Cache Purger (imperva_cache_purger) — agent index

**Purge-module purger for the Imperva CDN** — propagates invalidations to the edge. Version **1.0.1**.

**Creds:** needs an Imperva API key (Key entity/env, not plain config) — it can purge (and possibly
reconfigure) your CDN.

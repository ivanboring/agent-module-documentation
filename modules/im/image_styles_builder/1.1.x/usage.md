Image Styles Builder is a toolkit abstraction for programmatically generating sets of image styles, so a module or profile can ship consistent responsive image styles.

---

Defining a coherent set of image styles — a matrix of sizes and crops for responsive images — by hand in the UI is repetitive and hard to keep consistent across a project or distribution. Image Styles Builder provides an abstraction to build image styles programmatically, so a module or install profile can generate a consistent set. It is a developer/site-builder tool with no security surface; its value is consistency and repeatability of image-style configuration.

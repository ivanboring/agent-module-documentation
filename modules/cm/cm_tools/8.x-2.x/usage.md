ComputerMinds tools provides a collection of tools and helpers written by ComputerMinds.

---

ComputerMinds tools (cm_tools) is a collection of developer tools and helpers — utility functions,
services and small conveniences (from the ComputerMinds agency) that other custom code/modules can build on,
easing common Drupal development tasks.

Use it as a developer dependency for the helpers it provides. It is a developer-utility module; its features
are APIs/helpers for code, and it has no content or access role of its own. Use the provided tools in your
code.

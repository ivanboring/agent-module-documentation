CML Migrations provides migrate configurations to import CommerceML (1C) exchange data into Drupal, using Migrate Tools.

---

CML Migrations (cmlmigrations) provides the migration side of CommerceML (1C) exchange — migrate
configurations that import the catalog/product/order data received via CML into Drupal entities, built on
Migrate Tools. It depends on Migrate Tools, is configured at `cmlmigrations.settings`, and provides Drush
commands.

Use it alongside CML API to import 1C:Enterprise data into Drupal commerce content. It is a developer/
migration feature operating through the Migrate framework (Drush-driven); imported data comes from the 1C
exchange (treat as external input) and it has no runtime access role. Configure the migrations and run
them.

# lightGallery (lightgallery) — agent index

Integrates the **lightGallery** JS library with image/media fields — a lightbox gallery formatter.
Version **2.0.3**. Core `^10 || ^11`. Permission `configure lightgallery`.

Set it as the formatter on an image/media field. Note lightGallery's own licensing for commercial
use (the library is GPL/commercial dual-licensed) — check it applies to your use.

# Like and Dislike (like_and_dislike) — agent index

Like/dislike **widgets + statistics** on entities. Version **2.0.2**. Core `^10.1 || ^11`.
Perms: `administer like and dislike` + dynamic per-type permissions.

Enable per entity type; users vote content up/down with tallies shown. Consider flood/permission
control for anonymous voting to limit abuse.

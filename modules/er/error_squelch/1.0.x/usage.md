Suppress status/warning/error messages matching configured patterns.

---

Error Squelch suppresses Drupal status, warning, and error messages whose text matches configured patterns (substring or regex) — for hiding persistent test-mode notices, CI/CD log noise, and chatty third-party warnings. It only hides the messages; it does not fix the underlying cause, so use it judiciously (don't mask real problems). It's an admin/ops tool. Supports Drupal 10.3+ and 11.

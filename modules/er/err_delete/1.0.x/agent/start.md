# ERR Delete — agent index

Provides an **alternative delete button for nodes referenced via Entity Reference Revisions** (cleaner deletion
of ERR/composite content). Depends on core `node`. Provides permissions. Version **1.0.9**. Core `^10||^11`.

Content-management — deletion gated by its permission + normal node delete access; destructive. No broad access
role beyond permission.

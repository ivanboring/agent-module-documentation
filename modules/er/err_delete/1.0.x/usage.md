ERR Delete gives an alternative delete button for nodes with entity reference revisions.

---

ERR Delete provides an **alternative delete button for nodes referenced via Entity Reference Revisions**
(ERR) — handling deletion of content that participates in ERR relationships (e.g. paragraphs/composite content)
more cleanly than the default. It depends on core Node, provides its own permissions.

Use it to delete ERR-referenced nodes safely. It is a content-management feature; deletion is gated by its
permission (and normal node delete access), and it has no broad access-control role beyond that. Note deletion
is destructive — as with any delete, ensure the right content is being removed. Configure and use the delete
button.

Entity Reference Auto automates field input elements based on entity conditions.

---

Entity Reference Auto (er_auto) **automates entity-reference field input** — auto-selecting or
constraining the referenceable options of a reference field based on entity conditions (e.g. auto-fill a
reference from another field's value), reducing manual selection. It is in the Field types package.

Use it to automate reference-field values. It is a content-editing/field feature; the referenced entities still
follow normal entity access, and it has no access-control role. Configure the auto behaviour on the reference
field.

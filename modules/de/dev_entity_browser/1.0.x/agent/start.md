# Developer Entity Browser — agent index

Developer **dashboard to browse content entities/bundles, aggregate field names, review configuration**
(unified entity-model inspection). Provides permissions. Version **1.0.3**. Core `^10||^11`.

Developer/inspection tool — **exposes site structure/config** (sensitive) → restrict to trusted developers,
don't expose to untrusted users on production. No content-access role beyond permission.

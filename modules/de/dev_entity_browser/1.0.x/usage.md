Developer Entity Browser provides a unified developer dashboard to browse content entities, bundles, aggregate field names and review configuration settings.

---

Developer Entity Browser provides a unified dashboard for developers to inspect the site's entity model
— browsing content entities and bundles, aggregating field names, and reviewing configuration settings from
a single interface, improving developer efficiency when working with a site's data model. It provides its
own permissions and is in the Development package.

Use it to explore a site's entities/fields/config during development. It is a developer/inspection tool. The
security-relevant point is that it exposes the site's structure and configuration (which is sensitive
operational detail), so restrict it to trusted developers/administrators and don't expose it on production
to untrusted users. It has no content-access role beyond its permission. Use the dashboard to inspect the
entity model.

# Decoupled Kit (decoupled_kit) — agent index

Tools for **decoupled (headless) Drupal** tasks. Version **2.0.7**. Submodules `decoupled_kit_block`,
`decoupled_kit_redirect`.

**Security (headless):** content exposed to the front end (JSON:API/REST) must apply access;
cross-boundary redirects must not become open redirects. Confirm both.

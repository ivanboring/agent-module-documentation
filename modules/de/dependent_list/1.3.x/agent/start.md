# Dependent List — agent index

Defines **conditional list fields where field B's options depend on field A's value** (cascading selects —
country→city). Depends on core `options`, `field_ui`. Version **1.3.1**. Core `^10||^11`.

Content-editing/fields — shapes which options are offered (form UX/value), not access. No access role.

Dependent List lets you define conditional list fields where the options in field B depend on the value selected in field A.

---

Dependent List lets you define conditional (cascading) list fields — where the available options in one
field (B) depend on the value selected in another field (A), so choosing a country in A narrows the cities
in B, for example. It depends on core Options and Field UI, in the Fields package.

Use it for cascading/dependent select fields. It is a content-editing/fields feature affecting which options
are offered based on a prior selection; it shapes the form UX and stored value, not access, and has no
access-control role. Configure the dependency mapping between the fields.

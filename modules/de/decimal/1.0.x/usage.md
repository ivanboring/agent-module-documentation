Decimal provides decimal number fields.

---

Decimal provides a **decimal-number field type** — for storing exact decimal values (fixed precision/scale)
where core's number fields don't fit, e.g. financial amounts. It depends on core Field, in the Field types
package.

Use it to store precise decimal values. It is a fields/content feature; values follow normal field handling and
it has no content or access role. Add the decimal field to an entity.

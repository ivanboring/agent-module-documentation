# Devel Generate Commerce — agent index

Generates **dummy Commerce products, variations, stores and orders** for dev/testing. Depends on `commerce`,
`devel_generate`. Provides permissions. Version **1.2.0**. Core `^10||^11`.

**Development-only** — mass-creates content; **never run on production** (floods a live store); gate
permissions to developers on non-prod. No access role beyond permission.

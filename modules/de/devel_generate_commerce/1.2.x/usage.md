Devel Generate Commerce generates dummy commerce products, product types, variations and orders.

---

Devel Generate Commerce extends **Devel Generate** to create **dummy Drupal Commerce data** — products,
product types, variations, stores and orders — so developers can populate a store with realistic test data.
It depends on Commerce and Devel Generate, provides its own permissions, in the Development package.

Use it to seed a Commerce site for development/testing. **This is a development-only tool** — it mass-creates
content, so **never enable or run it on production** (it can flood a live store with fake products/orders);
gate its permissions to developers on non-production environments. It has no access-control role beyond its
permission. Run the generator on a dev site.

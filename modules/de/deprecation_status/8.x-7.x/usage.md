Shows data about the deprecation status of drupal.org projects.

---

Deprecation Status shows data about the deprecation status of drupal.org projects — surfacing, for a set of projects, whether they use deprecated Drupal APIs and their readiness for newer core versions, helping teams plan upgrades. Depends on core `file`; supports Drupal 9.3+, 10, and 11.

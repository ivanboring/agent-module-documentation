Details Field provides a field type for creating and displaying HTML details/summary elements.

---

Details Field **provides a field type for details/summary elements** — letting editors create collapsible
`<details>`/`<summary>` (accordion-style) content as a field and display it. It depends on core Field and Text.

Use it to add collapsible details content. It is a content-editing/display feature; the stored value is text
displayed in a details element and it has no access-control role. Note: as with any rich text, ensure the field's
text format sanitizes editor input. Configure the details field.

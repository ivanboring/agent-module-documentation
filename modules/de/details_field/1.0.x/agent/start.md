# Details Field — agent index

Provides a **field type for creating/displaying `<details>`/`<summary>` elements** (collapsible content). Depends
on core `field`, `text`. Version **1.0.0-beta1**. Core `^10||^11`.

Content-editing/display — stored value is text shown in a details element (sanitize via the text format); no access
role.

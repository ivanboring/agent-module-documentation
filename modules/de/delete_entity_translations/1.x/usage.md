Delete Entity Translations lets administrators delete entities together with their translations, for selected entity types, in bulk.

---

Removing multilingual content cleanly — an entity and all its translations — is fiddly through the standard UI. Delete Entity Translations provides a way to delete entities and their translations for selected entity types. Because it deletes content in bulk, it is a maintenance operation warranting the usual care: it is admin-gated, but bulk deletion is irreversible, so confirm the selection and keep a backup before running it against production.

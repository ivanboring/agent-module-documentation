An on-site developer console with history, timing, and Kint integration.

---

Developer console provides a developer console with history and exec-time tracking, Kint integration and more — an in-browser console for running PHP/dev commands against the site with output rendered via Kint, useful for debugging. Because it can execute code, it must be restricted to trusted developers and never enabled in production. Supports Drupal 9, 10, and 11.

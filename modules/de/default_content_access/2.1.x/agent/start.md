# Default Content Access — agent index

An **add-on for Default Content that exports/imports Content Access module settings** alongside content. Depends
on `default_content`, `content_access`. Version **2.1.0**. Core `^10||^11`.

Developer/devops helper — serializes Content Access settings (doesn't decide access itself; review exported
settings before shipping). No runtime access role of its own.

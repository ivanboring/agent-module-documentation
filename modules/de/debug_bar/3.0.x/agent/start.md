# Debug Bar — agent index

A **floating toolbar showing debug information**. Viewing gated by `view debug bar`, config by `administer
debug bar`. Version **3.0.0-rc2**. Core `^10||^11`.

Developer/debug — can expose **runtime/internal info**; grant `view debug bar` only to **trusted/dev roles**,
avoid broad exposure on production. No access role beyond permissions.

Suppress or delete default content from the Default Content API.

---

Default Content Tools lets you suppress Default Content import or delete the default content from the Default Content API — giving control over the content shipped/imported by modules using Default Content, so a site can skip importing it or remove it after install. It's a developer/site-building helper. Supports Drupal 10 and 11.

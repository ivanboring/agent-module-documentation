# Default Value — agent index

Provides a **default value for fields on existing entities at load time** (fallback for fields added to
existing content / empty fields — applied on load, not persisted). Config at `default_value.config`;
provides permissions. Version **1.0.5**. Core `^10||^11`.

Content/fields — affects the loaded value (runtime default), not access.

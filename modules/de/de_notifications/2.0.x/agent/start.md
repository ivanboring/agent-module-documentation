# Decoupled Entity Notifications — agent index

Lets **users subscribe to entity changes and delivers notifications** (for decoupled front-ends). Depends on core
`dynamic_entity_reference`. Provides permissions. Version **2.0.0**. Core `^10||^11`.

Decoupled/notifications — subscriptions tie **users to entities** (personal data); ensure notifications **respect
entity access** (don't reveal inaccessible content). No access role beyond permission.

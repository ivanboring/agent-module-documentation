Declarative Form Ajax allows form elements to declare AJAX update dependencies.

---

Declarative Form Ajax lets **Form API elements declare AJAX update dependencies** on other elements —
declaratively (in the form array) rather than wiring `#ajax` callbacks by hand — so a field can automatically
refresh when another field it depends on changes. It ships a demo submodule, is a developer/Form API feature.

Use it to build dependent-field AJAX behaviour with less boilerplate. It is a developer/API module; the AJAX
callbacks it wires run with the current user's privileges and should build/escape output normally, and it has
no content or access role. Use its declarative API in your forms.

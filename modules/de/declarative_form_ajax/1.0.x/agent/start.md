# Declarative Form Ajax — agent index

Lets **Form API elements declare AJAX update dependencies** on other elements declaratively (vs hand-wired
`#ajax`). Demo submodule. Version **1.0.0**. Core `^10||^11`.

Developer/Form API — callbacks run with the current user's privileges (escape output normally); no content/
access role.

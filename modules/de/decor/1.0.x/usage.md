Decor marks decorative images with empty alt text for accessibility.

---

Decor helps accessibility by assigning empty `alt` attributes to images that are purely decorative, so screen readers and other assistive technologies correctly skip them (per WCAG guidance that decorative images should have empty alt text rather than be described).

It's an accessibility helper with no content or access role. Supports Drupal 10, 11, and 12.

A debug bar showing information about the current request.

---

Debug Bar adds a debug bar that displays useful information about the current request — timings, queries, memory, routing and more, rendered as an on-page bar for developers, integrating PHP DebugBar. It's a development tool (not for production). Depends on `vendor_stream_wrapper`; supports Drupal 9 through 12.

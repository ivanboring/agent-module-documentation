# Decoupled Toolbox — agent index

**Common features/utilities for decoupled (headless) Drupal** (color/duration fields, comment/group/redirect/
weight, decoupled router, OpenAPI) via JSON:API; optional submodules. Provides permissions. Version
**1.6.0-rc0**. Core `>=10.1`.

Decoupled/integration — **exposes content over the API** (JSON:API/REST enforce entity+field access): restrict
fields/resources to public, gate write endpoints. No access role of its own beyond permissions.

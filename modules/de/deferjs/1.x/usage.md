Defer JS helps lazy-load JavaScript files, deferring their loading to improve initial page performance.

---

Blocking JavaScript delays page rendering. Defer JS lazy-loads JS files, deferring non-critical scripts so the page renders sooner. It is a front-end performance module with no security surface. Confirm deferred scripts still function (some scripts depend on load order or DOM-ready timing), and test interactive features after enabling.

AhaSend routes Drupal email through the AhaSend email-delivery service.

---

AhaSend allows sending email through the AhaSend delivery platform — providing a Mail System plugin so Drupal's outbound mail is delivered via AhaSend's API/SMTP for better deliverability and tracking.

AhaSend API credentials should be stored securely (env-backed); administration is gated by `administer ahasend`. Depends on `mailsystem`; supports Drupal 10 and 11.

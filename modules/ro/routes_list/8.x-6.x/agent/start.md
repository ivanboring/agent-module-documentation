# Routes List (routes_list) — agent index

Admin **report listing all registered routes** at `/admin/reports/routes-list`. Version **8.x-6.3**.
Permission **`access routes list`**.

A full route inventory is a **site-surface map** — useful to developers and attackers alike. Grant
the permission to **trusted developers/admins only**, not broadly.

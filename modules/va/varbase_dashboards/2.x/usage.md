Varbase Dashboards provides admin dashboards built on the Dashboard module, part of the Varbase distribution.

---

An admin landing dashboard — recent content, tasks, stats — orients editors and administrators. Varbase Dashboards provides such dashboards built on the core/contrib Dashboard module, as part of the Varbase distribution. It is admin-facing UI; the dashboards surface site data, so they are appropriately restricted to staff. On a non-Varbase site it carries Varbase assumptions but can provide the dashboards subject to that.

Varbase Media Header populates a universal media-header style at the top of pages, part of the Varbase distribution.

---

A media header — a hero image/video banner at the top of a page — is a common design element. Varbase Media Header provides a universal media-header style for the Varbase distribution. It is distribution/theming configuration with no security surface. On a Varbase site it supplies the header style; elsewhere it carries Varbase assumptions.

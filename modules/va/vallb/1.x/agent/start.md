# Views Ajax Lazy Load Block (vallb) — agent index

Builds a **view block lazily via Intersection Observer** (loads on scroll-into-view). Version **1.0.2**.
Performance feature. **Security:** the lazy-loaded view must honour the **same access** as inline
rendering — confirm access on the lazy-load path.

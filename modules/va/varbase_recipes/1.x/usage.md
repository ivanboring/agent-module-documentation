Varbase Recipes provides general custom config-action plugins for managing configuration via Drupal Recipes, part of the Varbase distribution.

---

Drupal Recipes apply packaged configuration; Varbase Recipes provides custom config-action plugins that recipes use to manage configuration, for the Varbase distribution. It is developer/distribution infrastructure. Because config actions modify configuration (which can include access rules and permissions), applying recipes is a configuration-changing operation — run recipes deliberately and review what a recipe's config actions change, especially anything touching permissions or access. It provides the action plugins; the recipes that use them define the changes.

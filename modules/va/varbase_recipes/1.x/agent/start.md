# Varbase Recipes (varbase_recipes) — agent index

Custom **config-action plugins for Drupal Recipes** (Varbase distribution). Version **1.0.0-beta3**.

Config actions modify configuration (incl. access/permissions) — run recipes **deliberately** and
review what a recipe's actions change, especially permission-affecting ones.

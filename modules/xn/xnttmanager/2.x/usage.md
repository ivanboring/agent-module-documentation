External Entities Manager (xnttmanager) provides an administrator interface for managing External Entities — inspecting and operating on external-entity types and data.

---

External Entities exposes remote data as Drupal entities; managing those types and inspecting their data benefits from a dedicated UI. External Entities Manager provides an administrator interface for that. It is an admin tool for the External Entities ecosystem. Because it operates on external-entity configuration and data (which may involve remote-source credentials and connections), it is admin-gated; confirm the interface is restricted to trusted administrators, since managing external-entity connections can involve the credentials and endpoints those connections use.

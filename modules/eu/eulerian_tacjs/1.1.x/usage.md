Eulerian TacJS adds the Eulerian analytics service to the TacJS consent-managed tag loader.

---

Eulerian TacJS **adds Eulerian to TacJS** — registering the Eulerian analytics/marketing service with the
TacJS consent-managed tag loader, so the Eulerian tag loads according to consent. It depends on the Eulerian and
TacJS modules.

Use it to load Eulerian analytics with consent. It is an analytics/privacy-integration feature. Security/data
handling: it loads the **third-party Eulerian tracking tag** (egress; runs in visitors' browsers, processes
analytics data — disclose and gate behind consent via TacJS). It has no access-control role. Configure the Eulerian
integration.

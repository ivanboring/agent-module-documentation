Eudonet provides an API client for the Eudonet CRM.

---

Eudonet **provides a Eudonet CRM API client** — a client/service layer for talking to the Eudonet CRM API,
used to read/write CRM records from Drupal. It works on core 10.1–11.

Use it as the Eudonet integration foundation. It is a CRM/integration base. Security/data handling: it **calls the
Eudonet API** (egress) with **credentials** (store as secrets — env/Key — over HTTPS) and moves **contact/CRM data
(PII)** — disclose per your privacy policy. It has no access-control role. Configure the Eudonet credentials.

A12S MaPS Sync handles MaPS System integration with Drupal.

---

A12S MaPS System Sync **integrates the MaPS System (DAM/PIM) with Drupal** — synchronizing digital assets
and/or product data from a MaPS System instance into Drupal (media/content), with multilingual support. It
depends on core Content Translation, provides its own permissions, in the A12S package.

Use it to sync MaPS System content into Drupal. It is an integration feature. Security/data handling: it connects
to the **MaPS System API** with **credentials** (store as secrets — env/Key — over HTTPS) and imports external
data (translations follow core content-translation access). It has no access-control role beyond its permission.
Configure the MaPS connection.

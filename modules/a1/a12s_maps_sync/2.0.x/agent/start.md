# A12S MaPS System Sync — agent index

**Integrates the MaPS System (DAM/PIM) to sync assets/product data into Drupal** (multilingual). Depends on core
`content_translation`. Provides permissions. Version **2.0.23**. Core `^9||^10||^11`.

Integration — MaPS **credentials** as secrets (env/Key, HTTPS); imports external data (translations follow
content-translation access). No access role beyond permission.

Accessible Autocomplete Element/Widget provides an accessible autocomplete element and field widget as a replacement for select elements.

---

Accessible Autocomplete Element/Widget provides an accessible autocomplete — a Form API element and
field widget that replaces standard select elements with a keyboard- and screen-reader-friendly
autocomplete (users type to filter options). It depends on core Options and is aimed at improving both
accessibility and usability of long option lists.

Use it where select dropdowns are long or need better accessibility/typeahead. It is a form/accessibility
widget affecting input; the stored values are still the field's allowed options, and it has no
access-control role. Use it as the element in custom forms or as the widget on options fields.

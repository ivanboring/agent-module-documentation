EBT Video and Image Gallery provides an Extra Block Types gallery block for videos and images, with lightbox support (GLightbox/PhotoSwipe).

---

EBT Video and Image Gallery is part of the Extra Block Types (EBT) family — configurable styled block
types. This one provides a video-and-image gallery block: a grid of media (images and videos) that opens
in a lightbox for full-size viewing, using GLightbox (with media-video support). It depends on EBT core,
core Media, GLightbox, GLightbox Media Video and Paragraphs.

Use it to build media galleries (portfolios, product galleries, event photos with videos) as a
configurable block. It is a content-display/media block; media and their access are unchanged — it
controls presentation (grid + lightbox). Configure the gallery items and placement.

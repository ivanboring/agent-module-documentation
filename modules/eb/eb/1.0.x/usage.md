Spreadsheet-driven entity architecture management using YAML.

---

Entity Builder (eb) provides spreadsheet-driven entity architecture management for Drupal — design, preview, and deploy entity architectures (bundles, fields) using YAML, so site builders can plan and generate content models from a structured definition rather than clicking through the UI. Depends on core `field`, `field_ui`, and `user`; supports Drupal 11.

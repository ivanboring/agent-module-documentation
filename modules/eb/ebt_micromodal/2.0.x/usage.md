EBT Micromodal provides an Extra Block Types block type that displays a button which opens content in a Micromodal accessible popup.

---

EBT Micromodal is part of the Extra Block Types (EBT) family — styled, configurable block types with
their own settings and Layout Builder/block placement. This one provides a "button with popup" block:
it renders a button that, when clicked, opens content in a Micromodal (a small, accessible modal
library) popup. Editors configure the button label and the modal content through the block's settings.

Use it to add call-to-action buttons that reveal more information, forms, or media in an accessible
modal without custom JavaScript. It depends on the EBT core module (`ebt_core`) which provides the
shared EBT infrastructure and styling options. It is a content-display/site-building block type with
no access-control role; the modal content is authored, so apply the usual text-format/escaping care to
what is placed inside.

# EBT Micromodal — agent index

**Extra Block Types (EBT)** block: a **button that opens content in a Micromodal** (accessible modal)
popup. Configure button label + modal content in block settings. Depends on `ebt_core`. Version
**2.0.0**. Core `^10.1||^11||^12`.

Content-display/site-building block (no access control). Modal content is authored — apply text-format/
escaping care.

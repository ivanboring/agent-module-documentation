# EBT Columns / Container — agent index

**Extra Block Types (EBT)** columns/container block for **multi-column layouts** with nested blocks (via
Block Field). Depends on `ebt_core`, `block_field`. Version **2.0.0**. Core `^10.1||^11||^12`.

Content-display/site-building block — nested blocks keep their own access; no access role of its own.

EBT Columns / Container provides an Extra Block Types columns/container block for building multi-column layouts, supporting nested blocks via block_field.

---

EBT Columns / Container is part of the Extra Block Types (EBT) family — configurable styled block types.
This one provides a columns/container block for building multi-column layouts, into which other blocks can
be nested (via Block Field), so editors can compose grid/column arrangements of block content. It depends on
EBT core and Block Field.

Use it to build multi-column/container layouts from blocks. It is a content-display/site-building block; it
governs layout/presentation of nested block content, and the nested blocks keep their own access. No
access-control role of its own. Configure the columns and nested blocks.

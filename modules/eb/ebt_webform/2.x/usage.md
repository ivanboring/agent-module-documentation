EBT Webform adds a Webform block type to the Enhanced Block Types (EBT) family, letting a webform be placed as a styled block.

---

Placing a webform where a block goes — in a layout, a sidebar — with the styling options the Enhanced Block Types family provides. EBT Webform adds a Webform block type. It is a content/layout convenience; the webform it embeds is the real form, with its own access and handlers, so the security of the embedded form is the webform's. Confirm the placed form's access and any handlers behave as expected in the block context.

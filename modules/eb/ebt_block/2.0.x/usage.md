EBT Block provides an Extra Block Types block that can embed/wrap another block with EBT styling options.

---

EBT Block is part of the Extra Block Types (EBT) family — configurable styled block types. This one
provides a block that can embed/wrap another block (via Block Field) with EBT's styling options, so an
existing block can be placed with the extra styling/configuration EBT offers. It depends on EBT core and
Block Field.

Use it to give an existing block EBT styling or to compose blocks. It is a content-display/site-building
block; the embedded block keeps its own access. No access-control role of its own. Configure the embedded
block and styling.

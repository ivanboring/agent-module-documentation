# EBT Block — agent index

**Extra Block Types (EBT)** block that **embeds/wraps another block** (via Block Field) with EBT styling.
Depends on `ebt_core`, `block_field`. Version **2.0.0**. Core `^10.1||^11||^12`.

Content-display/site-building — embedded block keeps its own access; no access role of its own.

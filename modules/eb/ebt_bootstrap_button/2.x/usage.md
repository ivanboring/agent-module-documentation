EBT Bootstrap Button adds a Bootstrap Button block type to the Enhanced Block Types (EBT) family.

---

A styled call-to-action button placed as a block. EBT Bootstrap Button adds a Bootstrap-styled button block type in the Enhanced Block Types (EBT) family. It assumes Bootstrap (the emitted classes are Bootstrap's — on a non-Bootstrap theme the button is unstyled until the classes have meaning). Display block, no security surface.

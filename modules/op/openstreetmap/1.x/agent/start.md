# OpenStreetMap (openstreetmap) — agent index

Tools to **sync Drupal nodes with OpenStreetMap** data. Version **1.0.4**. Submodules
`openstreetmap_queries`, `openstreetmap_views`. Uses OSM public APIs (respect usage policies);
validate synced external data before it becomes content.

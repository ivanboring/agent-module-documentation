# OpenIntranet Documents (openintranet_documents) — agent index

**Hierarchical document management with folders** (OpenIntranet distribution). Version
**1.0.0-alpha6**.

**Security is the access model:** documents can be confidential — control view/add/manage, use
**private:// storage served through access checks** (not directly fetchable by URL), and verify no
direct-URL bypass of folder access. (Same class as `foldershare`.)

AmplitudeJS integrates the AmplitudeJS audio library.

---

AmplitudeJS integrates the **AmplitudeJS** HTML5 audio library into Drupal — for building custom audio
players/playlists — with an `amplitudejs_formatters` submodule that provides field formatters to render audio
file fields as AmplitudeJS players. It is in the Media package.

Use it to add AmplitudeJS audio players. It is a media/content-display feature; audio files follow core
media/file access and it has no content or access role. Use the AmplitudeJS formatter on an audio field.

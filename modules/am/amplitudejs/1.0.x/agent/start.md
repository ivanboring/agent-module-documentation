# AmplitudeJS — agent index

Integrates the **AmplitudeJS HTML5 audio library** (custom audio players/playlists) with an
`amplitudejs_formatters` submodule (audio field formatters). Version **1.0.4**. Core `^9.3||^10||^11`.

Media/content-display — audio follows core media/file access; no content/access role.

Atom provides an Atom feed style plugin for Views, so a View can output an Atom feed.

---

Atom provides an Atom-feed display style for Views — letting a View output an Atom syndication feed
(an alternative to the RSS feed style core provides). It depends on core Views. This lets sites publish
Atom feeds of content (articles, updates) driven by a View.

Use it to offer Atom feeds of listings. It is a syndication/display feature; the feed content comes from
the View and respects the View's access (only accessible content appears). Select the Atom style as the
View's feed format and configure the fields/mapping.

ATD (Assisted Translation) assists with translation workflows using the locale system.

---

ATD **assists with translation workflows** — providing tooling to help translate interface/content strings,
built on core's Locale system. It depends on core Locale, in the Multilingual package (core 11.1+).

Use it as a translation helper. It is a multilingual/developer feature; strings follow core locale handling and
it has no content or access role. Use it to assist translations.
